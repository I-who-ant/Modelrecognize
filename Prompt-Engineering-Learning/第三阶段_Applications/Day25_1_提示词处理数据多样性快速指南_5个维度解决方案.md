## 🤔 真实问题

```
你生成了10000条数据,但发现:
❌ 问题都很像 (大量"xxx是什么?"的重复)
❌ 答案长度都150-200字 (太规整)
❌ 都是正式学术风格 (缺少口语化)
❌ 只覆盖几个场景 (其他场景没有)
❌ 多样性分数才0.35 (超差!)

问题根源: 提示词没有明确要求多样性!
```

---

## 📚 数据多样性的5个维度

```
维度1: 表达多样性 (Expression Diversity)
  ├─ 问题: 1万条数据,其实只有3千个不同的问题
  ├─ 症状: "为什么Python? Python为什么? Python的优点?"都是重复
  └─ 目标: 同一概念≥70%表述不同

维度2: 场景多样性 (Scenario Diversity)
  ├─ 问题: 初级问题特别多,高级/应用问题很少
  ├─ 症状: 某些场景被过度表示,某些场景缺失
  └─ 目标: 各场景均匀分布(Entropy > 0.8)

维度3: 长度多样性 (Length Diversity)
  ├─ 问题: 所有答案都是150-200字,太规整
  ├─ 症状: 答案长度标准差<50(很小)
  └─ 目标: 自然的长度分布(短:30%, 中:50%, 长:20%)

维度4: 风格多样性 (Style Diversity)
  ├─ 问题: 全部是学术风格,缺少口语化
  ├─ 症状: 缺少"我", "咱们", "其实"这样的口语词
  └─ 目标: 正式30% + 口语化50% + 对话20%

维度5: 属性多样性 (Attribute Diversity)
  ├─ 问题: 难度不平衡(初级太多)
  ├─ 症状: 难度分布严重不均
  └─ 目标: 初级:中级:高级 = 3:4:3
```

## 💡 用提示词解决多样性的3个核心技巧

### 技巧1: 显式要求多样性

**问题**: 不告诉LLM要多样,它就不会主动多样化

**解决**: 在提示词中明确列出多样性要求

```python
# ❌ 差的提示词
生成10条Python问答对。

# ✅ 好的提示词
生成10条Python问答对

    要求:
    1. 表达多样性: 问题不能重复
       - "Python是什么?"
       - "Python的定义"
       - "如何理解Python?"
       - "Python有什么特点?"
    
    2. 长度多样性: 答案长度差异大
       - 30%短答案(50-100字)
       - 50%中等答案(150-250字)
       - 20%长答案(300+字)
    
    3. 风格多样性: 混合正式和口语
       - 学术风格: "在计算机科学中..."
       - 口语风格: "简单来说..."
       - 对话风格: "你可能想知道..."
    
    4. 场景多样性: 覆盖不同用户
       - 初学者: 解释基础概念
       - 中级开发: 讨论最佳实践
       - 高级用户: 性能优化技巧
```

### 技巧2: 用角色扮演增加多样性

**原理**: 不同角色自然会产生不同的表达和风格

```python
# 提示词模板
你是一个问答生成器。从4个不同角色生成问答:

主题: {topic}

角色1-初学者导师:
  └─ 用最简单的词汇解释
  └─ 强调"为什么"而不是"怎么做"
  └─ 生成3个初学者会问的问题

角色2-专业人士:
  └─ 使用行业术语
  └─ 讨论细节和原理
  └─ 生成3个技术细节问题

角色3-学生:
  └─ 问题多角度
  └─ 包括比较性问题
  └─ 生成3个对比或分析问题

角色4-教师:
  └─ 从教学角度思考
  └─ 指出常见误解
  └─ 生成3个关键概念问题

# 实际效果
这样一个topic就能生成12条问题,而且风格/难度完全不同!
```

### 技巧3: 变体生成(改写/改述)

**原理**: 对同一内容进行5种不同的改写,产生多样性

```python
# 提示词模板
原问题: {question}
原答案: {answer}

请生成该问题的5个改写版本:

改写方向1-简化版:
  Q: (用更简单的词汇提问)
  A: (对应的简化答案)

改写方向2-学术版:
  Q: (更学术/专业的提问)
  A: (对应的学术答案)

改写方向3-口语版:
  Q: (更自然/日常的提问)
  A: (对应的口语答案)

改写方向4-对比版:
  Q: (与相关概念对比的问题)
  A: (对比分析答案)

改写方向5-应用版:
  Q: (实际应用场景问题)
  A: (应用指导答案)

# 成本
1条 → 5条 (数据量×5)
但每条都是不同的多样性!
```

## 🚀 4种多样性提升方法的对比

### 方法1: 改写(Paraphrase) ⭐推荐

```
原数据 → 改写成多个表述 → 返回多条数据

优点:
  ✓ 快速(每条数据生成2-3个变体)
  ✓ 准确性有保证(改写基于原数据)
  ✓ 成本低(只需改述)

缺点:
  ✗ 可能还是不够多样(本质还是改写)

提示词:
  "请用不同的表述方式改写以下问题,保留原意"

代码:
  for item in dataset:
      for variant in generate_paraphrases(item, num=2):
          new_dataset.append(variant)
```

### 方法2: 场景扩展(Scenario Expansion)

```
一个答案 → 3个版本(初学者/中级/高级) → 增加多样性

优点:
  ✓ 提升场景覆盖率
  ✓ 难度差异明显
  ✓ 实用性高

缺点:
  ✗ 需要生成3个版本(成本×3)

提示词:
  "请用初学者/专业人士/高级开发者的3种方式解释"

目标分布:
  初级(30%) + 中级(50%) + 高级(20%)
```

### 方法3: 长度均衡(Length Balance)

```
检测长度分布 → 采样调整 → 平衡分布

步骤:
  1. 统计当前数据的长度分布
  2. 确定目标分布(短30%, 中50%, 长20%)
  3. 对长度进行重采样,达到目标分布

优点:
  ✓ 让答案长度自然
  ✓ 避免"全都150-200字"的尴尬

缺点:
  ✗ 需要已有的数据(不能凭空生成)

代码示意:
  short_items = [d for d in data if len(d) < 100]
  medium_items = [d for d in data if 100 <= len(d) < 250]
  long_items = [d for d in data if len(d) >= 250]

  balanced = (
      random.sample(short, int(total*0.30)) +
      random.sample(medium, int(total*0.50)) +
      random.sample(long, int(total*0.20))
  )
```

### 方法4: 风格混合(Style Mixing)

```
原文本 → 生成口语化版本 → 混合风格

优点:
  ✓ 让数据更接近真实用户
  ✓ 模型学到多种表达方式

缺点:
  ✗ 需要LLM调用(成本高)

提示词:
  "请将以下学术文本改写成日常口语版本,
   保留所有信息但用更自然的表达"

目标比例:
  正式(30%) + 口语(50%) + 对话(20%)
```

## 📊 多样性问题诊断和改进方案

### 如何诊断你的数据?

```python
# 第1步: 计算重复度
unique_items = len(set(texts))
total_items = len(texts)
repetition_score = unique_items / total_items

if repetition_score < 0.7:
    问题 = "表达多样性差,很多重复"
    解决 = "使用改写和变体生成"

# 第2步: 检查长度分布
import numpy as np
lengths = [len(text.split()) for text in texts]
std_dev = np.std(lengths)

if std_dev < 50:
    问题 = "长度太规整,缺少自然变化"
    解决 = "对长度进行重新采样平衡"

# 第3步: 检查风格
formal_ratio = count_formal_words(texts) / len(texts)

if formal_ratio > 0.8:
    问题 = "全是学术风格,缺少口语化"
    解决 = "生成口语版本混合"

# 第4步: 检查场景覆盖
scenarios = [item['scenario'] for item in data]
scenario_dist = Counter(scenarios)
entropy = calculate_entropy(scenario_dist)

if entropy < 0.6:
    问题 = "某些场景过度表示"
    解决 = "使用场景扩展,均衡分布"
```

## 💻 完整代码示例

```python
# 快速开始: 一个函数解决多样性

def enhance_dataset_with_prompts(dataset, target_methods=None):
    """
    使用提示词快速提升数据多样性

    参数:
        dataset: 原始数据集
        target_methods: 要应用哪些方法 ['paraphrase', 'scenarios', 'styles']

    返回:
        增强后的数据集 (数据量通常3-5倍)
    """

    if target_methods is None:
        target_methods = ['paraphrase', 'scenarios', 'styles']

    enhanced = list(dataset)  # 保留原数据

    # 方法1: 改写
    if 'paraphrase' in target_methods:
        for item in dataset:
            prompt = f"""
原问题: {item['question']}

生成2个表述不同的改写版本:
"""
            variants = llm_call(prompt).split('\n\n')
            for variant in variants:
                enhanced.append({
                    **item,
                    'question': variant,
                    'is_variant': True
                })

    # 方法2: 场景扩展
    if 'scenarios' in target_methods:
        for item in dataset:
            prompt = f"""
原答案: {item['answer']}

用3种方式改写(初学者/中级/高级):
"""
            scenarios = llm_call(prompt).split('\n---\n')
            for i, scenario in enumerate(scenarios):
                enhanced.append({
                    **item,
                    'answer': scenario,
                    'difficulty': ['beginner', 'intermediate', 'advanced'][i]
                })

    # 方法3: 风格混合
    if 'styles' in target_methods:
        for item in dataset:
            if ',' in item.get('answer', ''):  # 只处理长答案
                prompt = f"""
原文本: {item['answer']}

转换为更口语化的版本:
"""
                casual = llm_call(prompt)
                enhanced.append({
                    **item,
                    'answer': casual,
                    'style': 'casual'
                })

    return enhanced

# 使用
data = load_dataset()  # 你的原始数据
enhanced_data = enhance_dataset_with_prompts(data)

print(f"原始: {len(data)} → 增强: {len(enhanced_data)}")
# 输出: 原始: 1000 → 增强: 4500
```
