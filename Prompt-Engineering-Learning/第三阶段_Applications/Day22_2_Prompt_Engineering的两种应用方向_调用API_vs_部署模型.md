## 第四部分:完整示例对比

### 4.1 场景:让AI查天气

#### 调用OpenAI API的方式

```python
# ========== 使用GPT-4 API + Function Calling模式 ==========
import openai

# 定义工具(标准JSON Schema)
tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "查询天气",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }
}]

# 调用API
response = openai.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": "你是一个助手"},
        {"role": "user", "content": "北京今天天气怎么样?"}
    ],
    tools=tools  # ← OpenAI自动处理
)

# GPT-4自动生成标准JSON
if response.choices[0].message.tool_calls:
    tool_call = response.choices[0].message.tool_calls[0]
    # {
    #   "function": {
    #     "name": "get_weather",
    #     "arguments": "{\"location\":\"北京\"}"
    #   }
    # }

    # 你只需解析JSON,很简单!
    import json
    args = json.loads(tool_call.function.arguments)
    weather = get_weather(args["location"])

# ⚠️ 你设计了什么?
# 1. 工具的JSON定义
# 2. 调用逻辑
# ✅ 简单!OpenAI帮你做了大部分工作!
```

#### 使用本地Llama模型的方式

```python
# ========== 使用本地Llama 3 + 提示词模式 ==========
import ollama

# 设计详细的系统提示(教模型如何输出)
system_prompt = """你是一个智能助手。

当你需要使用工具时,请按以下格式输出:

<tool_use>
工具名: get_weather
参数: location=北京
</tool_use>

示例1:
用户: 上海天气如何?
助手: <tool_use>
工具名: get_weather
参数: location=上海
</tool_use>

示例2:
用户: 广州今天下雨吗?
助手: <tool_use>
工具名: get_weather
参数: location=广州
</tool_use>

现在请处理用户的问题。"""

# 调用本地模型
response = ollama.chat(
    model="llama3",
    messages=[
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": "北京今天天气怎么样?"}
    ]
)

# Llama可能输出(不保证格式正确!)
# "好的,让我查一下。<tool_use>工具名: get_weather 参数: location=北京</tool_use>"
# 或者可能格式错误: "我需要调用get_weather工具,位置是北京"

# 你需要复杂的解析逻辑
import re
output = response['message']['content']

# 尝试提取(可能失败!)
match = re.search(r'<tool_use>(.*?)</tool_use>', output, re.DOTALL)
if match:
    tool_content = match.group(1)
    # 继续解析工具名和参数...
    tool_match = re.search(r'工具名[:=]\s*(\w+)', tool_content)
    param_match = re.search(r'参数[:=]\s*location=([^\n]+)', tool_content)

    if tool_match and param_match:
        tool_name = tool_match.group(1)
        location = param_match.group(1).strip()
        weather = get_weather(location)
    else:
        # 格式错误,需要重试或降级
        print("模型输出格式错误!")
else:
    # 没有工具调用,可能模型没理解
    print("模型没有调用工具!")

# ⚠️ 你设计了什么?
# 1. 详细的系统提示(教模型格式)
# 2. Few-shot示例
# 3. 复杂的解析逻辑
# 4. 错误处理
# ❌ 复杂!你需要做很多工作!
```
