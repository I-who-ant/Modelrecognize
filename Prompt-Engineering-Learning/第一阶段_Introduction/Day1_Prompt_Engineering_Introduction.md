## 📖 学习内容

### 1. 什么是 Prompt Engineering？

**定义**:
Prompt Engineering 是一门相对较新的学科，专注于开发和优化提示词，以高效地使用语言模型 (LMs) 解决各种应用和研究问题。

**核心要素**:
```
提示工程 = 指令设计 + 上下文管理 + 示例构造 + 输出格式化 + 迭代优化
```

### 2. 与传统编程的区别

| 对比维度 | 传统编程 | Prompt Engineering |
|---------|---------|-------------------|
| **输入** | 代码指令 | 自然语言提示 |
| **逻辑** | 显式编写 | 隐式学习 |
| **灵活性** | 刚性规则 | 灵活适应 |
| **调试** | 错误日志 | 输出分析 |
| **优化** | 算法改进 | 提示优化 |

### 3. 提示工程的核心价值

```
✅ 应用价值:
├─ 快速原型开发
├─ 无需训练的定制能力
├─ 多任务适配
└─ 降低使用门槛

✅ 研究价值:
├─ 探索 LLM 能力边界
├─ 改进模型表现
├─ 理解模型机制
└─ 开发新应用
```

### 5. 核心原则

#### 5.1 清晰性 (Clarity)

**要点**:
- 使用简洁明确的语言
- 避免模糊或歧义的表达
- 明确输入输出格式

**示例**:
```
❌ 模糊: "帮我写点东西"
✅ 清晰: "请写一篇 200 字的关于人工智能的文章"

❌ 模糊: "分析这个"
✅ 清晰: "分析以下文本的情感倾向，给出积极/中性/消极的分类"
```

#### 5.2 具体性 (Specificity)

**要点**:
- 提供详细的要求和约束
- 指定输出格式和结构
- 包含必要的背景信息

**示例**:
```
❌ 简单: "写一个函数"
✅ 具体: "写一个 Python 函数，用于计算两个列表的交集，包含错误处理，函数名为 `get_intersection`，返回列表类型"

❌ 简单: "总结这段文字"
✅ 具体: "用不超过 50 个字总结以下文本，提取关键信息，保持客观中立"
```

#### 5.3 上下文 (Context)

**要点**:
- 提供任务背景
- 包含相关信息
- 说明使用场景

**示例**:
```
无上下文: "翻译这句话"
有上下文: "你是一个专业的技术文档翻译专家。请将以下英文技术文档翻译成中文，保持专业术语的准确性，输出格式为：原文 -> 译文"

无上下文: "回答这个问题"
有上下文: "你是一个客服助手，用户询问产品相关问题。请用友好耐心的语气回答以下问题，并提供有用的建议。"
```

#### 5.4 迭代 (Iteration)

**要点**:
- 不断测试和改进
- 基于输出调整提示
- 记录有效模式

**迭代循环**:
```
设计提示 -> 测试输出 -> 分析问题 -> 优化提示 -> 重新测试
```
