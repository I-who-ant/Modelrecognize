## 你的核心困惑 🤔

**问题**：定向刺激是怎么设定提示词的？怎么就能将用户输入的问题匹配到一个提示词上？还是说就是一个通用的提示词？

**老王我告诉你**：这TM是个非常好的问题！很多人学完定向刺激都没搞清楚这个核心机制！

---

## 一句话答案 🎯

**定向刺激提示 = 半通用半定制的混合模式**

```
通用刺激信号模板 + 任务特定的定制内容 = 定向刺激提示
   ↑                      ↑
 可复用的框架          针对问题的调整
```

## 核心机制：三层匹配模型 📊

### 第一层：通用刺激信号框架（可复用）

**关键理解**：
- ✅ **刺激信号的"类别"是通用的**（角色、框架、结构、质量）
- ✅ **每个类别的"模板"是通用的**（可以套用到任何任务）
- ❌ **具体的"内容填充"不是通用的**（需要根据任务定制）

```python
        """获取该任务类型的刺激信号模板"""
        return self.task_templates.get(task_type, self.task_templates["问题解决类"])
```

- ✅ **每种任务类型有固定的模板**（可复用）
- ✅ **通过关键词匹配识别任务类型**（半自动）
- ❌ **具体问题的细节还需要定制**（不是完全自动）

### 第三层：问题特定定制（完全定制）

```python
# 问题特定定制 - 根据具体问题调整刺激信号
class QuestionSpecificCustomization:
    """根据具体问题定制刺激信号"""

    def customize_stimulus(self, user_question, task_template):
        """
        将通用模板定制为具体问题的刺激提示

        参数:
        - user_question: 用户的具体问题
        - task_template: 任务类型模板
        """
        # 提取问题关键信息
        question_context = self.extract_context(user_question)

        # 基于模板和问题定制刺激提示
        customized_prompt = self.build_prompt(question_context, task_template)

        return customized_prompt

    def extract_context(self, question):
        """从问题中提取上下文信息"""
        return {
            "领域": self.identify_domain(question),
            "焦点": self.identify_focus(question),
            "复杂度": self.estimate_complexity(question),
            "输出类型": self.identify_output_type(question)
        }

    def build_prompt(self, context, template):
        """构建定制的刺激提示"""
        # 选择合适的角色
        role = self.select_role(context, template["角色选择"])
        # 选择合适的框架
        framework = self.select_framework(context, template["框架选择"])
        # 定制输出结构
        structure = self.customize_structure(context, template["输出结构"])
        # 定制质量要求
        quality = self.customize_quality(context, template["质量要求"])

        # 组装最终提示
        final_prompt = f"""
【角色定位】作为一位{role}
【分析框架】运用{framework}
【输出要求】必须包含：{', '.join(structure)}
【质量标准】{', '.join(quality)}

{context['原始问题']}
"""
        return final_prompt

# 完整示例：从问题到定制刺激提示
def generate_directional_stimulus(user_question):
    """完整流程：生成定向刺激提示"""

    # 步骤1：匹配任务类型
    matcher = TaskTypeMatching()
    task_type = matcher.match_task_type(user_question)
    task_template = matcher.get_stimulus_template(task_type)

    print(f"步骤1: 识别任务类型 = {task_type}")

    # 步骤2：定制刺激信号
    customizer = QuestionSpecificCustomization()
    context = customizer.extract_context(user_question)
    context['原始问题'] = user_question

    print(f"步骤2: 提取问题上下文 = {context}")

    # 步骤3：构建最终提示
    final_prompt = customizer.build_prompt(context, task_template)

    print(f"\n步骤3: 生成最终刺激提示:")
    print("="*60)
    print(final_prompt)
    print("="*60)

    return final_prompt

# 实际使用
question = "分析我们公司新产品的市场竞争力"
stimulus_prompt = generate_directional_stimulus(question)
```

**关键理解**：
- ✅ **问题特定信息需要提取**（领域、焦点、复杂度等）
- ✅ **基于问题上下文选择合适的角色和框架**
- ✅ **输出结构和质量要求需要定制**
- ❌ **这部分是完全定制的，不能直接复用**

### Q1: 定向刺激是通用的还是定制的？

**答案：两者都有，是混合模式！**

```python
# 定向刺激 = 通用框架 + 定制内容
directional_stimulus = {
    "通用部分（可复用）": {

            "商业分析类": {...},
```

**类比**：
- **通用部分** 就像"汽车底盘"（可以复用）
- **定制部分** 就像"车身外观和内饰"（需要根据需求定制）

```python
    def use_template(self, scenario_key, specific_question):

        template = self.templates.get(scenario_key)
        if template:

        """列出所有可用场景"""
        return list(self.templates.keys())
```

## 总结：核心机制图解 📊

```
用户问题
   ↓
识别任务类型（关键词匹配）
   ↓
选择通用模板（任务类型库）
   ↓
定制化调整（基于问题特征）
   ↓
生成最终刺激提示
   ↓
输入到AI
   ↓
获得高质量输出
```

### 关键要点总结 🔑

1. **定向刺激 = 通用框架 + 定制内容**
   - 刺激信号类别是通用的（角色、框架、结构、质量）
   - 具体内容需要根据问题定制

2. **匹配机制 = 任务识别 + 模板选择 + 定制调整**
   - 通过关键词识别任务类型
   - 从模板库选择合适模板
   - 根据问题特征定制调整

3. **使用方式 = 手工 / 半自动 / 全自动**
   - 手工：最精准，适合重要任务
   - 半自动：平衡效率和质量
   - 全自动：最快速，适合批量处理

4. **最佳实践 = 建立个人模板库**
   - 收集常见场景模板
   - 持续优化和扩展
   - 提高复用效率
