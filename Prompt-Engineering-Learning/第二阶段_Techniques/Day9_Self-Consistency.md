## 📖 理论学习

### 1. 什么是 Self-Consistency？

#### 1.1 核心定义

**定义**:
Self-Consistency 是一种提示技术，通过生成多个推理路径，然后选择最一致（或最可能）的答案来提升推理准确性和可靠性。

**本质特征**:
```
Single Path: 问题 → 单条推理 → 答案
Self-Consistency: 问题 → 多条推理 → 选择一致答案

工作机制:
多样化推理 → 路径比较 → 一致性评估 → 最佳答案选择
```

**关键要素**:
```
Self-Consistency = CoT提示 + 多路径生成 + 一致性评估 + 答案选择
```

#### 1.2 认知科学基础

**群体决策理论**:
```yaml
认知机制:
人类决策: 多人讨论 → 多角度思考 → 达成共识
自一致性: 多路径推理 → 多角度分析 → 选择最优

集体智慧效应:
- 分散的个体知识整合
- 错误相互抵消
- 正确答案得到强化
- 整体决策质量提升

关键条件:
1. 多样性: 不同的推理路径
2. 独立性: 路径间相互独立
3. 聚合性: 有有效的聚合机制
4. 激励性: 鼓励诚实表达
```

**错误纠正机制**:
```yaml
错误类型:
1. 系统性错误
   - 所有人都会犯的错误

2. 随机性错误
```

### 2. Self-Consistency 的工作机制

#### 2.1 多路径生成机制

**生成策略**:
```python
# 伪代码示例
def generate_reasoning_paths(question, cot_prompt, num_paths=5):
    """
    生成多条推理路径
    """
    reasoning_paths = []
    sampling_strategies = [
        "temperature_sampling", # 温度采样
        "top_p_sampling", # Top-p采样
        "beam_search", # 束搜索
        "diverse_sampling", # 多样采样 : 从不同角度出发生成推理路径
        "random_sampling" # 随机采样 : 从所有可能的推理路径中随机选择一个
    ]

    for i in range(num_paths):
        # 使用不同的采样策略
        strategy = sampling_strategies[i % len(sampling_strategies)]

        # 添加多样性诱导
        diversity_prompt = add_diversity_inducer(cot_prompt, strategy)

        # 生成推理路径
        path = model.generate(
            question + diversity_prompt,
            sampling_strategy=strategy,
            temperature=0.7 + 0.3 * (i / num_paths)  # 递增温度
        )

        reasoning_paths.append(path)

    return reasoning_paths

def add_diversity_inducer(prompt, strategy):
    """
    为提示添加多样性诱导
    """
    diversity_inducers = {
        "temperature_sampling": "请尝试不同的思考角度。",
        "top_p_sampling": "请从多个角度分析这个问题。",
        "beam_search": "请探索多种可能的推理路径。",
        "diverse_sampling": "请用不同的方法解决这个问题。",
        "random_sampling": "请随机选择一个方向进行推理。"
    }

    return diversity_inducers.get(strategy, "")
```

```python
def validate_reasoning_path(path, question):
    """
    验证推理路径的有效性
    """
    validation_results = {}

    # 1. 结构完整性检查
    validation_results["structure"] = check_structure_completeness(path)

    validation_results["answer"] = check_answer_validity(path, question)

def check_structure_completeness(path):
    """检查结构完整性"""
    # 检查是否有明确的推理步骤
    steps = extract_reasoning_steps(path)

    completeness_score = 0
    if len(steps) >= 3:  # 至少3步
        completeness_score += 0.4
    if has_clear_conclusion(path):  # 有明确结论
        completeness_score += 0.3
    if has_intermediate_checks(path):  # 有中间检查
        completeness_score += 0.3

    return completeness_score

def check_logical_consistency(path):
    """检查逻辑一致性"""
    # 检查推理链条是否合理
    logical_errors = detect_logical_errors(path)

    consistency_score = 1.0 - (len(logical_errors) * 0.2)
    return max(0, consistency_score)
```

#### 2.3 一致性评估机制

**一致性计算方法**:
```yaml
方法1: 语义相似度
技术:
- 计算答案的语义向量
- 使用余弦相似度
- 设置相似度阈值
- 聚类相似答案

计算公式:
similarity(a, b) = (a · b) / (|a| × |b|)

阈值设置:
高一致性: similarity > 0.8
中一致性: 0.5 < similarity <= 0.8
低一致性: similarity <= 0.5

方法2: 语义等价
技术:
- 识别语义等价答案
- 处理同义表达
- 处理数值等价
- 考虑逻辑等价

等价判断:
直接等价: 答案完全相同
数值等价: 数值相同但表达不同
逻辑等价: 逻辑上得出相同结论
同义等价: 同义词表达相同含义

方法3: 结构匹配
技术:
- 匹配答案结构
- 识别模式相似性
- 分析推理模式
- 计算模式一致性

结构特征:
答案类型: 数值/文本/逻辑值/选择
答案格式: 列表/段落/表格/公式
推理模式: 演绎/归纳/类比/反证
```

**一致性评估算法**:
```python
def calculate_consistency_score(reasoning_paths):
    """
    计算推理路径的一致性得分
    """
    # 1. 提取所有答案
    answers = [extract_final_answer(path) for path in reasoning_paths]

    # 2. 计算答案相似度矩阵
    similarity_matrix = compute_answer_similarity_matrix(answers)

    # 3. 聚类相似答案
    clusters = cluster_similar_answers(answers, similarity_matrix)

    # 4. 找到最大聚类
    largest_cluster = max(clusters, key=len)

    # 5. 计算一致性得分
    consistency_score = len(largest_cluster) / len(reasoning_paths)

    # 6. 分析一致性质量
    consistency_quality = assess_cluster_quality(largest_cluster, similarity_matrix)

    return {
        "score": consistency_score,
        "largest_cluster_size": len(largest_cluster),
        "cluster_coherence": consistency_quality,
        "winning_answer": get_cluster_representative(largest_cluster),
        "support_count": len(largest_cluster)
    }

def select_best_answer(reasoning_paths, consistency_results):
    """
    基于一致性选择最佳答案
    """
    # 1. 识别获胜聚类
    winning_cluster = get_largest_cluster(consistency_results)

    # 2. 评估路径质量
    path_quality_scores = [evaluate_path_quality(path) for path in winning_cluster]

    # 3. 综合评估选择
    best_path_index = np.argmax(path_quality_scores)
    best_path = winning_cluster[best_path_index]

    # 4. 返回最终答案
    return extract_final_answer(best_path)
```

```yaml
自一致性CoT提示:

问题: 计算 (123 + 456) × 789 - 321 × 654

请从不同角度逐步推理：

路径1: 直接计算
推理:

步骤2: 再计算乘法: 579 × 789 = 456,831
步骤3: 接着计算: 321 × 654 = 210,234
步骤4: 最后计算: 456,831 - 210,234 = 246,597

路径2: 分组计算
推理:
步骤1: 将表达式分组: [(123 + 456) × 789] - [321 × 654]
步骤2: 计算第一组: 123 + 456 = 579, 579 × 789
步骤3: 实际计算: 579 × 789 = 456,831
步骤4: 计算第二组: 321 × 654 = 210,234
步骤5: 相减: 456,831 - 210,234 = 246,597
答案: 246,597

推理:
步骤1: 重新计算 (123 + 456) × 789
步骤2: 123 + 456 = 579, 579 × 789
步骤3: 验证: 500×789 = 394,500, 79×789 = 62,331, 总计 456,831
步骤4: 重新计算 321 × 654
步骤5: 验证: 300×654 = 196,200, 21×654 = 13,734, 总计 209,934
步骤6: 计算: 456,831 - 209,934 = 246,897 (注意计算错误)
步骤7: 重新仔细计算: 321 × 654 = 210,234
步骤8: 最终: 456,831 - 210,234 = 246,597
答案: 246,597
"""

一致性分析:
答案分布:
- 246,597: 2条路径 (66.7%)
- 246,897: 1条路径 (33.3%)

一致性评估:
- 主要答案: 246,597
- 支持度: 2/3 = 66.7%
- 选择: 246,597
- 置信度: 中等
```

**任务 2: 代数方程**
```yaml

示例问题:
问题: "解方程：2x + 5 = 13"

自一致性CoT提示:
"""
问题: 解方程 2x + 5 = 13

请用不同方法逐步推理：

路径1: 移项法
推理:
步骤1: 理解方程 - 这是线性方程
步骤2: 移项：2x = 13 - 5

步骤4: 两边除以2：x = 8 ÷ 2 = 4
步骤5: 验证：2×4 + 5 = 8 + 5 = 13 ✓
答案: x = 4

路径2: 代入验证法
推理:
步骤1: 假设解为 x
步骤2: 方程为 2x + 5 = 13
步骤3: 测试 x = 3：2×3 + 5 = 6 + 5 = 11 ≠ 13
步骤4: 测试 x = 4：2×4 + 5 = 8 + 5 = 13 ✓
步骤5: 测试 x = 5：2×5 + 5 = 10 + 5 = 15 ≠ 13
```

**改进的一致性计算**:
```python
def improved_consistency_scoring(reasoning_paths, question):
    """
    改进的一致性评分算法
    """
    # 1. 提取和标准化答案
    raw_answers = [extract_answer(path) for path in reasoning_paths]
    normalized_answers = [normalize_answer(ans) for ans in raw_answers]

    # 2. 计算语义相似度
    similarity_matrix = compute_semantic_similarity(normalized_answers)

    # 3. 使用谱聚类找一致性答案
    clusters = spectral_clustering(similarity_matrix, threshold=0.6)

    # 4. 计算每个聚类的质量分数
    cluster_quality = {}
    for i, cluster in enumerate(clusters):
        if len(cluster) == 0:
            continue

        # 内部一致性
        internal_consistency = calculate_internal_consistency(
            [normalized_answers[j] for j in cluster]
        )

        # 逻辑一致性
        logical_consistency = evaluate_logical_consistency(
            [reasoning_paths[j] for j in cluster]
        )

        # 答案合理性
        answer_plausibility = assess_answer_plausibility(
            [normalized_answers[j] for j in cluster], question
        )

        # 综合质量分数
        quality_score = (
            0.4 * internal_consistency +
            0.3 * logical_consistency +
            0.3 * answer_plausibility
        )

        cluster_quality[i] = {
            "size": len(cluster),
            "members": cluster,
            "quality": quality_score,
            "representative": get_cluster_representative(
                [normalized_answers[j] for j in cluster]
            )
        }

    # 5. 选择最佳聚类
    best_cluster = max(cluster_quality.items(),
                      key=lambda x: x[1]["size"] * x[1]["quality"])

    # 6. 计算最终一致性得分
    consistency_score = best_cluster[1]["size"] / len(reasoning_paths)

    return {
        "consistency_score": consistency_score,
        "winning_cluster": best_cluster[1],
        "all_clusters": cluster_quality,
        "winning_answer": best_cluster[1]["representative"],
        "support_ratio": best_cluster[1]["size"] / len(reasoning_paths)
    }
```
