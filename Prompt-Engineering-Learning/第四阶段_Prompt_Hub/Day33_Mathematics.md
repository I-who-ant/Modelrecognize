**示例 - 代数计算**:
```
问题: 解方程 2x² - 5x + 2 = 0

步骤1: 理解问题
- 这是一个一元二次方程
- 标准形式: ax² + bx + c = 0
- 其中 a=2, b=-5, c=2

步骤2: 选择方法
使用求根公式: x = [-b ± √(b² - 4ac)] / 2a

步骤3: 计算判别式
Δ = b² - 4ac
  = (-5)² - 4(2)(2)
  = 25 - 16
  = 9

因为 Δ > 0,所以有两个不相等的实数根

步骤4: 求解
x = [5 ± √9] / (2×2)
  = [5 ± 3] / 4

x₁ = (5 + 3) / 4 = 8/4 = 2
x₂ = (5 - 3) / 4 = 2/4 = 0.5

步骤5: 验证
验证 x₁ = 2:
2(2)² - 5(2) + 2 = 2(4) - 10 + 2 = 8 - 10 + 2 = 0 ✓

验证 x₂ = 0.5:
2(0.5)² - 5(0.5) + 2 = 2(0.25) - 2.5 + 2 = 0.5 - 2.5 + 2 = 0 ✓

最终答案: x₁ = 2, x₂ = 0.5 (或 x₁ = 2, x₂ = 1/2)
```

**示例 - 行程问题**:
```
问题:
甲乙两地相距450公里。一辆汽车从甲地开往乙地,平均速度为60公里/小时。
行驶2小时后,因故障停车修理了30分钟,然后以75公里/小时的速度继续行驶。
问:汽车从甲地到乙地一共用了多少时间?

步骤1: 提取信息
- 总路程: 450公里
- 第一阶段: 速度60km/h,行驶2小时
- 停车修理: 30分钟 = 0.5小时
- 第二阶段: 速度75km/h

步骤2: 设定变量
设第二阶段行驶时间为 t 小时

步骤3: 建立方程
第一阶段路程: 60 × 2 = 120公里
第二阶段路程: 75t 公里

总路程方程:
120 + 75t = 450

步骤4: 求解
75t = 450 - 120
75t = 330
t = 330 / 75
t = 4.4小时

步骤5: 计算总时间
总时间 = 第一阶段 + 修理时间 + 第二阶段
       = 2 + 0.5 + 4.4
       = 6.9小时
       = 6小时54分钟

步骤6: 验证
总路程 = 60×2 + 75×4.4 = 120 + 330 = 450公里 ✓
时间合理性: 如果全程60km/h需要450/60=7.5小时,
现在6.9小时,因为后半程加速了,符合逻辑 ✓

答案: 汽车从甲地到乙地一共用了6小时54分钟(或6.9小时)
```

**示例 - 三角形面积**:
```
问题:
在△ABC中,AB = 6cm, AC = 8cm, ∠BAC = 60°,
求△ABC的面积。

步骤1: 画图标注
      B
     /
    /
   / 60°
  A-------C
  6cm  8cm

步骤2: 识别公式
三角形面积公式(两边及夹角):
S = (1/2) × a × b × sin(C)

其中a、b是两边,C是夹角

步骤3: 应用公式
S = (1/2) × AB × AC × sin(∠BAC)
  = (1/2) × 6 × 8 × sin(60°)
  = (1/2) × 6 × 8 × (√3/2)
  = 24 × (√3/2)
  = 12√3 cm²

步骤4: 数值计算
12√3 ≈ 12 × 1.732 ≈ 20.78 cm²

步骤5: 验证合理性
- 三角形两边分别为6cm和8cm
- 如果是直角三角形,面积 = (1/2)×6×8 = 24cm²
- 现在夹角60° < 90°,所以面积应该小于24cm²
- 20.78 < 24 ✓ 合理

答案: △ABC的面积为 12√3 cm² (约20.78 cm²)
```

**示例 - 组合数学**:
```
问题:
从10个人中选出4个人组成委员会,其中必须包含特定的2个人,
有多少种不同的选法?

步骤1: 分析问题
- 总人数: 10人
- 需要选: 4人
- 约束: 必须包含特定2人

这意味着:
- 特定2人已经确定入选
- 还需要从剩余8人中选2人

步骤2: 数学建模
需要计算的是组合数 C(8, 2)
公式: C(n, r) = n! / [r! × (n-r)!]

步骤3: 编写代码

```python
import math

def combination(n, r):
    """计算组合数 C(n, r)"""
    return math.factorial(n) // (math.factorial(r) * math.factorial(n - r))

# 从剩余8人中选2人
n = 8
r = 2

result = combination(n, r)
print(f"C({n}, {r}) = {result}")

# 详细计算过程
numerator = math.factorial(n)
denominator = math.factorial(r) * math.factorial(n - r)
print(f"\n详细计算:")
print(f"{n}! = {numerator}")
print(f"{r}! = {math.factorial(r)}")
print(f"{n-r}! = {math.factorial(n-r)}")
print(f"C({n}, {r}) = {numerator} / ({math.factorial(r)} × {math.factorial(n-r)}) = {result}")

# 验证: 手动列举部分组合
print(f"\n验证: 8个人选2个,可能的组合数应该是28")
```

执行结果:
```
C(8, 2) = 28

详细计算:
8! = 40320
2! = 2
6! = 720
C(8, 2) = 40320 / (2 × 720) = 28
```

步骤4: 数学验证
C(8, 2) = 8! / (2! × 6!)
        = (8 × 7 × 6!) / (2 × 1 × 6!)
        = (8 × 7) / 2
        = 56 / 2
        = 28

步骤5: 答案解释
因为特定的2人必须在委员会中,相当于他们的位置已经固定。
剩下的2个位置需要从其余8人中选择,选法数为C(8,2) = 28种。

最终答案: 有28种不同的选法
```

### 模板5: 数学证明

```
命题: {要证明的数学命题}

证明步骤:
1. 明确已知条件和待证结论
2. 选择证明方法(直接证明/反证法/数学归纳法等)
3. 逐步推导
4. 得出结论

证明要求:
- 逻辑严密
- 步骤清晰
- 引用定理需注明
```

**示例 - 不等式证明**:
```
命题: 对于任意正实数 a, b,证明 (a+b)/2 ≥ √(ab)
(算术平均数不小于几何平均数)

证明:

已知: a > 0, b > 0
待证: (a+b)/2 ≥ √(ab)

证明方法: 直接证明(作差法)

步骤1: 构造差式
设 M = (a+b)/2 - √(ab)

步骤2: 化简
要证 M ≥ 0,即证:
(a+b)/2 - √(ab) ≥ 0

两边同乘2:
a + b - 2√(ab) ≥ 0

移项:
a + b ≥ 2√(ab)

两边同时平方(因为两边都≥0,不等号方向不变):
(a + b)² ≥ 4ab

展开:
a² + 2ab + b² ≥ 4ab

移项:
a² + 2ab + b² - 4ab ≥ 0
a² - 2ab + b² ≥ 0

因式分解:
(a - b)² ≥ 0

步骤3: 分析结论
因为 (a - b)² 作为完全平方式,无论a、b取何值,都有:
(a - b)² ≥ 0

等号成立当且仅当 a - b = 0,即 a = b

步骤4: 逆推得证
由 (a - b)² ≥ 0
⇒ a² - 2ab + b² ≥ 0
⇒ a² + 2ab + b² ≥ 4ab
⇒ (a + b)² ≥ 4ab
⇒ a + b ≥ 2√(ab) (两边开方,a+b>0)
⇒ (a+b)/2 ≥ √(ab)

结论:
原命题得证。
等号成立的充要条件是 a = b

这就是著名的算术-几何平均不等式(AM-GM不等式)
```

```

求等比数列 2, 6, 18, 54, ... 的前8项和。

项数 n = 8

步骤2: 应用求和公式
等比数列求和公式:
Sₙ = a₁(1 - rⁿ) / (1 - r)  (当 r ≠ 1时)

步骤3: 代入计算
S₈ = 2 × (1 - 3⁸) / (1 - 3)
   = 2 × (1 - 6561) / (-2)
   = 2 × (-6560) / (-2)
   = 6560

步骤4: 验证(计算前几项检查)
a₁ = 2
a₂ = 2 × 3 = 6
a₃ = 6 × 3 = 18
a₄ = 18 × 3 = 54
a₅ = 54 × 3 = 162
a₆ = 162 × 3 = 486
a₇ = 486 × 3 = 1458
a₈ = 1458 × 3 = 4374

手动求和:
S₈ = 2 + 6 + 18 + 54 + 162 + 486 + 1458 + 4374 = 6560 ✓

答案: 前8项和为 6560

### 模板7: 概率统计

```
问题: {概率或统计问题}

求解步骤:
1. 确定样本空间和事件
2. 选择合适的概率模型
3. 计算概率或统计量
4. 解释结果的实际意义

常用公式:
- 古典概型: P(A) = |A| / |Ω|
- 条件概率: P(A|B) = P(AB) / P(B)
- 期望: E(X) = Σ xᵢ × P(xᵢ)
```

**示例 - 古典概型**:
```
问题:
一个袋子里有5个红球和3个白球,随机取出2个球。
求:
(1) 2个都是红球的概率
(2) 1红1白的概率
(3) 至少有1个红球的概率

步骤1: 确定样本空间
总共8个球,取2个球的方法数:
C(8, 2) = 8×7/2 = 28 (样本空间大小)

步骤2: 计算各事件的概率

(1) 2个都是红球
从5个红球中取2个:
C(5, 2) = 5×4/2 = 10

P(2个都是红球) = 10/28 = 5/14 ≈ 0.357

(2) 1红1白
从5个红球中取1个,从3个白球中取1个:
C(5, 1) × C(3, 1) = 5 × 3 = 15

P(1红1白) = 15/28 ≈ 0.536

(3) 至少有1个红球
方法一(正面计算):
至少1个红球 = 1红1白 + 2个都是红球
P = 15/28 + 10/28 = 25/28 ≈ 0.893

方法二(对立事件):
至少1个红球 = 1 - 没有红球
没有红球(2个都是白球): C(3,2) = 3
P(至少1红) = 1 - 3/28 = 25/28 ≈ 0.893 ✓

步骤3: 验证
检查所有可能事件的概率和:
- 2红: 10/28
- 1红1白: 15/28
- 2白: 3/28
总和: (10+15+3)/28 = 28/28 = 1 ✓

答案:
(1) 2个都是红球的概率为 5/14 (约35.7%)
(2) 1红1白的概率为 15/28 (约53.6%)
(3) 至少有1个红球的概率为 25/28 (约89.3%)
```

### 模板8: 微积分问题

```
问题: {微积分问题:求导/积分/极值等}

求解步骤:
1. 识别问题类型和所需公式
2. 应用求导/积分法则
3. 逐步计算
4. 简化结果
5. 验证(代入特殊值或求导验证积分)

常用法则:
- 导数: (xⁿ)' = nxⁿ⁻¹, (eˣ)' = eˣ, (ln x)' = 1/x
- 积分: ∫xⁿdx = xⁿ⁺¹/(n+1) + C
```

**示例 - 求函数极值**:
```
问题:
求函数 f(x) = x³ - 3x² - 9x + 5 的极值。

步骤1: 求一阶导数
f'(x) = 3x² - 6x - 9

步骤2: 令导数为0,求驻点
3x² - 6x - 9 = 0
x² - 2x - 3 = 0
(x - 3)(x + 1) = 0

得驻点: x = 3 或 x = -1

步骤3: 求二阶导数判断极值类型
f''(x) = 6x - 6

在 x = 3:
f''(3) = 6(3) - 6 = 12 > 0 → 极小值点

在 x = -1:
f''(-1) = 6(-1) - 6 = -12 < 0 → 极大值点

步骤4: 计算极值
极大值:
f(-1) = (-1)³ - 3(-1)² - 9(-1) + 5
      = -1 - 3 + 9 + 5
      = 10

极小值:
f(3) = 3³ - 3(3)² - 9(3) + 5
     = 27 - 27 - 27 + 5
     = -22

步骤5: 绘制函数草图验证

f(x)
  |     极大值点(-1, 10)
 10|        •
  | ╱     ╲
  |        ╲
  0|         ╲    ╱
  |          ╲  ╱
-22|          •  极小值点(3, -22)
  |_____________x
   -1    0    3

答案:
- 函数在 x = -1 处取得极大值,f(-1) = 10
- 函数在 x = 3 处取得极小值,f(3) = -22
```
