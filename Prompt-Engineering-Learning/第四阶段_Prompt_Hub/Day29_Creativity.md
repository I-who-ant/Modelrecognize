# Day29: Creativity - 创意写作提示词模板库

> **应用场景**: 创意写作、头脑风暴、内容生成、故事创作、营销文案等

---

## 📝 场景概述

### 核心挑战
- 生成内容的原创性和新颖性
- 保持创意输出的质量稳定
- 符合特定风格和受众需求
- 避免陈词滥调和重复内容

### 技术要求
- 激发多样化的创意思路
- 控制创意方向和边界
- 保证内容的连贯性和逻辑性
- 适应不同的写作风格和领域

---

## 🎯 快速模板库

### 模板1: 基础创意生成 (Zero-Shot)

```
任务: 创作{内容类型}

主题: {主题描述}

要求:
- 风格: {如幽默、正式、诗意等}
- 长度: {字数或段落数}
- 受众: {目标读者群体}
- 特殊要求: {其他限制}

请输出原创内容。
```

**示例 - 营销文案**:
```
任务: 创作产品营销文案

主题: 智能手表新品发布

要求:
- 风格: 科技感、简洁有力
- 长度: 100字左右
- 受众: 25-35岁城市白领
- 特殊要求: 突出健康监测功能

→ 输出:
**时间由你掌控，健康为你守护**

不只是腕上的时间，更是全天候的健康管家。全新智能手表X1，搭载医疗级心率监测，7×24小时血氧追踪，AI睡眠分析让每一夜都充满质量。超长续航15天，轻至35克，让科技成为你最轻盈的守护。

现在预订，享早鸟价8折优惠。让健康，触手可及。
```

### 模板2: 头脑风暴 (发散思维)

```
任务: 为以下主题进行头脑风暴

主题: {核心主题}

请从以下角度思考:
1. 传统角度: {常规思路}
2. 逆向思维: {反常规思路}
3. 类比联想: {从其他领域借鉴}
4. 未来视角: {5-10年后的可能性}
5. 极端场景: {推到极致会怎样}

每个角度提供3-5个具体想法,越新颖越好。
```

**示例 - 产品创新**:
```
任务: 为"智能厨房"产品进行头脑风暴

主题: 未来的智能厨房体验

1. 传统角度 (现有技术延伸):
   - 语音控制的智能炉灶,精准温控
   - 冰箱自动识别食材并推荐菜谱
   - 洗碗机联网,远程启动和监控
   - 智能秤自动记录营养摄入
   - 烤箱预设程序,一键烘焙

2. 逆向思维 (反常规):
   - 无火烹饪:超声波/激光加热技术
   - 去厨具化:食材直接变成成品(分子料理打印机)
   - 反自动化:回归手工,AI只做教练指导
   - 共享厨房:多户家庭共用一个智能厨房中心
   - 虚拟厨房:VR中学习,现实中由机器人执行

3. 类比联想 (跨界借鉴):
   - 借鉴游戏:烹饪成就系统,收集食谱解锁新技能
   - 借鉴医疗:厨房健康检测,实时分析食材营养
   - 借鉴教育:分级烹饪课程,从新手到大厨
   - 借鉴社交:烹饪直播,远程协作做饭
   - 借鉴金融:食材期货,提前预订应季食材

4. 未来视角 (5-10年后):
   - AI大厨:理解你的口味偏好,自动创新菜谱
   - 细胞培养肉:厨房内培养蛋白质
   - 废料循环:厨余垃圾转化为肥料或能源
   - 全息投影:名厨虚拟指导,手把手教学
   - 脑机接口:想象中的味道直接生成

5. 极端场景 (推到极致):
   - 零厨房:胶囊营养剂完全替代食物
   - 全自动:从采购到烹饪到清洁完全无人化
   - 超个性化:每个人有专属的分子级定制食谱
   - 时空厨房:任何历史时期/地域的菜肴都能还原
   - 感官增强:AR眼镜让普通食物呈现米其林体验
```

### 模板3: 故事创作 (叙事结构)

```
任务: 创作{故事类型}

故事设定:
- 背景: {时代/地点/环境}
- 主角: {角色设定}
- 冲突: {核心矛盾}
- 主题: {想表达的主题}

请按三幕结构创作:

第一幕 - 设定 (25%):
- 介绍主角和世界观
- 引出核心冲突

第二幕 - 对抗 (50%):
- 主角面对挑战
- 遭遇转折和挫折
- 达到最低点

第三幕 - 解决 (25%):
- 最终对决
- 解决冲突
- 主题升华

要求:
- 情节有起伏
- 人物有成长
- 结尾有余味
```

**示例 - 科幻短篇**:
```
任务: 创作科幻短篇小说

故事设定:
- 背景: 2157年,火星殖民地
- 主角: 李墨,殖民地农业工程师,35岁
- 冲突: 地球切断供给,殖民地面临饥荒
- 主题: 人类的韧性与希望

【第一幕 - 危机降临】(约500字)

火星殖民地"晨曦"建立第二十三年,李墨例行检查着温室的营养液循环系统。透过透明穹顶,赭红色的荒原延伸至地平线,地球只是夜空中一个蓝色的光点。

"紧急通讯,全体人员请注意。"广播打断了她的工作。

总督的声音疲惫而凝重:"地球联邦议会通过决议,即日起暂停对所有火星殖民地的物资补给。原因是...地球自己也出了问题。"

李墨的手停在半空。殖民地的食物自给率只有67%,剩余部分完全依赖地球补给。最后一艘货船三个月前离开,下一次预定补给是两个月后。但现在,不会有下一次了。

"我们有六个月的储备。"总督继续说,"六个月内,我们必须实现完全自给,否则..."

否则一万两千名殖民者将面临饥荒。李墨看着温室里仅有的三百株作物,这些植物在火星低重力环境下生长缓慢,产量只有地球的40%。六个月,根本不够。

她深吸一口气,打开通讯器:"这里是李墨,我需要召集所有农业组的成员。我有个疯狂的想法。"

【第二幕 - 绝境求生】(约1000字)

李墨的计划听起来像是科幻小说:改造火星土壤,让作物直接在火星大气压下生长。

"你疯了。"生物学家王教授摇头,"火星土壤含有高氯酸盐,对植物有毒。大气压只有地球的1%,温度低至零下60度。"

"所以我们需要基因编辑。"李墨调出全息投影,"我分析了耐寒微生物的基因,如果能把耐寒基因导入作物..."

"那需要三年的实验周期。我们只有六个月。"

"如果失败,我们都会死。不如放手一搏。"李墨的眼神坚定,"而且我们有AI辅助,可以加速筛选。"

接下来的日子,李墨几乎住在了实验室。AI系统每天生成上千个基因编辑方案,她逐一测试、失败、再测试。土豆变成了黑色然后枯萎,小麦发芽后无法成熟,水稻根本不发芽。

第四十天,她培育的第127代改良小麦在模拟火星环境下坚持了三天,然后死了。

第六十天,王教授找到她:"李墨,该放弃了。我们应该想其他办法,比如降低配给标准,或许能撑到地球恢复..."

"不。"李墨的眼睛布满血丝,"地球未必会恢复。我们必须靠自己。"

第七十五天,殖民地开始实行配给制,每人每天的食物量减少了30%。李墨感觉到饥饿,但她把自己的配给分给了实验室的助手们。

第八十天,她崩溃了。在实验室哭了整整一夜后,她做了一个梦。梦里她回到了地球,奶奶的菜园里,那些顽强生长在贫瘠土地上的红薯。

她醒来,调出红薯的基因数据。红薯耐贫瘠、适应性强、产量高。为什么她之前一直执着于小麦和水稻?

第八十五天,改良红薯在火星土壤中发芽了。

第九十天,它长出了叶子。

第一百天,它在零下40度的温度下依然存活。

"成功了..."李墨看着培养箱里那株墨绿色的植物,泪水模糊了双眼。

【第三幕 - 火星奇迹】(约500字)

六个月后,殖民地外围开辟的五十公顷火星农场里,改良红薯铺满了赭红色的大地。透明的增压帐篷下,这些经过基因改造的作物在火星严酷环境中茁壮生长。

收获季,李墨站在田埂上,看着殖民者们欢呼雀跃地收获火星上第一批真正意义上的本地作物。产量超出预期,足够支撑殖民地完全自给。

"地球发来通讯。"总督走过来递给她一个平板,"他们的危机解除了,补给船下个月就能出发。"

李墨笑了:"告诉他们,不用了。我们已经不需要地球的补给了。不过,如果他们想要一些火星红薯的种子,我们可以分享。"

她蹲下身,轻轻触摸着火星土壤。曾经贫瘠有毒的尘土,现在能够孕育生命。人类用了二十三年把地球作物搬到火星,却只用了六个月就让火星拥有了自己的农业。

"李墨工程师?"一个年轻的助手跑过来,"新一批改良玉米的实验数据出来了,成功率87%!"

她站起身,望向天边的地球。那个蓝色星球依然在闪烁,但火星不再是它的附庸。这片红色大地,已经成为了真正的第二家园。

温室里,她种下了第一粒火星小麦的种子。有一天,这里会有金色的麦田,会有绿色的森林,会有蓝色的湖泊。

火星的春天,才刚刚开始。

---

**主题升华:**
这个故事表面上是关于农业技术突破,深层主题是:
- 人类面对绝境时的创造力和韧性
- 依赖与自立的转变
- 从"移植文明"到"本土文明"的进化
- 危机往往是进化的催化剂
```

### 模板4: 风格模仿

```
任务: 模仿{作家/风格}的写作风格

参考风格特点:
- 语言特色: {如简洁/华丽/幽默等}
- 句式特点: {长句/短句/排比等}
- 修辞手法: {比喻/拟人/夸张等}
- 主题偏好: {常写的主题}

主题: {写作主题}

请创作一段{字数}字的文字,体现该风格特点。
```

**示例 - 模仿鲁迅风格**:
```
任务: 模仿鲁迅的写作风格

参考风格特点:
- 语言特色: 犀利、冷峻、讽刺
- 句式特点: 短句为主,节奏感强
- 修辞手法: 反讽、对比、白描
- 主题偏好: 批判社会现实,揭露人性

主题: 现代社交媒体现象

→ 输出:

《论"点赞"》

我向来不惮以最坏的恶意来揣测国人的社交,然而我还不料到,也不信竟会虚伪到这地步。

朋友圈里,照片经过十七次滤镜,文字斟酌了三十分钟,发出后便开始等待那些"点赞"。赞来了,心中窃喜;赞少了,便觉得自己是被世界抛弃了的人。于是删除,重发,再删除,再重发。

我看见有人对着屏幕皱眉,却也麻木地点下那个"赞"。问他为何赞,答曰:"人家给我点了,我不点不好意思。"这便是现代的人情往来了。从前送礼还要上门,如今只需动动手指,便算是尽了情谊。

真诚吗?不真诚。在意吗?也不在意。不过是在这虚拟的世界里,彼此交换着廉价的好感,以此证明自己还活着,还被人记得。

至于生活的真相,都藏在那些不发朋友圈的时刻里了。

---

**风格特点分析:**
✅ 短句节奏:"赞来了,心中窃喜;赞少了,便觉得..."
✅ 冷峻讽刺:"从前送礼还要上门,如今只需动动手指"
✅ 犀利批判:"交换着廉价的好感"
✅ 经典句式:"我向来不惮以最坏的恶意来揣测..."(致敬《纪念刘和珍君》)
✅ 白描手法:直接描述行为,不加修饰
```

### 模板5: 多角度创意 (Self-Consistency)

```
任务: 从多个角度创作{内容类型}

主题: {主题}

请从以下3个不同角度创作,然后选出最佳版本:

角度1 - {角度A,如感性视角}:
[创作内容1]

角度2 - {角度B,如理性视角}:
[创作内容2]

角度3 - {角度C,如幽默视角}:
[创作内容3]

对比分析:
- 版本1优点/缺点:
- 版本2优点/缺点:
- 版本3优点/缺点:

推荐版本: {选择理由}
```

**示例 - 产品Slogan**:
```
任务: 从多个角度创作产品Slogan

主题: 环保可降解包装袋

角度1 - 环保理念视角:
"今天的选择,明天的地球"
"不只是一个袋子,是对未来的承诺"
"让包装回归自然"

分析:强调环保价值,容易引起共鸣,但可能显得说教

角度2 - 实用功能视角:
"3个月自然降解,0负担"
"用完即走,大自然帮你收拾"
"强韧如塑料,温柔如自然"

分析:突出产品特性,理性消费者喜欢,但缺乏情感

角度3 - 幽默创意视角:
"塑料袋的觉悟:我该消失了"
"地球在减肥,包装袋也在"
"会自己说再见的袋子"

分析:有记忆点,年轻人喜欢,但可能不够严肃

对比分析:
- 版本1: 价值观正确,但同质化严重,缺乏差异化
- 版本2: 信息明确,转化率可能高,但缺乏传播性
- 版本3: 传播性强,容易记住,但可能削弱环保严肃性

推荐版本(组合策略):
主Slogan用版本2的"强韧如塑料,温柔如自然"
- 优点:既有功能对比,又有情感表达
- 平衡了理性和感性
- 简洁有力,易于传播

副Slogan用版本1的"今天的选择,明天的地球"
- 在详细介绍时强化环保价值

社交媒体用版本3的"会自己说再见的袋子"
- 增加趣味性和传播性
```

### 模板6: 受限创作 (创意约束)

```
任务: 在限制条件下创作

主题: {主题}

限制条件:
- 必须包含词语: {指定词语列表}
- 禁止使用词语: {禁用词语列表}
- 字数限制: {最少-最多字数}
- 其他限制: {如必须押韵、必须使用特定句式等}

请在满足所有限制的情况下完成创作。
```

**示例 - 受限诗歌创作**:
```
任务: 在限制条件下创作现代诗

主题: 城市夜晚

限制条件:
- 必须包含词语: 霓虹、孤独、回家、星光
- 禁止使用词语: 美丽、漂亮、快乐、悲伤(避免直接情感词)
- 字数限制: 80-120字
- 其他限制: 每段4行,至少2段,有意境留白

→ 输出:

《城市夜归人》

霓虹在玻璃幕墙上流淌
将影子拉得很长很长
地铁里的人都低着头
各自在屏幕里寻找方向

孤独是二十三点的便利店
是自动售货机前的停留
星光被淹没在灯火里
回家的路,一个人走

---

**限制检查:**
✅ 包含指定词: 霓虹(第1行)、孤独(第5行)、星光(第7行)、回家(第8行)
✅ 无禁用词: 未使用"美丽、漂亮、快乐、悲伤"
✅ 字数: 96字(符合80-120)
✅ 结构: 2段,每段4行
✅ 意境: 通过"影子拉得很长"、"便利店"、"星光被淹没"等意象表达情绪,不直接说"悲伤"或"孤独的感觉"
```

### 模板7: 续写扩展

```
任务: 续写以下内容

原文:
{已有内容}

续写要求:
- 保持风格一致
- 逻辑连贯自然
- 长度: {字数}
- 方向: {发展方向,如转折/高潮/收尾等}

请继续创作。
```

**示例 - 故事续写**:
```
任务: 续写以下内容

原文:
"深夜三点,我被一阵敲门声惊醒。透过猫眼,门外空无一人。但敲门声还在继续,一下,又一下,仿佛来自另一个世界。"

续写要求:
- 保持悬疑风格
- 逻辑连贯自然
- 长度: 200-300字
- 方向: 揭示真相(非恐怖向,合理解释)

→ 输出:

我强迫自己冷静下来,仔细分辨声音的来源。敲门声很有规律,每隔三秒一次,声音低沉。我意识到,这不像是人的敲门——太机械,太精准。

披上外套,我打开门。走廊空荡荡的,只有安全指示灯发出微弱的绿光。但声音还在继续。我沿着墙壁摸索,终于在邻居家门口找到了声源。

那是一个扫地机器人,正在执着地撞击着门板。它的传感器似乎故障了,把门当成了障碍物,试图"越过"它。而撞击的振动通过墙壁传导,让我误以为是自己家的门。

回到房间,我给他发了条微信。窗外天色微亮,城市开始苏醒。这个深夜的小插曲,不过是现代生活的一个注脚——我们被机器包围,有时候,连恐惧都源自它们。
```

### 模板8: 创意组合 (SCAMPER法)

```
任务: 使用SCAMPER法进行创意组合

原始概念: {基础概念}

S - Substitute (替代): 能替换什么元素?
C - Combine (组合): 能和什么组合?
A - Adapt (调整): 能从什么改编?
M - Modify (修改): 能修改什么属性?
P - Put to other uses (改变用途): 能用于什么?
E - Eliminate (消除): 能去掉什么?
R - Reverse (颠倒): 能颠倒什么?

请从每个角度提供2-3个创意,然后选出最有潜力的想法深入发展。
```

**示例 - 产品创新**:
```
任务: 使用SCAMPER法进行创意组合

原始概念: 传统雨伞

S - Substitute (替代):
1. 用无人机替代伞骨,悬浮在头顶的雨伞
2. 用空气墙替代伞布,离子风场驱散雨滴
3. 用可编程智能材料替代普通伞布,自动调节透光度

C - Combine (组合):
1. 雨伞 + 太阳能板 = 发电雨伞,雨天也能充电
2. 雨伞 + 空气净化 = 净化雨伞,边挡雨边净化空气
3. 雨伞 + AR显示 = 信息雨伞,伞面显示天气、导航信息

A - Adapt (调整):
1. 改编自降落伞原理,雨伞可以缓降
2. 改编自植物叶片,仿生自清洁表面
3. 改编自变色龙,伞面可根据环境变色

M - Modify (修改):
1. 超小型化,手表大小,使用时展开
2. 巨型化,可以覆盖整个公交站台的共享雨伞
3. 形状修改,正方形/三角形雨伞,更好的覆盖

P - Put to other uses (改变用途):
1. 晴天当太阳伞,雨天当雨伞,夜晚当照明
2. 收起来当登山杖使用
3. 作为街头艺人的表演道具,LED灯光伞

E - Eliminate (消除):
1. 去掉伞柄,变成头戴式雨伞帽
2. 去掉中心支撑,变成分散式多点支撑
3. 去掉物理实体,用声波或磁场创建无形"雨伞"

R - Reverse (颠倒):
1. 反向收纳,湿面在内,不会弄湿地面
2. 伞布在内侧,外骨骼设计,更抗风
3. 雨伞不是挡雨,而是收集雨水用于后续利用

---

**最有潜力想法深入发展:**

选择: Reverse-1 "反向收纳雨伞" + Combine-1 "发电雨伞"

**产品概念: ReVerse智能反向伞**

核心创新:
1. 反向折叠机制
   - 打开时,湿面朝内自动折叠
   - 收纳后形成密闭空间,水不会滴落
   - 上车、进门不再尴尬

2. 太阳能充电系统
   - 伞面集成柔性太阳能薄膜
   - 雨天收集能量,可为手机充电
   - 伞柄集成USB接口和电量显示

3. 智能传感
   - 自动检测雨量,调整伞面角度
   - 风力传感,大风时自动加固骨架
   - APP连接,提醒天气和充电状态

目标用户:
- 都市通勤族(解决上车滴水问题)
- 户外爱好者(太阳能充电)
- 科技尝鲜者(智能功能)

定价策略: 299元(普通反向伞50元,加上智能功能溢价合理)

营销slogan: "反转雨天,正向生活"

**SCAMPER方法优势:**
通过系统性地从7个维度思考,产生了21个不同角度的创意,避免思维定势,最后组合出实用且有市场潜力的产品概念。
```

## 💡 最佳实践

### 1. 选择合适的模板

```
快速营销文案:
└─ 使用模板1: 基础创意生成

需要多个创意方案:
└─ 使用模板2: 头脑风暴
└─ 使用模板5: 多角度创意

长篇内容创作:
└─ 使用模板3: 故事创作(三幕结构)
└─ 使用模板7: 续写扩展

特定风格需求:
└─ 使用模板4: 风格模仿

创意受限场景:
└─ 使用模板6: 受限创作

产品/服务创新:
└─ 使用模板8: SCAMPER创意组合
```

### 2. 提升创意质量技巧

**明确约束**:
1. 限制反而激发创意(字数、主题、风格)
2. 给出具体的受众和使用场景
3. 提供参考示例但不限制想象

**多样性控制**:
1. 要求提供多个版本对比选择
2. 指定不同角度或风格
3. 使用"意外"、"新颖"等关键词

**迭代优化**:
1. 先生成初稿,再要求改进特定方面
2. 结合用户反馈逐步调整
3. A/B测试不同版本的效果

## ⚠️ 常见陷阱

### 陷阱1: 需求过于宽泛

```
❌ 错误:
"帮我写个广告"

✅ 正确:
"为智能手表新品创作一段30秒短视频脚本
- 目标: 25-35岁都市白领
- 风格: 简洁科技感
- 重点: 健康监测功能
- 调性: 温暖关怀,不要冷冰冰"
```

### 陷阱2: 缺少风格参考

```
❌ 错误: 直接要求模仿某种风格,不给示例

✅ 正确: 提供具体的风格特征或参考作品
"模仿《纽约客》杂志的写作风格:
- 长句与短句交替
- 细节描写丰富
- 客观冷静的语调
- 适度的讽刺"
```

### 陷阱3: 忽略迭代优化

```
❌ 错误: 一次生成就直接使用

✅ 正确: 多轮迭代改进
第1轮: 生成3个初稿
第2轮: 选出最佳,要求优化特定部分
第3轮: 细节润色和调整
```
