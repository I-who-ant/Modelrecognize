### Day 2: Prompt Engineering - LLM Settings

**学习目标**: 掌握 LLM 参数设置对输出的影响

**学习内容**:
```
1. Temperature (温度)
   ├─ 0.0-0.3: 确定性输出
   ├─ 0.4-0.7: 平衡创造性和一致性
   └─ 0.8-1.0: 高创造性

2. Top-p (核采样)
   ├─ 原理和计算方式
   ├─ 与 Temperature 的关系
   └─ 最佳实践

3. Max Tokens
   ├─ 长度控制策略
   ├─ 成本优化
   └─ 质量平衡

4. Frequency & Presence Penalty
   ├─ 频率惩罚作用
   ├─ 存在惩罚作用
   └─ 组合使用策略
```

**实践任务**:

## 💡 学习建议

### 高效学习策略

```
1. 理论 + 实践结合
   - 每天 40% 时间阅读理论
   - 60% 时间动手实践

2. 渐进式学习
   - 从简单到复杂
   - 每次掌握 1-2 种技术

3. 项目驱动
   - 每个技术对应实际项目
   - 积累真实经验

4. 持续记录
   - 建立个人笔记系统
   - 记录最佳实践

5. 社区协作
   - 参与开源项目
   - 分享学习心得
```

### 常见问题解决

```
Q1: 如何选择合适的技术？
A1: 根据任务特点选择，简单任务用 Zero-shot，复杂推理用 CoT。

Q2: 如何评估提示词效果？
A2: 使用多指标评估，包括准确性、完整性、创造性等。

Q3: 如何处理模型输出不稳定？
A3: 降低 Temperature，使用 Self-Consistency，增加约束条件。

Q4: 如何优化长文本处理？
A4: 使用分段处理，Prompt Chaining，检索增强生成。
```
