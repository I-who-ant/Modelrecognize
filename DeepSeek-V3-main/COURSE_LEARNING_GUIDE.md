## 🔗 与DeepSeek-V3的对应关系

### 课程概念 → DeepSeek代码

| 课程概念 | DeepSeek-V3中的体现 | 代码位置 |
|---------|-------------------|---------|
| 词嵌入 | ParallelEmbedding | model.py:89-128 |
| 线性层 | linear函数 | model.py:131+ |
| 归一化 | RMSNorm | model.py中 |
| 激活函数 | SwiGLU | MLP部分 |
| 多头注意力 | MLA(改进版) | Attention部分 |
| Softmax | 输出层 | 最后一层 |
| 前向传播 | Transformer.forward | model.py |
| 梯度下降 | Adam优化器 | 训练代码 |
| 残差连接 | Residual | 每层都有 |
| Layer Norm | RMSNorm | 归一化层 |
