## 📌 基本定义

**序列符号表示（Sequence Notation）** 是一套用于**数学化地描述序列数据**的符号系统。它让我们能够精确地表示：
- 序列中的每个元素
- 序列的长度
- 时间步/位置信息
- 输入和输出的对应关系

### 核心目的

```
从模糊的自然语言 → 精确的数学符号

"我爱深度学习"
    ↓
x^<1>, x^<2>, x^<3>, x^<4>
```

---

## 🎯 为什么需要符号表示？

### 问题：自然语言描述不精确

```
用自然语言描述:
"把句子中的每个词输入到神经网络"
"依次处理每个时间步"
"当前输出依赖于前面的所有输入"

问题:
❌ 不够精确
❌ 难以写成代码
❌ 无法进行数学推导
❌ 容易产生歧义
```

### 解决：统一的符号系统

```
用数学符号:
x^<t>: 第 t 个时间步的输入
y^<t>: 第 t 个时间步的输出
T_x: 输入序列长度
h^<t>: 第 t 个时间步的隐藏状态

优势:
✅ 精确无歧义
✅ 便于数学推导
✅ 直接对应代码实现
✅ 国际通用标准
```

## 🔤 核心符号系统

### 1️⃣ **时间步索引 - 上标记号 `<t>`**

```
符号: x^<t>
读法: "x 上标尖括号 t"
含义: 第 t 个时间步的 x

为什么用 <t> 而不是 t？
└─ 避免与次方混淆: x² (平方) vs x^<2> (第2个时间步)
```

#### **示例：句子的时间步表示**
```
句子: "我 爱 AI"

时间步表示:
x^<1> = "我"
x^<2> = "爱"
x^<3> = "AI"

时间轴:
  t=1    t=2    t=3
   ↓      ↓      ↓
  我  →  爱  →  AI
```

---

### 2️⃣ **序列长度 - T 符号**

```
符号: T_x, T_y
含义:
├─ T_x: 输入序列的长度
└─ T_y: 输出序列的长度

注意:
- T 通常用大写
- 下标区分输入/输出
- 不同样本可以有不同的 T
```

#### **示例：可变长度序列**
```
句子1: "我爱AI"
├─ T_x^(1) = 3  (3个词)
└─ x^(1)<1> = "我", x^(1)<2> = "爱", x^(1)<3> = "AI"

句子2: "深度学习很有趣"
├─ T_x^(2) = 5  (5个词)
└─ x^(2)<1> = "深度", ..., x^(2)<5> = "有趣"

关键:
(1), (2) 表示不同的训练样本
<1>, <2>, <3> 表示同一样本内的时间步
```

---

### 3️⃣ **样本索引 - 圆括号 `(i)`**

```
符号: x^(i)<t>
读法: "第 i 个样本的第 t 个时间步"
含义:
├─ (i): 训练集中的第 i 个样本（批次维度）
└─ <t>: 该样本内的第 t 个时间步（时间维度）
```

#### **完整符号示例**
```
训练集: 2个句子

样本1: "我爱AI"
├─ x^(1)<1> = "我"
├─ x^(1)<2> = "爱"
└─ x^(1)<3> = "AI"
    T_x^(1) = 3

样本2: "DeepSeek-V3是LLM"
├─ x^(2)<1> = "DeepSeek-V3"
├─ x^(2)<2> = "是"
└─ x^(2)<3> = "LLM"
    T_x^(2) = 3
```

---

### 4️⃣ **输入与输出符号**

```
基本约定:
├─ x^<t>: 输入序列的第 t 个元素
├─ y^<t>: 输出序列的第 t 个元素
├─ ŷ^<t>: 模型预测的第 t 个输出
└─ a^<t> 或 h^<t>: 第 t 个隐藏状态/激活值
```

#### **示例：情感分类任务**
```
任务: 判断句子的情感（正面/负面）

输入序列: "这部电影太棒了"
x^<1> = "这部"
x^<2> = "电影"
x^<3> = "太棒了"
T_x = 3

输出: 正面情感
y = 1  (正面)

注意: 这是 many-to-one 任务
- 输入: 多个时间步
- 输出: 单个标签
```

#### **示例：机器翻译任务**
```
任务: 英译中

输入 (英文): "I love AI"
x^<1> = "I"
x^<2> = "love"
x^<3> = "AI"
T_x = 3

输出 (中文): "我爱人工智能"
y^<1> = "我"
y^<2> = "爱"
y^<3> = "人工智能"
T_y = 3

注意: 这是 many-to-many 任务
- T_x 可能 ≠ T_y (英文3个词，中文3个词)
```

## 🧮 词表与向量表示

### 词表（Vocabulary）

```
定义: 所有可能出现的词的集合
符号: V
大小: |V| 或 vocab_size

示例词表:
V = {"我", "爱", "AI", "深度", "学习", ...}
|V| = 10,000  (假设词表大小)  
```

### One-Hot 编码

```
定义: 将词表示为稀疏向量

假设词表:
V = ["我", "爱", "AI", "深度", "学习"]
|V| = 5

One-hot 表示:
"我"  → [1, 0, 0, 0, 0]
"爱"  → [0, 1, 0, 0, 0]
"AI"  → [0, 0, 1, 0, 0]

维度: |V| × 1 (一个词)
```

### 符号表示

```
符号: x^<t>
形状: [|V|, 1]  或记为  ℝ^|V|

完整表示:
句子 "我爱AI":
x^<1> ∈ ℝ^10000  (如果 |V| = 10000)
x^<2> ∈ ℝ^10000
x^<3> ∈ ℝ^10000

整个序列:
X = [x^<1>, x^<2>, x^<3>] ∈ ℝ^{10000 × 3}
```

## 📊 不同任务的符号表示

### 任务类型分类

根据输入输出的序列性质，可以分为 5 类：

### 1️⃣ **One-to-One（非序列任务）**
```
标准的前馈神经网络
输入: 单个向量
输出: 单个向量

示例: 图像分类
x ∈ ℝ^d      (不需要时间步标记)
y ∈ {1,...,C}

符号:
- 不使用 <t> 标记
- 就是普通的 x, y
```

### 2️⃣ **Many-to-One（序列到单值）**
```
输入: 序列 x^<1>, x^<2>, ..., x^<T_x>
输出: 单个值 y

符号表示:
输入: {x^<t>}_{t=1}^{T_x}
输出: y

示例: 情感分析
输入: "这部电影很精彩" → [x^<1>, x^<2>, ..., x^<5>]
输出: 正面 → y = 1

应用:
- 文本分类
- 视频动作识别（视频序列 → 动作类别）
```

### 3️⃣ **One-to-Many（单值到序列）**
```
输入: 单个值 x
输出: 序列 y^<1>, y^<2>, ..., y^<T_y>

符号表示:
输入: x
输出: {y^<t>}_{t=1}^{T_y}

示例: 图像描述生成
输入: 一张图片 → x ∈ ℝ^{224×224×3}
输出: "一只猫在沙发上睡觉" → [y^<1>, y^<2>, ..., y^<8>]

应用:
- 音乐生成（单个音符 → 旋律序列）
- 图像描述
```

### 4️⃣ **Many-to-Many（同步序列）**
```
输入: x^<1>, x^<2>, ..., x^<T>
输出: y^<1>, y^<2>, ..., y^<T>

特点: T_x = T_y（输入输出长度相同）

符号表示:
对于 t = 1, 2, ..., T:
  y^<t> = f(x^<1>, ..., x^<t>)

示例: 词性标注
输入: "我 爱 AI"
输出: "代词 动词 名词"

每个时间步有对应的输出:
x^<1> = "我"    → y^<1> = "代词"
x^<2> = "爱"    → y^<2> = "动词"
x^<3> = "AI"    → y^<3> = "名词"

应用:
- 命名实体识别（NER）
- 视频帧级标注
```

### 5️⃣ **Many-to-Many（异步序列）**
```
输入: x^<1>, x^<2>, ..., x^<T_x>
输出: y^<1>, y^<2>, ..., y^<T_y>

特点: T_x ≠ T_y（输入输出长度不同）

符号表示:
Encoder: 处理 {x^<t>}_{t=1}^{T_x}
Decoder: 生成 {y^<t>}_{t=1}^{T_y}

示例: 机器翻译
输入 (英文): "I love you" (T_x = 3)
输出 (中文): "我爱你" (T_y = 3)

输入 (英文): "Good morning" (T_x = 2)
输出 (中文): "早上好" (T_y = 3)

关键: T_x 和 T_y 独立确定

应用:
- 机器翻译
- 文本摘要
- 问答系统
```

## 📐 维度分析

### 单个样本的维度

```
符号        含义              维度
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
x^<t>       第 t 步输入       [n_x, 1]  或 ℝ^{n_x}
y^<t>       第 t 步输出       [n_y, 1]  或 ℝ^{n_y}
h^<t>       第 t 步隐藏状态   [n_h, 1]  或 ℝ^{n_h}

其中:
n_x: 输入特征维度 (词表大小 |V|)
n_y: 输出维度
n_h: 隐藏层维度
```

### 批量处理的维度

```
符号        含义              维度
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
X^<t>       第 t 步的批量     [n_x, m]
Y^<t>       第 t 步的批量输出 [n_y, m]
H^<t>       第 t 步的批量隐藏 [n_h, m]

其中:
m: 批量大小 (batch size)
```

### 完整序列的维度

```
符号        含义              维度
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
X           整个输入序列      [n_x, T_x, m]
Y           整个输出序列      [n_y, T_y, m]
H           所有隐藏状态      [n_h, T_x, m]

注意: 不同框架可能顺序不同
PyTorch: [batch, seq_len, features]
TensorFlow: [batch, seq_len, features]
```

## 🎨 直观理解：数据流图

### 情感分析（Many-to-One）

```
时间:   t=1      t=2      t=3      t=4
        ↓        ↓        ↓        ↓
输入:  "这"     "电影"   "很"     "棒"
       x^<1>    x^<2>    x^<3>    x^<4>
        ↓        ↓        ↓        ↓
      [RNN] → [RNN] → [RNN] → [RNN]
        ↓        ↓        ↓        ↓
       h^<1>    h^<2>    h^<3>    h^<4>
                                   ↓
                                 [分类器]
                                   ↓
                                  y = 正面

符号:
T_x = 4
x^<t> ∈ ℝ^{|V|}
h^<t> ∈ ℝ^{n_h}
y ∈ {0, 1}
```

### 机器翻译（Many-to-Many）

```
Encoder 阶段:
时间:   t=1    t=2    t=3
        ↓      ↓      ↓
输入:  "I"   "love"  "AI"
      x^<1>  x^<2>  x^<3>
        ↓      ↓      ↓
     [RNN] → [RNN] → [RNN]
        ↓      ↓      ↓
      h^<1>  h^<2>  h^<3>
                      ↓
                   context (编码器输出)
                      ↓
Decoder 阶段:
时间:   t=1    t=2    t=3
        ↓      ↓      ↓
     [RNN] → [RNN] → [RNN]
        ↓      ↓      ↓
      y^<1>  y^<2>  y^<3>
        ↓      ↓      ↓
       "我"   "爱"   "AI"

符号:
Encoder: {x^<t>}_{t=1}^{3}, T_x = 3
Decoder: {y^<t>}_{t=1}^{3}, T_y = 3
```

## 🔗 与 DeepSeek-V3 的关系

### DeepSeek-V3 的符号表示

```
任务: 语言建模（自回归生成）

输入文本: "DeepSeek-V3 是一个大语言模型"

Step 1: Token 化
tokens = ["DeepSeek", "-", "V", "3", "是", "一个", "大", "语言", "模型"]
T = 9

Step 2: 符号表示
x^<1> = "DeepSeek"
x^<2> = "-"
x^<3> = "V"
...
x^<9> = "模型"

Step 3: 自回归预测
给定 x^<1>, ..., x^<t-1>，预测 x^<t>

数学表示:
P(x^<t> | x^<1>, ..., x^<t-1>)

完整概率:
P(sentence) = ∏_{t=1}^{T} P(x^<t> | x^<1>, ..., x^<t-1>)
```

### Transformer 的符号表示

```
输入序列: X = [x^<1>, x^<2>, ..., x^<T>]
        ↓
Position Encoding: X + PE
        ↓
Multi-Head Self-Attention:
  Q^<t> = x^<t> W_Q
  K^<t> = x^<t> W_K
  V^<t> = x^<t> W_V
        ↓
Attention(Q, K, V) = softmax(QK^T / √d_k) V
        ↓
输出: Y = [y^<1>, y^<2>, ..., y^<T>]

关键:
- 每个 x^<t> 都能"看到"所有其他位置
- 用 <t> 标记位置，但不是顺序处理
```

## 💡 核心要点总结

### 1. 基本符号约定

```
符号         含义
━━━━━━━━━━━━━━━━━━━━━━━━━━━
<t>         时间步索引 (尖括号)
(i)         样本索引 (圆括号)
T_x, T_y    序列长度
x^<t>       第 t 步输入
y^<t>       第 t 步输出
h^<t>       第 t 步隐藏状态
```

### 2. 完整符号示例

```
x^(i)<t>: 第 i 个样本的第 t 个时间步输入
T_x^(i): 第 i 个样本的输入序列长度

示例:
x^(3)<5> = "学习"  (第3个样本的第5个词是"学习")
T_x^(3) = 10       (第3个样本有10个词)
```

### 3. 任务类型符号

```
Many-to-One:   {x^<t>}_{t=1}^{T_x} → y
One-to-Many:   x → {y^<t>}_{t=1}^{T_y}
Many-to-Many:  {x^<t>}_{t=1}^{T_x} → {y^<t>}_{t=1}^{T_y}
```

### 4. 维度标记

```
x^<t> ∈ ℝ^{n_x}     (输入维度)
y^<t> ∈ ℝ^{n_y}     (输出维度)
h^<t> ∈ ℝ^{n_h}     (隐藏层维度)
```

### 2. 区分不同的括号

```
符号         示例         含义
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

(i)         x^(2)       第2个样本

组合:
x^(i)<t> = 第 i 个样本的第 t 个时间步
```

## 📖 符号速查表

### 快速参考

| 符号 | 读法 | 含义 | 示例 |
|-----|------|------|------|
| `x^<t>` | x 上标 t | 第 t 步输入 | x^<3> = "AI" |
| `y^<t>` | y 上标 t | 第 t 步输出 | y^<2> = "爱" |
| `x^(i)` | x 圆括号 i | 第 i 个样本 | x^(5) = 第5个句子 |
| `T_x` | T 下标 x | 输入序列长度 | T_x = 10 |
| `T_y` | T 下标 y | 输出序列长度 | T_y = 8 |
| `h^<t>` | h 上标 t | 第 t 步隐藏状态 | h^<5> ∈ ℝ^{128} |
| `x^(i)<t>` | 组合 | 第 i 样本第 t 步 | x^(3)<7> |
| `|V|` | V 的大小 | 词表大小 | \|V\| = 10000 |
