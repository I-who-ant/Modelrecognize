## 📌 基本定义

**循环神经网络（Recurrent Neural Network, RNN）** 是一类专门用于处理**序列数据**的神经网络，其核心特点是：
- ✅ 具有**循环连接**（recurrent connection）
- ✅ 具有**内部状态**（隐藏状态 h^<t>）
- ✅ 能够**捕捉时间依赖**关系
- ✅ 在所有时间步**共享参数**

### 核心思想

```
传统神经网络: 独立处理每个输入
RNN: 当前输出依赖于当前输入 + 历史信息

数学表达:
h^<t> = f(W_hh · h^<t-1> + W_xh · x^<t> + b_h)
y^<t> = g(W_hy · h^<t> + b_y)

关键:
h^<t-1> → 历史信息（循环连接）
```

---

## 🎯 为什么需要 RNN？

### 回顾：传统网络的问题

```
传统前馈网络（Feedforward Neural Network）:
输入 x → 隐藏层 h → 输出 y

问题:
❌ 无法处理序列数据
❌ 不保留历史信息
❌ 无法捕捉时间依赖

示例:
"我爱深度学习" vs "深度学习爱我"
→ 传统网络无法区分词序
```

### RNN 的解决方案

```
RNN 的核心创新: 循环连接

时间 t-1           时间 t           时间 t+1
   ↓                 ↓                 ↓
  x^<t-1>           x^<t>            x^<t+1>
   ↓                 ↓                 ↓
  [RNN] ←------→   [RNN] ←------→   [RNN]
   ↓     循环         ↓     循环        ↓
  h^<t-1>           h^<t>            h^<t+1>
   ↓                 ↓                 ↓
  y^<t-1>           y^<t>            y^<t+1>

关键:
✅ h^<t> 包含了从 h^<0> 到 h^<t-1> 的所有历史信息 （循环连接）
✅ 相同的参数在所有时间步复用
✅ 可以处理任意长度的序列
```

## 🧮 RNN 的数学原理

### 1️⃣ **核心公式**

```
隐藏状态更新（核心）:
h^<t> = tanh(W_hh · h^<t-1> + W_xh · x^<t> + b_h)

输出计算:
y^<t> = W_hy · h^<t> + b_y

如果是分类任务:
ŷ^<t> = softmax(y^<t>)
```

#### **符号说明**

| 符号 | 含义 | 维度 |
|------|------|------|
| `x^<t>` | 第 t 步输入 | [n_x, 1] |
| `h^<t>` | 第 t 步隐藏状态 | [n_h, 1] |
| `y^<t>` | 第 t 步输出 | [n_y, 1] |
| `W_xh` | 输入到隐藏层的权重 | [n_h, n_x] |
| `W_hh` | 隐藏层到隐藏层的权重 | [n_h, n_h] |
| `W_hy` | 隐藏层到输出的权重 | [n_y, n_h] |
| `b_h` | 隐藏层偏置 | [n_h, 1] |
| `b_y` | 输出层偏置 | [n_y, 1] |

---

### 2️⃣ **简化形式（向量拼接）**

```
将输入和隐藏状态拼接:
h^<t> = tanh(W · [h^<t-1>, x^<t>] + b)

其中:
W = [W_hh | W_xh]  拼接矩阵
[h^<t-1>, x^<t>] = [h^<t-1>  垂直拼接
                     x^<t>]

维度:
W: [n_h, n_h + n_x]
[h^<t-1>, x^<t>]: [n_h + n_x, 1]
结果: [n_h, 1]
```

---

### 3️⃣ **初始化隐藏状态**

```
第一个时间步 t=1:
h^<0> = 0  (通常初始化为零向量)
或
h^<0> = 某个学到的向量

所以:
h^<1> = tanh(W_hh · 0 + W_xh · x^<1> + b_h)
      = tanh(W_xh · x^<1> + b_h)
```

## 🔄 RNN 的展开结构

### 循环形式（Folded）

```
这是 RNN 的"折叠"表示：

     x^<t>
       ↓
    ┌─────┐
    │ RNN │←──── h^<t-1> (循环连接)
    └─────┘
       ↓
     y^<t>

特点:
- 紧凑表示
- 强调循环连接
- 参数共享清晰
```

### 展开形式（Unfolded）

```
这是 RNN 的"展开"表示（更直观）：

时间:  t=0    t=1      t=2      t=3      t=4
       ↓      ↓        ↓        ↓        ↓
      h^<0>  x^<1>    x^<2>    x^<3>    x^<4>
       ↓      ↓        ↓        ↓        ↓
       0 → [RNN] → [RNN] → [RNN] → [RNN]
            ↓   ↓    ↓   ↓    ↓   ↓    ↓   ↓
           h^<1>   h^<2>   h^<3>   h^<4>
            ↓       ↓       ↓       ↓
           y^<1>   y^<2>   y^<3>   y^<4>

特点:
- 每个时间步是同一个 RNN 单元
- 箭头 → 表示信息流动方向
- 所有 [RNN] 共享相同的参数 W, b
```

## 💻 RNN 前向传播详细步骤

### 伪代码实现

```python
def rnn_forward(x, h_prev, W_xh, W_hh, W_hy, b_h, b_y):
    """
    单个时间步的前向传播

    参数:
        x: 当前输入, shape [n_x, 1]
        h_prev: 前一时刻隐藏状态, shape [n_h, 1]
        W_xh: 输入到隐藏权重, shape [n_h, n_x]
        W_hh: 隐藏到隐藏权重, shape [n_h, n_h]
        W_hy: 隐藏到输出权重, shape [n_y, n_h]
        b_h: 隐藏层偏置, shape [n_h, 1]
        b_y: 输出层偏置, shape [n_y, 1]

    返回:
        h_next: 当前时刻隐藏状态, shape [n_h, 1]
        y: 当前时刻输出, shape [n_y, 1]
    """
    # 计算隐藏状态
    h_next = np.tanh(
        np.dot(W_hh, h_prev) +
        np.dot(W_xh, x) +
        b_h
    )

    # 计算输出
    y = np.dot(W_hy, h_next) + b_y

    # 如果是分类任务，还需要 softmax
    # y_hat = softmax(y)

    return h_next, y


def rnn_forward_sequence(X, h0, params):
    """
    完整序列的前向传播

    参数:
        X: 输入序列, list of [n_x, 1], 长度 T_x
        h0: 初始隐藏状态, shape [n_h, 1]
        params: 字典，包含 W_xh, W_hh, W_hy, b_h, b_y

    返回:
        H: 所有隐藏状态, list of [n_h, 1]
        Y: 所有输出, list of [n_y, 1]
    """
    T_x = len(X)
    H = []
    Y = []

    h = h0
    for t in range(T_x):
        h, y = rnn_forward(
            X[t], h,
            params['W_xh'], params['W_hh'], params['W_hy'],
            params['b_h'], params['b_y']
        )
        H.append(h)
        Y.append(y)

    return H, Y
```

### 示例计算（情感分析）

```
任务: 判断 "这电影很棒" 的情感

Step 1: 初始化
h^<0> = [0, 0, 0]  (假设 n_h = 3)

Step 2: 时间步 t=1，输入 "这"
x^<1> = one-hot("这") ∈ ℝ^10000
h^<1> = tanh(W_hh·[0,0,0] + W_xh·x^<1> + b_h)
      = tanh(W_xh·x^<1> + b_h)
      = [0.5, -0.2, 0.8]  (示例值)

Step 3: 时间步 t=2，输入 "电影"
x^<2> = one-hot("电影")
h^<2> = tanh(W_hh·[0.5,-0.2,0.8] + W_xh·x^<2> + b_h)
      = [0.3, 0.6, -0.1]  (示例值)

Step 4: 时间步 t=3，输入 "很"
h^<3> = tanh(W_hh·h^<2> + W_xh·x^<3> + b_h)
      = [0.7, 0.4, 0.2]

Step 5: 时间步 t=4，输入 "棒"
h^<4> = tanh(W_hh·h^<3> + W_xh·x^<4> + b_h)
      = [0.9, 0.8, 0.5]

Step 6: 输出层（使用最后的隐藏状态）
y = sigmoid(W_hy·h^<4> + b_y)
  = sigmoid([1.0, -0.5] · [0.9, 0.8, 0.5] + [0.1])
  = [0.85]  → 正面情感

关键:
✅ h^<4> 包含了整个句子的信息
✅ 每个时间步的 h 都携带了历史信息
```

## 🔙 RNN 的反向传播（BPTT）

### BPTT（Backpropagation Through Time）原理

```
问题: RNN 是在时间维度上展开的网络
解决: 沿着时间反向传播梯度

计算图:
t=1     t=2     t=3     t=4
 ↓       ↓       ↓       ↓
x^<1> → x^<2> → x^<3> → x^<4>
 ↓       ↓       ↓       ↓
[RNN] → [RNN] → [RNN] → [RNN]
 ↓       ↓       ↓       ↓
h^<1> → h^<2> → h^<3> → h^<4>
 ↓       ↓       ↓       ↓
y^<1>   y^<2>   y^<3>   y^<4>
 ↓       ↓       ↓       ↓
L^<1>   L^<2>   L^<3>   L^<4>

总损失: L = Σ L^<t>

反向传播:
从 t=4 → t=3 → t=2 → t=1
梯度沿着时间反向流动
```

---

### 梯度计算公式

```
1. 输出层梯度（从损失函数开始）:
∂L/∂y^<t> = ... (取决于损失函数)

2. 隐藏层梯度（关键！）:
∂L/∂h^<t> = ∂L/∂y^<t> · ∂y^<t>/∂h^<t> + ∂L/∂h^<t+1> · ∂h^<t+1>/∂h^<t>
            └─────────┬────────┘       └──────────┬──────────┘
              当前时刻的梯度              下一时刻传回的梯度

3. 权重梯度（累加所有时间步）:
∂L/∂W_hy = Σ_t (∂L/∂y^<t> · h^<t>^T)
∂L/∂W_hh = Σ_t (∂L/∂h^<t> · h^<t-1>^T)
∂L/∂W_xh = Σ_t (∂L/∂h^<t> · x^<t>^T)
```

---

### 梯度消失问题（RNN 的致命缺陷）

```
问题: 梯度需要从 t=T 反向传播到 t=1

梯度链式法则:
∂L/∂h^<1> = ∂L/∂h^<T> · ∂h^<T>/∂h^<T-1> · ... · ∂h^<2>/∂h^<1>

关键项: ∂h^<t+1>/∂h^<t>
= ∂/∂h^<t> [tanh(W_hh·h^<t> + ...)]
= (1 - tanh²(·)) · W_hh

问题分析:
├─ 如果 |W_hh| < 1 且 tanh 梯度 < 1
│  → 连乘 T 次后 → 梯度消失（vanishing gradient）
│  → 长期依赖无法学习
│
└─ 如果 |W_hh| > 1
   → 连乘 T 次后 → 梯度爆炸（exploding gradient）
   → 训练不稳定

数值示例:
假设 ∂h^<t+1>/∂h^<t> ≈ 0.5
传播 10 步: 0.5^10 ≈ 0.001 ← 梯度消失！
传播 100 步: 0.5^100 ≈ 10^-31 ← 完全消失！
```

## 📊 不同 RNN 架构变体

### 1️⃣ **Vanilla RNN（标准 RNN）**

```
结构: 最基础的 RNN
h^<t> = tanh(W·[h^<t-1>, x^<t>] + b)

优点:
✅ 简单直观
✅ 参数少

缺点:
❌ 梯度消失严重
❌ 只能捕捉短期依赖（约 10 步）
```

---

### 2️⃣ **双向 RNN（Bidirectional RNN）**

```
结构: 同时从前向和后向处理序列

前向:  → → → →
      x1 x2 x3 x4
后向:  ← ← ← ←

h^<t> = [h_forward^<t>, h_backward^<t>]

应用:
- 命名实体识别（NER）
- 词性标注
- 机器翻译的 Encoder

限制:
❌ 需要看到完整序列（不能用于实时生成）
```

---

### 3️⃣ **深层 RNN（Deep RNN）**

```
结构: 多层堆叠

层3: → → → →
层2: → → → →
层1: → → → →
输入: x1 x2 x3 x4

公式:
h_l^<t> = tanh(W_l·[h_l^<t-1>, h_{l-1}^<t>] + b_l)

优点:
✅ 更强的表达能力

缺点:
❌ 梯度消失更严重
❌ 训练更困难
```

## 🎨 直观理解：记忆与遗忘

### 类比：看电影的过程

```
传统网络 = 看照片
RNN = 看电影，边看边记笔记

时间 t=1: 看到主角拿起杯子
→ 记住: "主角手里有杯子"
→ h^<1> = [0.8, ...]

时间 t=2: 看到主角走向水龙头
→ 记住: "手里有杯子" + "正在走向水龙头"
→ h^<2> = [0.7, 0.5, ...]

时间 t=3: 看到主角接水
→ 记住: "接水"（杯子信息仍保留）
→ h^<3> = [0.6, 0.4, 0.9, ...]

时间 t=4: 看到主角喝水
→ 理解: "主角在喝水"（基于所有历史）
→ h^<4> = [0.5, 0.3, 0.8, 0.7]

问题: 如果电影很长（100 个镜头）
→ 笔记会模糊（梯度消失）
→ 记不住开头的情节（长期依赖丢失）
```

---

### 隐藏状态的本质

```
h^<t> 就像是一个"压缩的记忆"

例如:
句子: "我昨天在北京吃了烤鸭，今天来到上海"

h^<3> (处理完"北京"后):
[0.8, -0.2, 0.5, ...]
  ↑     ↑     ↑
  表示  表示  表示
  "地点" "时间" "动作"

h^<7> (处理完"上海"后):
[0.9, -0.1, 0.3, ...]
  ↑
  更新了地点信息，但"北京"的信息在衰减

问题: 如果句子很长，早期的信息会被"覆盖"
→ 这就是 RNN 的根本缺陷
```

## 🔗 与 DeepSeek-V3 的关系

### RNN 的历史地位

```
深度学习序列模型演进史:

2010-2015: RNN 时代
├─ RNN 是处理序列的主流方法
├─ 应用：语音识别、机器翻译
└─ 局限：梯度消失、无法并行

2014-2016: LSTM/GRU 时代
├─ 通过门控机制缓解梯度消失
├─ 能捕捉更长的依赖（约 100 步）
└─ 局限：仍然是顺序处理、慢

2017-现在: Transformer 时代
├─ 完全抛弃循环结构
├─ 使用 Self-Attention 机制
├─ 可以并行训练
└─ DeepSeek-V3 就是基于 Transformer！

结论:
RNN 是理解 Transformer 的基础
需要理解 RNN 的局限，才能理解 Transformer 为什么伟大
```

### DeepSeek-V3 vs RNN

| 特性 | RNN | DeepSeek-V3 (Transformer) |
|------|-----|---------------------------|
| **核心机制** | 循环连接 | Self-Attention ⭐ |
| **处理方式** | 顺序处理（t=1→2→3...） | 并行处理 ⭐ |
| **长期依赖** | ❌ 梯度消失，约 10-100 步 | ✅ 任意长度 ⭐ |
| **训练速度** | ❌ 慢（无法并行） | ✅ 快（GPU 加速） ⭐ |
| **参数共享** | ✅ 所有时间步共享 W | ✅ 所有位置共享 W_Q, W_K, W_V |
| **位置信息** | ✅ 隐式（通过循环） | ✅ 显式（Position Encoding）|
| **典型应用** | 早期 NLP 任务 | 现代 LLM（GPT, DeepSeek-V3）|

## 💡 核心要点总结

### 1. RNN 的核心公式

```
h^<t> = tanh(W_hh·h^<t-1> + W_xh·x^<t> + b_h)
y^<t> = W_hy·h^<t> + b_y

关键:
├─ h^<t-1> → 循环连接（携带历史）
├─ tanh → 激活函数（非线性）
└─ 参数 W, b 在所有时间步共享
```

---

### 2. RNN 的优点

```
✅ 可以处理任意长度序列
✅ 参数数量不随序列长度增长
✅ 理论上可以捕捉长期依赖
✅ 参数共享（泛化能力强）
```

---

### 3. RNN 的缺点（致命）

```
❌ 梯度消失/爆炸（长期依赖丢失）
❌ 顺序处理（无法并行，训练慢）
❌ 实际只能记住约 10-100 步
❌ 训练不稳定
```

---

### 4. 典型应用

```
🔤 NLP: 情感分析、命名实体识别、语言模型
🎵 语音: 语音识别、语音合成
📈 时序: 股票预测、天气预报
🎬 视频: 动作识别、视频描述生成
```

## 🎓 学习建议

### 1. 重点理解三件事

```
1. 循环连接的意义
   └─ h^<t> 依赖于 h^<t-1>
   └─ 历史信息的传递

2. 参数共享
   └─ 所有时间步用同一个 W
```
