## 📌 基本定义

**词嵌入学习** 是指通过在大规模文本语料上训练神经网络模型,自动学习词的低维稠密向量表示,使得语义相近的词在向量空间中接近。

### 核心思想

```
分布式假设 (Distributional Hypothesis):
"You shall know a word by the company it keeps"
(通过一个词的上下文来理解这个词)

核心原理:
✅ 上下文相似的词,语义相似
✅ 通过预测任务学习词表示
✅ 无监督学习 (只需文本语料)

主流算法:
1. Word2Vec (2013)
   - CBOW: 用上下文预测中心词
   - Skip-gram: 用中心词预测上下文

2. GloVe (2014)
   - 基于全局词共现统计

3. FastText (2016)
   - Word2Vec + 子词信息
```

## 🧮 Word2Vec 算法

### 算法概览

```
Word2Vec 有两种架构:

1. CBOW (Continuous Bag of Words)
   输入: 上下文词
   输出: 中心词
   目标: 用周围词预测中心词

2. Skip-gram
   输入: 中心词
   输出: 上下文词
   目标: 用中心词预测周围词

训练语料:
"The quick brown fox jumps over the lazy dog"

窗口大小 m = 2:
中心词: "fox"
上下文: ["quick", "brown", "jumps", "over"]

CBOW: ["quick", "brown", "jumps", "over"] → "fox"
Skip-gram: "fox" → "quick", "brown", "jumps", "over"
```

---

### CBOW 架构

```
Continuous Bag of Words (CBOW)
────────────────────────────────

输入层: 上下文词的 one-hot 表示
  o_{c-m}, ..., o_{c-1}, o_{c+1}, ..., o_{c+m}

嵌入层: 查找词向量
  e_{c-m}, ..., e_{c-1}, e_{c+1}, ..., e_{c+m}

隐藏层: 平均上下文词向量
  h = (e_{c-m} + ... + e_{c+m}) / (2m)

输出层: softmax 预测中心词
  P(w_c | context) = softmax(W_out · h)

损失函数:
  L = -log P(w_c | context)

网络结构:
     o_{c-2}   o_{c-1}   o_{c+1}   o_{c+2}
       ↓         ↓         ↓         ↓
    [嵌入层 E: vocab_size × d]
       ↓         ↓         ↓         ↓
     e_{c-2}   e_{c-1}   e_{c+1}   e_{c+2}
       └─────────┴─────────┴─────────┘
                    ↓
               平均 → h
                    ↓
         [输出层 W_out: vocab_size × d]
                    ↓
               softmax
                    ↓
            P(w_c | context)

参数:
- 嵌入矩阵 E: [vocab_size, d]
- 输出矩阵 W_out: [vocab_size, d]

总参数量: 2 × vocab_size × d
```

---

### Skip-gram 架构

```
Skip-gram
──────────

输入层: 中心词的 one-hot 表示
  o_c

嵌入层: 查找词向量
  e_c = E · o_c

输出层: 对每个上下文词预测
  P(w_{c+j} | w_c) = softmax(W_out · e_c)

目标: 最大化
  P(context | w_c) = ∏_{-m≤j≤m, j≠0} P(w_{c+j} | w_c)

损失函数:
  L = -Σ_{-m≤j≤m, j≠0} log P(w_{c+j} | w_c)

网络结构:
       w_c (中心词)
         ↓
      [嵌入层 E]
         ↓
        e_c
         ↓
    [输出层 W_out]
         ↓
      softmax
         ↓
    ┌────┴────┬────┬────┐
    ↓         ↓    ↓    ↓
P(w_{c-2}) P(w_{c-1}) P(w_{c+1}) P(w_{c+2})

关键区别:
CBOW: 多个输入 → 一个输出
Skip-gram: 一个输入 → 多个输出

实践经验:
✅ Skip-gram 在小数据上更好
✅ CBOW 训练更快
✅ Skip-gram 对低频词效果更好
```

## ⚡ 负采样 (Negative Sampling)

### 问题: Softmax 计算代价高

```
原始 softmax:
P(w_o | w_c) = exp(u_o^T · v_c) / Σ_{w∈V} exp(u_w^T · v_c)
                                   └──────┬──────┘
                              需要遍历整个词汇表!

计算复杂度: O(|V|)
对于 vocab_size = 100,000, 每个样本需要计算 100,000 次指数

问题:
❌ 训练极慢
❌ 内存占用大
❌ 难以扩展到大词汇表

示例:
训练 1 亿词 × 100,000 词汇表 = 10^13 次运算!
```

---

### 负采样的解决方案

```
核心思想:
不计算完整 softmax
而是采样少量"负样本"进行对比

正样本: 真实的上下文词对
负样本: 随机采样的不相关词对

目标函数:
──────────

原始 (softmax):
  max log P(w_o | w_c)

负采样:
  max log σ(u_o^T · v_c)  +  Σ_{i=1}^k E_{w_i ~ P_n(w)} [log σ(-u_i^T · v_c)]
      └──────┬──────┘        └───────────────┬───────────────┘
       正样本最大化                   负样本最小化

其中:
- σ: sigmoid 函数
- k: 负样本数量 (通常 5-20)
- P_n(w): 负样本分布 (通常 ∝ freq(w)^{3/4})

示例:
────

输入: "fox" → "jumps" (正样本)

正样本: ("fox", "jumps") → 希望 σ(u_{jumps}^T · v_{fox}) → 1

负样本: 从词汇表随机采样 k 个词
  ("fox", "banana") → 希望 σ(u_{banana}^T · v_{fox}) → 0
  ("fox", "computer") → 希望 σ(u_{computer}^T · v_{fox}) → 0
  ("fox", "happy") → 希望 σ(u_{happy}^T · v_{fox}) → 0
  ...

只需要计算 1 + k 个词,而不是整个词汇表!

复杂度:
原始: O(|V|)
负采样: O(k)  (k << |V|)

速度提升: 100,000 / 10 = 10,000 倍!
```

---

### 负样本分布

```
如何选择负样本?

朴素方法: 均匀分布
  P(w) = 1 / |V|

问题:
❌ 高频词被过度采样
❌ 低频词被忽略

Word2Vec 方法: 频率的 3/4 次方
  P(w) ∝ count(w)^{3/4}

原理:
- 完全均匀: 高频词权重过大
- 直接频率: 低频词权重过小
- 3/4 次方: 折中方案

示例:
     词      频率   均匀分布  频率分布  3/4次方分布
─────────────────────────────────────────────
    the      100    0.001     0.333     0.178
    is        50    0.001     0.167     0.119
    dog       10    0.001     0.033     0.032
    rare       1    0.001     0.003     0.006

观察:
✅ 3/4 次方平滑了频率差异
✅ 高频词仍有较高概率
✅ 低频词也有合理概率
```

## 💻 Word2Vec 完整实现

### Skip-gram + 负采样

```python
import numpy as np
from collections import Counter

class Word2VecSkipGram:
    """
    Skip-gram with Negative Sampling
    """
    def __init__(self, vocab_size, embedding_dim, learning_rate=0.025,
                 neg_samples=5, window_size=2):
        """
        参数:
            vocab_size: 词汇表大小
            embedding_dim: 嵌入维度
            learning_rate: 学习率
            neg_samples: 负样本数量
            window_size: 上下文窗口大小
        """
        self.vocab_size = vocab_size
        self.embedding_dim = embedding_dim
        self.lr = learning_rate
        self.neg_samples = neg_samples
        self.window_size = window_size

        # 初始化嵌入矩阵
        # 输入嵌入 (中心词)
        self.W_in = np.random.uniform(
            -0.5/embedding_dim, 0.5/embedding_dim,
            (vocab_size, embedding_dim)
        )

        # 输出嵌入 (上下文词)
        self.W_out = np.zeros((vocab_size, embedding_dim))

    def sigmoid(self, x):
        """Sigmoid 函数"""
        return 1 / (1 + np.exp(-np.clip(x, -500, 500)))

    def train_pair(self, center_idx, context_idx, negative_indices):
        """
        训练单个词对

        参数:
            center_idx: 中心词索引
            context_idx: 上下文词索引 (正样本)
            negative_indices: 负样本索引列表
        """
        # 中心词向量
        v_center = self.W_in[center_idx]  # [d]

        # === 正样本 ===
        u_pos = self.W_out[context_idx]  # [d]
        score_pos = np.dot(v_center, u_pos)
        pred_pos = self.sigmoid(score_pos)

        # 梯度
        grad_pos = self.lr * (1 - pred_pos)
        self.W_out[context_idx] += grad_pos * v_center
        grad_center = grad_pos * u_pos

        # === 负样本 ===
        for neg_idx in negative_indices:
            u_neg = self.W_out[neg_idx]
            score_neg = np.dot(v_center, u_neg)
            pred_neg = self.sigmoid(score_neg)

            # 梯度 (希望 pred_neg → 0)
            grad_neg = -self.lr * pred_neg
            self.W_out[neg_idx] += grad_neg * v_center
            grad_center += grad_neg * u_neg

        # 更新中心词向量
        self.W_in[center_idx] += grad_center

    def train(self, corpus_indices, word_freqs, epochs=5):
        """
        训练 Word2Vec

        参数:
            corpus_indices: 语料索引列表
            word_freqs: 词频字典 {word_idx: count}
            epochs: 训练轮数
        """
        corpus_len = len(corpus_indices)

        # 构建负采样分布 (频率的 3/4 次方)
        total_count = sum(word_freqs.values())
        neg_sample_probs = np.zeros(self.vocab_size)

        for idx, count in word_freqs.items():
            neg_sample_probs[idx] = (count / total_count) ** 0.75

        neg_sample_probs /= neg_sample_probs.sum()

        print(f"开始训练 Word2Vec (Skip-gram)")
        print(f"  词汇表大小: {self.vocab_size}")
        print(f"  语料长度: {corpus_len}")
        print(f"  窗口大小: {self.window_size}")
        print(f"  负样本数: {self.neg_samples}")
        print(f"  训练轮数: {epochs}")
        print()

        for epoch in range(epochs):
            total_loss = 0
            num_pairs = 0

            for i in range(corpus_len):
                # 中心词
                center_idx = corpus_indices[i]

                # 上下文窗口
                window_start = max(0, i - self.window_size)
                window_end = min(corpus_len, i + self.window_size + 1)

                for j in range(window_start, window_end):
                    if j == i:
                        continue

                    context_idx = corpus_indices[j]

                    # 采样负样本
                    negative_indices = np.random.choice(
                        self.vocab_size,
                        size=self.neg_samples,
                        replace=False,
                        p=neg_sample_probs
                    )

                    # 训练
                    self.train_pair(center_idx, context_idx, negative_indices)
                    num_pairs += 1

            print(f"Epoch {epoch+1}/{epochs} 完成, 训练了 {num_pairs} 个词对")

        print("训练完成!")

    def get_embedding(self, word_idx):
        """获取词的嵌入向量"""
        return self.W_in[word_idx]

    def most_similar(self, word_idx, top_k=5):
        """找到最相似的词"""
        query = self.W_in[word_idx]

        # 计算余弦相似度
        similarities = []
        for idx in range(self.vocab_size):
            if idx == word_idx:
                continue

            vec = self.W_in[idx]
            cos_sim = np.dot(query, vec) / (
                np.linalg.norm(query) * np.linalg.norm(vec) + 1e-10
            )
            similarities.append((idx, cos_sim))

        # 排序
        similarities.sort(key=lambda x: x[1], reverse=True)
        return similarities[:top_k]


# 使用示例
if __name__ == "__main__":
    # 模拟语料
    text = """
    the quick brown fox jumps over the lazy dog
    the dog runs fast in the park
    the cat sits on the mat
    the brown cat and the black dog
    """.lower().split()

    # 构建词汇表
    word_counter = Counter(text)
    vocab = {word: idx for idx, (word, _) in enumerate(word_counter.most_common())}
    idx2word = {idx: word for word, idx in vocab.items()}
    vocab_size = len(vocab)

    # 转换为索引
    corpus_indices = [vocab[word] for word in text]

    # 词频
    word_freqs = {vocab[word]: count for word, count in word_counter.items()}

    print("=" * 60)
    print("Word2Vec 训练示例")
    print("=" * 60)
    print(f"词汇表: {list(vocab.keys())}")
    print(f"词汇表大小: {vocab_size}")
    print(f"语料长度: {len(corpus_indices)}")
    print()

    # 创建模型
    model = Word2VecSkipGram(
        vocab_size=vocab_size,
        embedding_dim=10,
        learning_rate=0.025,
        neg_samples=3,
        window_size=2
    )

    # 训练
    model.train(corpus_indices, word_freqs, epochs=20)
    print()

    # 测试
    test_words = ['the', 'dog', 'cat']
    for word in test_words:
        if word in vocab:
            word_idx = vocab[word]
            print(f"与 '{word}' 最相似的词:")
            similar = model.most_similar(word_idx, top_k=3)
            for idx, sim in similar:
                print(f"  {idx2word[idx]:10s}: {sim:.4f}")
            print()

## 🌐 GloVe 算法

### 核心思想

```
GloVe (Global Vectors for Word Representation)

与 Word2Vec 的区别:
Word2Vec: 基于局部上下文窗口
GloVe: 基于全局词共现统计

核心思想:
词向量应该编码词-词共现统计信息

共现矩阵 X:
  X_ij = 词 i 和词 j 在窗口内共现的次数

示例语料:
"I like deep learning. I like NLP."

共现矩阵 (窗口=1):
        I  like  deep  learning  NLP
I       0    2     0      0       0
like    2    0     1      0       1
deep    0    1     0      1       0
learning 0   0     1      0       0
NLP     0    1     0      0       0

目标函数:
───────

J = Σ_{i,j=1}^{|V|} f(X_ij) (w_i^T · w̃_j + b_i + b̃_j - log X_ij)^2

其中:
- w_i: 词 i 的嵌入向量
- w̃_j: 词 j 的上下文向量
- b_i, b̃_j: 偏置项
- f(X_ij): 权重函数

权重函数 f:
  f(x) = (x / x_max)^α   if x < x_max
         1               otherwise

通常: x_max = 100, α = 0.75

直觉:
✅ 高频共现: 权重大 (重要)
✅ 低频共现: 权重小 (噪声)
✅ 过高频: 截断 (避免 "the", "a" 主导)
```

### GloVe vs Word2Vec

```
对比总结:
──────────

Word2Vec (Skip-gram):
- 局部窗口
- 在线学习 (SGD)
- 快速训练
- 适合大语料

GloVe:
- 全局共现统计
- 批量学习
- 需要预先统计
- 适合中等语料

性能:
- 相似任务上性能相近
- GloVe 在词类比任务上略好
- Word2Vec 在相似度任务上略好

实践建议:
✅ 大语料 (>1B 词): Word2Vec
✅ 中等语料: GloVe
✅ 需要增量训练: Word2Vec
✅ 有预计算资源: GloVe
```

## 🎨 FastText

### 核心创新

```
FastText = Word2Vec + 子词 (Subword) 信息

问题:
Word2Vec/GloVe 将词视为原子单位
无法利用词的内部结构

示例:
"unhappiness" = "un" + "happy" + "ness"

Word2Vec:
"unhappiness" → 单一向量
如果训练集没见过,则无法处理 (OOV)

FastText:
"unhappiness" → "un" + "happy" + "ness" + "unhappiness"
即使没见过,也能通过子词组合得到表示!

子词表示:
──────────

n-gram 字符:
"apple" → ["<ap", "app", "ppl", "ple", "le>"]
          + "apple"

最终向量:
v("apple") = Σ v(n-gram) / num_ngrams

优势:
✅ 处理 OOV (词汇表外词)
✅ 处理形态丰富的语言 (如德语、芬兰语)
✅ 捕捉词缀信息 (前缀、后缀)
✅ 拼写错误鲁棒性

示例:
训练集有 "running"
FastText 可以推断 "runs", "runner" 的向量
因为它们共享 "run" 这个子词

适用场景:
✅ 形态丰富的语言
✅ 低资源语言
✅ 需要处理 OOV
✅ 社交媒体文本 (拼写变体多)
```

## 💡 核心要点总结

### 词嵌入学习的四个关键

```
1. 分布式假设
   词的意义由其上下文决定
   上下文相似 → 语义相似

2. 预测任务
   CBOW: 上下文 → 中心词
   Skip-gram: 中心词 → 上下文
   GloVe: 共现矩阵分解

3. 负采样优化
   避免完整 softmax
   只计算少量负样本
   速度提升数千倍

4. 子词信息
   FastText 利用字符 n-gram
   处理 OOV 和形态变化
```

---

### 算法选择指南

```
情况 1: 大规模语料 (>1B 词)
→ Word2Vec Skip-gram + 负采样

情况 2: 中等语料 + 有计算资源
→ GloVe

情况 3: 形态丰富语言 (德语、芬兰语)
→ FastText

情况 4: 低资源语言 / 拼写变体多
→ FastText

情况 5: 需要增量训练
→ Word2Vec

情况 6: 追求最佳性能 + 有时间
→ 都试试,选最好的
```

### 超参数调优

```
嵌入维度 (d):
- 小数据: 50-100
- 中等: 100-300
- 大数据: 300-500
- 过大: 过拟合

窗口大小 (m):
- 小窗口 (2-5): 捕捉句法
- 大窗口 (5-10): 捕捉语义
- 实践: 5 是常用值

负样本数 (k):
- 小数据: 5-10
- 大数据: 2-5
- 实践: 5 是常用值

学习率:
- 初始: 0.025
- 衰减: 线性下降到 0.0001

最小词频:
- 过滤低频词
- 通常: 5 或 10

训练轮数:
- 小数据: 10-20
- 大数据: 5-10
