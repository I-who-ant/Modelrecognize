## 📌 基本定义

**情感分类 (Sentiment Classification)** 是判断文本情感倾向的任务，通常分为正面/负面/中性。使用词嵌入可以显著提升性能。

### 任务定义

```
情感分类任务:
═══════════

输入: 一段文本（评论、推文、评价等）
输出: 情感标签

常见设定:
────────

二分类:
  正面 (Positive): ⭐⭐⭐⭐⭐
  负面 (Negative): ⭐

三分类:
  正面 (Positive)
  中性 (Neutral)
  负面 (Negative)

五分类:
  非常正面 ⭐⭐⭐⭐⭐
  正面 ⭐⭐⭐⭐
  中性 ⭐⭐⭐
  负面 ⭐⭐
  非常负面 ⭐

示例:
────

文本: "This movie is amazing! I love it!"
标签: Positive (正面)

文本: "Terrible service, never coming back."
标签: Negative (负面)

应用场景:
────────

✅ 产品评论分析
✅ 社交媒体监控
✅ 客户反馈分析
✅ 舆情监测
✅ 市场调研
```

## 🎯 为什么使用词嵌入？

### 传统方法的问题

```
方法 1: 词袋模型 (Bag of Words)
══════════════════════════════

表示:
  "I love this movie" → [1, 1, 1, 1, 0, 0, ...]
  词汇表中的词: [I, love, this, movie, hate, bad, ...]
                 ↑   ↑    ↑    ↑     ↓    ↓
                 1   1    1    1     0    0

问题:
❌ 丢失词序信息
   "I love this" vs "this love I" (相同表示)
❌ 高维稀疏
   词汇表 10,000 → 10,000 维向量
❌ 无语义信息
   "love" 和 "like" 是独立维度

方法 2: TF-IDF
═══════════════

改进:
  考虑词频和逆文档频率
  降低常见词（"the", "a"）权重

问题:
❌ 仍然稀疏
❌ 仍然无语义
❌ 仍然丢失词序

方法 3: N-gram
══════════════

表示:
  Unigram: ["I", "love", "this", "movie"]
  Bigram: ["I love", "love this", "this movie"]
  Trigram: ["I love this", "love this movie"]

改进:
  ✅ 保留部分词序信息

问题:
❌ 维度爆炸
   词汇表 10K → Bigram 100M 维
❌ 数据稀疏
   大部分 n-gram 从未出现
```

---

### 词嵌入的优势

```
使用词嵌入:
═══════════

表示:
  "I love this movie"
  → [e_I, e_love, e_this, e_movie]
  → [[0.2, -0.1, ...], [0.5, 0.3, ...], ...]

每个词 → 稠密向量 (如 300 维)

优势:
════

1. 语义信息 ✅
   "love" 和 "like" 的向量接近
   "love" 和 "hate" 的向量远离

2. 低维稠密 ✅
   300 维 vs 10,000 维
   每个维度都有意义

3. 预训练 ✅
   可以使用 Word2Vec/GloVe
   在大规模语料上预训练

4. 泛化能力 ✅
   训练时没见过"adore"
   但 "adore" ≈ "love"
   → 模型仍能正确分类

5. 保留词序 ✅
   通过 RNN/LSTM 处理序列
   捕捉上下文信息

性能提升:
────────

传统 BoW + Logistic Regression: 75%
词嵌入 + RNN: 85%
词嵌入 + LSTM: 88%
预训练 BERT: 92%

提升 10-15%！
```

## 🏗️ 模型架构

### 基础架构：平均池化

```
最简单的方法:
═══════════

步骤:
1. 词 → 词向量
2. 平均池化
3. 全连接层 → 分类

架构:
────

输入: "I love this movie"
  ↓
[词嵌入层]
  ↓
e_I, e_love, e_this, e_movie
  ↓
[平均池化]
  ↓
h = (e_I + e_love + e_this + e_movie) / 4
  ↓
[全连接层]
  ↓
logits = W·h + b
  ↓
[Softmax]
  ↓
P(positive), P(negative)

代码:
────

```python
class SentimentClassifierAvg(nn.Module):
    def __init__(self, vocab_size, embedding_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.fc = nn.Linear(embedding_dim, num_classes)

    def forward(self, x):
        # x: [batch_size, seq_len]
        embeds = self.embedding(x)  # [batch_size, seq_len, embed_dim]
        pooled = embeds.mean(dim=1)  # [batch_size, embed_dim]
        logits = self.fc(pooled)  # [batch_size, num_classes]
        return logits
```

优点:
  ✅ 简单快速
  ✅ 适合短文本

缺点:
  ❌ 丢失词序
  ❌ 所有词权重相同
```

### 进阶架构：RNN/LSTM

```
使用循环神经网络:
═══════════════

步骤:
1. 词 → 词向量
2. RNN/LSTM 处理序列
3. 取最后隐藏状态
4. 全连接层 → 分类

架构:
────

输入: "I love this movie"
  ↓
[词嵌入层]
  ↓
e_I, e_love, e_this, e_movie
  ↓
[LSTM 层]
  ↓
h_1 → h_2 → h_3 → h_4
              ↓
          (最后状态)
              ↓
[全连接层]
  ↓
logits = W·h_4 + b
  ↓
[Softmax]
  ↓
P(positive), P(negative)

代码:
────

```python
class SentimentClassifierLSTM(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        # x: [batch_size, seq_len]
        embeds = self.embedding(x)  # [batch_size, seq_len, embed_dim]

        # LSTM
        lstm_out, (h_n, c_n) = self.lstm(embeds)
        # lstm_out: [batch_size, seq_len, hidden_dim]
        # h_n: [1, batch_size, hidden_dim]

        # 取最后时间步的隐藏状态
        h_last = h_n.squeeze(0)  # [batch_size, hidden_dim]

        # 分类
        logits = self.fc(h_last)  # [batch_size, num_classes]
        return logits
```

优点:
  ✅ 保留词序
  ✅ 捕捉上下文
  ✅ 适合长文本

缺点:
  ❌ 训练慢
  ❌ 梯度消失（长序列）
```

### 高级架构：双向 LSTM + Attention

```
最佳实践:
════════

架构:
────

输入: "I love this movie"
  ↓
[词嵌入层]
  ↓
e_I, e_love, e_this, e_movie
  ↓
[双向 LSTM]
  ↓
h_1 ← h_2 ← h_3 ← h_4  (反向)
h_1 → h_2 → h_3 → h_4  (正向)
  ↓
[拼接]
  ↓
H = [h_1, h_2, h_3, h_4]  (每个 h 包含双向信息)
  ↓
[Attention 层]
  ↓
α_i = softmax(W·h_i)  (注意力权重)
context = Σ α_i · h_i  (加权和)
  ↓
[全连接层]
  ↓
logits = W·context + b
  ↓
[Softmax]
  ↓
P(positive), P(negative)

代码:
────

```python
class SentimentClassifierAttn(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim,
                           bidirectional=True, batch_first=True)

        # Attention
        self.attn = nn.Linear(hidden_dim * 2, 1)

        # 分类层
        self.fc = nn.Linear(hidden_dim * 2, num_classes)

    def forward(self, x):
        # x: [batch_size, seq_len]
        embeds = self.embedding(x)  # [batch_size, seq_len, embed_dim]

        # 双向 LSTM
        lstm_out, _ = self.lstm(embeds)
        # lstm_out: [batch_size, seq_len, hidden_dim*2]

        # Attention
        attn_scores = self.attn(lstm_out).squeeze(-1)
        # attn_scores: [batch_size, seq_len]

        attn_weights = torch.softmax(attn_scores, dim=1)
        # attn_weights: [batch_size, seq_len]

        # 加权和
        context = torch.bmm(attn_weights.unsqueeze(1), lstm_out).squeeze(1)
        # context: [batch_size, hidden_dim*2]

        # 分类
        logits = self.fc(context)  # [batch_size, num_classes]
        return logits
```

优点:
  ✅ 双向信息
  ✅ 动态关注重要词
  ✅ 性能最好

示例:
  "I love this movie"
  Attention 权重: [0.1, 0.6, 0.1, 0.2]
                    ↑   ↑
                  关注 "love" 和 "movie"
```

## 💻 完整实现

### 端到端情感分类系统

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
from collections import Counter
import numpy as np

# ═══════════════════════════════════════════════════════
# 数据集
# ═══════════════════════════════════════════════════════

class SentimentDataset(Dataset):
    """情感分类数据集"""

    def __init__(self, texts, labels, vocab, max_len=50):
        self.texts = texts
        self.labels = labels
        self.vocab = vocab
        self.max_len = max_len

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, idx):
        text = self.texts[idx]
        label = self.labels[idx]

        # 文本 → 索引
        indices = [self.vocab.get(word, self.vocab['<UNK>'])
                  for word in text.split()]

        # 填充/截断
        if len(indices) < self.max_len:
            indices += [self.vocab['<PAD>']] * (self.max_len - len(indices))
        else:
            indices = indices[:self.max_len]

        return torch.LongTensor(indices), torch.LongTensor([label])


# ═══════════════════════════════════════════════════════
# 模型
# ═══════════════════════════════════════════════════════

class SentimentClassifier(nn.Module):
    """
    情感分类器
    支持多种架构: avg, rnn, lstm, bilstm, attn
    """

    def __init__(self, vocab_size, embedding_dim, hidden_dim,
                 num_classes, architecture='lstm', pretrained_embeddings=None):
        super().__init__()
        self.architecture = architecture

        # 词嵌入层
        if pretrained_embeddings is not None:
            self.embedding = nn.Embedding.from_pretrained(
                pretrained_embeddings, freeze=False
            )
        else:
            self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=0)

        # 不同架构
        if architecture == 'avg':
            # 平均池化
            self.fc = nn.Linear(embedding_dim, num_classes)

        elif architecture in ['rnn', 'lstm', 'gru']:
            # RNN 系列
            if architecture == 'rnn':
                self.rnn = nn.RNN(embedding_dim, hidden_dim, batch_first=True)
            elif architecture == 'lstm':
                self.rnn = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)
            else:  # gru
                self.rnn = nn.GRU(embedding_dim, hidden_dim, batch_first=True)

            self.fc = nn.Linear(hidden_dim, num_classes)

        elif architecture == 'bilstm':
            # 双向 LSTM
            self.rnn = nn.LSTM(embedding_dim, hidden_dim,
                              bidirectional=True, batch_first=True)
            self.fc = nn.Linear(hidden_dim * 2, num_classes)

        elif architecture == 'attn':
            # 双向 LSTM + Attention
            self.rnn = nn.LSTM(embedding_dim, hidden_dim,
                              bidirectional=True, batch_first=True)
            self.attn = nn.Linear(hidden_dim * 2, 1)
            self.fc = nn.Linear(hidden_dim * 2, num_classes)

        self.dropout = nn.Dropout(0.5)

    def forward(self, x):
        # x: [batch_size, seq_len]
        embeds = self.embedding(x)  # [batch_size, seq_len, embed_dim]
        embeds = self.dropout(embeds)

        if self.architecture == 'avg':
            # 平均池化
            pooled = embeds.mean(dim=1)  # [batch_size, embed_dim]
            logits = self.fc(pooled)

        elif self.architecture in ['rnn', 'lstm', 'gru', 'bilstm']:
            # RNN
            rnn_out, (h_n, *_) = self.rnn(embeds)

            if self.architecture == 'bilstm':
                # 拼接双向隐藏状态
                h_last = torch.cat([h_n[-2], h_n[-1]], dim=1)
            else:
                h_last = h_n.squeeze(0)

            h_last = self.dropout(h_last)
            logits = self.fc(h_last)

        elif self.architecture == 'attn':
            # Attention
            rnn_out, _ = self.rnn(embeds)
            # rnn_out: [batch_size, seq_len, hidden_dim*2]

            attn_scores = self.attn(rnn_out).squeeze(-1)
            attn_weights = torch.softmax(attn_scores, dim=1)
            context = torch.bmm(attn_weights.unsqueeze(1), rnn_out).squeeze(1)

            context = self.dropout(context)
            logits = self.fc(context)

        return logits


# ═══════════════════════════════════════════════════════
# 训练与评估
# ═══════════════════════════════════════════════════════

def train_epoch(model, dataloader, criterion, optimizer, device):
    """训练一个 epoch"""
    model.train()
    total_loss = 0
    correct = 0
    total = 0

    for inputs, labels in dataloader:
        inputs, labels = inputs.to(device), labels.to(device).squeeze()

        # 前向传播
        outputs = model(inputs)
        loss = criterion(outputs, labels)

        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        # 统计
        total_loss += loss.item()
        _, predicted = outputs.max(1)
        correct += predicted.eq(labels).sum().item()
        total += labels.size(0)

    avg_loss = total_loss / len(dataloader)
    accuracy = 100. * correct / total
    return avg_loss, accuracy


def evaluate(model, dataloader, criterion, device):
    """评估模型"""
    model.eval()
    total_loss = 0
    correct = 0
    total = 0

    with torch.no_grad():
        for inputs, labels in dataloader:
            inputs, labels = inputs.to(device), labels.to(device).squeeze()

            outputs = model(inputs)
            loss = criterion(outputs, labels)

            total_loss += loss.item()
            _, predicted = outputs.max(1)
            correct += predicted.eq(labels).sum().item()
            total += labels.size(0)

    avg_loss = total_loss / len(dataloader)
    accuracy = 100. * correct / total
    return avg_loss, accuracy


# ═══════════════════════════════════════════════════════
# 主函数
# ═══════════════════════════════════════════════════════

if __name__ == "__main__":
    # 示例数据
    train_texts = [
        "this movie is great",
        "i love this film",
        "amazing performance",
        "best movie ever",
        "terrible movie",
        "i hate this film",
        "worst movie i have seen",
        "boring and bad"
    ]
    train_labels = [1, 1, 1, 1, 0, 0, 0, 0]  # 1=正面, 0=负面

    # 构建词汇表
    all_words = " ".join(train_texts).split()
    word_counts = Counter(all_words)
    vocab = {'<PAD>': 0, '<UNK>': 1}
    vocab.update({word: idx+2 for idx, (word, _) in
                 enumerate(word_counts.most_common())})

    print(f"词汇表大小: {len(vocab)}")

    # 数据集
    dataset = SentimentDataset(train_texts, train_labels, vocab, max_len=10)
    dataloader = DataLoader(dataset, batch_size=2, shuffle=True)

    # 模型
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    model = SentimentClassifier(
        vocab_size=len(vocab),
        embedding_dim=50,
        hidden_dim=64,
        num_classes=2,
        architecture='bilstm'  # 可选: avg, rnn, lstm, bilstm, attn
    ).to(device)

    # 训练
    criterion = nn.CrossEntropyLoss()
    optimizer = optim.Adam(model.parameters(), lr=0.001)

    print("\n开始训练...")
    for epoch in range(20):
        train_loss, train_acc = train_epoch(model, dataloader, criterion, optimizer, device)
        print(f"Epoch {epoch+1}/20 - Loss: {train_loss:.4f}, Acc: {train_acc:.2f}%")

    # 测试
    test_texts = [
        "this is wonderful",
        "this is terrible"
    ]

    model.eval()
    for text in test_texts:
        # 预处理
        indices = [vocab.get(word, vocab['<UNK>']) for word in text.split()]
        indices += [vocab['<PAD>']] * (10 - len(indices))
        inputs = torch.LongTensor([indices]).to(device)

        # 预测
        with torch.no_grad():
            outputs = model(inputs)
            prob = torch.softmax(outputs, dim=1)
            predicted = outputs.argmax(dim=1).item()

        sentiment = "正面" if predicted == 1 else "负面"
        confidence = prob[0][predicted].item()
        print(f"\n文本: '{text}'")
        print(f"预测: {sentiment} (置信度: {confidence:.2%})")
```

## 💡 核心要点总结

### 使用词嵌入的关键步骤

```
1. 数据准备
   ✅ 文本 → 分词
   ✅ 构建词汇表
   ✅ 词 → 索引

2. 词嵌入
   ✅ 随机初始化 or 加载预训练
   ✅ 是否冻结 (freeze)
   ✅ 是否微调 (fine-tune)

3. 序列编码
   ✅ 平均池化 (简单)
   ✅ RNN/LSTM (保留顺序)
   ✅ Attention (动态权重)

4. 分类
   ✅ 全连接层
   ✅ Softmax
   ✅ 交叉熵损失

5. 训练技巧
   ✅ Dropout (防止过拟合)
   ✅ 学习率衰减
   ✅ Early Stopping
```

## 🤔 常见问题

```
Q1: 应该使用预训练词向量还是从头训练？
A1: 看数据量
    - 小数据 (<10K): 必须用预训练 ⭐⭐⭐
    - 中数据 (10K-100K): 推荐用预训练
    - 大数据 (>100K): 可以从头训练

Q2: 是否应该冻结词嵌入层？
A2: 看任务相关性
    - 领域差异大: 不冻结，微调
    - 领域相近: 可以冻结
    - 数据少: 冻结 (防止过拟合)

Q3: 如何处理词汇表外的词 (OOV)?
A3: 几种方法:
    - <UNK> 标记 (最简单)
    - 使用 FastText (子词信息)
    - 字符级编码
    - BERT (子词分词)

Q4: 序列长度不一致怎么办？
A4: 填充 (Padding)
    - 设定最大长度
    - 短的填充 <PAD>
    - 长的截断

Q5: BiLSTM 一定比 LSTM 好吗？
A5: 通常是的
    - 双向信息更丰富
    - 但计算量翻倍
    - 实时任务可能不适用
```
