# 序列模型模块 - 学习路线图

**模块目标**: 理解序列建模的核心思想，为学习 Transformer 奠定基础
**预计学习时间**: 2-3 周（优化路径）/ 4-5 周（完整路径）
**核心重点**: 词嵌入 ⭐⭐⭐ + 理解为什么需要 Attention ⭐⭐⭐
**与 DeepSeek-V3 的关系**: 理解文本表示和序列建模的演进历程

---

## 🎯 学习目标

完成本模块后，你将能够：

1. ✅ 理解序列数据的特点和建模挑战
2. ✅ 掌握 RNN/LSTM 的基本原理（理解局限性）
3. ✅ **深入理解词嵌入** - 文本如何表示为向量 ⭐⭐⭐
4. ✅ 理解为什么 RNN 无法满足现代 LLM 的需求
5. ✅ 理解 Attention 机制的提出背景和必要性
6. ✅ 为学习 Transformer 做好充分准备

## 📊 详细内容规划

### 🔍 **Phase 1: 序列建模基础（必学）**

#### **0. 序列模型意义** ⭐⭐⭐
```
核心问题: 为什么需要序列模型？
学习要点:
  ├─ 序列数据的特点（时间/顺序依赖）
  ├─ 传统神经网络的局限
  ├─ 序列模型的应用场景
  └─ 与 DeepSeek-V3 的关系

类比: 看电影 vs 看单帧图片
时间: 30分钟
```

#### **1. 符号表示** ⭐⭐⭐
```
核心问题: 如何数学化地表示序列？
学习要点:
  ├─ 序列符号标记 (x^<t>, y^<t>)
  ├─ 时间步的概念
  ├─ 输入/输出序列的维度
  └─ 词表与 one-hot 编码

数学: x^<t> ∈ ℝ^n, T_x, T_y
时间: 1小时
```

#### **2. 循环神经网络模型** ⭐⭐⭐
```
核心问题: RNN 如何处理序列？
学习要点:
  ├─ RNN 的基本结构
  ├─ 隐藏状态的传递 h^<t> = f(W·[h^<t-1>, x^<t>])
  ├─ 参数共享机制
  ├─ 前向传播过程
  └─ RNN 的变体（many-to-one, one-to-many 等）

类比: 阅读理解时的记忆传递
时间: 2-3小时
```

#### **3. 时间反向传播（BPTT）** ⭐⭐
```
核心问题: RNN 如何训练？
学习要点:
  ├─ 反向传播通过时间展开
  ├─ 梯度计算链式法则
  ├─ 计算复杂度
  └─ 为什么容易梯度消失

数学: ∂L/∂W = Σ_t (∂L/∂h^<t>) · (∂h^<t>/∂W)
时间: 1-2小时（理解原理即可）
```

#### **4. 不同类型的 RNN** ⭐⭐
```
核心问题: RNN 有哪些架构变体？
学习要点:
  ├─ One-to-One (标准神经网络)
  ├─ One-to-Many (图像描述生成)
  ├─ Many-to-One (情感分类)
  ├─ Many-to-Many (机器翻译)
  └─ 应用场景匹配

图示: 各种架构的可视化
时间: 1小时
```

#### **7. RNN 梯度消失** ⭐⭐⭐ **重要！**
```
核心问题: RNN 的致命缺陷是什么？
学习要点:
  ├─ 为什么会梯度消失/爆炸
  ├─ 长期依赖问题
  ├─ 梯度裁剪的作用
  └─ 为什么需要 LSTM/GRU

数学: 连乘效应 ∏_t W → 0 或 ∞
关键理解: 这是为什么需要改进的核心原因！
时间: 1小时
```

---

### 🔧 **Phase 2: 改进架构（快速了解）**

#### **8. 门控循环单元（GRU）** ⭐⭐
```
核心问题: GRU 如何缓解梯度消失？
学习要点:
  ├─ 更新门（update gate）
  ├─ 重置门（reset gate）
  ├─ 如何控制信息流
  └─ 与 RNN 的对比

建议: 理解原理即可，不必深入实现
时间: 1-2小时
```

#### **9. 长短期记忆网络（LSTM）** ⭐⭐
```
核心问题: LSTM 的门控机制是什么？
学习要点:
  ├─ 遗忘门、输入门、输出门
  ├─ 细胞状态 (cell state) C^<t>
  ├─ 为什么能记住长期依赖
  └─ LSTM vs GRU

关键理解: LSTM 在 2010 年代很流行，但现代 LLM 用 Transformer
建议: 快速浏览，重点是理解"为什么 Transformer 能替代它"
时间: 1-2小时
```

#### **10-11. 双向 RNN / 深度 RNN** ⭐ 可选
```
建议: 快速浏览或跳过
原因: 现代 Transformer 的 self-attention 实现了类似功能
时间: 30分钟（可选）
```

#### **14. 词嵌入特性** ⭐⭐⭐

#### **15. 嵌入矩阵** ⭐⭐⭐
```
核心问题: 词嵌入如何实现？
学习要点:
  ├─ 嵌入矩阵 E ∈ ℝ^{vocab_size × embed_dim}
  ├─ 查表操作 e = E · o (o 是 one-hot)

代码: 实现简单的嵌入层
时间: 1小时
```

#### **16-18. Word2Vec 与负采样** ⭐⭐

核心问题: 如何训练词嵌入？

  └─ 为什么现代 LLM 不单独训练词嵌入

建议: 理解思想即可，现代方法已更新
时间: 2-3小时

时间: 1-2小时

#### **28. 注意力机制原理** ⭐⭐⭐⭐⭐ **核心！**

核心问题: Attention 解决了什么问题？

  ├─ 注意力权重: α = softmax(score(Q, K))

### 3. 通过对比加深理解

```

├─ 计算效率: 慢 vs 快
└─ 性能: 受限 vs 强大

对比学习帮助你理解"为什么 Transformer 是革命性的"
```

```

Attention: 像考试时翻书找答案
Self-Attention: 每个词都看其他所有词

多用类比帮助直观理解！
```
