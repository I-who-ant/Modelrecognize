 ## 0. 导读
 目标：把“深度 L 层网络的结构 → 一次性向量化前向传播 → 矩阵维度与广播规则”串成可复用的检查清单，作为搭建/排错任意前向计算的标准手册。
 
 ---
 
 ## 1. 记号与维度
 - 层与宽度：
   - 第 0 层是输入：n[0] = n_x
   - 第 l 层神经元个数：n[l]，l = 1..L
 - 参数形状（列向量规范）：
   - W[l] ∈ R^{n[l] × n[l−1]}
   - b[l] ∈ R^{n[l] × 1}
 - 中间量（一次处理 m 个样本的 mini-batch）：
   - X = A[0] ∈ R^{n[0] × m}
   - Z[l] = W[l]A[l−1] + b[l] ∈ R^{n[l] × m}
   - A[l] = g[l](Z[l]) ∈ R^{n[l] × m}
 - 激活 g[l]: 隐藏层常用 ReLU/Tanh；输出层二分类用 Sigmoid，多分类用 Softmax。
 
 > 列向量规范把每个样本放在矩阵的“列”，能自然满足 W[l]A[l−1] 的相乘条件，并让 b[l] 通过列方向广播。
 
 ---
 
 ## 2. 前向传播（一次性向量化）
 - 初始化：A[0] = X
 - 逐层：
   - Z[l] = W[l]·A[l−1] + b[l]
   - A[l] = g[l](Z[l])
 - 输出：A[L] = y_hat 参与损失计算
 
 > b[l] 的形状固定为 (n[l], 1)，在计算 Z[l] 时沿列（样本维）广播到 (n[l], m)。
 
 ---
 
 ## 3. 激活与损失的搭配
 - 二分类：
   - A[L] = sigmoid(Z[L])，n[L] = 1
   - 损失 BCE：L = −[ y log a + (1−y) log(1−a) ]
 - 多分类（C 类）：
   - A[L] = softmax(Z[L]) 按列归一化，n[L] = C
   - 损失 CE：L = −Σ_c y_c log a_c（对每列样本求和/平均）
 - 隐藏层：ReLU/Tanh 等不直接决定损失形式，但会强烈影响梯度流动与收敛速度（ReLU 避免饱和但有“死亡”风险；Sigmoid/Tanh 端部梯度小易消失；GeLU/SwiGLU 更平滑）。
 
 ---
 
 ## 4. 维度匹配与广播规则
 - 乘法匹配：W[l](n[l], n[l−1]) × A[l−1](n[l−1], m) → Z[l](n[l], m)
 - 偏置广播：b[l](n[l], 1) 自动广播为 (n[l], m)
 - Softmax 轴：对 Z[L] 的“列”做 softmax（axis=0 保持列为样本的约定），确保每列概率和为 1。
 - keepdims：在做按列/按行的聚合时建议 keepdims=True，避免形状退化导致广播异常。
 
 ---
 
 ## 5. 常见错误与快速检查
 - 错把样本放成“行”→ 形状会变成 (m, n)，导致 W@A 维度错位。
 - b[l] 写成 (1, n[l]) 或 (m, 1) → 广播方向错误或隐式拼接错误。
 - Softmax 用错轴 → 变成“每行和为 1”，而不是“每个样本（列）和为 1”。
 - 忘了 keepdims → sum/mean 结果降维，后续广播失败。
 
 检查清单：
 - A[0]=X:(n[0], m)，W[l]:(n[l], n[l−1])，b[l]:(n[l],1)
 - Z[l], A[l] 最终都是 (n[l], m)
 - Softmax/交叉熵 与 Sigmoid/BCE 正确配对
 - 逐层打印/断言形状，出问题从最近一层回溯
 
 ---
 
 ## 6. 代码示例（NumPy，列向量规范）
 ```python
 import numpy as np
 
 def relu(z):
     return np.maximum(0, z)
 
 def sigmoid(z):
     return 1.0 / (1.0 + np.exp(-z))
 
 def softmax(z):  # z: (n_classes, m) — 按列做 softmax
     z = z - np.max(z, axis=0, keepdims=True)  # 数值稳定
     expz = np.exp(z)
     return expz / np.sum(expz, axis=0, keepdims=True)
 
 def forward(X, params, activations):
     """
     X: (n_x, m)
     params: {"W1":(n1,n0),"b1":(n1,1),...,"WL":(nL,nL-1),"bL":(nL,1)}
     activations: ["relu"|"sigmoid"|"tanh"|"softmax", ...], len=L
     返回: (A_L, caches)
     """
     A = X
     caches = []
     L = len(activations)
     for l in range(1, L+1):
         W, b = params[f"W{l}"], params[f"b{l}"]
         Z = W @ A + b  # (n[l], m); b 广播
         act = activations[l-1]
         if act == 'relu':
             A = relu(Z)
         elif act == 'sigmoid':
             A = sigmoid(Z)
         elif act == 'tanh':
             A = np.tanh(Z)
         elif act == 'softmax':
             A = softmax(Z)
         else:
             raise ValueError(f"unknown activation: {act}")
         caches.append((A, Z, W, b))  # 反向需要 Z、W 以及激活后的 A
     return A, caches
 ```

 ## 7. 小型维度例子（落地速查）
 设 n[0]=4, n[1]=5, n[2]=3，m=10：
 - X:(4,10)，W1:(5,4)，b1:(5,1) → Z1:(5,10)，A1:(5,10)
 - W2:(3,5)，b2:(3,1) → Z2:(3,10)，A2:(3,10)
 - 若多分类：对 A2 的每列 softmax。

 ## 8. 与反向传播的接口
 - 反向阶段会用到 Z[l]（激活导数用）与 A[l−1]（线性层输入）以及 W[l]。
 - 因此前向时缓存 (A[l], Z[l], W[l], b[l]) 是常见做法；也可以另外缓存 A[l−1]。
