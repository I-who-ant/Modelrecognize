## 基本定义

**神经网络**: 由多个层(Layer)组成的计算模型,每层包含多个神经元(Neuron/Unit),通过权重(Weight)和偏置(Bias)连接。

**前向传播 (Forward Propagation)**: 输入数据从输入层逐层传递到输出层,计算最终预测结果的过程。

**核心思想**:
- 神经网络 = 多个逻辑回归单元堆叠
- 每层进行线性变换 + 非线性激活
- 逐层传递,最终得到预测

## 第一部分: 神经网络表示方法 (课程26) ⭐⭐⭐

### 1. 从逻辑回归到神经网络

#### 逻辑回归回顾

```python
# 单个逻辑回归单元
输入: x = [x₁, x₂, x₃]
参数: w = [w₁, w₂, w₃], b

计算:
z = w^T x + b
a = σ(z)  # sigmoid激活

输出: a (单个值)
```

#### 神经网络 = 多个逻辑回归堆叠

```python
# 神经网络 = 很多逻辑回归单元组成的层
第1层: 4个神经元 → 4个逻辑回归单元
第2层: 3个神经元 → 3个逻辑回归单元
输出层: 1个神经元 → 1个逻辑回归单元
```

### 2. 神经网络的层次结构

#### 标准的3层神经网络

```
输入层        隐藏层1       隐藏层2       输出层
(Layer 0)    (Layer 1)    (Layer 2)    (Layer 3)

x₁ ●           ●            ●
              ●            ●            ● ŷ
x₂ ●           ●            ●
              ●
x₃ ●

特征维度      隐藏单元      隐藏单元      输出
  n           n[1]         n[2]         n[3]=1
```

**层的编号**:
- 第0层 (L=0): 输入层 (通常不算作网络层)
- 第1层 (L=1): 第一个隐藏层
- 第2层 (L=2): 第二个隐藏层
- 第3层 (L=3): 输出层

**约定**:
- 层数 = 隐藏层数 + 输出层数 (不包括输入层)
- "3层神经网络" = 2个隐藏层 + 1个输出层

### 3. 符号表示法 ⭐⭐⭐

#### 上标表示

```python
# [l] 表示第 l 层
# (i) 表示第 i 个样本

W[l]  : 第 l 层的权重矩阵
b[l]  : 第 l 层的偏置向量
Z[l]  : 第 l 层的线性输出
A[l]  : 第 l 层的激活输出

# 第 l 层第 i 个样本
Z[l](i) : 第 i 个样本在第 l 层的线性输出
A[l](i) : 第 i 个样本在第 l 层的激活输出
```

#### 下标表示

```python
# 下标 i 或 j 表示神经元编号

W[l]ᵢⱼ : 第 l 层,第 i 个神经元,来自上一层第 j 个神经元的权重
a[l]ᵢ  : 第 l 层,第 i 个神经元的激活值
```

### 4. 权重矩阵的维度 ⭐⭐⭐

**关键规则**:

```python
第 l 层:
- 神经元数量: n[l]
- 上一层神经元数量: n[l-1]

权重矩阵:
W[l].shape = (n[l], n[l-1])
       ↑          ↑
    当前层     上一层

偏置向量:
b[l].shape = (n[l], 1)
       ↑
    当前层

激活输出:
A[l].shape = (n[l], m)
       ↑      ↑
    当前层  样本数
```

**为什么这样设计?**

```python
# 使得矩阵乘法维度匹配
Z[l] = W[l] @ A[l-1] + b[l]

维度分析:
W[l]:    (n[l], n[l-1])
A[l-1]:  (n[l-1], m)
------
结果:    (n[l], m) ✅ 正确!
```

## 第二部分: 神经网络输出计算 (课程27) ⭐⭐⭐

### 1. 单个样本的前向传播

#### 第1层计算

```python
输入: x (3, 1)  # 单个样本

# 第1层 (隐藏层)
z[1] = W[1] @ x + b[1]     # (4, 3) @ (3, 1) + (4, 1) = (4, 1)
a[1] = σ(z[1])              # (4, 1)

解释:
- W[1] 是 (4, 3) 矩阵,4行对应4个神经元
- 每一行 W[1]ᵢ 是第 i 个神经元的权重
- z[1]ᵢ = W[1]ᵢ @ x + b[1]ᵢ  是第 i 个神经元的线性输出
```

**详细展开**:

```python
# 第1层的4个神经元
神经元1: z[1]₁ = w[1]₁₁·x₁ + w[1]₁₂·x₂ + w[1]₁₃·x₃ + b[1]₁
        a[1]₁ = σ(z[1]₁)

神经元2: z[1]₂ = w[1]₂₁·x₁ + w[1]₂₂·x₂ + w[1]₂₃·x₃ + b[1]₂
        a[1]₂ = σ(z[1]₂)

神经元3: z[1]₃ = w[1]₃₁·x₁ + w[1]₃₂·x₂ + w[1]₃₃·x₃ + b[1]₃
        a[1]₃ = σ(z[1]₃)

神经元4: z[1]₄ = w[1]₄₁·x₁ + w[1]₄₂·x₂ + w[1]₄₃·x₃ + b[1]₄
        a[1]₄ = σ(z[1]₄)

向量化:
z[1] = W[1] @ x + b[1] = [[z[1]₁],
                          [z[1]₂],
                          [z[1]₃],
                          [z[1]₄]]

a[1] = σ(z[1]) = [[a[1]₁],
                  [a[1]₂],
                  [a[1]₃],
                  [a[1]₄]]
```

#### 第2层计算

```python
# 第2层 (输出层)
z[2] = W[2] @ a[1] + b[2]   # (1, 4) @ (4, 1) + (1, 1) = (1, 1)
a[2] = σ(z[2])              # (1, 1)

解释:
- a[1] 是第1层的输出,成为第2层的输入
- W[2] 是 (1, 4) 矩阵,只有1个神经元
- z[2] 是标量(封装在(1,1)矩阵中)
```

### 2. 完整的前向传播流程

```python
def forward_propagation_single(x, parameters):
    """
    单个样本的前向传播

    参数:
    x: (n[0], 1) 输入特征
    parameters: 字典,包含 W[1], b[1], W[2], b[2]

    返回:
    a[2]: (n[2], 1) 最终预测
    cache: 字典,包含中间值
    """
    # 提取参数
    W1 = parameters['W1']  # (n[1], n[0])
    b1 = parameters['b1']  # (n[1], 1)
    W2 = parameters['W2']  # (n[2], n[1])
    b2 = parameters['b2']  # (n[2], 1)

    # 第1层
    z1 = W1 @ x + b1       # (n[1], 1)
    a1 = sigmoid(z1)        # (n[1], 1)

    # 第2层
    z2 = W2 @ a1 + b2      # (n[2], 1)
    a2 = sigmoid(z2)        # (n[2], 1)

    # 保存中间值(供反向传播使用)
    cache = {
        'z1': z1, 'a1': a1,
        'z2': z2, 'a2': a2
    }

    return a2, cache
```

### 3. 多个样本的前向传播(向量化) ⭐⭐⭐

**关键**: 将 m 个样本堆叠成矩阵!

```python
# 单个样本
x:    (n[0], 1)
a[1]: (n[1], 1)
a[2]: (n[2], 1)

# m 个样本(向量化)
X:    (n[0], m)  # 每一列是一个样本
A[1]: (n[1], m)  # 每一列是一个样本在第1层的激活
A[2]: (n[2], m)  # 每一列是一个样本的最终预测
```

#### 向量化计算

```python
# 输入
X = [x⁽¹⁾ x⁽²⁾ x⁽³⁾ ... x⁽ᵐ⁾]  # (n[0], m)

# 第1层
Z[1] = W[1] @ X + b[1]  # (n[1], n[0]) @ (n[0], m) + (n[1], 1)
                        # = (n[1], m) + (n[1], 1)  ← b[1]广播!
                        # = (n[1], m)

A[1] = σ(Z[1])          # (n[1], m)

# 第2层
Z[2] = W[2] @ A[1] + b[2]  # (n[2], n[1]) @ (n[1], m) + (n[2], 1)
                           # = (n[2], m)

A[2] = σ(Z[2])             # (n[2], m)
```

**理解**: 每一列独立计算

```python
Z[1] = [z[1]⁽¹⁾ z[1]⁽²⁾ z[1]⁽³⁾ ... z[1]⁽ᵐ⁾]
       ↓       ↓       ↓           ↓
     样本1   样本2   样本3       样本m

每一列 z[1]⁽ⁱ⁾ = W[1] @ x⁽ⁱ⁾ + b[1]
```

### 4. 完整的向量化实现

```python
import numpy as np

def sigmoid(z):
    """Sigmoid激活函数"""
    return 1 / (1 + np.exp(-z))

def initialize_parameters(n_x, n_h, n_y):
    """
    初始化参数

    参数:
    n_x: 输入层大小
    n_h: 隐藏层大小
    n_y: 输出层大小

    返回:
    parameters: 参数字典
    """
    np.random.seed(1)

    # 随机初始化(小值)
    W1 = np.random.randn(n_h, n_x) * 0.01
    b1 = np.zeros((n_h, 1))
    W2 = np.random.randn(n_y, n_h) * 0.01
    b2 = np.zeros((n_y, 1))

    # 检查维度
    assert W1.shape == (n_h, n_x), f"W1维度错误: {W1.shape}"
    assert b1.shape == (n_h, 1), f"b1维度错误: {b1.shape}"
    assert W2.shape == (n_y, n_h), f"W2维度错误: {W2.shape}"
    assert b2.shape == (n_y, 1), f"b2维度错误: {b2.shape}"

    parameters = {
        'W1': W1,
        'b1': b1,
        'W2': W2,
        'b2': b2
    }

    return parameters

def forward_propagation(X, parameters):
    """
    向量化的前向传播

    参数:
    X: (n_x, m) 输入数据
    parameters: 参数字典

    返回:
    A2: (n_y, m) 预测输出
    cache: 中间值字典
    """
    # 提取参数
    W1 = parameters['W1']
    b1 = parameters['b1']
    W2 = parameters['W2']
    b2 = parameters['b2']

    # 前向传播
    Z1 = W1 @ X + b1        # (n_h, m)
    A1 = sigmoid(Z1)         # (n_h, m)

    Z2 = W2 @ A1 + b2       # (n_y, m)
    A2 = sigmoid(Z2)         # (n_y, m)

    # 验证维度
    n_x, m = X.shape
    n_h = W1.shape[0]
    n_y = W2.shape[0]

    assert Z1.shape == (n_h, m), f"Z1维度错误: {Z1.shape}"
    assert A1.shape == (n_h, m), f"A1维度错误: {A1.shape}"
    assert Z2.shape == (n_y, m), f"Z2维度错误: {Z2.shape}"
    assert A2.shape == (n_y, m), f"A2维度错误: {A2.shape}"

    cache = {
        'Z1': Z1,
        'A1': A1,
        'Z2': Z2,
        'A2': A2
    }

    return A2, cache

# ============ 示例使用 ============

# 网络结构
n_x = 3  # 输入: 3个特征
n_h = 4  # 隐藏层: 4个神经元
n_y = 1  # 输出: 1个神经元

# 初始化参数
parameters = initialize_parameters(n_x, n_h, n_y)

print("=" * 60)
print("参数维度:")
print("=" * 60)
for key, value in parameters.items():
    print(f"{key}: {value.shape}")
print()

# 生成测试数据
m = 5  # 5个样本
X = np.random.randn(n_x, m)

print("=" * 60)
print("前向传播:")
print("=" * 60)
print(f"输入 X: {X.shape}")

# 前向传播

print(f"Z1: {cache['Z1'].shape}")
print(f"A1: {cache['A1'].shape}")
print(f"Z2: {cache['Z2'].shape}")
print(f"A2 (预测): {cache['A2'].shape}")
print()

print("=" * 60)
print("预测结果 (前3个样本):")
print("=" * 60)
print(A2[:, :3])
```

层数: L
每层神经元数: n[0], n[1], n[2], ..., n[L]

for l in range(1, L+1):

### 6. 不同激活函数

虽然课程主要讲sigmoid,但实际中还有其他激活函数:

```python
def relu(z):
    """ReLU: 更常用于隐藏层"""
    return np.maximum(0, z)

def tanh(z):
    """Tanh: 也常用于隐藏层"""
    return np.tanh(z)

def softmax(z):
    """Softmax: 用于多分类输出层"""
    exp_z = np.exp(z - np.max(z, axis=0, keepdims=True))
    return exp_z / np.sum(exp_z, axis=0, keepdims=True)

# 实际网络可能这样:
# 隐藏层用 ReLU
Z1 = W1 @ X + b1
A1 = relu(Z1)

# 输出层用 Sigmoid(二分类) 或 Softmax(多分类)
Z2 = W2 @ A1 + b2
A2 = sigmoid(Z2)  # 或 softmax(Z2)
```

## 直观理解

### 类比1: 流水线工厂

```
原材料(X) → 车间1(Layer 1) → 半成品(A1) → 车间2(Layer 2) → 成品(A2)

每个车间:
- 有多个工人(神经元)
- 每个工人做线性变换(z = w^T x + b)
- 然后做非线性处理(a = σ(z))
- 所有工人的输出 → 下一个车间的输入
```

### 类比2: 信息传递

```
输入信号 → [第1层处理] → 中间信号 → [第2层处理] → 输出结果

每层做什么:
1. 线性组合: 将输入加权求和
2. 非线性变换: 通过激活函数
3. 传递给下一层
```

### 类比3: 特征提取

```
原始像素 → [第1层] → 边缘特征 → [第2层] → 形状特征 → [输出层] → 类别

每层学习:
- 第1层: 低级特征(边缘、纹理)
- 第2层: 中级特征(部件)
- 输出层: 高级特征(整体)
```

## 完整示例: 二分类问题

```python
import numpy as np
import matplotlib.pyplot as plt

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def initialize_parameters(n_x, n_h, n_y):
    """初始化参数"""
    W1 = np.random.randn(n_h, n_x) * 0.01
    b1 = np.zeros((n_h, 1))
    W2 = np.random.randn(n_y, n_h) * 0.01
    b2 = np.zeros((n_y, 1))

    return {'W1': W1, 'b1': b1, 'W2': W2, 'b2': b2}

def forward_propagation(X, parameters):
    """前向传播"""
    W1 = parameters['W1']
    b1 = parameters['b1']
    W2 = parameters['W2']
    b2 = parameters['b2']

    Z1 = W1 @ X + b1
    A1 = sigmoid(Z1)
    Z2 = W2 @ A1 + b2
    A2 = sigmoid(Z2)

    cache = {'Z1': Z1, 'A1': A1, 'Z2': Z2, 'A2': A2}
    return A2, cache

# 生成数据: 螺旋分类问题
np.random.seed(1)
m = 400  # 样本数
N = m // 2  # 每类样本数

# 生成螺旋数据
theta = np.linspace(0, 4*np.pi, N)
r = np.linspace(0.5, 1, N)

# 类别1
X1 = np.c_[r * np.cos(theta), r * np.sin(theta)]
Y1 = np.zeros(N)

# 类别2
X2 = np.c_[-r * np.cos(theta), -r * np.sin(theta)]
Y2 = np.ones(N)

# 合并
X = np.vstack([X1, X2]).T  # (2, 400)
Y = np.hstack([Y1, Y2]).reshape(1, -1)  # (1, 400)

# 网络结构
n_x = 2   # 2个特征(x, y坐标)
n_h = 4   # 4个隐藏神经元
n_y = 1   # 1个输出

# 初始化并前向传播
parameters = initialize_parameters(n_x, n_h, n_y)
predictions, cache = forward_propagation(X, parameters)

print("=" * 60)
print("螺旋分类问题")
print("=" * 60)
print(f"数据形状: X={X.shape}, Y={Y.shape}")
print(f"网络结构: {n_x} → {n_h} → {n_y}")
print(f"参数维度:")
for key, val in parameters.items():
    print(f"  {key}: {val.shape}")
print(f"\n前向传播:")
print(f"  Z1: {cache['Z1'].shape}")
print(f"  A1: {cache['A1'].shape}")
print(f"  Z2: {cache['Z2'].shape}")
print(f"  预测: {predictions.shape}")
print(f"\n预测范围: [{predictions.min():.4f}, {predictions.max():.4f}]")
```

## 在DeepSeek-V3中的应用

### 直接应用 🔴

**1. 线性层(全连接层)**:

```python
# DeepSeek-V3中的线性层
def linear(x, weight, bias=None):
    """
    x:      (batch, seq_len, in_features)
    weight: (out_features, in_features)
    bias:   (out_features,)
    """
    output = x @ weight.T  # 矩阵乘法
    if bias is not None:
        output = output + bias  # 广播
    return output

# 和神经网络的一层完全一样!
# output = activation(W @ x + b)
```

**2. Transformer的FFN层**:

```python
# Feed-Forward Network (两层全连接)
class FFN:
    def forward(self, x):
        # 第1层: 扩展维度
        h = linear(x, W1, b1)  # (batch, seq, d_model) → (batch, seq, d_ff)
        h = gelu(h)             # 激活函数(类似sigmoid)

        # 第2层: 恢复维度
        out = linear(h, W2, b2)  # (batch, seq, d_ff) → (batch, seq, d_model)
        return out

# 这就是一个2层神经网络!
```

**3. 多层堆叠**:

```python
# DeepSeek-V3有60层
for layer in layers:  # 60次
    # Attention层
    x = attention(x)

    # FFN层(2层神经网络)
    x = ffn(x)

# 总共 60 × 2 = 120 层线性变换!
```

- 向量化计算m个样本
- 维度管理和检查

## 常见疑问

### Q1: 为什么权重矩阵是 (n[l], n[l-1]) 而不是 (n[l-1], n[l])?

**A**: 为了使矩阵乘法方便

```python
如果 W[l] 是 (n[l], n[l-1]):
Z[l] = W[l] @ A[l-1]
     = (n[l], n[l-1]) @ (n[l-1], m)
     = (n[l], m) ✅ 正确!

如果 W[l] 是 (n[l-1], n[l]):
Z[l] = A[l-1] @ W[l]
     = (n[l-1], m) @ (n[l-1], n[l])
     ❌ 维度不匹配!

或者需要:
Z[l] = (W[l].T @ A[l-1].T).T
     很麻烦!

所以约定 W[l] 是 (n[l], n[l-1])
```

### Q2: 为什么要用激活函数?

**A**: 没有激活函数,神经网络退化成线性模型

```python
如果没有激活函数:
Z[1] = W[1] @ X + b[1]
A[1] = Z[1]  # 没有激活

Z[2] = W[2] @ A[1] + b[2]
     = W[2] @ (W[1] @ X + b[1]) + b[2]
     = (W[2] @ W[1]) @ X + (W[2] @ b[1] + b[2])
     = W_combined @ X + b_combined

退化成单层线性模型!

有了激活函数:
A[1] = σ(Z[1])  # 非线性!
Z[2] = W[2] @ A[1] + b[2]
     无法简化,保持非线性表达能力
```

### Q3: 为什么初始化权重要用小的随机数?

**A**: 避免对称性和梯度问题

```python
# ❌ 全部初始化为0
W1 = np.zeros((n_h, n_x))
→ 所有神经元完全相同
→ 梯度相同,更新后还是相同
→ 网络无法学习!

# ❌ 初始化为大值
W1 = np.random.randn(n_h, n_x) * 10
→ Z很大
→ sigmoid(Z) 接近0或1
→ 梯度接近0 (梯度消失)

# ✅ 小的随机数
W1 = np.random.randn(n_h, n_x) * 0.01
→ 打破对称性
→ Z在合理范围
→ 梯度正常
```

### Q4: 隐藏层应该有多少个神经元?

**A**: 这是超参数,需要实验

```python
经验法则:
- 太少: 欠拟合(underfitting) - 模型太简单
- 太多: 过拟合(overfitting) - 模型太复杂

常见做法:
1. 从小开始,逐渐增加
2. 通常是输入维度的倍数(如 2×n_x, 4×n_x)
3. 使用验证集选择
4. 考虑计算资源

示例:
输入: 100维
隐藏层: 50-200 都可能合理
需要通过实验确定
```

### Q5: 层数越多越好吗?

**A**: 不一定,有trade-off

```python
更多层:
✅ 优点:
  - 更强的表达能力
  - 可以学习复杂特征
  - 层次化特征提取

❌ 缺点:
  - 更难训练(梯度消失/爆炸)
  - 需要更多数据
  - 计算成本高
  - 容易过拟合

实践:
- 简单问题: 1-2层够了
- 图像: 数十到上百层(ResNet, VGG)
- NLP: 数十层(Transformer)
- DeepSeek-V3: 60层

关键: 根据数据和任务选择
```

## 总结

### 核心公式

```python
# 第 l 层的前向传播
Z[l] = W[l] @ A[l-1] + b[l]
A[l] = g[l](Z[l])

其中:
- W[l]: (n[l], n[l-1]) 权重矩阵
- b[l]: (n[l], 1) 偏置向量
- A[l-1]: (n[l-1], m) 上一层激活
- g[l]: 激活函数
- Z[l], A[l]: (n[l], m) 当前层输出
```

### 关键记忆点

1. **层的概念**: 输入层 → 隐藏层 → 输出层
2. **符号约定**: [l]表示层, (i)表示样本
3. **权重维度**: W[l]是(n[l], n[l-1])
4. **前向传播**: 线性变换 → 激活函数 → 下一层
5. **向量化**: 所有m个样本同时计算
6. **维度检查**: 随时验证shape
