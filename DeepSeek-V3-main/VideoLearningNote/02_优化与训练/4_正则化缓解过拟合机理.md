### 1. L2正则化的数学机理

#### A. 约束优化视角

```python
"""
正则化的两种等价形式:

形式1: 惩罚形式 (Penalty Form)
min  L(W) + λ||W||²
 W

形式2: 约束形式 (Constraint Form)
min  L(W)
 W
s.t. ||W||² ≤ C

两者等价! (通过拉格朗日对偶)
"""

import numpy as np
import matplotlib.pyplot as plt

def visualize_constraint_form():
    """
    可视化约束优化

    目标: 最小化损失L(w1, w2)
    约束: w1² + w2² ≤ C
    """
    # 创建网格
    w1 = np.linspace(-3, 3, 100)
    w2 = np.linspace(-3, 3, 100)
    W1, W2 = np.meshgrid(w1, w2)

    # 损失函数等高线 (假设是二次函数)
    # L(w) = (w1-2)² + (w2-1.5)²
    Loss = (W1 - 2)**2 + (W2 - 1.5)**2

    fig, axes = plt.subplots(1, 2, figsize=(14, 6))

    # 左图: 无约束
    ax1 = axes[0]
    contour1 = ax1.contour(W1, W2, Loss, levels=20, cmap='viridis')
    ax1.scatter([2], [1.5], c='red', s=200, marker='*',
               label='无约束最优解', zorder=5)
    ax1.set_xlabel('w₁', fontsize=12)
    ax1.set_ylabel('w₂', fontsize=12)
    ax1.set_title('无正则化: 自由优化', fontsize=14, fontweight='bold')
    ax1.legend(fontsize=11)
    ax1.grid(True, alpha=0.3)
    ax1.set_aspect('equal')

    # 右图: 有约束
    ax2 = axes[1]
    contour2 = ax2.contour(W1, W2, Loss, levels=20, cmap='viridis')

    # L2约束: w1² + w2² ≤ 1
    theta = np.linspace(0, 2*np.pi, 100)
    C = 1.0
    ax2.plot(C*np.cos(theta), C*np.sin(theta), 'r-',
            linewidth=3, label=f'L2约束: ||W||²≤{C}')
    ax2.fill(C*np.cos(theta), C*np.sin(theta),
            alpha=0.2, color='red')

    # 约束最优解 (等高线与约束边界相切点)
    # 解析解: w* = C * (w_unconstrained / ||w_unconstrained||)
    w_opt = np.array([2, 1.5])
    w_opt_constrained = C * w_opt / np.linalg.norm(w_opt)

    ax2.scatter([w_opt_constrained[0]], [w_opt_constrained[1]],
               c='green', s=200, marker='*',
               label='L2正则化最优解', zorder=5)
    ax2.scatter([2], [1.5], c='red', s=100, marker='o',
               alpha=0.5, label='无约束最优解', zorder=5)

    # 绘制箭头
    ax2.annotate('', xy=w_opt_constrained, xytext=(2, 1.5),
                arrowprops=dict(arrowstyle='->', lw=2, color='blue'))
    ax2.text(1.5, 1.2, '正则化\n拉向原点', fontsize=10,
            bbox=dict(boxstyle='round', facecolor='lightblue'))

    ax2.set_xlabel('w₁', fontsize=12)
    ax2.set_ylabel('w₂', fontsize=12)
    ax2.set_title('L2正则化: 约束优化', fontsize=14, fontweight='bold')
    ax2.legend(fontsize=11)
    ax2.grid(True, alpha=0.3)
    ax2.set_aspect('equal')

    plt.tight_layout()
    plt.show()

    print("\n关键洞察:")
    print("=" * 60)
    print("1. L2正则化 = 在球形约束内优化")
    print("2. 最优解被'拉向'原点")
    print("3. 权重变小 → 模型更简单 → 泛化更好")
    print("4. λ越大 → 约束越紧 → 权重越小")
```

#### B. 梯度视角

```python
"""
L2正则化如何影响梯度?

原始损失:
L = Data_Loss(W)
∇L = ∇Data_Loss

L2正则化后:
L_reg = Data_Loss(W) + (λ/2)||W||²
∇L_reg = ∇Data_Loss + λW
         ↑             ↑
      数据梯度      正则化梯度

效果:
- 正则化梯度总是指向原点
- 权重更新时被'拉回'原点
- 权重无法无限增大
"""

def visualize_gradient_effect():
    """
    可视化正则化对梯度的影响
    """
    fig, axes = plt.subplots(1, 2, figsize=(14, 6))

    # 假设当前权重点
    w_current = np.array([1.5, 1.0])

    # 数据梯度 (假设指向右上)
    grad_data = np.array([0.8, 0.6])

    # L2正则化梯度 (总是指向原点)
    lambda_reg = 0.5
    grad_reg = lambda_reg * w_current

    # 总梯度
    grad_total = grad_data + grad_reg

    # 左图: 梯度分解
    ax1 = axes[0]
    ax1.scatter([0], [0], c='black', s=100, marker='o', label='原点')
    ax1.scatter([w_current[0]], [w_current[1]], c='blue', s=200,
               marker='*', label='当前权重', zorder=5)

    # 绘制梯度向量
    ax1.quiver(w_current[0], w_current[1],
              grad_data[0], grad_data[1],
              angles='xy', scale_units='xy', scale=1,
              color='green', width=0.01, label='数据梯度')

    ax1.quiver(w_current[0], w_current[1],
              grad_reg[0], grad_reg[1],
              angles='xy', scale_units='xy', scale=1,
              color='red', width=0.01, label='正则化梯度')

    ax1.quiver(w_current[0], w_current[1],
              grad_total[0], grad_total[1],
              angles='xy', scale_units='xy', scale=1,
              color='purple', width=0.015, label='总梯度')

    ax1.set_xlim(-0.5, 3)
    ax1.set_ylim(-0.5, 2.5)
    ax1.set_xlabel('w₁', fontsize=12)
    ax1.set_ylabel('w₂', fontsize=12)
    ax1.set_title('梯度分解', fontsize=14, fontweight='bold')
    ax1.legend(fontsize=11)
    ax1.grid(True, alpha=0.3)
    ax1.set_aspect('equal')

    # 右图: 权重更新轨迹
    ax2 = axes[1]

    # 模拟训练过程
    w = np.array([2.0, 1.5])
    trajectory_no_reg = [w.copy()]
    trajectory_with_reg = [w.copy()]

    lr = 0.1
    lambda_reg = 0.3

    for _ in range(20):
        # 无正则化
        grad_data = np.array([0.5, 0.3])  # 假设的数据梯度
        w_no_reg = trajectory_no_reg[-1] - lr * grad_data
        trajectory_no_reg.append(w_no_reg)

        # 有正则化
        w_with_reg = trajectory_with_reg[-1]
        grad_total = grad_data + lambda_reg * w_with_reg
        w_with_reg = w_with_reg - lr * grad_total
        trajectory_with_reg.append(w_with_reg)

    trajectory_no_reg = np.array(trajectory_no_reg)
    trajectory_with_reg = np.array(trajectory_with_reg)

    # 绘制轨迹
    ax2.plot(trajectory_no_reg[:, 0], trajectory_no_reg[:, 1],
            'b-o', label='无正则化', linewidth=2, markersize=5)
    ax2.plot(trajectory_with_reg[:, 0], trajectory_with_reg[:, 1],
            'r-s', label='L2正则化', linewidth=2, markersize=5)

    ax2.scatter([0], [0], c='black', s=200, marker='*',
               label='原点', zorder=5)

    ax2.set_xlabel('w₁', fontsize=12)
    ax2.set_ylabel('w₂', fontsize=12)
    ax2.set_title('权重更新轨迹对比', fontsize=14, fontweight='bold')
    ax2.legend(fontsize=11)
    ax2.grid(True, alpha=0.3)
    ax2.set_aspect('equal')

    plt.tight_layout()
    plt.show()

    print("\n关键洞察:")
    print("=" * 60)
    print("1. 正则化梯度总是指向原点 (负梯度 = -λW)")
    print("2. 每次更新都会'拉回'权重")
    print("3. 权重被限制在原点附近")
    print("4. λ越大,拉力越强")

# visualize_gradient_effect()
```

#### C. 权重衰减视角

```python
"""
L2正则化 = 权重衰减 (Weight Decay)

标准更新:
W_new = W - α × ∇L

L2正则化更新:
W_new = W - α × (∇Data_Loss + λW)
      = W - α × ∇Data_Loss - αλW
      = (1 - αλ) × W - α × ∇Data_Loss
         ↑
      权重衰减因子

每次更新:
1. 先衰减: W × (1 - αλ)
2. 再更新: - α × ∇Data_Loss

效果: 权重不断被'拉小'
"""

def demonstrate_weight_decay():
    """
    演示权重衰减过程
    """
    # 初始权重
    W = np.array([1.0, 2.0, -1.5, 0.8, -0.5])

    # 超参数
    alpha = 0.01  # 学习率
    lambda_reg = 0.1  # 正则化系数
    decay_factor = 1 - alpha * lambda_reg  # 衰减因子

    print(f"衰减因子: {decay_factor:.6f}")
    print(f"每次迭代权重变为原来的 {decay_factor:.2%}")
    print("\n权重演化:")
    print("=" * 60)

    # 模拟100次迭代 (假设没有数据梯度,只有衰减)
    epochs = [0, 10, 20, 50, 100]
    for epoch in range(101):
        if epoch in epochs:
            print(f"Epoch {epoch:3d}: W = {W}")

        # 只考虑衰减 (数据梯度=0)
        W = W * decay_factor

    print("\n关键洞察:")
    print("=" * 60)
    print(f"1. 每次更新权重都乘以 {decay_factor:.4f} < 1")
    print("2. 权重指数衰减到0附近")
    print(f"3. 100次后权重变为原来的 {decay_factor**100:.6f}")
    print("4. 这就是'Weight Decay'名称的由来")
```

### 2. 为什么小权重 = 简单模型?

#### A. 神经网络视角

```python
"""
关键问题: 为什么权重小,模型就简单?

答案: 小权重 → 激活函数近似线性 → 模型退化为线性

以tanh为例:
- tanh(z) 在z接近0时近似线性: tanh(z) ≈ z
- 如果权重W很小 → z = Wx + b 也很小
- → tanh(z) ≈ z
- → 神经网络退化为线性模型!

线性模型 = 简单模型 = 低容量 = 不易过拟合
"""

def visualize_activation_linearity():
    """
    可视化激活函数的线性近似
    """
    z = np.linspace(-5, 5, 1000)

    # Tanh激活函数
    tanh_z = np.tanh(z)

    # 线性近似 (在原点的切线)
    linear_approx = z

    fig, axes = plt.subplots(1, 2, figsize=(14, 6))

    # 左图: 完整范围
    ax1 = axes[0]
    ax1.plot(z, tanh_z, 'b-', linewidth=2, label='tanh(z)')
    ax1.plot(z, linear_approx, 'r--', linewidth=2, label='线性近似: z')
    ax1.axhline(y=0, color='k', linestyle='--', alpha=0.3)
    ax1.axvline(x=0, color='k', linestyle='--', alpha=0.3)

    # 标注线性区域
    ax1.axvspan(-1, 1, alpha=0.2, color='green', label='近似线性区域')

    ax1.set_xlabel('z = Wx + b', fontsize=12)
    ax1.set_ylabel('激活值', fontsize=12)
    ax1.set_title('Tanh激活函数 vs 线性近似', fontsize=14, fontweight='bold')
    ax1.legend(fontsize=11)
    ax1.grid(True, alpha=0.3)

    # 右图: 放大线性区域
    ax2 = axes[1]
    z_small = np.linspace(-1, 1, 1000)
    tanh_small = np.tanh(z_small)
    linear_small = z_small

    ax2.plot(z_small, tanh_small, 'b-', linewidth=3, label='tanh(z)')
    ax2.plot(z_small, linear_small, 'r--', linewidth=3, label='线性近似: z')
    ax2.axhline(y=0, color='k', linestyle='--', alpha=0.3)
```

#### B. 多项式视角

```python
"""
类比: 多项式拟合

低阶多项式 (简单):
y = w₀ + w₁x
- 只能拟合直线
- 不会过拟合

高阶多项式 (复杂):
y = w₀ + w₁x + w₂x² + ... + w₁₀x¹⁰
- 可以拟合复杂曲线
- 容易过拟合

L2正则化的效果:
- 高阶系数w₂, w₃, ..., w₁₀ → 0
- 模型退化为低阶多项式
- 更简单,更平滑
"""

def demonstrate_polynomial_regularization():
    """
    演示多项式正则化
    """
    # 生成数据
    np.random.seed(42)
    X = np.linspace(0, 1, 20)
    y_true = np.sin(2 * np.pi * X)
    y = y_true + 0.2 * np.random.randn(20)

    # 测试数据
    X_test = np.linspace(0, 1, 100)
    y_test_true = np.sin(2 * np.pi * X_test)

    fig, axes = plt.subplots(1, 3, figsize=(18, 5))

    # 三种情况
    configs = [
        {'degree': 15, 'lambda': 0, 'title': '高阶无正则化 (过拟合)'},
        {'degree': 15, 'lambda': 0.01, 'title': '高阶+弱正则化 (适中)'},
        {'degree': 15, 'lambda': 1.0, 'title': '高阶+强正则化 (欠拟合)'},
    ]

    for ax, config in zip(axes, configs):
        degree = config['degree']
        lambda_reg = config['lambda']

        # 构造特征矩阵
        X_poly = np.column_stack([X**i for i in range(degree+1)])
        X_test_poly = np.column_stack([X_test**i for i in range(degree+1)])

        # 带正则化的最小二乘
        # W = (X^T X + λI)^(-1) X^T y
        XtX = X_poly.T @ X_poly
        I = np.eye(degree + 1)
        I[0, 0] = 0  # 不正则化常数项

        W = np.linalg.inv(XtX + lambda_reg * I) @ X_poly.T @ y

        # 预测
        y_pred = X_test_poly @ W

        # 绘图
        ax.scatter(X, y, c='blue', s=50, alpha=0.6, label='训练数据')
        ax.plot(X_test, y_test_true, 'g--', linewidth=2, label='真实函数')
        ax.plot(X_test, y_pred, 'r-', linewidth=2, label='拟合曲线')

        ax.set_xlabel('x', fontsize=12)
        ax.set_ylabel('y', fontsize=12)
        ax.set_title(config['title'], fontsize=12, fontweight='bold')
        ax.legend(fontsize=10)
        ax.grid(True, alpha=0.3)

        # 显示权重大小
        weights_norm = np.linalg.norm(W)
        ax.text(0.5, -1.3, f'||W|| = {weights_norm:.2f}',
               fontsize=11, ha='center',
               bbox=dict(boxstyle='round', facecolor='yellow', alpha=0.7))

        # 显示高阶系数
        high_order_weights = W[5:]  # 5阶以上
        ax.text(0.5, -1.6, f'高阶系数: {np.mean(np.abs(high_order_weights)):.4f}',
               fontsize=10, ha='center')

    plt.tight_layout()
    plt.show()

    print("\n关键洞察:")
    print("=" * 60)
    print("1. 无正则化: 高阶系数很大,曲线剧烈抖动")
    print("2. 弱正则化: 高阶系数变小,曲线平滑")
    print("3. 强正则化: 高阶系数接近0,退化为低阶")
    print("4. 正则化 = 限制模型复杂度")

# demonstrate_polynomial_regularization()
```

### 3. L1正则化的稀疏性原理

#### 数学解释

```python
"""
为什么L1产生稀疏解?

关键: L1的梯度是常数!

L2梯度: ∇(w²) = 2w
- 权重大时,梯度大
- 权重小时,梯度小
- 很难降到0

L1梯度: ∇(|w|) = sign(w) = ±1
- 不管权重多大,梯度都是±1
- 小权重也会被推向0
- 容易产生稀疏解
"""

def compare_l1_l2_gradients():
    """
    对比L1和L2的梯度
    """
    w = np.linspace(-3, 3, 1000)

    # L1和L2的值
    l1_penalty = np.abs(w)
    l2_penalty = w ** 2

    # L1和L2的梯度
    l1_grad = np.sign(w)
    l2_grad = 2 * w

    fig, axes = plt.subplots(2, 2, figsize=(14, 10))

    # 1. 惩罚函数
    ax1 = axes[0, 0]
    ax1.plot(w, l1_penalty, 'r-', linewidth=2, label='L1: |w|')
    ax1.plot(w, l2_penalty, 'b-', linewidth=2, label='L2: w²')
    ax1.axhline(y=0, color='k', linestyle='--', alpha=0.3)
    ax1.axvline(x=0, color='k', linestyle='--', alpha=0.3)
    ax1.set_xlabel('权重 w', fontsize=12)
    ax1.set_ylabel('惩罚值', fontsize=12)
    ax1.set_title('惩罚函数对比', fontsize=14, fontweight='bold')
    ax1.legend(fontsize=11)
    ax1.grid(True, alpha=0.3)
    ax1.set_ylim(-0.5, 5)

    # 2. 梯度函数
    ax2 = axes[0, 1]
    ax2.plot(w, l1_grad, 'r-', linewidth=3, label='L1梯度: sign(w)')
    ax2.plot(w, l2_grad, 'b-', linewidth=3, label='L2梯度: 2w')
    ax2.axhline(y=0, color='k', linestyle='--', alpha=0.3)
    ax2.axvline(x=0, color='k', linestyle='--', alpha=0.3)
```

### 4. Dropout的工作机理

#### 集成学习视角

```python
"""
Dropout = 隐式的集成学习

单次前向传播:
- 随机dropout → 得到一个子网络
- 训练这个子网络

整个训练:
- 每次dropout不同 → 不同的子网络
- 相当于训练了2^n个子网络 (n=神经元数)

测试时:
- 使用所有神经元
- 相当于对所有子网络做平均
- 集成学习 → 泛化更好
"""

def visualize_dropout_ensemble():
    """
    可视化Dropout的集成效果
    """
    fig, axes = plt.subplots(2, 2, figsize=(14, 10))

    # 原始网络
    ax1 = axes[0, 0]
    # 简化绘图: 显示3层网络
    layer_sizes = [4, 5, 3]

    def draw_network(ax, dropout_mask=None, title=''):
        ax.clear()
        ax.set_xlim(0, 3)
        ax.set_ylim(0, max(layer_sizes) + 1)
        ax.axis('off')
        ax.set_title(title, fontsize=12, fontweight='bold')

        # 绘制节点
        for layer_idx, size in enumerate(layer_sizes):
            for node_idx in range(size):
                x = layer_idx
                y = node_idx + (max(layer_sizes) - size) / 2

                # 检查是否被dropout
                if dropout_mask is not None and dropout_mask[layer_idx][node_idx] == 0:
                    color = 'lightgray'
                    alpha = 0.3
                else:
                    color = 'skyblue'
                    alpha = 1.0

                circle = plt.Circle((x, y), 0.15, color=color,
                                  ec='black', alpha=alpha, zorder=3)
                ax.add_patch(circle)

                # 绘制连接
                if layer_idx < len(layer_sizes) - 1:
                    next_size = layer_sizes[layer_idx + 1]
                    for next_node in range(next_size):
                        next_y = next_node + (max(layer_sizes) - next_size) / 2

                        # 检查连接是否被dropout
                        if dropout_mask is not None:
                            if (dropout_mask[layer_idx][node_idx] == 0 or
                                dropout_mask[layer_idx+1][next_node] == 0):
                                line_alpha = 0.1
                            else:
                                line_alpha = 0.5
                        else:
                            line_alpha = 0.5

                        ax.plot([x, x+1], [y, next_y], 'k-',
                               alpha=line_alpha, linewidth=1, zorder=1)

    # 1. 完整网络
    draw_network(axes[0, 0], title='完整网络 (测试时)')

    # 2-4. 不同的dropout子网络
    np.random.seed(42)
    for idx, ax in enumerate([axes[0, 1], axes[1, 0], axes[1, 1]]):
        # 生成随机dropout mask
        dropout_mask = []
        for size in layer_sizes:
            mask = (np.random.rand(size) > 0.5).astype(int)
            dropout_mask.append(mask)

        draw_network(ax, dropout_mask, title=f'训练时子网络 {idx+1}')

    plt.tight_layout()
    plt.show()

    print("\n关键洞察:")
    print("=" * 60)
    print("1. 每次训练使用不同的子网络")
    print("2. Dropout=0.5 → 2^n个可能的子网络")
    print("3. 训练 = 隐式训练多个子网络")
    print("4. 测试 = 所有子网络的平均 (集成)")
    print("5. 集成学习 → 更好的泛化")
```

### 5. 贝叶斯视角

```python
"""
正则化 = 先验分布 (Bayesian Prior)

最大后验估计 (MAP):
W* = argmax P(W|Data)
   = argmax P(Data|W) × P(W)
   = argmax log P(Data|W) + log P(W)
     ↑                      ↑
   似然 (数据拟合)       先验 (正则化)

L2正则化 = 高斯先验:
P(W) ∝ exp(-||W||²/2σ²)
→ log P(W) = -||W||²/2σ² + const
→ 等价于L2正则化

L1正则化 = 拉普拉斯先验:
P(W) ∝ exp(-|W|/b)
→ log P(W) = -|W|/b + const
→ 等价于L1正则化
"""

def visualize_bayesian_view():
    """
    可视化贝叶斯视角
    """
    w = np.linspace(-3, 3, 1000)

    # 高斯先验 (L2)
    sigma = 1.0
    gaussian_prior = (1 / (sigma * np.sqrt(2*np.pi))) * \
                    np.exp(-w**2 / (2*sigma**2))

    # 拉普拉斯先验 (L1)
    b = 1.0
    laplace_prior = (1 / (2*b)) * np.exp(-np.abs(w) / b)

    # 均匀先验 (无正则化)
    uniform_prior = np.ones_like(w) * 0.15

    fig, axes = plt.subplots(1, 2, figsize=(14, 6))

    # 左图: 先验分布
    ax1 = axes[0]
    ax1.plot(w, uniform_prior, 'g-', linewidth=2,
            label='均匀先验 (无正则化)')
    ax1.plot(w, gaussian_prior, 'b-', linewidth=2,
            label='高斯先验 (L2)')
    ax1.plot(w, laplace_prior, 'r-', linewidth=2,
            label='拉普拉斯先验 (L1)')

    ax1.axvline(x=0, color='k', linestyle='--', alpha=0.3)
    ax1.set_xlabel('权重 w', fontsize=12)
    ax1.set_ylabel('概率密度', fontsize=12)
    ax1.set_title('先验分布', fontsize=14, fontweight='bold')
    ax1.legend(fontsize=11)
    ax1.grid(True, alpha=0.3)

    # 标注
    ax1.text(0, gaussian_prior[len(w)//2] + 0.05,
            '高斯: 偏好小权重', fontsize=10, ha='center',
            bbox=dict(boxstyle='round', facecolor='lightblue'))
    ax1.text(0, laplace_prior[len(w)//2] + 0.15,
            '拉普拉斯: 强烈偏好0', fontsize=10, ha='center',
            bbox=dict(boxstyle='round', facecolor='lightcoral'))

    # 右图: 负对数先验 (等价于正则化项)
    ax2 = axes[1]

    neg_log_gaussian = w**2 / (2*sigma**2)
    neg_log_laplace = np.abs(w) / b

    ax2.plot(w, neg_log_laplace, 'r-', linewidth=2,
            label='-log P(w) [拉普拉斯] = |w|')
    ax2.plot(w, neg_log_gaussian, 'b-', linewidth=2,
            label='-log P(w) [高斯] = w²')

    ax2.axvline(x=0, color='k', linestyle='--', alpha=0.3)
    ax2.set_xlabel('权重 w', fontsize=12)
    ax2.set_ylabel('负对数先验 (惩罚)', fontsize=12)
    ax2.set_title('负对数先验 = 正则化项', fontsize=14, fontweight='bold')
    ax2.legend(fontsize=11)
    ax2.grid(True, alpha=0.3)
    ax2.set_ylim(0, 5)

    plt.tight_layout()
    plt.show()

    print("\n关键洞察:")
    print("=" * 60)
    print("1. 正则化 = 对权重的先验假设")
    print("2. L2 = 高斯先验: 权重服从正态分布")
    print("3. L1 = 拉普拉斯先验: 权重集中在0附近")
    print("4. 无正则化 = 均匀先验: 任何权重等概率")
    print()
    print("5. 贝叶斯视角提供了理论基础")
    print("6. 解释了为什么正则化是合理的")
```

### 3. 与学习率的关系

```python
"""
正则化强度与学习率的交互

权重更新:
W_new = W × (1 - αλ) - α × ∇Data_Loss
         ↑
      衰减因子

关系:
- α大 → 衰减强
- λ大 → 衰减强
- αλ控制总衰减

实践:
- 增大α → 应减小λ
- 增大λ → 应减小α
- 两者需要平衡
"""

def demonstrate_lr_reg_interaction():
    """
    演示学习率与正则化的交互
    """
    print("\n学习率与正则化交互:")
    print("=" * 60)

    configs = [
        {'lr': 0.01, 'lambda': 0.1, 'name': '低lr + 中等λ'},
        {'lr': 0.1, 'lambda': 0.01, 'name': '高lr + 低λ'},
        {'lr': 0.01, 'lambda': 1.0, 'name': '低lr + 高λ'},
    ]

    for config in configs:
        lr = config['lr']
        lambda_reg = config['lambda']
        decay_factor = 1 - lr * lambda_reg

        print(f"\n{config['name']}:")
        print(f"  学习率α = {lr}")
        print(f"  正则化λ = {lambda_reg}")
        print(f"  衰减因子 = {decay_factor:.6f}")
        print(f"  每步权重变为原来的 {decay_factor:.2%}")
```

### 2. 选择性正则化

```python
"""
DeepSeek-V3不是对所有参数都正则化

排除项:
1. bias参数
   - 不影响模型复杂度
   - 正则化反而有害

2. LayerNorm参数 (γ, β)
   - 已经被归一化约束
   - 不需要额外正则化

3. Position Embedding
   - 位置信息不应被惩罚
   - 需要保留完整信息

只正则化:
- 权重矩阵 (W_q, W_k, W_v, W_o)
- FFN权重
- Embedding权重 (可选)
"""

# 实现选择性正则化
def create_param_groups(model):
    """
    创建参数组: 分别设置正则化
    """
    # 不正则化的参数名称
    no_decay = [
        'bias',
        'LayerNorm.weight',
        'LayerNorm.bias',
        'position_embedding',
    ]

    # 参数分组
    optimizer_grouped_parameters = [
        {
            # 需要正则化的参数
            'params': [
                p for n, p in model.named_parameters()
                if not any(nd in n for nd in no_decay) and p.requires_grad
            ],
            'weight_decay': 0.1,
            'name': 'with_decay'
        },
        {
            # 不正则化的参数
            'params': [
                p for n, p in model.named_parameters()
                if any(nd in n for nd in no_decay) and p.requires_grad
            ],
            'weight_decay': 0.0,
            'name': 'no_decay'
        }
    ]

    return optimizer_grouped_parameters
```

## 常见误区

### ❌ 误区1: 认为正则化只影响权重大小

```python
"""
错误: 正则化只是让权重变小

事实:
1. 让权重变小 (直接效果)
2. 激活函数线性化 (间接效果)
3. 降低有效VC维 (理论效果)
4. 实现奥卡姆剃刀 (哲学意义)
5. 等价于贝叶斯先验 (统计意义)

正则化是多层次的作用!
"""
```

### ❌ 误区2: 认为L1一定比L2好

```python
"""
错误: L1产生稀疏,所以更好

事实:
- L1适合: 需要特征选择、解释性强
- L2适合: 通用场景、大多数深度学习
- 不是哪个"更好",而是哪个"更合适"

实践:
- 深度学习几乎都用L2 (weight decay)
- L1主要用于传统ML和特征选择
"""
```

### ❌ 误区3: 认为Dropout=随机删除

```python
"""
错误: Dropout就是随机删除神经元

正确理解:
1. 训练时: 随机失活 + 缩放 (Inverted Dropout)
2. 测试时: 使用所有神经元 (不dropout)
3. 等价于: 训练多个子网络的集成
4. 效果: 防止co-adaptation,提升泛化

关键: Inverted Dropout的缩放!
- 保持期望不变
- 测试时不需要缩放
"""
```

### ❌ 误区4: 认为数据多就不需要正则化

```python
"""
错误: 我有1亿数据,不会过拟合,不需要正则化

事实:
- 大数据能减少过拟合,但不能消除
- 大模型仍可能过拟合到大数据
- 正则化还有其他作用 (稳定训练、防止梯度爆炸)

DeepSeek-V3案例:
- 14.8T tokens (巨量!)
- 671B参数 (巨大!)
- 仍使用weight_decay=0.1和dropout=0.1
- 提升训练稳定性和最终性能
"""
```

## 总结

### 核心机理

```
L2正则化为什么有效?

1. 数学机理:
   ∇L_reg = ∇L_data + λW
   → 权重被拉向原点
   → 权重变小

2. 神经网络机理:
   权重小 → z=Wx+b小
   → 激活函数线性化
   → 模型容量降低
   → 不易过拟合

3. 统计学机理:
   L2 = 高斯先验
   → 偏好小权重
   → 奥卡姆剃刀
   → 简单模型泛化好

4. 信息论机理:
   正则化 = MDL原则
   → 平衡拟合与复杂度
   → 最短描述长度
```

### L1 vs L2 本质区别

```
L1产生稀疏的原因:

1. 梯度恒定: ∇|w| = sign(w) = ±1
   → 小权重也被推向0
   → 容易变为0

2. 几何形状: 菱形约束
   → 有尖角在坐标轴上
   → 等高线易与尖角相交
   → 解在轴上 (某些权重=0)

L2不产生稀疏的原因:

1. 梯度正比: ∇w² = 2w
   → 权重越小,梯度越小
   → 难以降到0

2. 几何形状: 圆形约束
   → 平滑无尖角
   → 解一般不在轴上
```

### Dropout的奥秘

```
为什么随机丢弃能提升性能?

1. 集成学习:
   - 训练2^n个子网络
   - 测试时集成
   - 集成 → 泛化好

2. 防止共适应:
   - 神经元被迫独立
   - 不过度依赖特定组合
   - 更鲁棒

3. 隐式正则化:
   - 等价于数据增强
   - 增加训练噪声
   - 提升泛化
```

```
正则化的本质:

   /     \
低VC维  小权重
  ↓       ↓
泛化好  激活线性化
  ↓       ↓
  好的泛化能力!
```
