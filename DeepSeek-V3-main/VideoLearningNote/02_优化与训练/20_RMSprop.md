## 📌 基本定义

**RMSprop** (Root Mean Square Propagation)
是 Geoffrey Hinton 在 2012 年提出的自适应学习率优化算法，通过维护梯度平方的指数加权平均来**为每个参数动态调整学习率**。

### 核心思想
在不同维度上使用不同的学习率 - 对于梯度变化剧烈的方向使用较小学习率，对于梯度平缓的方向使用较大学习率。

---

## 🎯 为什么需要 RMSprop?

### 动量梯度下降的局限

虽然动量能减少震荡，但仍存在问题：

1. **学习率全局统一**
   - 所有参数使用相同的学习率
   - 无法适应不同参数的特性

2. **峡谷问题未完全解决**
   - 纵向震荡虽然减小，但仍存在
   - 横向加速有限

### RMSprop 的创新

✅ **自适应学习率** - 每个参数有独立的有效学习率
✅ **抑制震荡维度** - 梯度大的方向自动减小步长
✅ **加速平缓维度** - 梯度小的方向自动增大步长
✅ **数值稳定性** - 避免梯度爆炸/消失的影响

---

## 🔧 算法原理

### 核心公式

```
s_dθ = β * s_dθ + (1 - β) * dθ²      # 累积梯度平方
θ = θ - α * dθ / (√s_dθ + ε)         # 自适应更新
```

**参数说明**:
- `s_dθ`: 梯度平方的指数加权平均
- `β`: 衰减率，通常取 0.9 或 0.999
- `α`: 全局学习率
- `dθ`: 当前梯度
- `ε`: 数值稳定项 (通常 10^-8)，防止除零

### 关键洞察

```
梯度大的参数:
  → s_dθ 大 → √s_dθ 大 → 有效学习率小 → 更新步长小
 
梯度小的参数:
  → s_dθ 小 → √s_dθ 小 → 有效学习率大 → 更新步长大
```

**结果**: 自动平衡不同参数的更新速度！

## 🧮 完整算法流程

### 伪代码实现

```python
# 初始化
s_dW = 0   # 权重W的梯度平方累积
s_db = 0   # 偏置b的梯度平方累积
β = 0.9    # 衰减率（推荐值）
ε = 1e-8   # 数值稳定项

# 每次迭代
for epoch in range(num_epochs):
    for mini_batch in mini_batches:
        # 1. 计算当前mini-batch的梯度
        dW, db = compute_gradients(mini_batch)

        # 2. 累积梯度平方的指数加权平均
        s_dW = β * s_dW + (1 - β) * dW**2
        s_db = β * s_db + (1 - β) * db**2

        # 3. 自适应更新参数
        W = W - α * dW / (np.sqrt(s_dW) + ε)
        b = b - α * db / (np.sqrt(s_db) + ε)
```

### 向量化实现

```python
import numpy as np

class RMSpropOptimizer:
    def __init__(self, learning_rate=0.001, beta=0.9, epsilon=1e-8):
        self.lr = learning_rate
        self.beta = beta
        self.epsilon = epsilon
        self.s = {}  # 存储梯度平方的累积

    def initialize(self, parameters):
        """初始化梯度平方累积器"""
        for key in parameters:
            self.s[key] = np.zeros_like(parameters[key])

    def update(self, parameters, gradients):
        """RMSprop更新"""
        for key in parameters:
            # 累积梯度平方
            self.s[key] = (self.beta * self.s[key] +
                          (1 - self.beta) * gradients[key]**2)

            # 自适应更新
            parameters[key] -= (self.lr * gradients[key] /
                               (np.sqrt(self.s[key]) + self.epsilon))

        return parameters
```

## 🎨 直观理解

### 椭圆峡谷可视化

```
成本函数等高线 (纵向陡峭,横向平缓):

    纵向 (梯度大)
      ↕
  ●●●●●●●●
  ●      ●
  ●   *  ● ← 横向 (梯度小)
  ●  目标 ●
  ●●●●●●●●

标准GD:
  纵向: 大梯度 → 大步长 → 震荡 ⚠️
  横向: 小梯度 → 小步长 → 缓慢 ⚠️

RMSprop:
  纵向: 大梯度 → s大 → 步长自动缩小 ✅
  横向: 小梯度 → s小 → 步长自动放大 ✅

结果: 路径更直接,收敛更快!
```

### 物理类比

想象在不同地形上行走:

```
标准梯度下降:
  └─> 穿同一双鞋走所有路 (统一学习率)
      在陡坡上容易滑倒 (震荡)
      在平地上走得很慢

RMSprop:
  └─> 鞋底会自动适应地形 (自适应学习率)
      陡坡上鞋底摩擦力大 (减小步长)
      平地上步幅自动加大 (增大步长)
```

## 📊 参数选择指南

### β (衰减率)

| β值 | 效果 | 适用场景 |
|-----|------|---------|
| 0.9 | 标准设置 | 大多数情况 |
| **0.999** | **常用值** | **深度网络、Adam中** |
| 0.99 | 中等平滑 | 一般训练 |

**推荐**: β = 0.9 或 0.999 (Adam中常用0.999)

### α (学习率)

```
典型值: 0.001 (比标准GD小)

原因:
- RMSprop已通过除以√s调整步长
- 全局学习率作为基准倍数
- 过大会导致不稳定

调整策略:
- 从 0.001 开始
- 观察训练曲线
- 逐步调整 (0.0001, 0.01等)
```

### ε (数值稳定项)

```
标准值: 1e-8

作用:
- 防止除零错误
- 当 s_dθ 很小时提供数值稳定性
- 通常不需要调整
```

## ⚖️ 优缺点分析

### ✅ 优点

1. **自适应学习率**
   - 每个参数独立调整
   - 自动平衡不同参数的更新

2. **有效解决峡谷问题**
   - 抑制震荡方向
   - 加速收敛方向

3. **数值稳定**
   - 梯度归一化效果
   - 减少梯度爆炸/消失的影响

4. **实现简单**
   - 计算开销适中
   - 内存需求合理 (2x参数量)

5. **适用性广**
   - 适合非平稳目标 (non-stationary objectives)
   - 适合RNN等循环网络

### ⚠️ 缺点

1. **学习率衰减**
   - s_dθ 单调递增
   - 学习率持续减小
   - 可能过早停止学习

2. **超参数敏感**
   - β 和 α 需要仔细调整
   - 不同问题可能需要不同设置

3. **不保证收敛**
   - 非凸优化中可能陷入局部最优
   - 理论保证弱于某些算法

4. **额外内存**
   - 需要存储 s (梯度平方累积)
   - 内存翻倍

## 🔬 与其他方法对比

### 1. RMSprop vs 动量

| 特性 | 动量GD | RMSprop |
|-----|--------|---------|
| **核心思想** | 累积梯度方向 | 调整学习率 |
| **解决问题** | 加速+减少震荡 | 自适应步长 |
| **维护变量** | 速度 v | 梯度平方 s |
| **学习率** | 全局统一 | 每参数自适应 |
| **适用场景** | 一般深度网络 | 非平稳、RNN |

### 2. 三种优化器对比

```
标准GD:    θ = θ - α·dθ
           └─> 固定学习率,直接更新

动量GD:    v = β·v + (1-β)·dθ
           θ = θ - α·v
           └─> 考虑历史方向,平滑更新

RMSprop:   s = β·s + (1-β)·dθ²
           θ = θ - α·dθ/√s
           └─> 自适应学习率,归一化更新
```

### 3. 协同效果

```
动量:    关注"去哪里" (方向)
RMSprop: 关注"走多快" (步长)

结合两者 → Adam优化器 (下节课!)
```

✅ **推荐使用**:
- 训练RNN/LSTM等循环网络
- 非平稳目标函数 (目标随时间变化)
- 在线学习/流式数据场景
- 梯度稀疏的问题 (如NLP)

❌ **可能不适合**:
- 非常小的模型

### 3. 调试建议

```python

print(f"s_dW stats: mean={s_dW.mean():.2e}, max={s_dW.max():.2e}")

# → 降低全局学习率 α

```


## 🧪 数学推导

### 为什么除以√s?

**目标**: 归一化不同参数的更新步长

假设有两个参数 θ₁ 和 θ₂:
```
参数1: 梯度稳定在 dθ₁ ≈ 0.01
参数2: 梯度稳定在 dθ₂ ≈ 10

标准GD:
  Δθ₁ = -α·0.01 = 非常小
  Δθ₂ = -α·10   = 非常大
  → 比例 1:1000 (严重不平衡!)

RMSprop:
  s₁ ≈ 0.01² = 0.0001
  s₂ ≈ 10²   = 100

  Δθ₁ = -α·0.01/√0.0001 = -α·1
  Δθ₂ = -α·10/√100       = -α·1
  → 比例 1:1 (完美平衡!)
```

**关键**: 除以梯度的RMS (Root Mean Square) 实现归一化

### 与二阶方法的联系

RMSprop 可以看作对角近似的牛顿法:

```
牛顿法:    θ = θ - α·H⁻¹·dθ
           其中 H 是海森矩阵(二阶导数)

RMSprop:   θ = θ - α·dθ/√s
           ≈ θ - α·diag(1/√s)·dθ

解释:
- √s ≈ 曲率的近似 (二阶信息)
- 除以√s ≈ 使用曲率调整步长
- 只用对角元素 → 计算高效
```

### s的演化

展开 s_dθ (假设β=0.9):
```
s₁ = 0.1·dθ₁²
s₂ = 0.9·s₁ + 0.1·dθ₂² = 0.09·dθ₁² + 0.1·dθ₂²
s₃ = 0.9·s₂ + 0.1·dθ₃² = 0.081·dθ₁² + 0.09·dθ₂² + 0.1·dθ₃²
...

s_t ≈ 0.1·(dθ_t² + 0.9·dθ_(t-1)² + 0.81·dθ_(t-2)² + ...)
```

**洞察**: s 是梯度平方的指数加权平均 → 反映最近的梯度大小

1. **自适应学习率的核心**
   ```
   s = β·s + (1-β)·grad²
   θ = θ - α·grad/√s
   ```

2. **关键优势**
   - ✅ 每个参数独立调整学习率
   - ✅ 自动平衡不同参数的更新
   - ✅ 有效解决峡谷问题

3. **参数设置**
   - β = 0.9 (标准) 或 0.999 (深度网络)
   - α = 0.001 (典型起点)
   - ε = 1e-8 (固定)

4. **应用场景**
   - RNN/LSTM训练
   - 非平稳目标
   - 梯度稀疏问题
