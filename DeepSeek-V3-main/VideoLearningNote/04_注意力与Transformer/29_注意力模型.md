## 🎯 1. Transformer 模型

### 1.1 完整架构

```
Transformer 整体架构:
════════════════════

Encoder (编码器, N=6 层):
  Input → Embedding + PosEncoding
          ↓
        Multi-Head Attention
          ↓
        Feed Forward
          ↓
        (重复 6 次)

Decoder (解码器, N=6 层):
  Output → Embedding + PosEncoding
           ↓
        Masked Multi-Head Attention
           ↓
        Cross-Attention (Q=解码器, K=编码器, V=编码器)
           ↓
        Feed Forward
           ↓
        (重复 6 次)

最终: Linear + Softmax → 输出概率

关键组件:
═════════

1. Input Embedding + Positional Encoding
2. Multi-Head Self-Attention
3. Masked Multi-Head Self-Attention (仅解码器)
4. Cross-Attention (仅解码器)
5. Feed-Forward Network
6. Residual Connection + Layer Normalization
7. Output Linear Layer + Softmax
```

### 1.2 编码器详细结构

```
编码器单层结构:
══════════════

Input: [batch_size, seq_len]

├─ Embedding: [batch_size, seq_len, d_model]
├─ Positional Encoding: [batch_size, seq_len, d_model]
   ↓ (相加)
├─ Multi-Head Self-Attention
   ├─ Linear(Q,K,V) → Q,K,V
   ├─ Scaled Dot-Product Attention
   ├─ Multi-Head 拼接
   └─ Linear(O)
   ↓ (Residual + LayerNorm)
├─ Feed Forward
   ├─ Linear(d_model → d_ff)
   ├─ ReLU
   └─ Linear(d_ff → d_model)
   ↓ (Residual + LayerNorm)
Output: [batch_size, seq_len, d_model]

代码实现:
════════

class EncoderLayer(nn.Module):
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        self.self_attention = MultiHeadAttention(d_model, n_heads, dropout)
        self.feed_forward = FeedForward(d_model, d_ff, dropout)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout1 = nn.Dropout(dropout)
        self.dropout2 = nn.Dropout(dropout)

    def forward(self, x):
        # Self-Attention + 残差连接
        attn_output = self.self_attention(x, x, x, mask=None)
        x = self.norm1(x + self.dropout1(attn_output))

        # Feed Forward + 残差连接
        ff_output = self.feed_forward(x)
        x = self.norm2(x + self.dropout2(ff_output))

        return x


class Encoder(nn.Module):
    def __init__(self, vocab_size, d_model, n_heads, d_ff,
                 n_layers, dropout=0.1):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.pos_encoding = PositionalEncoding(d_model, dropout)
        self.layers = nn.ModuleList([
            EncoderLayer(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])

    def forward(self, x):
        x = self.embedding(x)
        x = self.pos_encoding(x)

        for layer in self.layers:
            x = layer(x)

        return x


# 使用示例
encoder = Encoder(
    vocab_size=10000,
    d_model=512,
    n_heads=8,
    d_ff=2048,
    n_layers=6
)

src = torch.randint(0, 10000, (10, 32))  # [seq_len=10, batch_size=32]
encoder_output = encoder(src)  # [10, 32, 512]
```

### 1.3 解码器详细结构

```
解码器单层结构:
══════════════

Input: [batch_size, seq_len]

├─ Embedding: [batch_size, seq_len, d_model]
├─ Positional Encoding: [batch_size, seq_len, d_model]
   ↓ (相加)
├─ Masked Multi-Head Self-Attention
   ├─ 目标: 防止看到未来信息
   ├─ Query, Key, Value 都来自解码器
   └─ 使用因果 mask
   ↓ (Residual + LayerNorm)
├─ Cross-Attention
   ├─ Query 来自解码器
   ├─ Key, Value 来自编码器
   └─ 跨序列注意力
   ↓ (Residual + LayerNorm)
├─ Feed Forward
   └─ 同编码器
   ↓ (Residual + LayerNorm)
Output: [batch_size, seq_len, d_model]

因果 Mask:
═════════

作用: 防止解码器在生成第 t 个词时看到第 t+1, t+2, ... 个词

掩码矩阵:
  t=1: [1]
  t=2: [1, 1]
  t=3: [1, 1, 1]
  ...
  t=T: [1, 1, 1, ..., 1] (T 个 1)

可视化:
  [[True, False, False],
   [True, True,  False],
   [True, True,  True]]

代码实现:
════════

class DecoderLayer(nn.Module):
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        self.self_attention = MultiHeadAttention(d_model, n_heads, dropout)
        self.cross_attention = MultiHeadAttention(d_model, n_heads, dropout)
        self.feed_forward = FeedForward(d_model, d_ff, dropout)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        self.dropout1 = nn.Dropout(dropout)
        self.dropout2 = nn.Dropout(dropout)
        self.dropout3 = nn.Dropout(dropout)

    def forward(self, x, encoder_output, tgt_mask, src_mask=None):
        # 1. Masked Self-Attention (自回归)
        self_attn_output = self.self_attention(x, x, x, mask=tgt_mask)
        x = self.norm1(x + self.dropout1(self_attn_output))

        # 2. Cross-Attention (编码器-解码器)
        cross_attn_output = self.cross_attention(
            x, encoder_output, encoder_output, mask=src_mask
        )
        x = self.norm2(x + self.dropout2(cross_attn_output))

        # 3. Feed Forward
        ff_output = self.feed_forward(x)
        x = self.norm3(x + self.dropout3(ff_output))

        return x


class Decoder(nn.Module):
    def __init__(self, vocab_size, d_model, n_heads, d_ff,
                 n_layers, dropout=0.1):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.pos_encoding = PositionalEncoding(d_model, dropout)
        self.layers = nn.ModuleList([
            DecoderLayer(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])
        self.output_proj = nn.Linear(d_model, vocab_size)

    def forward(self, x, encoder_output, tgt_mask, src_mask=None):
        x = self.embedding(x)
        x = self.pos_encoding(x)

        for layer in self.layers:
            x = layer(x, encoder_output, tgt_mask, src_mask)

        # 输出层
        output = self.output_proj(x)
        return output


# 使用示例
decoder = Decoder(
    vocab_size=10000,
    d_model=512,
    n_heads=8,
    d_ff=2048,
    n_layers=6
)

tgt = torch.randint(0, 10000, (10, 32))  # [seq_len=10, batch_size=32]
encoder_output = torch.randn(10, 32, 512)  # [seq_len, batch_size, d_model]
tgt_mask = subsequent_mask(10)  # [10, 10] 因果掩码

decoder_output = decoder(tgt, encoder_output, tgt_mask)  # [10, 32, 512]
```

### 1.4 完整的 Transformer 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class Transformer(nn.Module):
    """完整的 Transformer 模型"""

    def __init__(self, src_vocab_size, tgt_vocab_size, d_model=512,
                 n_heads=8, d_ff=2048, n_layers=6, dropout=0.1):
        super().__init__()
        self.d_model = d_model

        # 编码器
        self.encoder = Encoder(
            src_vocab_size, d_model, n_heads, d_ff, n_layers, dropout
        )

        # 解码器
        self.decoder = Decoder(
            tgt_vocab_size, d_model, n_heads, d_ff, n_layers, dropout
        )

        # 输出层
        self.output_proj = nn.Linear(d_model, tgt_vocab_size)

        # 初始化参数
        self._init_parameters()

    def _init_parameters(self):
        """参数初始化"""
        for p in self.parameters():
            if p.dim() > 1:
                nn.init.xavier_uniform_(p)

    def forward(self, src, tgt, src_mask=None, tgt_mask=None):
        """
        参数:
            src: [src_len, batch_size]
            tgt: [tgt_len, batch_size]
            src_mask: [batch_size, 1, src_len] (可选)
            tgt_mask: [batch_size, tgt_len, tgt_len] (可选)

        返回:
            output: [tgt_len, batch_size, tgt_vocab_size]
        """
        # 编码
        encoder_output = self.encoder(src)

        # 解码
        decoder_output = self.decoder(
            tgt, encoder_output, tgt_mask, src_mask
        )

        # 输出
        output = self.output_proj(decoder_output)

        return output

    def encode(self, src):
        """仅编码 (用于推理)"""
        return self.encoder(src)

    def decode(self, tgt, encoder_output, tgt_mask=None):
        """仅解码 (用于推理)"""
        return self.decoder(tgt, encoder_output, tgt_mask)


def subsequent_mask(size):
    """创建因果掩码"""
    mask = torch.triu(torch.ones(size, size), diagonal=1).bool()
    # 上三角为 True (遮蔽), 下三角为 False (保留)
    # [size, size]
    return mask == False  # 反转,使下三角为 True


def create_padding_mask(seq, pad_idx=0):
    """创建 padding 掩码"""
    mask = (seq != pad_idx).unsqueeze(1).unsqueeze(2)
    # [batch_size, 1, 1, seq_len]
    return mask


def create_masks(src, tgt, pad_idx=0):
    """创建所有掩码"""
    src_mask = create_padding_mask(src, pad_idx)
    tgt_mask = subsequent_mask(tgt.size(0))

    return src_mask, tgt_mask


# 使用示例
transformer = Transformer(
    src_vocab_size=10000,
    tgt_vocab_size=10000,
    d_model=512,
    n_heads=8,
    d_ff=2048,
    n_layers=6
)

# 训练模式
src = torch.randint(0, 10000, (10, 32))  # [10, 32]
tgt = torch.randint(0, 10000, (12, 32))  # [12, 32]

src_mask, tgt_mask = create_masks(src, tgt)
output = transformer(src, tgt, src_mask, tgt_mask)
# output: [12, 32, 10000]

# 推理模式 (自回归生成)
def greedy_decode(model, src, max_len=100, start_symbol=1, end_symbol=2):
    """贪心解码"""
    src = src.unsqueeze(1)  # [len, 1]
    batch_size = src.size(1)

    # 编码
    memory = model.encode(src)

    # 初始化目标序列
    ys = torch.ones(1, batch_size).fill_(start_symbol).type_as(src)

    for i in range(max_len - 1):
        tgt = ys
        tgt_mask = subsequent_mask(tgt.size(0)).type_as(src)

        # 解码一步
        out = model.decode(tgt, memory, tgt_mask)
        out = out.transpose(0, 1)

        # 预测下一个词
        prob = model.output_proj(out[:, -1])
        _, next_word = torch.max(prob, dim=1)
        next_word = next_word.data[0]

        if next_word == end_symbol:
            break

        ys = torch.cat([ys, torch.ones(1, batch_size).type_as(src).fill_(next_word)], dim=0)

    return ys[1:]


# 推理示例
src = torch.randint(0, 10000, (10, 1))
translated = greedy_decode(transformer, src)
# translated: [seq_len, 1]
```

## 🎯 2. BERT 模型

### 2.1 架构特点

```
BERT = Bidirectional Encoder Representations from Transformers

核心特点:
├─ 仅使用编码器 (Encoder-Only)
├─ 双向 Self-Attention (可以看到前后文)
├─ 预训练 + 微调范式
└─ 两种预训练任务:
    ├─ Masked Language Modeling (MLM)
    └─ Next Sentence Prediction (NSP)

应用场景:
├─ 文本分类
├─ 序列标注 (NER, POS)
├─ 问答系统
└─ 句子相似度
```

### 2.2 BERT 的 Self-Attention

```
BERT 的注意力模式:
══════════════════

双向注意力:
  输入: "I love you"

  对每个位置,注意力可以关注前后所有位置:

  位置 1 ("I"):
    可以关注: [I, love, you] ✓

  位置 2 ("love"):
    可以关注: [I, love, you] ✓ (前后都能看到!)

  位置 3 ("you"):
    可以关注: [I, love, you] ✓

vs GPT 的单向注意力:
  输入: "I love you"

  对每个位置,注意力只能关注前面的位置:

  位置 1 ("I"):
    可以关注: [I] ✓

  位置 2 ("love"):
    可以关注: [I, love] ✓

  位置 3 ("you"):
    可以关注: [I, love, you] ✓

优势: BERT 可以看到完整上下文,更适合理解任务
```

### 2.3 BERT 的预训练任务

```
任务1: Masked Language Modeling (MLM)
═════════════════════════════════════

目标: 预测被遮蔽的词

示例:
  原始: "I love you"
  遮蔽: "I [MASK] you"

  训练: 模型预测 "love" (或同义词)

策略: 15% 的词被遮蔽
├─ 80%: 替换为 [MASK]
├─ 10%: 保持不变 (提升鲁棒性)
└─ 10%: 随机替换 (防止过拟合)

代码实现:
════════

class BERTPretrainer(nn.Module):
    def __init__(self, config):
        super().__init__()
        self.bert = BERT(config)
        self.mlm_head = nn.Linear(config.d_model, config.vocab_size)
        self.nsp_head = nn.Linear(config.d_model, 2)  # Next Sentence Prediction

    def forward(self, input_ids, segment_ids=None, attention_mask=None,
                masked_positions=None):
        # 获取 BERT 输出
        sequence_output, pooled_output = self.bert(
            input_ids, segment_ids, attention_mask
        )

        # MLM 任务
        if masked_positions is not None:
            mlm_output = []
            for pos in masked_positions:
                mlm_output.append(sequence_output[pos])
            mlm_output = torch.stack(mlm_output)  # [num_masked, batch_size, d_model]
            mlm_logits = self.mlm_head(mlm_output)  # [num_masked, batch_size, vocab_size]
        else:
            mlm_logits = None

        # NSP 任务
        nsp_logits = self.nsp_head(pooled_output)  # [batch_size, 2]

        return mlm_logits, nsp_logits

任务2: Next Sentence Prediction (NSP)
════════════════════════════════════

目标: 判断两个句子是否连续

示例:
  句子A: "I love you"
  句子B: "Do you love me?"
  标签: IsNext  ✓ (连续)

  vs

  句子A: "I love you"
  句子B: "The sky is blue"
  标签: NotNext  ✗ (不连续)

输入格式:
  [CLS] Sentence A [SEP] Sentence B [SEP]

注意: NSP 在 BERT 后续版本中被移除 (RoBERTa)
```

## 🎯 3. GPT 模型

### 3.1 架构特点

```
GPT = Generative Pre-trained Transformer

核心特点:
├─ 仅使用解码器 (Decoder-Only)
├─ 单向 Self-Attention (只能看到过去)
├─ 自回归语言模型 (Autoregressive)
└─ 预训练: 预测下一个词

应用场景:
├─ 文本生成
├─ 对话系统
├─ 代码生成
└─ 创意写作

演进历史:
├─ GPT-1: 117M 参数
├─ GPT-2: 1.5B 参数 (引发关注)
├─ GPT-3: 175B 参数 (涌现能力)
└─ GPT-4: 未公开 (可能更大)
```

### 3.2 自回归生成

```
自回归语言模型:
════════════════

目标: 给定前 t-1 个词,预测第 t 个词

数学表达:
  P(w_t | w_1, w_2, ..., w_{t-1})

训练过程:
  输入: "I love you"
  目标: 预测每个位置的后一个词

  位置1 (I):
    输入: [CLS]
    目标: "I"

  位置2 (love):
    输入: [CLS, I]
    目标: "love"

  位置3 (you):
    输入: [CLS, I, love]
    目标: "you"

总损失: -log P("I"|[CLS]) - log P("love"|[CLS,I]) - log P("you"|[CLS,I,love])

推理过程:
  输入: [CLS]
  输出: "I" → 概率分布

  输入: [CLS, I]
  输出: "love" → 概率分布

  输入: [CLS, I, love]
  输出: "you" → 概率分布

  输入: [CLS, I, love, you]
  输出: [EOS] → 完成

代码实现:
════════

class GPTModel(nn.Module):
    def __init__(self, vocab_size, d_model, n_heads, d_ff, n_layers):
        super().__init__()
        self.transformer = Transformer(
            src_vocab_size=vocab_size,
            tgt_vocab_size=vocab_size,
            d_model=d_model,
            n_heads=n_heads,
            d_ff=d_ff,
            n_layers=n_layers
        )
        # GPT 使用相同的 vocab_size 作为源和目标
        self.transformer.encoder.embedding = self.transformer.decoder.embedding

    def forward(self, input_ids):
        # 编码器输出
        encoder_output = self.transformer.encode(input_ids)

        # 解码器输入 (右移一位)
        tgt = input_ids[:-1]  # 去掉最后一个词
        tgt_mask = subsequent_mask(len(tgt))

        # 解码
        decoder_output = self.transformer.decode(tgt, encoder_output, tgt_mask)

        # 输出
        output = self.transformer.output_proj(decoder_output)

        return output

    def generate(self, input_ids, max_len=100, temperature=1.0):
        """自回归生成"""
        for _ in range(max_len):
            # 前向传播
            logits = self.forward(input_ids)  # [seq_len, 1, vocab_size]
            next_token_logits = logits[-1, 0, :] / temperature

            # 采样或贪心
            probs = F.softmax(next_token_logits, dim=-1)
            next_token = torch.multinomial(probs, 1)

            # 添加到序列
            input_ids = torch.cat([input_ids, next_token.unsqueeze(0)], dim=0)

            # 如果遇到结束符,停止
            if next_token.item() == EOS_TOKEN:
                break

        return input_ids
```

## 🎯 4. Vision Transformer (ViT)

### 4.1 图像注意力

```
Vision Transformer 的思想:
═════════════════════════

将图像视为"patch"序列
每个 patch 相当于一个"词"

步骤:
1. 将图像划分为固定大小的 patch
2. 每个 patch 展平并线性变换为嵌入
3. 添加位置编码
4. 使用 Transformer 编码器

示例:
  输入: 224×224×3 图像
  patch size: 16×16
  图像划分: 14×14 = 196 个 patches

  每个 patch: 16×16×3 = 768 像素
  线性变换: 768 → 512 (嵌入维度)

  最终输入: [196, 512] (类似序列)

代码实现:
════════

class ViT(nn.Module):
    def __init__(self, img_size, patch_size, n_classes, d_model,
                 n_heads, d_ff, n_layers):
        super().__init__()
        self.img_size = img_size
        self.patch_size = patch_size
        self.n_patches = (img_size // patch_size) ** 2

        # Patch 嵌入
        self.patch_embedding = nn.Conv2d(
            3, d_model, kernel_size=patch_size, stride=patch_size
        )

        # 位置嵌入
        self.position_embedding = nn.Parameter(
            torch.randn(1, self.n_patches + 1, d_model)  # +1 for [CLS]
        )

        # 分类 token
        self.cls_token = nn.Parameter(torch.randn(1, 1, d_model))

        # Transformer 编码器
        self.transformer = Encoder(
            vocab_size=None,  # 不使用 vocab
            d_model=d_model,
            n_heads=n_heads,
            d_ff=d_ff,
            n_layers=n_layers
        )

        # 分类头
        self.classifier = nn.Linear(d_model, n_classes)

    def forward(self, x):
        batch_size = x.size(0)

        # Patch 嵌入
        x = self.patch_embedding(x)  # [batch, d_model, h, w]
        x = x.flatten(2).transpose(1, 2)  # [batch, n_patches, d_model]

        # 添加 CLS token
        cls_tokens = self.cls_token.expand(batch_size, -1, -1)  # [batch, 1, d_model]
        x = torch.cat([cls_tokens, x], dim=1)  # [batch, n_patches+1, d_model]

        # 添加位置嵌入
        x = x + self.position_embedding

        # Transformer 编码 (去掉 CLS token 的位置信息)
        x = x.transpose(0, 1)  # [n_patches+1, batch, d_model]
        x = self.transformer(x)
        x = x.transpose(0, 1)  # [batch, n_patches+1, d_model]

        # 只取 CLS token 进行分类
        cls_output = x[:, 0]  # [batch, d_model]
        output = self.classifier(cls_output)

        return output


# 使用示例
vit = ViT(
    img_size=224,
    patch_size=16,
    n_classes=1000,
    d_model=512,
    n_heads=8,
    d_ff=2048,
    n_layers=6
)

# 输入: [batch, 3, 224, 224]
images = torch.randn(32, 3, 224, 224)
output = vit(images)  # [32, 1000]
```

## 🎯 5. Graph Attention Network (GAT)

### 5.1 图注意力

```
图注意力网络 (Graph Attention Network):
═════════════════════════════════════

将注意力应用于图结构数据

节点: 图中的顶点
边: 节点之间的连接
邻居: 与节点直接相连的节点

注意力的作用:
为每个节点的邻居分配不同的权重

数学表达:
  h_i' = σ(Σ_{j∈N(i)} α_{ij} · W h_j)

其中:
  h_i': 节点 i 的新表示
  N(i): 节点 i 的邻居集合
  α_{ij}: 注意力权重 (从 i 到 j)
  W: 线性变换矩阵

注意力权重计算:
  α_{ij} = softmax_j (LeakyReLU( a^T [W h_i || W h_j] ))

其中:
  ||: 拼接操作
  a: 注意力向量
  LeakyReLU: 激活函数
```

### 5.2 GAT 完整实现

```python
class GraphAttentionLayer(nn.Module):
    """图注意力层"""

    def __init__(self, in_features, out_features, dropout=0.6,
                 alpha=0.2, concat=True):
        super().__init__()
        self.in_features = in_features
        self.out_features = out_features
        self.dropout = dropout
        self.alpha = alpha
        self.concat = concat

        self.W = nn.Parameter(torch.empty(size=(in_features, out_features)))
        self.a = nn.Parameter(torch.empty(size=(2*out_features, 1)))

        nn.init.xavier_uniform_(self.W.data, gain=1.414)
        nn.init.xavier_uniform_(self.a.data, gain=1.414)

        self.leakyrelu = nn.LeakyReLU(self.alpha)

    def forward(self, h, adj):
        """
        参数:
            h: [batch_size, n_nodes, in_features]
            adj: [batch_size, n_nodes, n_nodes] (邻接矩阵)

        返回:
            h': [batch_size, n_nodes, out_features]
        """
        batch_size, n_nodes, in_features = h.shape

        # 线性变换
        Wh = torch.matmul(h, self.W)  # [batch, n_nodes, out_features]

        # 计算注意力分数
        a_input = torch.cat([Wh.repeat(1, 1, n_nodes).view(batch_size, n_nodes*n_nodes, -1),
                             Wh.repeat(1, n_nodes, 1)], dim=-1)
        # [batch, n_nodes*n_nodes, 2*out_features]
        a_input = a_input.view(batch_size, n_nodes, n_nodes, 2*self.out_features)

        e = self.leakyrelu(torch.matmul(a_input, self.a).squeeze(-1))
        # [batch, n_nodes, n_nodes]

        # 应用邻接矩阵掩码 (无连接的节点注意力分数设为 -inf)
        zero_vec = -9e15 * torch.ones_like(e)
        e = torch.where(adj > 0, e, zero_vec)

        # Softmax
        attention = F.softmax(e, dim=-1)
        attention = F.dropout(attention, self.dropout, training=self.training)

        # 加权求和
        h_prime = torch.matmul(attention, Wh)  # [batch, n_nodes, out_features]

        if self.concat:
            return F.elu(h_prime)
        else:
            return h_prime


class GAT(nn.Module):
    """完整的 GAT 模型"""

    def __init__(self, n_features, n_hidden, n_classes, dropout, alpha, n_heads):
        super().__init__()
        self.dropout = dropout

        self.attentions = nn.ModuleList([
            GraphAttentionLayer(n_features if i == 0 else n_hidden * n_heads,
                              n_hidden, dropout=dropout, alpha=alpha, concat=True)
            for i in range(n_heads)
        ])

        self.out_att = GraphAttentionLayer(n_heads * n_hidden, n_classes,
                                          dropout=dropout, alpha=alpha, concat=False)

    def forward(self, x, adj):
        x = F.dropout(x, self.dropout, training=self.training)
        x = torch.cat([att(x, adj) for att in self.attentions], dim=-1)
        x = F.dropout(x, self.dropout, training=self.training)
        x = F.elu(self.out_att(x, adj))
        return F.log_softmax(x, dim=-1)


# 使用示例
gat = GAT(
    n_features=32,  # 节点特征维度
    n_hidden=16,    # 隐藏层维度
    n_classes=7,    # 类别数
    dropout=0.6,
    alpha=0.2,
    n_heads=8
)

# 输入: [batch_size, n_nodes, features]
batch_size = 32
n_nodes = 100
x = torch.randn(batch_size, n_nodes, 32)  # 节点特征
adj = torch.randint(0, 2, (batch_size, n_nodes, n_nodes))  # 邻接矩阵
adj = adj + adj.transpose(1, 2)  # 对称 (无向图)
adj = (adj > 0).float()  # 二值化

output = gat(x, adj)  # [batch_size, n_nodes, n_classes]
```

## 🔍 6. 对比分析

### 6.1 不同注意力模型的对比

```
注意力模型对比表:
═══════════════════

┌─────────────┬──────────┬──────────┬──────────┬──────────┐
│ 模型        │ 架构     │ 注意力   │ 任务类型 │ 参数规模 │
├─────────────┼──────────┼──────────┼──────────┼──────────┤
│ Transformer │ Encoder+ │ Self+    │ 翻译/    │ 60M      │
│             │ Decoder  │ Cross    │ 摘要等   │          │
├─────────────┼──────────┼──────────┼──────────┼──────────┤
│ BERT        │ Encoder  │ Self     │ 分类/    │ 340M     │
│             │ (双向)   │          │ NER/问答 │          │
├─────────────┼──────────┼──────────┼──────────┼──────────┤
│ GPT         │ Decoder  │ Self     │ 生成/    │ 175B     │
│             │ (单向)   │ (因果)   │ 对话     │          │
├─────────────┼──────────┼──────────┼──────────┼──────────┤
│ ViT         │ Encoder  │ Self     │ 图像分类 │ 86M      │
│             │          │          │          │          │
├─────────────┼──────────┼──────────┼──────────┼──────────┤
│ GAT         │ 注意力层 │ 图注意力 │ 节点分类 │ 10K      │
│             │          │          │          │          │
└─────────────┴──────────┴──────────┴──────────┴──────────┘

架构特点:
═════════

Transformer:
  优势:
    ✓ 通用性强 (可处理各种序列任务)
    ✓ 并行计算 (训练快)
    ✓ 长距离依赖 (无梯度消失)
  劣势:
    ✗ 计算复杂度 O(n²)
    ✗ 需要位置编码

BERT:
  优势:
    ✓ 双向编码 (理解上下文)
    ✓ 预训练+微调 (迁移学习)
    ✓ 多种任务 (分类、序列标注)
  劣势:
    ✗ 仅编码器 (不能生成)
    ✗ 推理慢 (需要全序列)

GPT:
  优势:
    ✓ 生成能力强
    ✓ 少样本学习 (涌现能力)
    ✓ 大规模预训练
  劣势:
    ✗ 单向 (看不到未来信息)
    ✗ 幻觉问题 (可能生成错误信息)

ViT:
  优势:
    ✓ 纯注意力 (无卷积)
    ✓ 适合大数据 (ImageNet-21K)
    ✓ 可解释性 (注意力可视化)
  劣势:
    ✗ 需要大量数据 (比 CNN 多)
    ✗ 计算复杂 (图像 patches 很多)

GAT:
  优势:
    ✓ 处理图结构数据
    ✓ 节点间关系建模
    ✓ 不需要预定义特征
  劣势:
    ✗ 仅适用于图数据
    ✗ 计算复杂度高 (图可能很大)
```

### 6.2 选择建议

```
如何选择注意力模型:
═════════════════

1. 任务类型:
   ├─ 翻译/摘要 → Transformer
   ├─ 分类/NER → BERT
   ├─ 生成/对话 → GPT
   ├─ 图像分类 → ViT
   └─ 图挖掘 → GAT

2. 数据量:
   ├─ 大数据 (>1M) → GPT/ViT/BERT-large
   ├─ 中数据 (~100K) → BERT/GPT-base
   ├─ 小数据 (~10K) → BERT-small/GAT
   └─ 极少数据 (<1K) → 迁移学习

3. 计算资源:
   ├─ 大算力 (GPU 集群) → GPT-3/4
   ├─ 中等算力 (单卡) → Transformer/BERT-base
   └─ 小算力 (CPU) → GAT/Lightweight models

4. 延迟要求:
   ├─ 实时 (毫秒级) → 优化后的 Transformer
   ├─ 准实时 (秒级) → BERT
   └─ 离线 (分钟/小时) → GPT

5. 可解释性:
   ├─ 需要高可解释性 → GAT/ViT
   ├─ 中等可解释性 → Transformer/BERT
   └─ 低可解释性 → GPT-3/4
```

## 💡 核心要点总结

```
注意力模型核心要点:
═════════════════

1. Transformer 架构
   = Encoder + Decoder + Attention + FeedForward
   通用性强,是其他模型的基础

2. BERT (Bidirectional)
   仅编码器,双向注意力
   适合理解任务 (分类、标注)

3. GPT (Generative)
   仅解码器,单向注意力
   适合生成任务 (对话、写作)

4. Vision Transformer
   图像 → patches → 序列
   注意力替代卷积

5. Graph Attention Network
   图结构数据的注意力
   节点间关系建模

6. 共同点
   都有 Multi-Head Attention
   都需要位置编码
   都有残差连接和层归一化

7. 性能对比
   Transformer 最通用
   BERT 最适合理解
   GPT 最适合生成
   ViT 在大数据上优于 CNN
   GAT 是图数据标配

8. 选择指南
   任务类型 + 数据量 + 计算资源
```
