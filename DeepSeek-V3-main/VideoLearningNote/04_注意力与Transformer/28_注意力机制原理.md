## 📌 核心问题

```
注意力机制解决了什么问题？
═══════════════════════

Seq2Seq 的局限性:
┌─────────────────────────────────────────┐
│  Encoder: "I love you" → c              │
│  Decoder: c → "我爱你"                  │
│                                          │
│  问题:                                 │
│  • c 是固定长度的向量                   │
│  • 必须将所有信息压缩到 c 中             │
│  • 长序列信息损失                       │
│  • 无法选择性关注相关信息               │
└─────────────────────────────────────────┘

注意力机制的解决方案:
┌─────────────────────────────────────────┐
│  Encoder: "I love you"                  │
│  h₁ = "I"    h₂ = "love"  h₃ = "you"    │
│                                          │
│  Decoder 每步可以选择性关注:             │
│  生成"我": 关注 h₁ ("I")                 │
│  生成"爱": 关注 h₂ ("love")              │
│  生成"你": 关注 h₃ ("you")               │
│                                          │
│  优势:                                 │
│  ✅ 不需要压缩所有信息                   │
│  ✅ 选择性关注相关信息                   │
│  ✅ 处理长序列无信息损失                 │
│  ✅ 可解释性强                           │
└─────────────────────────────────────────┘

🎯 核心思想: 让解码器在每步生成时"看"整个输入序列,
    并选择性地关注与当前生成最相关的部分
```

## 🎯 注意力机制的基本思想

### 1. 什么是注意力？

```
注意力的直观理解:
═══════════════

人类注意力:
  当我们读这句话时:
  "I love you" → "我爱你"

  大脑会:
  • 看到 "I" → 关注 "我"
  • 看到 "love" → 关注 "爱"
  • 看到 "you" → 关注 "你"

  每一步都选择性关注最相关的信息!

机器注意力:
  Decoder 在生成每个词时:
  • 计算与每个 Encoder 隐藏状态的相关性
  • 得到注意力权重 (哪个词更重要)
  • 加权求和得到上下文
  • 基于这个上下文生成下一个词

图示:
════

时间步 t=1 (生成"我"):
  注意力权重: [0.8, 0.1, 0.1]
  上下文 c₁ = 0.8×h₁ + 0.1×h₂ + 0.1×h₃

时间步 t=2 (生成"爱"):
  注意力权重: [0.1, 0.8, 0.1]
  上下文 c₂ = 0.1×h₁ + 0.8×h₂ + 0.1×h₃

时间步 t=3 (生成"你"):
  注意力权重: [0.1, 0.1, 0.8]
  上下文 c₃ = 0.1×h₁ + 0.1×h₂ + 0.8×h₃

这就是注意力! 每步都动态选择关注点!
```

### 2. 为什么需要注意力？

```
Seq2Seq + 注意力 vs 纯 Seq2Seq:
═════════════════════════════

纯 Seq2Seq:
  输入: "I love you" (10个词)
  输出: "我爱你" (4个词)

  过程:
    h₁ ──┐
    h₂ ──┤
    h₃ ──┼─── RNN ─── c (固定向量)
    ...  │
    h₁₀ ─┘

    问题: 所有信息必须压缩到 c 中
    短序列: 可能还行
    长序列: 信息损失严重!

Seq2Seq + 注意力:
  输入: "I love you" (10个词)
  输出: "我爱你" (4个词)

  过程:
    h₁ ──┐
    h₂ ──┐    注意力权重
    h₃ ──┼─── α₁, α₂, α₃ ──→ c₁ → y₁="我"
    ...  │
    h₁₀ ─┘

    每步的 c_t 都不同!
    c₁ 关注 h₁ (生成"我")
    c₂ 关注 h₂ (生成"爱")
    c₃ 关注 h₃ (生成"你")
    c₄ 关注结束符

优势:
✅ 处理长序列无信息损失
✅ 解码每步都有针对性上下文
✅ 可解释性强 (能看到关注点)
✅ 提升机器翻译质量 5-10%
```

## 🧮 注意力机制的数学原理

### 核心公式

```
注意力机制的核心公式:
══════════════════

给定:
  Query: Q (查询向量, 当前解码状态)
  Keys: K = [k₁, k₂, ..., kₙ] (键向量, Encoder 隐藏状态)
  Values: V = [v₁, v₂, ..., vₙ] (值向量, 通常 = Keys)

步骤1: 计算注意力分数 (Score)
  score_i = f(Q, K_i)

  常用方法:
  • 点积注意力: score_i = Q · K_i
  • 加性注意力: score_i = wᵀ tanh(W₁Q + W₂K_i)
  • Scaled Dot-Product: score_i = (Q · K_i) / √d_k

步骤2: Softmax 归一化得到权重
  α_i = softmax(score_i) = exp(score_i) / Σⱼ exp(score_j)

  确保 α_i ≥ 0 且 Σ α_i = 1

步骤3: 加权求和得到上下文
  Attention(Q, K, V) = Σᵢ αᵢ · Vᵢ

完整流程:
  Q ──┐
       │ 计算分数
  K₁ ──┤ ──── α₁
  K₂ ──┤ ──── α₂
  ...  │   ↓
  Kₙ ──┤ ──── αₙ
       │
  V₁ ──┤       ↓
  V₂ ──┤    Σ αᵢVᵢ → 上下文向量
  ...  │
  Vₙ ──┘

可视化:
════════

输入: Query Q
输入: Keys K = [k₁, k₂, k₃, k₄]
输入: Values V = [v₁, v₂, v₃, v₄]

分数: [Q·k₁, Q·k₂, Q·k₃, Q·k₄] = [2.1, 0.3, -0.5, 1.8]
权重: [0.77, 0.13, 0.05, 0.54]  (softmax 后)

上下文: c = 0.77·v₁ + 0.13·v₂ + 0.05·v₃ + 0.54·v₄
```

### 具体数学推导

```
示例: 机器翻译中的注意力
════════════════════════

假设:
  源序列: "I love you" (English)
  目标序列: "我爱你" (Chinese)

Encoder (双向 LSTM):
  输入: x₁="I", x₂="love", x₃="you"

  隐藏状态:
    h₁ = [0.2, -0.1, 0.5, 0.3]  (对应 "I")
    h₂ = [0.1, 0.4, -0.2, 0.6]  (对应 "love")
    h₃ = [-0.3, 0.2, 0.1, 0.4]  (对应 "you")

Decoder (时间步 t=1, 生成"我"):
  当前隐藏状态: s₁ = [0.1, 0.3, -0.2, 0.5]

  计算注意力分数:
    score₁ = s₁ · h₁ = 0.1×0.2 + 0.3×(-0.1) + (-0.2)×0.5 + 0.5×0.3
            = 0.02 - 0.03 - 0.10 + 0.15 = 0.04

    score₂ = s₁ · h₂ = 0.1×0.1 + 0.3×0.4 + (-0.2)×(-0.2) + 0.5×0.6
            = 0.01 + 0.12 + 0.04 + 0.30 = 0.47

    score₃ = s₁ · h₃ = 0.1×(-0.3) + 0.3×0.2 + (-0.2)×0.1 + 0.5×0.4
            = -0.03 + 0.06 - 0.02 + 0.20 = 0.21

  Softmax 归一化:
    e^0.04 = 1.04, e^0.47 = 1.60, e^0.21 = 1.23
    sum = 1.04 + 1.60 + 1.23 = 3.87

    α₁ = 1.04 / 3.87 = 0.27  (关注 "I")
    α₂ = 1.60 / 3.87 = 0.41  (关注 "love")
    α₃ = 1.23 / 3.87 = 0.32  (关注 "you")

  加权求和:
    c₁ = 0.27×h₁ + 0.41×h₂ + 0.32×h₃
       = 0.27×[0.2,-0.1,0.5,0.3] + 0.41×[0.1,0.4,-0.2,0.6] + 0.32×[-0.3,0.2,0.1,0.4]
       = [0.05,-0.03,0.14,0.08] + [0.04,0.16,-0.08,0.25] + [-0.10,0.06,0.03,0.13]
       = [-0.01, 0.19, 0.09, 0.46]

  生成"我":
    输入: s₁, c₁, <SOS>
    输出: y₁ = "我"

Decoder (时间步 t=2, 生成"爱"):
  新隐藏状态: s₂ = [0.2, 0.5, -0.1, 0.3]

  重新计算注意力分数:
    score₁ = s₂ · h₁ = 0.2×0.2 + 0.5×(-0.1) + (-0.1)×0.5 + 0.3×0.3
            = 0.04 - 0.05 - 0.05 + 0.09 = 0.03

    score₂ = s₂ · h₂ = 0.2×0.1 + 0.5×0.4 + (-0.1)×(-0.2) + 0.3×0.6
            = 0.02 + 0.20 + 0.02 + 0.18 = 0.42

    score₃ = s₂ · h₃ = 0.2×(-0.3) + 0.5×0.2 + (-0.1)×0.1 + 0.3×0.4
            = -0.06 + 0.10 - 0.01 + 0.12 = 0.15

  Softmax 归一化:
    e^0.03 = 1.03, e^0.42 = 1.52, e^0.15 = 1.16
    sum = 1.03 + 1.52 + 1.16 = 3.71

    α₁ = 1.03 / 3.71 = 0.28  (关注 "I")
    α₂ = 1.52 / 3.71 = 0.41  (关注 "love")
    α₃ = 1.16 / 3.71 = 0.31  (关注 "you")

  加权求和:
    c₂ = 0.28×h₁ + 0.41×h₂ + 0.31×h₃
       = [0.06,-0.03,0.14,0.08] + [0.04,0.16,-0.08,0.25] + [-0.09,0.06,0.03,0.12]
       = [0.01, 0.19, 0.09, 0.45]

  生成"爱":
    输入: s₂, c₂, "我"
    输出: y₂ = "爱"

关键观察:
  生成"我"时,主要关注 h₁ (α₁=0.27, α₂=0.41, α₃=0.32) ✓ 合理
  生成"爱"时,主要关注 h₂ (α₁=0.28, α₂=0.41, α₃=0.31) ✓ 合理

  注意: 注意力权重是概率分布,表示对每个位置的关注程度
```

## 🔍 从 Seq2Seq 到注意力

### Seq2Seq + 注意力的完整架构

```
完整架构图:
══════════

           Encoder (双向 LSTM)
           ┌────────────────────────┐
           │  x₁ → h₁ → [h₁₊, h₁₋]  │
           │  x₂ → h₂ → [h₂₊, h₂₋]  │
           │  x₃ → h₃ → [h₃₊, h₃₋]  │
           └──────────┬─────────────┘
                      ↓
           拼接隐藏状态: hₜ = [hₜ₊ ⊕ hₜ₋]

           ┌────────────────────────┐
           │ 注意力机制 (每步都不同!) │
           └──────────┬─────────────┘
                      ↓
           Decoder (单向 LSTM)
           ┌────────────────────────┐
           │ <SOS> → s₀              │
           │ s₀, c₁ → s₁ → y₁="我"   │
           │ s₁, c₂ → s₂ → y₂="爱"   │
           │ s₂, c₃ → s₃ → y₃="你"   │
           │ s₃ → <EOS>              │
           └────────────────────────┘

注意力机制详细:
═════════════

时间步 t=1 (生成 y₁="我"):
  Query: s₀ (初始隐藏状态)
  Keys: [h₁, h₂, h₃] (Encoder 隐藏状态)
  Values: [h₁, h₂, h₃]

  计算:
    分数 = [s₀·h₁, s₀·h₂, s₀·h₃]
    权重 = softmax(分数)
    上下文 c₁ = Σ αᵢ·hᵢ

  输入到 Decoder:
    s₁ = f(s₀, y₀, c₁)
    y₁ = g(s₁, c₁)

时间步 t=2 (生成 y₂="爱"):
  Query: s₁ (上一时间步的隐藏状态)
  Keys: [h₁, h₂, h₃] (不变)
  Values: [h₁, h₂, h₃] (不变)

  重新计算:
    分数 = [s₁·h₁, s₁·h₂, s₁·h₃]
    权重 = softmax(分数) ← 注意: 权重变了!
    上下文 c₂ = Σ αᵢ·hᵢ

  输入到 Decoder:
    s₂ = f(s₁, y₁, c₂)
    y₂ = g(s₂, c₂)

时间步 t=3 (生成 y₃="你"):
  Query: s₂
  重新计算注意力,得到 c₃
  s₃ = f(s₂, y₂, c₃)
  y₃ = g(s₃, c₃)

关键点:
  ✓ 每步的 Query 不同 (s₀, s₁, s₂)
  ✓ Keys 和 Values 保持不变
  ✓ 但注意力权重每步都重新计算!
  ✓ 上下文向量 cₜ 每步都不同!
```

### 对比: 纯 Seq2Seq vs Seq2Seq + Attention

```
纯 Seq2Seq (无注意力):
═══════════════════════

编码:
  输入: x₁, x₂, x₃
  h₁ = f(x₁, h₀)
  h₂ = f(x₂, h₁)
  h₃ = f(x₃, h₂)
  c = h₃  ← 只有最后的状态!

解码:
  时间步1: s₀ = f(c), y₁ = g(s₀)
  时间步2: s₁ = f(s₀, y₁), y₂ = g(s₁)
  时间步3: s₂ = f(s₁, y₂), y₃ = g(s₂)

  问题: 所有的 sₜ 都基于同一个 c!
        无法区分不同时间步需要的不同信息

Seq2Seq + 注意力:
════════════════

编码:
  输入: x₁, x₂, x₃
  h₁, h₂, h₃  (保留所有隐藏状态)

解码:
  时间步1: c₁ = Attention(s₀, [h₁,h₂,h₃]), y₁ = g(s₀, c₁)
  时间步2: c₂ = Attention(s₁, [h₁,h₂,h₃]), y₂ = g(s₁, c₂)
  时间步3: c₃ = Attention(s₂, [h₁,h₂,h₃]), y₃ = g(s₂, c₃)

  优势: 每个时间步都有针对性的上下文!

性能对比:
════════

BLEU 分数 (机器翻译):
  英→中: 基准 25 → +注意力 35  (提升 40%)
  英→法: 基准 30 → +注意力 40  (提升 33%)

长序列性能:
  序列长度 30: +注意力提升 15%
  序列长度 50: +注意力提升 35%
  序列长度 100: +注意力提升 60% ⭐⭐⭐

  结论: 序列越长,注意力优势越明显!
```

## 🔍 Self-Attention 机制

### 什么是 Self-Attention？

```
Self-Attention 的核心思想:
═══════════════════════

Self-Attention (自注意力):
  Query, Key, Value 都来自同一个序列

传统 Attention:
  Query 来自 Decoder
  Key, Value 来自 Encoder
  → 跨序列的注意力

Self-Attention:
  Query 来自序列位置 i
  Key, Value 来自序列所有位置
  → 序列内部的注意力

  作用: 找到序列内部词与词之间的关联关系

示例: "I love you"
═══════════════

位置1 ("I"):
  Query: q₁
  Key: [k₁, k₂, k₃]
  Value: [v₁, v₂, v₃]

  注意力权重: [α₁₁, α₁₂, α₁₃]
  α₁₁ = "I" 与 "I" 的关联 (自己与自己, 通常较高)
  α₁₂ = "I" 与 "love" 的关联 (可能中等)
  α₁₃ = "I" 与 "you" 的关联 (通常较低)

  上下文: c₁ = α₁₁v₁ + α₁₂v₂ + α₁₃v₃

位置2 ("love"):
  Query: q₂
  Key: [k₁, k₂, k₃]
  Value: [v₁, v₂, v₃]

  注意力权重: [α₂₁, α₂₂, α₂₃]
  α₂₁ = "love" 与 "I" 的关联 (通常中等)
  α₂₂ = "love" 与 "love" 的关联 (自己与自己, 通常较高)
  α₂₃ = "love" 与 "you" 的关联 (较高, 因为是一个短语)

  上下文: c₂ = α₂₁v₁ + α₂₂v₂ + α₂₃v₃

位置3 ("you"):
  Query: q₃
  Key: [k₁, k₂, k₃]
  Value: [v₁, v₂, v₃]

  注意力权重: [α₃₁, α₃₂, α₃₃]
  α₃₁ = "you" 与 "I" 的关联 (较低)
  α₃₂ = "you" 与 "love" 的关联 (较高)
  α₃₃ = "you" 与 "you" 的关联 (自己与自己, 通常较高)

  上下文: c₃ = α₃₁v₁ + α₃₂v₂ + α₃₃v₃

注意: Self-Attention 捕捉的是"我爱"这个短语内部的关系!
```

### Self-Attention 的数学计算

```
完整计算过程:
════════════

输入序列: X = [x₁, x₂, ..., xₙ], 每个 xᵢ ∈ ℝ^(d_model)

步骤1: 线性变换得到 Q, K, V
  Q = XW^Q  (Query)
  K = XW^K  (Key)
  V = XW^V  (Value)

  其中:
    W^Q ∈ ℝ^(d_model × d_k)
    W^K ∈ ℝ^(d_model × d_k)
    W^V ∈ ℝ^(d_model × d_v)

  通常 d_k = d_v = d_model / h (h 是头数)

步骤2: 计算注意力分数 (缩放点积)
  对于每个 Query qᵢ:
    scoresᵢ = [qᵢ·k₁/√d_k, qᵢ·k₂/√d_k, ..., qᵢ·kₙ/√d_k]

  为什么除以 √d_k?
    防止点积过大导致 softmax 饱和
    例如: 如果 d_k=64, 点积最大可达 64×max_val
    除以 √64=8 后, 数值更稳定

步骤3: Softmax 得到权重
  αᵢⱼ = softmax(scoresᵢⱼ) = exp(scoresᵢⱼ) / Σₗ exp(scoresᵢₗ)

步骤4: 加权求和得到输出
  oᵢ = Σⱼ αᵢⱼ · vⱼ

矩阵形式 (更高效):
═══════════════

输入: X ∈ ℝ^(n×d_model)

线性变换:
  Q = XW^Q ∈ ℝ^(n×d_k)
  K = XW^K ∈ ℝ^(n×d_k)
  V = XW^V ∈ ℝ^(n×d_v)

注意力分数矩阵:
  S = (QK^T) / √d_k ∈ ℝ^(n×n)

注意力权重矩阵:
  A = softmax(S) ∈ ℝ^(n×n)  (每行是一个概率分布)

输出:
  O = AV ∈ ℝ^(n×d_v)

注意: 这是 Single-Head 的计算
     Multi-Head 只是并行计算 h 次, 然后拼接

可视化:
════════

输入 X:
    x₁ x₂ x₃ ... xₙ
    ↓  ↓  ↓      ↓
  Q [q₁ q₂ q₃ ... qₙ]
  K [k₁ k₂ k₃ ... kₙ]
  V [v₁ v₂ v₃ ... vₙ]
    ↓  ↓  ↓      ↓
  S = (QK^T)/√d_k
    ↓
  A = softmax(S)  (每行是一个概率分布)
    ↓
  O = AV  (每个位置的新表示)
```

### Self-Attention 的优势

```
Self-Attention vs RNN vs CNN:
═════════════════════════════

RNN:
  优势:
    ✓ 参数少
    ✓ 捕捉顺序信息
    ✓ 处理变长序列

  劣势:
    ✗ 梯度路径长 (梯度消失)
    ✗ 无法并行计算
    ✗ 难以捕捉长距离依赖

CNN:
  优势:
    ✓ 并行计算
    ✓ 捕捉局部模式
    ✓ 稳定训练

  劣势:
    ✗ 需要多层堆叠才能捕捉全局
    ✗ 感受野受限
    ✗ 位置信息需要额外处理

Self-Attention:
  优势:
    ✓ 并行计算 (所有位置同时计算)
    ✓ 直接捕捉任意位置间的关系
    ✓ 计算复杂度 O(n²·d) (n 序列长度)
    ✓ 可解释性强 (注意力权重可视化)
    ✓ 是 Transformer 的核心组件

  劣势:
    ✗ 二次复杂度 (n²), 长序列计算量大
    ✗ 需要位置编码 (本身无位置信息)

计算复杂度对比:
══════════════

RNN: O(n·d²)
  n: 序列长度
  d: 隐藏维度

Self-Attention: O(n²·d)
  复杂度更高,但可并行

实际运行时间 (GPU 上):
  RNN: 慢 (无法并行)
  Self-Attention: 快 (高度并行)

  当 n=512 时:
    RNN: 需要 512 步串行计算
    Self-Attention: 一步并行计算

长距离依赖:
═══════════

RNN:
  位置1 → ... → 位置100
  梯度需要经过 99 步传递
  → 严重梯度消失

Self-Attention:
  位置1 与位置100 直接连接
  一步计算相关性
  → 无梯度消失问题

这就是为什么 Transformer 替代了 RNN!
```

## 🔬 注意力机制的变体

### 1. 全局注意力 vs 局部注意力

```
全局注意力 (Global Attention):
════════════════════════════

定义: 每一个 Query 都关注所有的 Key

计算:
  c_t = Σᵢ αᵢ · hᵢ
  其中 αᵢ = softmax(s_t · hᵢ) for all i

特点:
  ✓ 考虑所有位置的信息
  ✓ 模型容量大
  ✗ 计算复杂度 O(n²)
  ✗ 对长序列效率低

示例:
  输入: "I love you"
  生成"我": 关注 "I", "love", "you" (全部)
  生成"爱": 关注 "I", "love", "you" (全部)

局部注意力 (Local Attention):
═══════════════════════════

定义: 每一个 Query 只关注一个固定窗口内的 Key

计算:
  c_t = Σᵢ∈[p_t-D, p_t+D] αᵢ · hᵢ
  其中 p_t 是预测的位置, D 是窗口大小

特点:
  ✓ 计算复杂度 O(n·D) (线性)
  ✓ 效率高
  ✗ 可能错过远距离的重要信息
  ✗ 需要预测对齐位置

示例:
  输入: "I love you"
  生成"我": 关注 "I", "love" (窗口大小=2)
  生成"爱": 关注 "love", "you" (窗口大小=2)

比较:
════

全局注意力适合短序列 (< 100)
局部注意力适合长序列 (> 100)
```

### 2. 硬注意力 vs 软注意力

```
硬注意力 (Hard Attention):
════════════════════════

定义: 选择一个位置 (argmax), 权重为 1, 其他为 0

数学:
  αᵢ = 1 if i = argmax_j (s_t · h_j)
      0 otherwise

特点:
  ✓ 计算更简单
  ✓ 确定性
  ✗ 不可微 (无法端到端训练)
  ✗ 信息损失 (只选择一个位置)

实际应用:
  使用强化学习训练 (REINFORCE)
  训练稳定性较差

软注意力 (Soft Attention):
════════════════════════

定义: 所有位置的加权平均,权重是概率分布

数学:
  αᵢ = softmax(s_t · h_j) ∈ (0,1), Σ αᵢ = 1

特点:
  ✓ 可微 (端到端训练)
  ✓ 信息保留 (所有位置都有贡献)
  ✗ 计算复杂度稍高
  ✗ 需要 softmax (可能数值不稳定)

实际应用:
  更常用,训练更稳定
  几乎所有现代模型都用软注意力
```

### 3. 多头注意力 (Multi-Head Attention)

```
多头注意力的思想:
═══════════════

单头注意力:
  只能学习一种类型的相关性

多头注意力:
  并行计算 h 个注意力
  每个头学习不同类型的相关性
  最后拼接所有头的输出

数学:
  head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)
  MultiHead(Q,K,V) = Concat(head_1, ..., head_h)W^O

其中:
  W_i^Q, W_i^K, W_i^V ∈ ℝ^(d_model × d_k)
  d_k = d_model / h
  W^O ∈ ℝ^(h·d_k × d_model)

示例: 2 头注意力
════════════════

输入: "I love you"

头1 (头位置相关性):
  关注 "I love", "love you" 等位置关系
  权重: 位置1与位置2高, 位置1与位置3中等

头2 (语义相关性):
  关注主谓关系 "I love"
  权重: 位置1与位置2最高

拼接:
  c_1 = concat(head_1, head_2)

优势:
✓ 学习多种相关性
✓ 提升模型表达能力
✓ Transformer 的标配
```

### 4. 交叉注意力 (Cross-Attention)

```
交叉注意力的定义:
═══════════════

定义: Query 来自一个序列, Key, Value 来自另一个序列

应用场景:
  序列到序列模型 (机器翻译)
  编码器-解码器架构

计算:
  Query: 来自解码器 (Q = D W^Q)
  Key: 来自编码器 (K = E W^K)
  Value: 来自编码器 (V = E W^V)

  交叉注意力 = Attention(Q, K, V)

在机器翻译中的应用:
═══════════════════

编码器输出: 英文 "I love you" 的隐藏状态
解码器状态: 当前生成到 "我"

交叉注意力:
  Query: 解码器当前状态
  Key: 编码器所有隐藏状态
  Value: 编码器所有隐藏状态

  作用: 找到与当前生成最相关的英文部分

时间步1 (生成"我"):
  注意力权重: [0.7, 0.2, 0.1]
  → 主要关注 "I"

时间步2 (生成"爱"):
  注意力权重: [0.2, 0.7, 0.1]
  → 主要关注 "love"

时间步3 (生成"你"):
  注意力权重: [0.1, 0.2, 0.7]
  → 主要关注 "you"

这正是我们想要的行为!
```

### 基础注意力实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class Attention(nn.Module):
    """基础注意力机制"""

    def __init__(self, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size

        # 线性变换层
        self.attn = nn.Linear(hidden_size * 2, hidden_size)
        self.v = nn.Linear(hidden_size, 1, bias=False)

    def forward(self, encoder_outputs, decoder_hidden):
        """
        参数:
            encoder_outputs: [batch_size, seq_len, hidden_size]
            decoder_hidden: [batch_size, hidden_size]

        返回:
            context: [batch_size, hidden_size]
            attn_weights: [batch_size, seq_len]
        """
        batch_size, seq_len, hidden_size = encoder_outputs.shape

        # 重复 decoder_hidden 以匹配 encoder_outputs 的形状
        decoder_hidden = decoder_hidden.unsqueeze(1).repeat(1, seq_len, 1)
        # [batch_size, seq_len, hidden_size]

        # 拼接 encoder output 和 decoder hidden
        energy = torch.cat((encoder_outputs, decoder_hidden), dim=2)
        # [batch_size, seq_len, hidden_size * 2]

        # 计算注意力分数
        energy = torch.tanh(self.attn(energy))
        # [batch_size, seq_len, hidden_size]

        # 计算注意力权重 (最后一个线性层输出一个分数)
        attn_weights = self.v(energy).squeeze(2)
        # [batch_size, seq_len]

        # Softmax 得到概率分布
        attn_weights = F.softmax(attn_weights, dim=1)
        # [batch_size, seq_len]

        # 加权求和得到上下文向量
        context = torch.bmm(
            attn_weights.unsqueeze(1),  # [batch_size, 1, seq_len]
            encoder_outputs            # [batch_size, seq_len, hidden_size]
        ).squeeze(1)
        # [batch_size, hidden_size]

        return context, attn_weights


class AttentionSeq2Seq(nn.Module):
    """带注意力的 Seq2Seq 模型"""

    def __init__(self, vocab_size, embed_size, hidden_size):
        super().__init__()
        self.vocab_size = vocab_size
        self.hidden_size = hidden_size

        # 编码器
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.encoder = nn.LSTM(embed_size, hidden_size, bidirectional=True)

        # 注意力机制
        self.attention = Attention(hidden_size)

        # 解码器
        self.decoder = nn.LSTM(embed_size, hidden_size)
        self.output = nn.Linear(hidden_size, vocab_size)

        # 线性层调整维度 (双向 LSTM 输出 2*hidden_size)
        self.encoder_projection = nn.Linear(hidden_size * 2, hidden_size)

    def forward(self, src, tgt, teacher_forcing_ratio=0.5):
        """
        参数:
            src: [src_len, batch_size]
            tgt: [tgt_len, batch_size]

        返回:
            outputs: [tgt_len, batch_size, vocab_size]
        """
        src_len, batch_size = src.shape
        tgt_len = tgt.shape[0]

        # 编码
        embedded = self.embedding(src)
        # [src_len, batch_size, embed_size]

        encoder_outputs, (hidden, cell) = self.embedding(embedded)
        # encoder_outputs: [src_len, batch_size, hidden_size*2]
        # hidden: [2, batch_size, hidden_size] (双向)
        # cell: [2, batch_size, hidden_size]

        # 调整隐藏状态 (单向 → 双向)
        hidden = hidden.view(2, 2, batch_size, self.hidden_size)
        hidden = torch.cat((hidden[0], hidden[1]), dim=2)
        # [2, batch_size, hidden_size*2]

        cell = cell.view(2, 2, batch_size, self.hidden_size)
        cell = torch.cat((cell[0], cell[1]), dim=2)
        # [2, batch_size, hidden_size*2]

        # 调整到解码器期望的形状
        hidden = self.encoder_projection(hidden)
        cell = self.encoder_projection(cell)
        # [2, batch_size, hidden_size]

        # 调整 encoder_outputs 形状
        encoder_outputs = encoder_outputs.transpose(0, 1)
        # [batch_size, src_len, hidden_size*2]

        # 解码
        embedded = self.embedding(tgt)
        # [tgt_len, batch_size, embed_size]

        outputs = []
        context, _ = self.attention(encoder_outputs, hidden[-1])

        # 第一个时间步
        decoder_input = embedded[0:1]  # <SOS>
        decoder_state = (hidden, cell)

        for t in range(1, tgt_len):
            # 解码一步
            decoder_output, decoder_state = self.decoder(
                decoder_input, decoder_state
            )
            # decoder_output: [1, batch_size, hidden_size]

            # 注意力
            context, attn_weights = self.attention(
                encoder_outputs, decoder_state[0][-1]
            )

            # 输出
            output = self.output(decoder_output.squeeze(0))
            # [batch_size, vocab_size]
            outputs.append(output)

            # Teacher Forcing
            if teacher_forcing_ratio > 0 and torch.rand(1).item() < teacher_forcing_ratio:
                decoder_input = embedded[t:t+1]  # 使用真实目标
            else:
                decoder_input = self.embedding(output.argmax(dim=1)).unsqueeze(0)

        return torch.stack(outputs)


# 使用示例
model = AttentionSeq2Seq(
    vocab_size=10000,
    embed_size=256,
    hidden_size=512
)

# 输入
src = torch.randint(0, 10000, (10, 32))  # [10, 32]
tgt = torch.randint(0, 10000, (15, 32))  # [15, 32]

# 前向传播
outputs = model(src, tgt)
# outputs: [14, 32, 10000]
```

### Self-Attention 完整实现

```python
class SelfAttention(nn.Module):
    """Self-Attention 实现"""

    def __init__(self, d_model, n_heads=8, dropout=0.1):
        super().__init__()
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads

        assert d_model % n_heads == 0, "d_model 必须能被 n_heads 整除"

        # 线性层
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

        self.dropout = nn.Dropout(dropout)
        self.scale = math.sqrt(self.d_k)

    def forward(self, x, mask=None):
        """
        参数:
            x: [batch_size, seq_len, d_model]
            mask: [batch_size, seq_len, seq_len] (可选)

        返回:
            output: [batch_size, seq_len, d_model]
            attention: [batch_size, n_heads, seq_len, seq_len]
        """
        batch_size, seq_len, d_model = x.shape

        # 线性变换得到 Q, K, V
        Q = self.W_q(x)  # [batch_size, seq_len, d_model]
        K = self.W_k(x)  # [batch_size, seq_len, d_model]
        V = self.W_v(x)  # [batch_size, seq_len, d_model]

        # 重塑为多头形式
        Q = Q.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        # [batch_size, n_heads, seq_len, d_k]
        K = K.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, seq_len, self.n_heads, self.d_k).transpose(1, 2)

        # 计算注意力分数
        scores = torch.matmul(Q, K.transpose(-2, -1)) / self.scale
        # [batch_size, n_heads, seq_len, seq_len]

        # 应用 mask
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)

        # Softmax
        attention_weights = F.softmax(scores, dim=-1)
        attention_weights = self.dropout(attention_weights)

        # 加权求和
        context = torch.matmul(attention_weights, V)
        # [batch_size, n_heads, seq_len, d_k]

        # 拼接多头
        context = context.transpose(1, 2).contiguous().view(
            batch_size, seq_len, d_model
        )
        # [batch_size, seq_len, d_model]

        # 输出线性层
        output = self.W_o(context)

        return output, attention_weights


class PositionEncoding(nn.Module):
    """位置编码"""

    def __init__(self, d_model, max_seq_len=5000, dropout=0.1):
        super().__init__()
        self.dropout = nn.Dropout(dropout)

        # 创建位置编码矩阵
        pe = torch.zeros(max_seq_len, d_model)
        position = torch.arange(0, max_seq_len, dtype=torch.float).unsqueeze(1)
        # [max_seq_len, 1]

        div_term = torch.exp(
            torch.arange(0, d_model, 2).float() *
            (-math.log(10000.0) / d_model)
        )

        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        pe = pe.unsqueeze(0).transpose(0, 1)
        # [max_seq_len, 1, d_model]

        self.register_buffer('pe', pe)

    def forward(self, x):
        """
        参数:
            x: [seq_len, batch_size, d_model]

        返回:
            x + position_encoding: [seq_len, batch_size, d_model]
        """
        x = x + self.pe[:x.size(0), :]
        return self.dropout(x)


class TransformerBlock(nn.Module):
    """Transformer 块"""

    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        self.self_attention = SelfAttention(d_model, n_heads, dropout)
        self.feed_forward = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Linear(d_ff, d_model)
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout1 = nn.Dropout(dropout)
        self.dropout2 = nn.Dropout(dropout)

    def forward(self, x):
        # Self-Attention + 残差连接 + LayerNorm
        attn_output, _ = self.self_attention(x)
        x = self.norm1(x + self.dropout1(attn_output))

        # Feed Forward + 残差连接 + LayerNorm
        ff_output = self.feed_forward(x)
        x = self.norm2(x + self.dropout2(ff_output))

        return x


# 使用示例
# 输入序列
x = torch.randn(10, 32, 512)  # [seq_len, batch_size, d_model]

# 位置编码
pos_encoding = PositionEncoding(512)
x = pos_encoding(x.transpose(0, 1)).transpose(0, 1)
# x: [10, 32, 512]

# Transformer 块
transformer_block = TransformerBlock(d_model=512, n_heads=8, d_ff=2048)
output = transformer_block(x)
# output: [10, 32, 512]
```

## 🎯 注意力机制的应用

### 1. 机器翻译 (最重要)

```
Seq2Seq + Attention:
═══════════════════

传统 Seq2Seq:
  编码: "I love you" → c
  解码: c → "我爱你"

  问题: 信息压缩损失

+ 注意力:
  编码: "I love you" → [h₁, h₂, h₃]
  解码:
    h₁, c₁ → "我"
    h₂, c₂ → "爱"
    h₃, c₃ → "你"

  优势: 每步都有针对性上下文

实际效果:
  英→中 BLEU: 25 → 35 (提升 40%)
  英→法 BLEU: 30 → 42 (提升 40%)
  英→德 BLEU: 28 → 38 (提升 36%)

  长序列改进更明显:
  序列长度 30: 提升 15%
  序列长度 50: 提升 35%
```

## 💡 注意力机制的局限性

```
注意力机制的局限性:
══════════════════

1. 计算复杂度 O(n²)
   问题: 序列长度 n 的二次增长
   解决: 稀疏注意力,局部注意力,线性注意力

2. 内存占用大
   问题: 注意力权重矩阵 O(n²)
   解决: 梯度检查点,混合精度训练

3. 无位置信息
   问题: Self-Attention 是 permutation-invariant
   解决: 位置编码 (Positional Encoding)

4. 推理速度慢
   问题: 需要存储所有历史注意力权重
   解决: 缓存机制,增量计算

5. 可解释性有限
   问题: 注意力权重 ≠ 真正的相关性
   研究: Attention Rollout, Attribution 方法

未来发展方向:
══════════════

1. 高效注意力:
   • Sparse Attention (稀疏注意力)
   • Linear Attention (线性注意力)
   • Performer (核函数近似)

2. 长期依赖:
   • Transformer-XL (循环记忆)
   • Reformer (局部敏感哈希)
   • Longformer (局部+全局注意力)

3. 可解释性:
   • 更好的可视化方法
   • 因果分析
   • 鲁棒性评估

4. 多模态:
   • 视觉-语言注意力
   • 音频-文本注意力
   • 跨模态对齐
```

## 🔗 注意力机制与 Transformer 的关系

```
Attention 是 Transformer 的核心
════════════════════════════

Transformer = Self-Attention + Feed-Forward + 残差连接 + 层归一化

架构组成:
  1. Self-Attention 层
  2. Feed-Forward 层
  3. 残差连接
  4. 层归一化
  5. 位置编码

编码器:
  Input → Embedding + PosEncoding → Multi-Head Attention → FeedForward → Output

解码器:
  Output → Embedding + PosEncoding → Masked Multi-Head Attention → Cross-Attention → FeedForward → Output

重要性:
  • Self-Attention 是 Transformer 的核心计算
  • 替代了 RNN 的循环结构
  • 实现了并行计算
  • 解决了长距离依赖问题

为什么 "Attention Is All You Need":
  ✓ 不需要 RNN (循环结构)
  ✓ 不需要 CNN (卷积结构)
  ✓ 只需要 Attention!

  证明了 Attention 的强大能力!
```

## 🤔 常见问题

```
Q1: 注意力权重越高越好吗？
A1: 不一定
    高权重表示强相关性
    但也要看整体分布是否合理
    最重要的是可视化是否"有意义"

Q2: 为什么除以 √d_k？
A2: 防止 softmax 饱和
    如果分数过大,softmax 会变成接近 one-hot
    除以 √d_k 可以让梯度更稳定

Q3: 多头注意力中,头数越多越好吗？
A3: 不是
    头数太多会导致每个头的维度太小
    无法捕捉足够的信息
    通常用 8 或 16 个头

Q4: 注意力机制可以用于 1D 数据吗？
A4: 可以
    不仅限于序列
    也可以用于图 (Graph Attention Network)
    甚至用于图像 (Vision Transformer)

Q5: Self-Attention 和 Transformer 有什么区别？
A5: Self-Attention 是 Transformer 的一个组件
    Transformer = Self-Attention + Feed-Forward + 残差连接
```
