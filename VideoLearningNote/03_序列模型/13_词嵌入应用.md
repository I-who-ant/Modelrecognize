## 📌 基本定义

**词嵌入应用** 是指将预训练或任务特定的词向量应用到各种自然语言处理任务中,作为模型的输入表示或特征,显著提升模型性能和泛化能力。

### 核心思想

```
词嵌入的价值不在于向量本身
而在于它在下游任务中的应用效果

关键优势:
✅ 迁移学习: 在大语料上预训练,迁移到小数据任务
✅ 语义捕捉: 自动学习词的语义表示
✅ 泛化能力: 处理训练集未见过的词组合
✅ 特征工程: 减少手工特征设计

应用范式:
1. 冻结嵌入: 使用预训练嵌入,不更新
2. 微调嵌入: 在任务上继续训练嵌入
3. 混合策略: 部分冻结,部分微调
```

## 💬 应用 1: 情感分析

### 任务定义

```
输入: 文本（评论、推文等）
输出: 情感类别（正面/负面/中性）

示例:
输入: "This movie is absolutely amazing!"
输出: 正面 (Positive)

输入: "Terrible service, never coming back."
输出: 负面 (Negative)

挑战:
❌ 词序重要: "not good" vs "good"
❌ 否定词处理: "not bad" 是正面
❌ 讽刺表达: "Yeah, right, perfect!"
```

---

### 基于词嵌入的情感分析架构

```
架构 1: 简单平均 + 分类器
─────────────────────────

输入: "This movie is great"

步骤 1: 查找词嵌入
"This"  → [0.1, -0.2, 0.5, ...]
"movie" → [0.3,  0.1, 0.2, ...]
"is"    → [0.0,  0.0, 0.1, ...]
"great" → [0.8,  0.7, 0.9, ...]

步骤 2: 平均池化
sentence_emb = mean([emb_This, emb_movie, emb_is, emb_great])
             = [0.3, 0.15, 0.425, ...]

步骤 3: 分类器
sentiment = softmax(W · sentence_emb + b)
          = [0.05, 0.92, 0.03]  ← [负面, 正面, 中性]
             └────┬────┘
            正面情感 (92%)

问题:
❌ 丢失了词序信息
❌ "not great" 和 "great" 表示相同

架构 2: RNN/LSTM + 词嵌入
─────────────────────────

         输出层
           ↑
      [Softmax]
           ↑
    最后隐藏状态 h^<T>
           ↑
[LSTM]→[LSTM]→[LSTM]→[LSTM]
  ↑      ↑      ↑      ↑
 emb   emb    emb    emb
  ↑      ↑      ↑      ↑
"This" "movie" "is" "great"

优势:
✅ 保留词序
✅ 捕捉上下文依赖
✅ 处理长距离依赖

架构 3: CNN + 词嵌入
─────────────────────

卷积核捕捉 n-gram 特征

"This movie is great"
  ↓    ↓    ↓    ↓
[0.1] [0.3] [0.0] [0.8]  ← 词嵌入
  └──┬──┘                 ← bigram 卷积核
    [特征1]
    └────┬────┘           ← trigram 卷积核
       [特征2]
         ↓
    [MaxPooling]
         ↓
    [分类器]

优势:
✅ 高效并行
✅ 捕捉局部模式
✅ 适合短文本
```

### 完整代码实现

```python
import numpy as np
import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader

class SentimentDataset(Dataset):
    """情感分析数据集"""
    def __init__(self, texts, labels, word2idx, max_len=50):
        self.texts = texts
        self.labels = labels
        self.word2idx = word2idx
        self.max_len = max_len

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, idx):
        text = self.texts[idx]
        label = self.labels[idx]

        # 转换为索引
        indices = [
            self.word2idx.get(word, self.word2idx['<UNK>'])
            for word in text.split()
        ]

        # 截断或填充
        if len(indices) < self.max_len:
            indices += [self.word2idx['<PAD>']] * (self.max_len - len(indices))
        else:
            indices = indices[:self.max_len]

        return torch.tensor(indices), torch.tensor(label)


class LSTMSentimentClassifier(nn.Module):
    """
    基于 LSTM + 词嵌入的情感分类器
    """
    def __init__(self, vocab_size, embedding_dim, hidden_dim,
                 num_classes, num_layers=2, dropout=0.5,
                 pretrained_embeddings=None):
        """
        参数:
            vocab_size: 词汇表大小
            embedding_dim: 词嵌入维度
            hidden_dim: LSTM 隐藏层维度
            num_classes: 类别数（如3: 正/负/中性）
            num_layers: LSTM 层数
            dropout: Dropout 比例
            pretrained_embeddings: 预训练词嵌入 [vocab_size, embedding_dim]
        """
        super(LSTMSentimentClassifier, self).__init__()

        # 嵌入层
        self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=0)

        # 如果提供预训练嵌入,加载它
        if pretrained_embeddings is not None:
            self.embedding.weight.data.copy_(torch.from_numpy(pretrained_embeddings))
            # 可选: 冻结嵌入层
            # self.embedding.weight.requires_grad = False

        # LSTM 层
        self.lstm = nn.LSTM(
            embedding_dim,
            hidden_dim,
            num_layers=num_layers,
            batch_first=True,
            dropout=dropout if num_layers > 1 else 0,
            bidirectional=True
        )

        # Dropout
        self.dropout = nn.Dropout(dropout)

        # 输出层 (双向LSTM, 所以是 2 * hidden_dim)
        self.fc = nn.Linear(2 * hidden_dim, num_classes)

    def forward(self, x):
        """
        参数:
            x: [batch_size, seq_len]

        返回:
            logits: [batch_size, num_classes]
        """
        # 嵌入层
        embedded = self.embedding(x)  # [batch_size, seq_len, embedding_dim]

        # LSTM
        lstm_out, (h_n, c_n) = self.lstm(embedded)
        # lstm_out: [batch_size, seq_len, 2*hidden_dim]
        # h_n: [2*num_layers, batch_size, hidden_dim]

        # 使用最后一个时间步的隐藏状态
        # 拼接前向和后向的最后隐藏状态
        h_forward = h_n[-2, :, :]   # [batch_size, hidden_dim]
        h_backward = h_n[-1, :, :]  # [batch_size, hidden_dim]
        h_concat = torch.cat([h_forward, h_backward], dim=1)  # [batch_size, 2*hidden_dim]

        # Dropout
        h_concat = self.dropout(h_concat)

        # 分类
        logits = self.fc(h_concat)  # [batch_size, num_classes]

        return logits


# 训练函数
def train_sentiment_model(model, train_loader, val_loader,
                          epochs=10, lr=0.001, device='cpu'):
    """训练情感分类模型"""
    model = model.to(device)
    criterion = nn.CrossEntropyLoss()
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)

    for epoch in range(epochs):
        # 训练阶段
        model.train()
        train_loss = 0
        train_correct = 0
        train_total = 0

        for texts, labels in train_loader:
            texts, labels = texts.to(device), labels.to(device)

            # 前向传播
            optimizer.zero_grad()
            logits = model(texts)
            loss = criterion(logits, labels)

            # 反向传播
            loss.backward()
            optimizer.step()

            # 统计
            train_loss += loss.item()
            _, predicted = torch.max(logits, 1)
            train_total += labels.size(0)
            train_correct += (predicted == labels).sum().item()

        train_acc = 100 * train_correct / train_total

        # 验证阶段
        model.eval()
        val_loss = 0
        val_correct = 0
        val_total = 0

        with torch.no_grad():
            for texts, labels in val_loader:
                texts, labels = texts.to(device), labels.to(device)

                logits = model(texts)
                loss = criterion(logits, labels)

                val_loss += loss.item()
                _, predicted = torch.max(logits, 1)
                val_total += labels.size(0)
                val_correct += (predicted == labels).sum().item()

        val_acc = 100 * val_correct / val_total

        print(f"Epoch {epoch+1}/{epochs}")
        print(f"  Train Loss: {train_loss/len(train_loader):.4f}, "
              f"Train Acc: {train_acc:.2f}%")
        print(f"  Val Loss: {val_loss/len(val_loader):.4f}, "
              f"Val Acc: {val_acc:.2f}%")


# 使用示例
if __name__ == "__main__":
    # 模拟数据
    texts = [
        "this movie is great",
        "terrible acting and plot",
        "absolutely loved it",
        "waste of time",
        "not bad but not great"
    ]
    labels = [1, 0, 1, 0, 2]  # 0: 负面, 1: 正面, 2: 中性

    # 构建词汇表
    vocabulary = set()
    for text in texts:
        vocabulary.update(text.split())

    word2idx = {word: idx+2 for idx, word in enumerate(vocabulary)}
    word2idx['<PAD>'] = 0
    word2idx['<UNK>'] = 1

    vocab_size = len(word2idx)

    # 创建数据集
    dataset = SentimentDataset(texts, labels, word2idx, max_len=10)
    train_loader = DataLoader(dataset, batch_size=2, shuffle=True)

    # 创建模型
    model = LSTMSentimentClassifier(
        vocab_size=vocab_size,
        embedding_dim=50,
        hidden_dim=64,
        num_classes=3,
        num_layers=2,
        dropout=0.5
    )

    print("=" * 60)
    print("情感分析模型")
    print("=" * 60)
    print(f"词汇表大小: {vocab_size}")
    print(f"嵌入维度: 50")
    print(f"隐藏维度: 64")
    print(f"类别数: 3 (负面/正面/中性)")
    print()
```

## 🏷️ 应用 2: 命名实体识别 (NER)

### 任务定义

```
输入: 文本序列
输出: 每个词的实体标签

示例:
输入: "Apple was founded by Steve Jobs in California"
输出:
  Apple      → B-ORG  (组织开始)
  was        → O      (非实体)
  founded    → O
  by         → O
  Steve      → B-PER  (人名开始)
  Jobs       → I-PER  (人名内部)
  in         → O
  California → B-LOC  (地点开始)

标注方案: BIO 标注
- B (Begin): 实体开始
- I (Inside): 实体内部
- O (Outside): 非实体

实体类型:
- PER (Person): 人名
- ORG (Organization): 组织
- LOC (Location): 地点
- MISC: 其他
```

---

### 基于词嵌入的 NER 架构

```
BiLSTM-CRF 架构:
──────────────────

        CRF 层 (条件随机场)
           ↑
      [线性层]
           ↑
    BiLSTM 隐藏状态
           ↑
   [BiLSTM] [BiLSTM] [BiLSTM] [BiLSTM]
      ↑        ↑        ↑        ↑
    词嵌入   词嵌入   词嵌入   词嵌入
      ↑        ↑        ↑        ↑
   "Apple"  "was"  "founded"  "by"

关键组件:
1. 词嵌入层: 将词映射到向量
2. BiLSTM: 捕捉上下文信息
3. CRF: 建模标签之间的依赖关系

为什么需要 BiLSTM?
✅ 看到完整上下文(前向+后向)
✅ "Apple" 后面的 "was founded" 暗示组织
✅ "Steve" 前面的 "by" 暗示人名

为什么需要 CRF?
✅ 标签约束: B-PER 后只能接 I-PER 或 O
✅ 全局最优: 整个序列的最优标注
```

### 完整代码实现

```python
import torch
import torch.nn as nn
from torch.nn.utils.rnn import pack_padded_sequence, pad_packed_sequence

class BiLSTM_CRF_NER(nn.Module):
    """
    基于 BiLSTM-CRF 的命名实体识别模型
    """
    def __init__(self, vocab_size, embedding_dim, hidden_dim,
                 num_tags, pretrained_embeddings=None):
        """
        参数:
            vocab_size: 词汇表大小
            embedding_dim: 词嵌入维度
            hidden_dim: LSTM 隐藏层维度
            num_tags: 标签数量 (如 BIO 标注的标签数)
            pretrained_embeddings: 预训练词嵌入
        """
        super(BiLSTM_CRF_NER, self).__init__()

        self.embedding_dim = embedding_dim
        self.hidden_dim = hidden_dim
        self.num_tags = num_tags

        # 嵌入层
        self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=0)
        if pretrained_embeddings is not None:
            self.embedding.weight.data.copy_(torch.from_numpy(pretrained_embeddings))

        # BiLSTM
        self.lstm = nn.LSTM(
            embedding_dim,
            hidden_dim // 2,  # 双向,所以除以2
            num_layers=2,
            batch_first=True,
            bidirectional=True,
            dropout=0.5
        )

        # 输出层
        self.hidden2tag = nn.Linear(hidden_dim, num_tags)

        # CRF 转移矩阵
        # transitions[i, j] 表示从标签 i 转移到标签 j 的分数
        self.transitions = nn.Parameter(torch.randn(num_tags, num_tags))

        # 约束: 不能转移到 <START>, 不能从 <END> 转移出去
        # 这里简化实现,实际应该加入这些约束

    def forward(self, x, lengths):
        """
        参数:
            x: [batch_size, seq_len]
            lengths: [batch_size] 每个序列的真实长度

        返回:
            emissions: [batch_size, seq_len, num_tags]
        """
        # 嵌入
        embedded = self.embedding(x)  # [batch_size, seq_len, embedding_dim]

        # Pack 序列 (处理变长序列)
        packed = pack_padded_sequence(
            embedded, lengths.cpu(), batch_first=True, enforce_sorted=False
        )

        # BiLSTM
        lstm_out, _ = self.lstm(packed)

        # Unpack
        lstm_out, _ = pad_packed_sequence(lstm_out, batch_first=True)
        # [batch_size, seq_len, hidden_dim]

        # 发射分数
        emissions = self.hidden2tag(lstm_out)
        # [batch_size, seq_len, num_tags]

        return emissions

    def decode(self, emissions, lengths):
        """
        Viterbi 解码,找到最优标签序列

        参数:
            emissions: [batch_size, seq_len, num_tags]
            lengths: [batch_size]

        返回:
            best_paths: List[List[int]] 每个序列的最优标签路径
        """
        batch_size, seq_len, num_tags = emissions.size()
        best_paths = []

        for i in range(batch_size):
            length = lengths[i].item()
            emission = emissions[i, :length, :]  # [length, num_tags]

            # 简化的 Viterbi 算法 (不考虑转移矩阵)
            _, path = torch.max(emission, dim=1)
            best_paths.append(path.tolist())

        return best_paths


# 示例标签映射
tag2idx = {
    'O': 0,
    'B-PER': 1, 'I-PER': 2,
    'B-ORG': 3, 'I-ORG': 4,
    'B-LOC': 5, 'I-LOC': 6,
    '<PAD>': 7
}
idx2tag = {v: k for k, v in tag2idx.items()}


# 使用示例
if __name__ == "__main__":
    # 模拟数据
    sentences = [
        "Apple was founded by Steve Jobs".split(),
        "Google is in California".split()
    ]

    # 标签
    tags = [
        ['B-ORG', 'O', 'O', 'O', 'B-PER', 'I-PER'],
        ['B-ORG', 'O', 'O', 'B-LOC']
    ]

    # 构建词汇表
    vocabulary = set()
    for sent in sentences:
        vocabulary.update(sent)

    word2idx = {word: idx+1 for idx, word in enumerate(vocabulary)}
    word2idx['<PAD>'] = 0

    vocab_size = len(word2idx)
    num_tags = len(tag2idx)

    # 创建模型
    model = BiLSTM_CRF_NER(
        vocab_size=vocab_size,
        embedding_dim=50,
        hidden_dim=128,
        num_tags=num_tags
    )

    print("=" * 60)
    print("命名实体识别模型 (BiLSTM-CRF)")
    print("=" * 60)
    print(f"词汇表大小: {vocab_size}")
    print(f"标签数量: {num_tags}")
    print(f"标签类型: {list(tag2idx.keys())}")
    print()

    # 转换为索引
    sent_indices = [
        torch.tensor([word2idx[w] for w in sent])
        for sent in sentences
    ]

    # Padding
    max_len = max(len(s) for s in sent_indices)
    padded = [
        torch.cat([s, torch.zeros(max_len - len(s), dtype=torch.long)])
        for s in sent_indices
    ]
    x = torch.stack(padded)  # [batch_size, max_len]

    lengths = torch.tensor([len(s) for s in sent_indices])

    # 前向传播
    emissions = model(x, lengths)
    print(f"发射分数形状: {emissions.shape}")

    # 解码
    predictions = model.decode(emissions, lengths)
    print("\n预测结果:")
    for i, (sent, pred) in enumerate(zip(sentences, predictions)):
        print(f"句子 {i+1}:")
        for word, tag_idx in zip(sent, pred):
            print(f"  {word:15s} → {idx2tag[tag_idx]}")
```

```
输入: 源语言句子
输出: 目标语言句子

输入 (英语): "I love deep learning"

挑战:

❌ 长距离依赖: 德语动词在句尾
```

### Seq2Seq + 词嵌入架构

```
Encoder-Decoder 架构:
─────────────────────

Encoder (编码器):
    h^<4>
      ↑
[LSTM]─→[LSTM]─→[LSTM]─→[LSTM]
  ↑       ↑       ↑       ↑
 emb    emb     emb     emb
  ↑       ↑       ↑       ↑
"I"   "love"  "deep" "learning"

Decoder (解码器):
 "我"    "爱"   "深度"  "学习"
  ↑       ↑       ↑       ↑
[LSTM]─→[LSTM]─→[LSTM]─→[LSTM]
  ↑       ↑       ↑       ↑
<START>  "我"    "爱"   "深度"
         └───────┬───────┘
        来自 Encoder 的上下文向量

关键组件:
1. Encoder 词嵌入: 英语词向量
2. Decoder 词嵌入: 中文词向量
3. 上下文向量 c: Encoder 的最后隐藏状态

问题:
❌ 信息瓶颈: 整个源句子压缩到一个向量 c
❌ 长句子性能差
→ 解决方案: Attention 机制 (后续课程)
```

## 📊 应用 4: 文本相似度

### 任务定义

```
输入: 两个文本
输出: 相似度分数

示例:
文本1: "The cat sits on the mat"
文本2: "The dog lies on the rug"
相似度: 0.75 (语义相近)

文本1: "I love programming"
文本2: "The weather is nice"
相似度: 0.05 (无关)

应用:
✅ 搜索引擎: 查询和文档的匹配
✅ 推荐系统: 相似文章推荐
✅ 问答系统: 问题和答案的匹配
✅ 去重: 检测重复内容
```

---

### 基于词嵌入的相似度计算

```
方法 1: 词向量平均
───────────────────

sentence_emb = mean([emb_word1, emb_word2, ..., emb_wordN])

similarity = cosine(sentence_emb1, sentence_emb2)

优点:
✅ 简单高效
✅ 无需训练

缺点:
❌ 忽略词序
❌ 所有词权重相同

方法 2: TF-IDF 加权平均
────────────────────────

sentence_emb = Σ (tfidf_i × emb_i)

优点:
✅ 考虑词的重要性
✅ 降低停用词影响

方法 3: Siamese Network
───────────────────────

        文本1              文本2
          ↓                  ↓
    [词嵌入+LSTM]       [词嵌入+LSTM]
          ↓                  ↓
        向量1              向量2
          └────────┬────────┘
               [余弦相似度]
                    ↓
                相似度分数

训练目标:
相似文本对 → 高分数
不相似文本对 → 低分数
```

### 完整代码实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SiameseLSTM(nn.Module):
    """
    孪生 LSTM 网络用于文本相似度计算
    """
    def __init__(self, vocab_size, embedding_dim, hidden_dim,
                 pretrained_embeddings=None):
        super(SiameseLSTM, self).__init__()

        # 嵌入层 (两个输入共享)
        self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=0)
        if pretrained_embeddings is not None:
            self.embedding.weight.data.copy_(torch.from_numpy(pretrained_embeddings))

        # LSTM (两个输入共享)
        self.lstm = nn.LSTM(
            embedding_dim,
            hidden_dim,
            num_layers=2,
            batch_first=True,
            dropout=0.3,
            bidirectional=False
        )

    def forward_once(self, x):
        """
        处理一个输入

        参数:
            x: [batch_size, seq_len]

        返回:
            output: [batch_size, hidden_dim]
        """
        # 嵌入
        embedded = self.embedding(x)  # [batch_size, seq_len, embedding_dim]

        # LSTM
        lstm_out, (h_n, c_n) = self.lstm(embedded)
        # h_n: [num_layers, batch_size, hidden_dim]

        # 使用最后一层的隐藏状态
        output = h_n[-1, :, :]  # [batch_size, hidden_dim]

        return output

    def forward(self, x1, x2):
        """
        计算两个输入的相似度

        参数:
            x1, x2: [batch_size, seq_len]

        返回:
            similarity: [batch_size] 相似度分数
        """
        # 分别编码
        output1 = self.forward_once(x1)
        output2 = self.forward_once(x2)

        # 余弦相似度
        similarity = F.cosine_similarity(output1, output2, dim=1)

        return similarity


# 对比损失 (Contrastive Loss)
class ContrastiveLoss(nn.Module):
    """
    对比损失函数

    拉近相似样本,推远不相似样本
    """
    def __init__(self, margin=1.0):
        super(ContrastiveLoss, self).__init__()
        self.margin = margin

    def forward(self, similarity, label):
        """
        参数:
            similarity: [batch_size] 相似度分数
            label: [batch_size] 1表示相似, 0表示不相似

        返回:
            loss: 标量
        """
        # 相似对: 希望相似度接近1
        loss_similar = label * (1 - similarity).pow(2)

        # 不相似对: 希望相似度小于 margin
        loss_dissimilar = (1 - label) * F.relu(similarity - self.margin).pow(2)

        loss = (loss_similar + loss_dissimilar).mean()
        return loss


# 使用示例
if __name__ == "__main__":
    # 模拟数据
    texts1 = [
        "I love programming",
        "The cat sits on the mat",
        "Deep learning is amazing"
    ]

    texts2 = [
        "I enjoy coding",           # 相似
        "The dog lies on the rug",  # 相似
        "The weather is nice"       # 不相似
    ]

    labels = [1, 1, 0]  # 1: 相似, 0: 不相似

    # 构建词汇表
    vocabulary = set()
    for text in texts1 + texts2:
        vocabulary.update(text.lower().split())

    word2idx = {word: idx+1 for idx, word in enumerate(vocabulary)}
    word2idx['<PAD>'] = 0

    vocab_size = len(word2idx)

    # 创建模型
    model = SiameseLSTM(
        vocab_size=vocab_size,
        embedding_dim=50,
        hidden_dim=64
    )

    criterion = ContrastiveLoss(margin=0.5)

    print("=" * 60)
    print("文本相似度模型 (Siamese LSTM)")
    print("=" * 60)
    print(f"词汇表大小: {vocab_size}")
    print(f"嵌入维度: 50")
    print(f"隐藏维度: 64")
    print()

    # 转换为索引并padding
    def text_to_indices(texts, word2idx, max_len=10):
        indices_list = []
        for text in texts:
            indices = [word2idx.get(w.lower(), 0) for w in text.split()]
            if len(indices) < max_len:
                indices += [0] * (max_len - len(indices))
            else:
                indices = indices[:max_len]
            indices_list.append(indices)
        return torch.tensor(indices_list)

    x1 = text_to_indices(texts1, word2idx)
    x2 = text_to_indices(texts2, word2idx)
    y = torch.tensor(labels, dtype=torch.float32)

    # 前向传播
    similarities = model(x1, x2)
    loss = criterion(similarities, y)

    print("预测相似度:")
    for i, (t1, t2, sim, label) in enumerate(zip(texts1, texts2, similarities, labels)):
        print(f"{i+1}. 文本1: {t1}")
        print(f"   文本2: {t2}")
        print(f"   相似度: {sim.item():.4f}, 标签: {'相似' if label == 1 else '不相似'}")
        print()

    print(f"对比损失: {loss.item():.4f}")
```

## 💡 核心要点总结

### 词嵌入应用的四个关键

```
1. 迁移学习
   预训练嵌入 → 迁移到下游任务
   减少标注数据需求

2. 语义表示
   自动学习词的语义
   无需手工特征工程

3. 泛化能力
   处理训练集未见词组合
   提升模型鲁棒性

4. 端到端学习
   与任务一起联合训练
   或冻结嵌入单独训练任务
```

---

### 应用范式对比

```
冻结嵌入 (Frozen Embeddings)
─────────────────────────────
预训练嵌入 → 冻结权重 → 训练下游任务

优点:
✅ 训练快
✅ 参数少
✅ 防止过拟合

缺点:
❌ 无法适应特定领域
❌ 可能包含无关信息

适用:
- 数据少
- 计算资源有限
- 通用领域任务

微调嵌入 (Fine-tuned Embeddings)
─────────────────────────────────
预训练嵌入 → 继续训练 → 适应任务

优点:
✅ 适应特定领域
✅ 任务性能更好

缺点:
❌ 训练慢
❌ 可能过拟合

适用:
- 数据充足
- 特定领域任务
- 追求最佳性能

随机初始化 (Random Initialization)
───────────────────────────────────
随机初始化 → 从头训练

优点:
✅ 完全适应任务
✅ 无预训练偏见

缺点:
❌ 需要大量数据
❌ 训练时间长

适用:
- 大规模数据
- 特殊领域(如医学)
- 低资源语言
```
