## 📌 基本定义

**嵌入矩阵（Embedding Matrix）** 是一个参数矩阵,将词汇表中的每个词映射到对应的稠密向量表示,是词嵌入在神经网络中的具体实现形式。

### 核心概念

```
嵌入矩阵 E ∈ ℝ^{d × |V|}

其中:
- d: 嵌入维度 (如 50, 100, 300)
- |V|: 词汇表大小 (如 10000, 50000)

E = [e_1, e_2, ..., e_|V|]
    ↑    ↑         ↑
  词1  词2       词|V|

每一列 e_i ∈ ℝ^d 是词 i 的嵌入向量

关键特性:
✅ 参数矩阵: 可学习/可更新
✅ 查找表: 根据词的索引查找向量
✅ 共享参数: 同一个词在不同位置用同一向量
✅ 低维表示: d << |V|
```

## 🎯 嵌入矩阵的维度

### 维度设计

```
嵌入矩阵形状: [embedding_dim, vocab_size]
或
嵌入矩阵形状: [vocab_size, embedding_dim]

两种实现方式:
──────────────

方式 1: [d, |V|]  ← 数学上更自然
E · o  = e
[d,|V|] × [|V|,1] = [d,1]

方式 2: [|V|, d]  ← 编程上更常用
o^T · E = e^T
[1,|V|] × [|V|,d] = [1,d]

本质相同,只是转置关系

示例:
假设 d=3, |V|=4
vocabulary = ["apple", "banana", "cat", "dog"]

方式 1: E = [d, |V|] = [3, 4]
┌                           ┐
│ 0.2   0.5   0.1   0.3     │ ← 维度1
│ -0.1  0.2  -0.4  -0.3     │ ← 维度2
│ 0.8   0.6   0.9   0.7     │ ← 维度3
└                           ┘
  ↑     ↑     ↑     ↑
apple banana cat  dog

方式 2: E = [|V|, d] = [4, 3]
┌                   ┐
│ 0.2  -0.1   0.8   │ ← apple
│ 0.5   0.2   0.6   │ ← banana
│ 0.1  -0.4   0.9   │ ← cat
│ 0.3  -0.3   0.7   │ ← dog
└                   ┘

PyTorch/TensorFlow 通常使用方式 2
```

## 🔍 如何查找词向量

### 方法 1: One-Hot 索引

```
数学原理:
─────────

给定词 w 的 one-hot 表示 o ∈ ℝ^{|V|}
o = [0, 0, ..., 1, ..., 0]^T
           ↑
        第 i 位是 1

词向量:
e = E · o  (如果 E 是 [d, |V|])
  = [e_1, e_2, ..., e_|V|] · o
  = e_i

解释: 矩阵-向量乘法相当于选择第 i 列

示例:
E = [
  [0.2,  0.5,  0.1,  0.3],
  [-0.1, 0.2, -0.4, -0.3],
  [0.8,  0.6,  0.9,  0.7]
]

查找 "cat" (索引 2):
o_cat = [0, 0, 1, 0]^T

e_cat = E · o_cat
      = [0.2, 0.5, 0.1, 0.3] × 0 +
        [0.2, 0.5, 0.1, 0.3] × 0 +
        [0.1, -0.4, 0.9] × 1 +      ← 选择第3列
        [0.2, 0.5, 0.1, 0.3] × 0
      = [0.1, -0.4, 0.9]^T

优点:
✅ 数学上清晰
✅ 易于理解

缺点:
❌ 浪费计算 (大部分乘法是 × 0)
❌ 浪费内存 (存储 one-hot 向量)
```

---

### 方法 2: 直接索引 (推荐)

```
实际实现:
─────────

不创建 one-hot 向量
直接用整数索引查找

伪代码:
def get_embedding(E, word_idx):
    """
    E: [vocab_size, embedding_dim]
    word_idx: 整数索引
    """
    return E[word_idx, :]  # 直接取第 word_idx 行

示例:
E = [
  [0.2, -0.1, 0.8],   ← 索引 0 (apple)
  [0.5,  0.2, 0.6],   ← 索引 1 (banana)
  [0.1, -0.4, 0.9],   ← 索引 2 (cat)
  [0.3, -0.3, 0.7]    ← 索引 3 (dog)
]

查找 "cat":
word_idx = 2
e_cat = E[2, :] = [0.1, -0.4, 0.9]

优点:
✅ 高效: O(1) 查找
✅ 节省内存: 只存储索引
✅ 节省计算: 无需矩阵乘法

这是 PyTorch nn.Embedding 的实现方式！
```

## 💻 完整实现

### NumPy 实现

```python
import numpy as np

class EmbeddingMatrix:
    """
    嵌入矩阵的完整实现
    """
    def __init__(self, vocab_size, embedding_dim, init_method='random'):
        """
        参数:
            vocab_size: 词汇表大小
            embedding_dim: 嵌入维度
            init_method: 初始化方法
                - 'random': 随机初始化
                - 'zeros': 全零初始化
                - 'xavier': Xavier 初始化
        """
        self.vocab_size = vocab_size
        self.embedding_dim = embedding_dim

        # 初始化嵌入矩阵
        if init_method == 'random':
            # 标准正态分布
            self.E = np.random.randn(vocab_size, embedding_dim) * 0.01

        elif init_method == 'zeros':
            self.E = np.zeros((vocab_size, embedding_dim))

        elif init_method == 'xavier':
            # Xavier 初始化
            limit = np.sqrt(6.0 / (vocab_size + embedding_dim))
            self.E = np.random.uniform(
                -limit, limit, (vocab_size, embedding_dim)
            )

        else:
            raise ValueError(f"未知初始化方法: {init_method}")

    def lookup(self, word_indices):
        """
        查找词向量 (支持批量)

        参数:
            word_indices: 整数或整数列表/数组

        返回:
            embeddings: [embedding_dim] 或 [batch_size, embedding_dim]
        """
        if isinstance(word_indices, (int, np.integer)):
            # 单个词
            return self.E[word_indices, :]
        else:
            # 批量查找
            return self.E[word_indices, :]

    def update(self, word_idx, gradient, learning_rate=0.01):
        """
        更新单个词的嵌入向量

        参数:
            word_idx: 词的索引
            gradient: 梯度 [embedding_dim]
            learning_rate: 学习率
        """
        self.E[word_idx, :] -= learning_rate * gradient

    def batch_update(self, word_indices, gradients, learning_rate=0.01):
        """
        批量更新多个词的嵌入

        参数:
            word_indices: [batch_size] 索引数组
            gradients: [batch_size, embedding_dim] 梯度矩阵
            learning_rate: 学习率
        """
        self.E[word_indices, :] -= learning_rate * gradients

    def get_all_embeddings(self):
        """返回完整嵌入矩阵"""
        return self.E

    def set_embedding(self, word_idx, embedding):
        """设置单个词的嵌入"""
        self.E[word_idx, :] = embedding

    def load_pretrained(self, pretrained_embeddings):
        """
        加载预训练嵌入

        参数:
            pretrained_embeddings: [vocab_size, embedding_dim]
        """
        if pretrained_embeddings.shape != self.E.shape:
            raise ValueError(
                f"形状不匹配: 期望 {self.E.shape}, "
                f"得到 {pretrained_embeddings.shape}"
            )
        self.E = pretrained_embeddings.copy()

    def cosine_similarity(self, idx1, idx2):
        """计算两个词的余弦相似度"""
        v1 = self.E[idx1, :]
        v2 = self.E[idx2, :]
        return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))

    def most_similar(self, word_idx, top_k=5):
        """
        找到最相似的词

        返回:
            List[(idx, similarity)]
        """
        query = self.E[word_idx, :]

        # 计算与所有词的相似度
        similarities = []
        for idx in range(self.vocab_size):
            if idx == word_idx:
                continue

            sim = np.dot(query, self.E[idx, :]) / (
                np.linalg.norm(query) * np.linalg.norm(self.E[idx, :])
            )
            similarities.append((idx, sim))

        # 排序
        similarities.sort(key=lambda x: x[1], reverse=True)
        return similarities[:top_k]

    def __repr__(self):
        return (
            f"EmbeddingMatrix(vocab_size={self.vocab_size}, "
            f"embedding_dim={self.embedding_dim}, "
            f"params={self.vocab_size * self.embedding_dim:,})"
        )


# 使用示例
if __name__ == "__main__":

    print("=" * 60)

    emb_matrix = EmbeddingMatrix(vocab_size, embedding_dim, init_method='xavier')
    print(f"嵌入矩阵: {emb_matrix}")
    print(f"形状: {emb_matrix.E.shape}")
    print()

    # 单个查找

    print(f"查找词 {word_idx}:")
    print(f"  嵌入向量: {embedding[:5]}... (前5维)")
    print(f"  维度: {embedding.shape}")
    print()

    # 批量查找
    word_indices = np.array([10, 20, 30, 40, 50])
    embeddings = emb_matrix.lookup(word_indices)
    print(f"批量查找 {len(word_indices)} 个词:")
    print(f"  嵌入矩阵形状: {embeddings.shape}")
    print()

    # 相似度计算
    sim = emb_matrix.cosine_similarity(10, 20)
    print(f"词 10 和词 20 的相似度: {sim:.4f}")

    print(f"与词 42 最相似的 5 个词:")
    for idx, similarity in similar:
        print(f"  词 {idx}: {similarity:.4f}")
    print()

    emb_matrix.update(42, gradient, learning_rate=0.01)
    print(f"更新词 42 的嵌入后:")
    print(f"  新嵌入: {emb_matrix.lookup(42)[:5]}...")
```

## 🔧 PyTorch 实现

### 使用 nn.Embedding

```python
import torch
import torch.nn as nn

class NeuralNetworkWithEmbedding(nn.Module):
    """
    包含嵌入层的神经网络示例
    """
    def __init__(self, vocab_size, embedding_dim, hidden_dim, output_dim):
        super(NeuralNetworkWithEmbedding, self).__init__()

        # 嵌入层
        self.embedding = nn.Embedding(vocab_size, embedding_dim)

        # 可选: 加载预训练嵌入
        # pretrained_embeddings = ...  # [vocab_size, embedding_dim]
        # self.embedding.weight.data.copy_(torch.from_numpy(pretrained_embeddings))

        # 可选: 冻结嵌入层
        # self.embedding.weight.requires_grad = False

        # 后续层
        self.fc1 = nn.Linear(embedding_dim, hidden_dim)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        """
        参数:
            x: [batch_size, seq_len] 词索引

        返回:
            output: [batch_size, output_dim]
        """
        # 嵌入层
        embedded = self.embedding(x)  # [batch_size, seq_len, embedding_dim]

        # 平均池化
        pooled = torch.mean(embedded, dim=1)  # [batch_size, embedding_dim]

        # 前馈网络
        hidden = self.relu(self.fc1(pooled))
        output = self.fc2(hidden)

        return output
```

## 🎨 嵌入矩阵的初始化方法

### 常用初始化策略

```
策略 1: 随机初始化
─────────────────

方法: 从正态/均匀分布采样

# 标准正态
E = np.random.randn(vocab_size, embedding_dim) * scale

# 均匀分布
E = np.random.uniform(-scale, scale, (vocab_size, embedding_dim))

scale 的选择:
- 过大: 训练不稳定
- 过小: 梯度消失
- 推荐: 0.01 或 Xavier

适用:
✅ 从头训练
✅ 特定领域任务
✅ 小词汇表

策略 2: Xavier 初始化
────────────────────

方法: 根据层的大小自适应

limit = sqrt(6 / (fan_in + fan_out))
E = uniform(-limit, limit)

对于嵌入层:
fan_in = vocab_size
fan_out = embedding_dim

优点:
✅ 保持方差
✅ 训练稳定

适用:
✅ 深度网络
✅ 无预训练数据

策略 3: He 初始化
───────────────

方法: 适合 ReLU 激活

std = sqrt(2 / fan_in)
E = normal(0, std)

适用:
✅ 使用 ReLU 激活
✅ 深度网络

策略 4: 预训练嵌入
─────────────────

方法: 加载 Word2Vec/GloVe

E = load_pretrained('glove.6B.100d.txt')

后续选择:
1. 冻结: E.requires_grad = False
2. 微调: 继续训练

优点:
✅ 利用大规模语料
✅ 更好的初始表示
✅ 加速收敛

适用:
✅ 通用领域
✅ 小数据任务

策略 5: 混合初始化
─────────────────

方法: 预训练 + 随机

# 词汇表内的词: 使用预训练
E[in_vocab_indices] = pretrained_embeddings

# OOV 词: 随机初始化
E[oov_indices] = random_init()

# 特殊标记: 特殊初始化
E[pad_idx] = zeros()
E[unk_idx] = mean(pretrained_embeddings)

优点:
✅ 最大化利用预训练
✅ 处理 OOV

适用:
✅ 实际应用
✅ 词汇表不完全匹配
```

### 代码示例

```python
import numpy as np

def initialize_embedding_matrix(vocab_size, embedding_dim, method='xavier'):
    """
    嵌入矩阵初始化

    参数:
        vocab_size: 词汇表大小
        embedding_dim: 嵌入维度
        method: 'random', 'xavier', 'he', 'zeros'
    """
    if method == 'random':
        E = np.random.randn(vocab_size, embedding_dim) * 0.01

    elif method == 'xavier':
        limit = np.sqrt(6.0 / (vocab_size + embedding_dim))
        E = np.random.uniform(-limit, limit, (vocab_size, embedding_dim))

    elif method == 'he':
        std = np.sqrt(2.0 / vocab_size)
        E = np.random.randn(vocab_size, embedding_dim) * std

    elif method == 'zeros':
        E = np.zeros((vocab_size, embedding_dim))

    else:
        raise ValueError(f"未知方法: {method}")

    return E


def load_pretrained_and_init(vocab, pretrained_file, embedding_dim):
    """
    加载预训练嵌入并初始化 OOV

    参数:
        vocab: 词汇表 (dict: word -> idx)
        pretrained_file: 预训练文件路径
        embedding_dim: 嵌入维度

    返回:
        E: [vocab_size, embedding_dim]
    """
    vocab_size = len(vocab)
    E = np.random.randn(vocab_size, embedding_dim) * 0.01

    # 加载预训练
    pretrained = {}
    with open(pretrained_file, 'r', encoding='utf-8') as f:
        for line in f:
            parts = line.strip().split()
            if len(parts) == embedding_dim + 1:
                word = parts[0]
                vector = np.array([float(x) for x in parts[1:]])
                pretrained[word] = vector

    # 填充词汇表中的词
    num_pretrained = 0
    for word, idx in vocab.items():
        if word in pretrained:
            E[idx] = pretrained[word]
            num_pretrained += 1

    print(f"加载了 {num_pretrained}/{vocab_size} 个预训练向量")
    print(f"OOV 词: {vocab_size - num_pretrained} (随机初始化)")

    # 特殊处理
    if '<PAD>' in vocab:
        E[vocab['<PAD>']] = np.zeros(embedding_dim)

    if '<UNK>' in vocab:
        # UNK 用预训练向量的平均
        if num_pretrained > 0:
            E[vocab['<UNK>']] = np.mean(
                [E[idx] for word, idx in vocab.items()
                 if word in pretrained],
                axis=0
            )

    return E


# 示例

vocab_size = len(vocab)
embedding_dim = 50

print("=" * 60)
print("嵌入矩阵初始化方法对比")
print("=" * 60)

for method in ['random', 'xavier', 'he', 'zeros']:
    E = initialize_embedding_matrix(vocab_size, embedding_dim, method)
    print(f"\n{method.upper()} 初始化:")
    print(f"  形状: {E.shape}")
    print(f"  均值: {np.mean(E):.6f}")
    print(f"  标准差: {np.std(E):.6f}")
    print(f"  最小值: {np.min(E):.6f}")
    print(f"  最大值: {np.max(E):.6f}")
```

## 💡 核心要点总结

### 嵌入矩阵的四个关键

```
1. 查找表机制
   整数索引 → 稠密向量
   高效 O(1) 查找

2. 参数共享
   同一词在不同位置用同一向量
   大幅减少参数

3. 可学习性
   嵌入向量可以通过反向传播更新
   适应特定任务

4. 维度权衡
   d ↑: 表达能力 ↑, 参数量 ↑, 计算量 ↑
   需要根据任务和数据选择
```

---

### 实现要点

```
NumPy 实现:
✅ 直接索引: E[idx, :]
✅ 批量查找: E[indices, :]
✅ 更新: E[idx, :] -= lr * grad

PyTorch 实现:
✅ nn.Embedding(vocab_size, embedding_dim)
✅ 自动反向传播
✅ GPU 加速
✅ 支持 padding_idx

关键操作:
- 查找: O(1)
- 更新: O(d)
- 全矩阵: O(|V| × d)
```

---

### 初始化策略选择

```
情况 1: 有预训练嵌入 + 通用领域
→ 加载预训练 + 微调

情况 2: 无预训练 + 数据充足
→ Xavier/He 初始化 + 从头训练

情况 3: 特定领域 + 小数据
→ 预训练嵌入 + 冻结

情况 4: 词汇表不匹配
→ 混合初始化 (预训练 + 随机)
```
