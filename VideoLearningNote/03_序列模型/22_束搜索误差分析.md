## 📌 问题背景

```
序列生成系统的两大组件:
═════════════════════

┌─────────────────────────────────────┐
│  组件1: RNN/LSTM 模型                │
│  作用: 计算 P(y | x)                │
│  训练: 最大似然估计                  │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│  组件2: 束搜索算法                  │
│  作用: 找到 y* = argmax P(y | x)    │
│  启发式搜索                          │
└─────────────────────────────────────┘
              ↓
          生成结果

核心问题:
════════

当生成结果不好时,问题出在哪里?

可能性1: 模型问题
  P(y | x) 本身计算错误
  模型没有学好

可能性2: 搜索问题
  P(y | x) 计算正确
  但束搜索没找到最优解

需要区分这两种情况!
→ 这就是束搜索误差分析的作用
```

## 🎯 误差分析框架

### 基本思想

```
假设:
════

人类翻译: y* (最优翻译)
模型输出: ŷ  (束搜索结果)

两个关键概率:
  P(y* | x): 人类翻译的概率
  P(ŷ | x):  模型输出的概率

情况分析:
════════

情况1: P(y* | x) > P(ŷ | x)
  ✅ 模型认为人类翻译更好
  ❌ 但束搜索没找到它
  → 搜索算法的问题 (Search Error)
  → 解决: 增大 beam_size

情况2: P(y* | x) ≤ P(ŷ | x)
  ❌ 模型认为自己的输出更好
  ✅ 束搜索找到了模型认为的最优解
  → 模型本身的问题 (Model Error)
  → 解决: 改进模型、更多训练数据

图示:
════

                P(y|x)
                  ↑
                  │
      ┌───────────┼───────────┐
      │           │           │
    P(ŷ)          │         P(y*)
      │           │           │
      │    情况1  │  情况2    │
      │  (搜索错) │ (模型错)  │
      └───────────┼───────────┘
                  │
                  └─→ 概率轴

情况1: P(y*) > P(ŷ)
  束搜索失败
  应该找到 y* 但没找到

情况2: P(y*) ≤ P(ŷ)
  束搜索成功
  找到了模型认为的最优解
  但模型的判断有问题
```

## 🔍 具体分析步骤

### 步骤 1: 收集数据

```
对于每个测试样本:
═══════════════

1. 人工标注: y* (参考翻译/标准答案)
2. 模型生成: ŷ  (束搜索输出)

3. 计算概率:
   P(y* | x): 人类翻译的模型概率
   P(ŷ | x):  模型输出的模型概率

⚠️ 注意:
  P(y* | x) 不是人类的判断概率
  而是**模型对人类翻译的打分**

示例:
════

输入: "I love you"
人类翻译: y* = "我爱你"
模型输出: ŷ  = "我喜欢你"

计算:
  P("我爱你" | "I love you") = 0.08
  P("我喜欢你" | "I love you") = 0.12

对比:
  P(y*) = 0.08 < P(ŷ) = 0.12
  → 情况2: 模型错误
  → 模型认为"喜欢"比"爱"更合适
```

---

### 步骤 2: 计算概率

```
如何计算 P(y | x)?
═══════════════════

方法: 强制解码 (Teacher Forcing)

给定序列 y = [y₁, y₂, ..., yₘ]:
  P(y | x) = ∏ᵢ₌₁ᵐ P(yᵢ | x, y₁, ..., yᵢ₋₁)

实现:
  将 y 作为输入,逐步计算每个词的概率

代码:
────

```python
def compute_sequence_probability(model, src, tgt):
    """
    计算序列概率 P(tgt | src)

    参数:
        model: Seq2Seq 模型
        src: 源序列 [src_len]
        tgt: 目标序列 [tgt_len]

    返回:
        log_prob: 对数概率 (标量)
    """
    # 编码
    encoder_output, encoder_hidden = model.encoder(src.unsqueeze(0))

    # 解码 (Teacher Forcing)
    decoder_input = tgt[:-1]  # 去掉 <EOS>
    decoder_target = tgt[1:]  # 去掉 <SOS>

    decoder_output, _ = model.decoder(
        decoder_input.unsqueeze(0),
        encoder_hidden,
        encoder_output
    )
    # decoder_output: [1, tgt_len-1, vocab_size]

    # 计算对数概率
    log_probs = F.log_softmax(decoder_output.squeeze(0), dim=1)
    # log_probs: [tgt_len-1, vocab_size]

    # 选择目标词的对数概率
    target_log_probs = log_probs.gather(
        dim=1,
        index=decoder_target.unsqueeze(1)
    ).squeeze(1)
    # target_log_probs: [tgt_len-1]

    # 累加
    total_log_prob = target_log_probs.sum().item()

    return total_log_prob


# 使用
src = torch.LongTensor([3, 145, 67, 2])  # "I love you <EOS>"
y_human = torch.LongTensor([1, 23, 56, 89, 2])  # "<SOS> 我 爱 你 <EOS>"
y_model = torch.LongTensor([1, 23, 78, 89, 2])  # "<SOS> 我 喜欢 你 <EOS>"

log_prob_human = compute_sequence_probability(model, src, y_human)
log_prob_model = compute_sequence_probability(model, src, y_model)

print(f"P(y_human | x) = {np.exp(log_prob_human):.4f}")
print(f"P(y_model | x) = {np.exp(log_prob_model):.4f}")

if log_prob_human > log_prob_model:
    print("→ 搜索错误: 束搜索应该找到人类翻译")
else:
    print("→ 模型错误: 模型认为自己的输出更好")
```

import torch
import numpy as np
from tqdm import tqdm

class BeamSearchErrorAnalysis:
    """束搜索误差分析"""

    def __init__(self, model, beam_search, test_data):
        """
        参数:
            model: Seq2Seq 模型
            beam_search: 束搜索解码器
            test_data: 测试数据 [(src, tgt_ref), ...]
        """
        self.model = model
        self.beam_search = beam_search
        self.test_data = test_data

    def compute_log_prob(self, src, tgt):
        """计算 log P(tgt | src)"""
        # (与上面的实现相同)
        # ...
        return total_log_prob

    def analyze(self):
        """
        执行误差分析

        返回:
            results: {
                'search_errors': int,
                'model_errors': int,
                'examples': List[dict]
            }
        """
        search_errors = 0
        model_errors = 0
        examples = []

        for src, tgt_ref in tqdm(self.test_data):
            # 1. 束搜索生成
            tgt_pred, _ = self.beam_search.search(src)

            # 2. 计算概率
            log_prob_ref = self.compute_log_prob(src, tgt_ref)
            log_prob_pred = self.compute_log_prob(src, tgt_pred)

            # 3. 分类错误
            if log_prob_ref > log_prob_pred:
                # 搜索错误
                search_errors += 1
                error_type = 'search'
            else:
                # 模型错误
                model_errors += 1
                error_type = 'model'

            # 4. 记录示例
            examples.append({
                'src': src,
                'tgt_ref': tgt_ref,
                'tgt_pred': tgt_pred,
                'log_prob_ref': log_prob_ref,
                'log_prob_pred': log_prob_pred,
                'error_type': error_type
            })

        # 5. 汇总结果
        total = len(self.test_data)
        results = {
            'total': total,
            'search_errors': search_errors,
            'model_errors': model_errors,
            'search_error_rate': search_errors / total,
            'model_error_rate': model_errors / total,
            'examples': examples
        }

        return results

    def print_report(self, results):
        """打印分析报告"""
        print("=" * 60)
        print("束搜索误差分析报告")
        print("=" * 60)
        print(f"\n总样本数: {results['total']}")
        print(f"\n搜索错误: {results['search_errors']} "
              f"({results['search_error_rate']:.1%})")
        print(f"模型错误: {results['model_errors']} "
              f"({results['model_error_rate']:.1%})")

        print("\n" + "-" * 60)
        print("建议:")
        print("-" * 60)

        if results['search_error_rate'] > 0.3:
            print("⚠️  搜索错误较多 (>30%)")
            print("   建议:")
            print("   - 增大 beam_size")
            print("   - 优化搜索算法")
            print("   - 考虑使用多样性束搜索")
        else:
            print("✅ 搜索错误较少 (<30%)")
            print("   束搜索性能良好")

        if results['model_error_rate'] > 0.5:
            print("\n⚠️  模型错误较多 (>50%)")
            print("   建议:")
            print("   - 改进模型架构 (如加入 Attention)")
            print("   - 增加训练数据")
            print("   - 调整学习率/批大小")
            print("   - 考虑预训练")
        else:
            print("\n✅ 模型错误可接受 (<50%)")

        # 打印典型示例
        print("\n" + "=" * 60)
        print("典型错误示例:")
        print("=" * 60)

        # 搜索错误示例
        search_examples = [e for e in results['examples']
                          if e['error_type'] == 'search']
        if search_examples:
            print("\n搜索错误示例 (前3个):")
            for i, ex in enumerate(search_examples[:3], 1):
                print(f"\n示例 {i}:")
                print(f"  源序列: {ex['src']}")
                print(f"  参考翻译: {ex['tgt_ref']}")
                print(f"  模型输出: {ex['tgt_pred']}")
                print(f"  P(参考) = {np.exp(ex['log_prob_ref']):.4f}")
                print(f"  P(输出) = {np.exp(ex['log_prob_pred']):.4f}")
                print(f"  → 束搜索应该找到参考翻译!")

        # 模型错误示例
        model_examples = [e for e in results['examples']
                         if e['error_type'] == 'model']
        if model_examples:
            print("\n模型错误示例 (前3个):")
            for i, ex in enumerate(model_examples[:3], 1):
                print(f"\n示例 {i}:")
                print(f"  源序列: {ex['src']}")
                print(f"  参考翻译: {ex['tgt_ref']}")
                print(f"  模型输出: {ex['tgt_pred']}")
                print(f"  P(参考) = {np.exp(ex['log_prob_ref']):.4f}")
                print(f"  P(输出) = {np.exp(ex['log_prob_pred']):.4f}")
                print(f"  → 模型认为自己的输出更好!")

### 情况1: 搜索错误占主导 (>30%)

```
问题:
════

束搜索没有找到模型认为最优的解

可能原因:
════════

1. beam_size 太小
   解决: 增大 k (5 → 10 → 20)

2. 搜索空间探索不足
   解决: 使用多样性束搜索

3. 长度偏差
   解决: 加强长度归一化

4. 早停策略过于激进
   解决: 延长搜索时间

改进方案:
════════

方案1: 增大 beam_size
  试验: k = [3, 5, 10, 20]
  评估: 计算 BLEU 分数
  观察: 搜索错误率是否下降

方案2: 优化长度惩罚
  试验: α = [0.5, 0.6, 0.7, 0.8]
  评估: 生成长度分布
  观察: 是否更接近参考长度

方案3: 多样性束搜索
  使用: Diverse Beam Search
  参数: 分组数 = 2-3
  观察: 是否捕获更多可能性

代码示例:
────────

```python
# 试验不同的 beam_size

for k in beam_sizes:
    beam_search = BeamSearch(model, beam_size=k)

best_k = min(results.keys(),
            key=lambda k: results[k]['search_error_rate'])
print(f"\n最佳 beam_size: {best_k}")
```
