## 📌 基本定义

**新序列采样（Advanced Sequence Sampling）** 是在基础采样策略之上发展的更高级技术，主要解决：

- ✅ **重复问题**: 避免生成重复的词或短语
- ✅ **质量控制**: 在保持多样性的同时确保质量
- ✅ **长度控制**: 生成适当长度的序列
- ✅ **约束生成**: 在特定约束下生成文本

### 核心改进

```
基础采样的问题:

问题 1: 贪婪采样 → 重复
"我爱编程编程编程编程..." ❌

问题 2: 随机采样 → 质量不稳定
"我爱西瓜但是猫飞机..." ❌

问题 3: 温度采样 → 仍需手动调参
τ 太小 → 重复
τ 太大 → 不连贯

新序列采样的解决方案:
✅ Top-k Sampling: 只从前 k 个候选中采样
✅ Nucleus Sampling (Top-p): 动态调整候选集大小
✅ 重复惩罚: 降低已出现词的概率
✅ 长度惩罚: 鼓励生成适当长度的序列
```

## 🔥 Top-k Sampling（Top-k 采样）

### 核心思想

```
策略: 只从概率最高的 k 个词中采样

步骤:
1. 模型预测下一个词的完整概率分布 P
2. 选出概率最高的 k 个词
3. 重新归一化这 k 个词的概率
4. 从这 k 个词中随机采样

示例:
原始概率分布（词表 10000 个词）:
P("编程") = 0.30
P("学习") = 0.20
P("你") = 0.15
P("我") = 0.10
P("猫") = 0.05
... (剩余 9995 个词的概率很低)

Top-k (k=3):
1. 选出前 3: ["编程", "学习", "你"]
2. 重新归一化:
   P'("编程") = 0.30 / (0.30+0.20+0.15) = 0.462
   P'("学习") = 0.20 / 0.65 = 0.308
   P'("你") = 0.15 / 0.65 = 0.231
3. 从这 3 个词中随机采样

效果:
✅ 避免采样到极低概率的词（如"猫"）
✅ 保持一定的多样性（3 个选择）
✅ 避免完全随机导致的不连贯
```

---

### 数学公式

```
Top-k 采样:

1. 排序:
   sorted_indices = argsort(P)[::-1]  # 降序

2. 截断:
   top_k_indices = sorted_indices[:k]

3. 归一化:
   P_k = P[top_k_indices]
   P_k_norm = P_k / sum(P_k)

4. 采样:
   next_word = np.random.choice(top_k_indices, p=P_k_norm)

关键参数 k:
k = 1:   等价于贪婪采样
k = 10:  小范围多样性
k = 50:  中等多样性
k = 100: 大范围多样性
k = vocab_size: 等价于完全随机采样
```

### 完整代码实现

```python
import numpy as np

def top_k_sampling(logits, k=10, temperature=1.0):
    """
    Top-k 采样

    参数:
        logits: 未归一化的分数 [vocab_size]
        k: 保留前 k 个候选
        temperature: 温度参数

    返回:
        sampled_word: 采样的词索引
    """
    # 温度调整
    logits = logits / temperature

    # 找到 top-k 的索引
    top_k_indices = np.argsort(logits)[-k:]  # 最大的 k 个

    # 只保留 top-k 的 logits
    top_k_logits = logits[top_k_indices]

    # Softmax 归一化
    exp_logits = np.exp(top_k_logits - np.max(top_k_logits))  # 数值稳定
    probs = exp_logits / np.sum(exp_logits)

    # 采样
    sampled_idx = np.random.choice(len(top_k_indices), p=probs)
    sampled_word = top_k_indices[sampled_idx]

    return sampled_word


def generate_with_top_k(model, seed, max_length=50, k=10, temperature=1.0):
    """
    使用 Top-k 采样生成序列

    参数:
        model: 语言模型
        seed: 起始词索引
        max_length: 最大生成长度
        k: Top-k 参数
        temperature: 温度参数

    返回:
        sequence: 生成的序列
    """
    sequence = [seed]
    h = model.init_hidden()

    for _ in range(max_length):
        # 获取 logits
        logits = model.get_logits(sequence, h)

        # Top-k 采样
        next_word = top_k_sampling(logits, k=k, temperature=temperature)

        sequence.append(next_word)

        # 停止条件
        if next_word == model.eos_token:
            break

        # 更新隐藏状态
        h = model.update_hidden(h, next_word)

    return sequence
```

### Top-k 的优缺点

```
优点:
✅ 简单直观，易于实现
✅ 有效避免采样到极低概率词
✅ 控制多样性（通过 k）
✅ 计算效率高（只需排序前 k 个）

缺点:
❌ k 是固定的（不够灵活）
   - 有时前 3 个词就占 90% 概率 → k=10 太大
   - 有时前 10 个词只占 50% 概率 → k=10 太小
❌ 无法自适应调整候选集大小
❌ 不同位置的最佳 k 可能不同

示例:
位置 1: "我 爱 ___"
  P("编程") = 0.70  ← 一个词就很明确
  P("学习") = 0.15
  P("你") = 0.10
  → k=10 太大！(其他 7 个词概率极低)

位置 2: "天气 ___"
  P("很好") = 0.20   ← 概率分散
  P("不错") = 0.18
  P("晴朗") = 0.15
  P("多云") = 0.12
  ...
  → k=10 合适
```

## 🌟 Nucleus Sampling (Top-p Sampling)

### 核心思想

```
策略: 动态选择最小候选集，使其累积概率 ≥ p

与 Top-k 的区别:
Top-k: 固定候选数量 k
Top-p: 固定累积概率 p，候选数量动态调整

步骤:
1. 按概率从高到低排序
2. 累加概率，直到 ≥ p
3. 从这些词中采样

示例 (p=0.9):
排序后:
P("编程") = 0.70  累积: 0.70
P("学习") = 0.15  累积: 0.85
P("你") = 0.10    累积: 0.95  ← 达到 0.9，停止
P("我") = 0.03    ← 不包括
P("猫") = 0.02    ← 不包括

候选集: ["编程", "学习", "你"]  (3个词)

另一个例子 (p=0.9):
P("很好") = 0.20  累积: 0.20
P("不错") = 0.18  累积: 0.38
P("晴朗") = 0.15  累积: 0.53
P("多云") = 0.12  累积: 0.65
P("阴天") = 0.10  累积: 0.75
P("下雨") = 0.08  累积: 0.83
P("凉爽") = 0.07  累积: 0.90  ← 达到 0.9，停止

候选集: 7个词  ← 自动调整！

关键优势:
✅ 自适应候选集大小
✅ 概率集中时 → 少量候选
✅ 概率分散时 → 较多候选
```

---

### 数学公式

```
Nucleus Sampling (Top-p):

给定累积概率阈值 p ∈ (0, 1]

1. 排序:
   sorted_indices = argsort(P)[::-1]  # 降序
   sorted_probs = P[sorted_indices]

2. 累积概率:
   cumulative_probs = cumsum(sorted_probs)

3. 找到截断点:
   cutoff_idx = min(i : cumulative_probs[i] ≥ p)

4. 候选集:
   nucleus_indices = sorted_indices[:cutoff_idx+1]
   nucleus_probs = sorted_probs[:cutoff_idx+1]

5. 归一化:
   nucleus_probs_norm = nucleus_probs / sum(nucleus_probs)

6. 采样:
   next_word = np.random.choice(nucleus_indices, p=nucleus_probs_norm)

参数 p 的选择:
p = 0.9:  保留前 90% 概率的词（常用）
p = 0.95: 保留前 95% 概率的词（更保守）
p = 0.8:  保留前 80% 概率的词（更随机）
p = 1.0:  等价于完全随机采样
```

### 完整代码实现

```python
def nucleus_sampling(logits, p=0.9, temperature=1.0):
    """
    Nucleus Sampling (Top-p)

    参数:
        logits: 未归一化的分数 [vocab_size]
        p: 累积概率阈值
        temperature: 温度参数

    返回:
        sampled_word: 采样的词索引
    """
    # 温度调整
    logits = logits / temperature

    # Softmax
    exp_logits = np.exp(logits - np.max(logits))
    probs = exp_logits / np.sum(exp_logits)

    # 按概率降序排序
    sorted_indices = np.argsort(probs)[::-1]
    sorted_probs = probs[sorted_indices]

    # 计算累积概率
    cumulative_probs = np.cumsum(sorted_probs)

    # 找到累积概率 >= p 的截断点
    cutoff_idx = np.argmax(cumulative_probs >= p)

    # Nucleus（核心候选集）
    nucleus_indices = sorted_indices[:cutoff_idx+1]
    nucleus_probs = sorted_probs[:cutoff_idx+1]

    # 重新归一化
    nucleus_probs_norm = nucleus_probs / np.sum(nucleus_probs)

    # 采样
    sampled_idx = np.random.choice(len(nucleus_indices), p=nucleus_probs_norm)
    sampled_word = nucleus_indices[sampled_idx]

    return sampled_word


def generate_with_nucleus(model, seed, max_length=50, p=0.9, temperature=1.0):
    """
    使用 Nucleus Sampling 生成序列

    参数:
        model: 语言模型
        seed: 起始词索引
        max_length: 最大生成长度
        p: 累积概率阈值
        temperature: 温度参数

    返回:
        sequence: 生成的序列
    """
    sequence = [seed]
    h = model.init_hidden()

    for _ in range(max_length):
        # 获取 logits
        logits = model.get_logits(sequence, h)

        # Nucleus 采样
        next_word = nucleus_sampling(logits, p=p, temperature=temperature)

        sequence.append(next_word)

        # 停止条件
        if next_word == model.eos_token:
            break

        h = model.update_hidden(h, next_word)

    return sequence

```

```
场景 1: 概率高度集中

✅ 不需要手动调整 k
```

## 🚫 重复惩罚（Repetition Penalty）

### 问题：生成重复

```
问题示例:
"我爱编程，编程让我快乐，编程是我的爱好，编程编程编程..."

原因:
RNN 语言模型容易陷入循环模式
已生成的词会在后续继续被高概率预测

常见重复类型:
1. 词级重复: "好好好好好..."
2. 短语重复: "我觉得我觉得我觉得..."
3. 模式重复: "A B C A B C A B C..."
```

---

### 解决方案：重复惩罚

```
核心思想:
降低已经出现过的词的概率

方法 1: 频率惩罚（Frequency Penalty）
P'(w) = P(w) / (1 + α · count(w))

其中:
- count(w): 词 w 在已生成序列中出现的次数
- α: 惩罚强度（如 1.2）

示例:
已生成: "我 爱 编程 编程"
原始概率: P("编程") = 0.30

频率惩罚 (α=1.2):
count("编程") = 2
P'("编程") = 0.30 / (1 + 1.2 × 2) = 0.30 / 3.4 ≈ 0.088  ← 大幅降低！

方法 2: 存在惩罚（Presence Penalty）
P'(w) = P(w) / (1 + β) if w in generated else P(w)

其中:
- β: 惩罚强度（如 0.5）
- 只要出现过就惩罚，不考虑次数

示例:
P'("编程") = 0.30 / (1 + 0.5) = 0.20  ← 固定惩罚

方法 3: 衰减惩罚（Decay Penalty）
P'(w) = P(w) · (γ ^ count(w))

其中:
- γ: 衰减因子（如 0.8）
- 指数衰减

示例:
count("编程") = 2
P'("编程") = 0.30 × (0.8^2) = 0.30 × 0.64 = 0.192
```

---

### 代码实现

```python
def apply_repetition_penalty(logits, generated_tokens, penalty=1.2, mode='frequency'):
    """
    应用重复惩罚

    参数:
        logits: 未归一化的分数 [vocab_size]
        generated_tokens: 已生成的词索引列表
        penalty: 惩罚强度
        mode: 'frequency', 'presence', 或 'decay'

    返回:
        penalized_logits: 惩罚后的 logits
    """
    penalized_logits = logits.copy()

    if mode == 'frequency':
        # 频率惩罚
        token_counts = {}
        for token in generated_tokens:
            token_counts[token] = token_counts.get(token, 0) + 1

        for token, count in token_counts.items():
            penalized_logits[token] /= (1 + penalty * count)

    elif mode == 'presence':
        # 存在惩罚
        unique_tokens = set(generated_tokens)
        for token in unique_tokens:
            penalized_logits[token] /= (1 + penalty)

    elif mode == 'decay':
        # 衰减惩罚
        token_counts = {}
        for token in generated_tokens:
            token_counts[token] = token_counts.get(token, 0) + 1

        for token, count in token_counts.items():
            penalized_logits[token] *= (penalty ** count)  # penalty < 1

    return penalized_logits


def generate_with_repetition_penalty(
    model, seed, max_length=50,
    penalty=1.2, penalty_mode='frequency',
    sampling='nucleus', p=0.9
):
    """
    带重复惩罚的序列生成

    参数:
        model: 语言模型
        seed: 起始词
        max_length: 最大长度
        penalty: 重复惩罚强度
        penalty_mode: 惩罚模式
        sampling: 采样策略 ('nucleus', 'top_k', 'greedy')
        p: Nucleus sampling 参数

    返回:
        sequence: 生成的序列
    """
    sequence = [seed]
    h = model.init_hidden()

    for _ in range(max_length):
        # 获取原始 logits
        logits = model.get_logits(sequence, h)

        # 应用重复惩罚
        logits = apply_repetition_penalty(
            logits,
            generated_tokens=sequence,
            penalty=penalty,
            mode=penalty_mode
        )

        # 采样
        if sampling == 'nucleus':
            next_word = nucleus_sampling(logits, p=p)
        elif sampling == 'top_k':
            next_word = top_k_sampling(logits, k=10)
        elif sampling == 'greedy':
            next_word = np.argmax(logits)
        else:
            raise ValueError(f"Unknown sampling: {sampling}")

        sequence.append(next_word)

        if next_word == model.eos_token:
            break

        h = model.update_hidden(h, next_word)

    return sequence

    penalized_logits = apply_repetition_penalty(
        logits, generated, penalty=1.5, mode='frequency'
    )
    penalized_probs = np.exp(penalized_logits) / np.sum(np.exp(penalized_logits))
    for i, word in enumerate(vocab):
        print(f"  {word}: {penalized_probs[i]:.4f}")
        if i == 3:  # "编程"
            print(f"    → 从 {probs[i]:.4f} 降低到 {penalized_probs[i]:.4f}")
```

### 重复惩罚的权衡

```
优点:
✅ 有效减少重复
✅ 生成更多样化的文本
✅ 简单易实现

缺点:
❌ 可能过度惩罚合理的重复
   例如: "深度学习和机器学习都是人工智能的分支，深度学习..."
   → "深度学习"第二次出现是合理的！
❌ 需要调整惩罚强度
   α 太小: 重复仍存在
   α 太大: 生成不自然

建议:
✅ α = 1.2-1.5 (频率惩罚)
✅ β = 0.3-0.6 (存在惩罚)
✅ 与 Nucleus Sampling 结合使用
✅ 根据任务调整（对话 vs 文章）
```

## 📏 长度惩罚（Length Penalty）

### 问题：生成长度失控

```
问题 1: 生成过短
"我爱编程。<EOS>"  ← 太短，信息不足

问题 2: 生成过长
"我爱编程，编程让我快乐，我每天都在学习编程，编程是我的生活..."
× 200 个词，没有停止 ← 太长

原因:
语言模型只关心每步的概率，不考虑整体长度
```

---

### 解决方案：长度惩罚

```
方法 1: 长度归一化（束搜索中常用）
score(seq) = log P(seq) / length^α

其中:
- α: 长度惩罚系数
- α = 0: 不惩罚
- α = 1: 完全归一化
- α < 1: 偏好较长序列
- α > 1: 偏好较短序列

示例:
序列 A: "我爱编程。" (4 个词)
log P(A) = -2.0
score(A, α=1) = -2.0 / 4^1 = -0.5

序列 B: "我爱编程，编程很有趣。" (8 个词)
log P(B) = -3.5
score(B, α=1) = -3.5 / 8^1 = -0.4375

→ 序列 B 得分更高（更长但更流畅）

方法 2: EOS 概率调整
在预测时，动态调整 <EOS> 的概率

P'(<EOS>) = P(<EOS>) · f(current_length, target_length)

其中:
f(l, t) = exp(-|(l - t) / t|)  # 接近目标长度时，<EOS> 概率高

示例:
target_length = 20
current_length = 5:  f = exp(-0.75) ≈ 0.47  ← 抑制 <EOS>
current_length = 18: f = exp(-0.10) ≈ 0.90  ← 鼓励 <EOS>
current_length = 25: f = exp(-0.25) ≈ 0.78  ← 鼓励 <EOS>

方法 3: 最小/最大长度约束
min_length = 10: 前 10 步，强制 P(<EOS>) = 0
max_length = 100: 第 100 步，强制选择 <EOS>
```

---

### 代码实现

```python
def apply_length_penalty(logits, current_length, min_length=5, max_length=100,
                         target_length=None, eos_token_id=0):
    """
    应用长度惩罚

    参数:
        logits: 未归一化的分数 [vocab_size]
        current_length: 当前序列长度
        min_length: 最小长度约束
        max_length: 最大长度约束
        target_length: 目标长度（可选）
        eos_token_id: <EOS> 标记的索引

    返回:
        adjusted_logits: 调整后的 logits
    """
    adjusted_logits = logits.copy()

    # 最小长度约束: 前 min_length 步，禁止 <EOS>
    if current_length < min_length:
        adjusted_logits[eos_token_id] = -np.inf  # 强制不选 <EOS>

    # 最大长度约束: 达到 max_length，强制 <EOS>
    elif current_length >= max_length:
        adjusted_logits[:] = -np.inf
        adjusted_logits[eos_token_id] = 0  # 只能选 <EOS>

    # 目标长度引导（可选）
    elif target_length is not None:
        # 距离目标长度的归一化距离
        distance = abs(current_length - target_length) / target_length
        # 距离越小，越鼓励 <EOS>
        eos_adjustment = -2.0 * distance  # 调整系数
        adjusted_logits[eos_token_id] += eos_adjustment

    return adjusted_logits


def generate_with_length_control(
    model, seed, min_length=10, max_length=50, target_length=None,
    sampling='nucleus', p=0.9
):
    """
    带长度控制的序列生成

    参数:
        model: 语言模型
        seed: 起始词
        min_length: 最小长度
        max_length: 最大长度
        target_length: 目标长度（可选）
        sampling: 采样策略
        p: Nucleus 参数

    返回:
        sequence: 生成的序列
    """
    sequence = [seed]
    h = model.init_hidden()

    for step in range(max_length):
        current_length = len(sequence)

        # 获取 logits
        logits = model.get_logits(sequence, h)

        # 应用长度惩罚
        logits = apply_length_penalty(
            logits,
            current_length=current_length,
            min_length=min_length,
            max_length=max_length,
            target_length=target_length,
            eos_token_id=model.eos_token
        )

        # 采样
        if sampling == 'nucleus':
            next_word = nucleus_sampling(logits, p=p)
        else:
            next_word = top_k_sampling(logits, k=10)

        sequence.append(next_word)

        # 停止条件
        if next_word == model.eos_token:
            break

        h = model.update_hidden(h, next_word)

    return sequence
```

```python
def advanced_generate(
    model,
    seed,
    max_length=100,
    min_length=5,
    # Nucleus sampling
    p=0.9,
    temperature=0.8,
    # Repetition penalty
    repetition_penalty=1.2,
    penalty_mode='frequency',
    # Length control
    target_length=None,
    # Other
    eos_token_id=0,
    verbose=False
):
    """
    高级序列生成（综合所有策略）

    参数:
        model: 语言模型
        seed: 起始词或序列
        max_length: 最大生成长度
        min_length: 最小生成长度
        p: Nucleus sampling 阈值
        temperature: 温度参数
        repetition_penalty: 重复惩罚强度
        penalty_mode: 'frequency', 'presence', 'decay'
        target_length: 目标长度（可选）
        eos_token_id: EOS 标记 ID
        verbose: 是否打印详细信息

    返回:
        sequence: 生成的序列
        metadata: 生成过程的元数据
    """
    # 初始化
    if isinstance(seed, int):
        sequence = [seed]
    else:
        sequence = list(seed)

    h = model.init_hidden()
    metadata = {
        'nucleus_sizes': [],
        'selected_probs': [],
        'penalties_applied': []
    }

    for step in range(max_length):
        current_length = len(sequence)

        # 1. 获取原始 logits
        logits = model.get_logits(sequence, h)

        # 2. 应用重复惩罚
        logits = apply_repetition_penalty(
            logits,
            generated_tokens=sequence,
            penalty=repetition_penalty,
            mode=penalty_mode
        )
        if verbose:
            penalty_info = f"重复惩罚已应用 (mode={penalty_mode}, α={repetition_penalty})"
            metadata['penalties_applied'].append(penalty_info)

        # 3. 应用长度惩罚
        logits = apply_length_penalty(
            logits,
            current_length=current_length,
            min_length=min_length,
            max_length=max_length,
            target_length=target_length,
            eos_token_id=eos_token_id
        )

        # 4. Nucleus Sampling
        # 温度调整
        logits = logits / temperature

        # Softmax
        exp_logits = np.exp(logits - np.max(logits))
        probs = exp_logits / np.sum(exp_logits)

        # 排序
        sorted_indices = np.argsort(probs)[::-1]
        sorted_probs = probs[sorted_indices]

        # 累积概率
        cumulative_probs = np.cumsum(sorted_probs)

        # 找到 nucleus
        cutoff_idx = np.argmax(cumulative_probs >= p)
        nucleus_indices = sorted_indices[:cutoff_idx+1]
        nucleus_probs = sorted_probs[:cutoff_idx+1]

        # 记录 nucleus 大小
        metadata['nucleus_sizes'].append(len(nucleus_indices))

        # 归一化并采样
        nucleus_probs_norm = nucleus_probs / np.sum(nucleus_probs)
        sampled_idx = np.random.choice(len(nucleus_indices), p=nucleus_probs_norm)
        next_word = nucleus_indices[sampled_idx]

        # 记录选中词的概率
        metadata['selected_probs'].append(probs[next_word])

        if verbose:
            print(f"Step {step+1}: nucleus_size={len(nucleus_indices)}, "
                  f"selected_prob={probs[next_word]:.4f}")

        # 5. 添加到序列
        sequence.append(next_word)

        # 6. 停止条件
        if next_word == eos_token_id:
            if verbose:
                print(f"遇到 <EOS>，生成结束。最终长度: {len(sequence)}")
            break

        # 7. 更新隐藏状态
        h = model.update_hidden(h, next_word)

    return sequence, metadata
```
