## 🎯 核心问题：为什么需要词嵌入？

### 问题的本质

```
深度学习模型处理文本的困境:
──────────────────────────

输入: 文本 "I love deep learning"
模型: 神经网络 (需要数值输入)

问题:
❌ 神经网络只能处理数字
❌ 文本是符号(字符串)
❌ 如何将符号转换为数字?

朴素方案: One-Hot 编码
───────────────────────

vocabulary = ["I", "love", "deep", "learning", "cat", "dog", ...]
vocab_size = 10,000

"I" → [1, 0, 0, 0, ..., 0]  (10000维)
"love" → [0, 1, 0, 0, ..., 0]
"deep" → [0, 0, 1, 0, ..., 0]

输入神经网络:
[1, 0, 0, ...] → [隐藏层] → [输出]

三大致命问题:
❌ 维度灾难: 10000维向量
❌ 无语义信息: "cat"和"dog"距离 = "cat"和"car"距离 = √2
❌ 稀疏表示: 99.99%是0，浪费计算资源

数学表达:
对于词汇表大小|V|的任意两个不同词 w_i, w_j:
  distance(one_hot(w_i), one_hot(w_j)) = √2  (常数!)
→ 完全无法区分语义相近和语义无关的词
```

---

## 🚀 解决方案：词嵌入的引入

### 核心思想

```
词嵌入 = 低维稠密向量表示

目标: 将每个词映射到低维连续空间
  word → vector ∈ ℝ^d  (d << |V|, 通常 d ≈ 50-300)

关键特性:
✅ 低维: 300维 << 10000维
✅ 稠密: 无冗余的0
✅ 语义: 相似词的向量接近
✅ 可学习: 通过训练优化

示例:
"cat" → [0.2, -0.5, 0.8, 0.1, -0.3, ...]  (300维)
"dog" → [0.3, -0.4, 0.7, 0.2, -0.2, ...]  (300维)
"car" → [-0.1, 0.8, -0.2, 0.5, 0.9, ...]  (300维)

观察:
cos_sim("cat", "dog") ≈ 0.85  ← 高相似度！
cos_sim("cat", "car") ≈ 0.12  ← 低相似度
→ 成功捕捉语义关系
```

## 🔄 词嵌入如何工作：完整流程

### 阶段1: 从One-Hot到词嵌入

```
核心机制: 嵌入矩阵查找
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

步骤1: 定义嵌入矩阵
────────────────────

嵌入矩阵 E ∈ ℝ^{d × |V|}

E = [e_1, e_2, e_3, ..., e_|V|]
     ↑    ↑    ↑         ↑
   词1  词2  词3       词|V|

示例: d=3, |V|=5
vocabulary = ["I", "love", "deep", "learning", "NLP"]

E = [
  [0.2,  0.5,  0.1,  0.3,  0.4],  ← 维度1
  [-0.1, 0.2, -0.4, -0.3,  0.1],  ← 维度2
  [0.8,  0.6,  0.9,  0.7,  0.5]   ← 维度3
]
  ↑     ↑     ↑     ↑      ↑
  I   love  deep  learning NLP

步骤2: One-Hot 索引
──────────────────

给定词 "deep" (索引=2)

One-Hot 表示:
o_deep = [0, 0, 1, 0, 0]^T

步骤3: 矩阵乘法提取词向量
───────────────────────────

数学原理:
e_deep = E · o_deep

计算:
[0.2,  0.5,  0.1,  0.3,  0.4]   [0]   [0.1]
[-0.1, 0.2, -0.4, -0.3,  0.1] · [0] = [-0.4]
[0.8,  0.6,  0.9,  0.7,  0.5]   [1]   [0.9]
                                 [0]
                                 [0]

结果:
e_deep = [0.1, -0.4, 0.9]^T

本质: 矩阵乘法相当于选择第3列！

关键洞察:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
E · one_hot(word_i) = e_i  (第i列)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

实际实现: 直接索引 (更高效)
─────────────────────────────

不做矩阵乘法,直接查找:
e_deep = E[:, 2]  或  E[2, :]  (看矩阵布局)

复杂度: O(1) 而不是 O(d × |V|)
```

### 阶段2: 词嵌入输入神经网络

```
场景: 情感分析
输入: "I love deep learning"
输出: 正面/负面/中性

完整数据流:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

步骤1: 文本 → 索引序列
────────────────────────

文本: ["I", "love", "deep", "learning"]
索引: [0, 1, 2, 3]

步骤2: 索引 → 词向量序列
───────────────────────────

通过嵌入矩阵E查找:

索引0 → e_I = [0.2, -0.1, 0.8]
索引1 → e_love = [0.5, 0.2, 0.6]
索引2 → e_deep = [0.1, -0.4, 0.9]
索引3 → e_learning = [0.3, -0.3, 0.7]

形成嵌入矩阵 (序列):
X_embedded = [
  [0.2, -0.1, 0.8],   ← t=1 (I)
  [0.5,  0.2, 0.6],   ← t=2 (love)
  [0.1, -0.4, 0.9],   ← t=3 (deep)
  [0.3, -0.3, 0.7]    ← t=4 (learning)
]
形状: [seq_len=4, embedding_dim=3]

步骤3: 词向量 → RNN/LSTM
────────────────────────

        h^<4> (最后隐藏状态)
          ↑
    [LSTM]→[LSTM]→[LSTM]→[LSTM]
      ↑      ↑      ↑      ↑
    [0.2]  [0.5]  [0.1]  [0.3]  ← 嵌入向量
    [-0.1] [0.2]  [-0.4] [-0.3]
    [0.8]  [0.6]  [0.9]  [0.7]
      ↑      ↑      ↑      ↑
     "I"  "love" "deep" "learning"

步骤4: 隐藏状态 → 分类器
────────────────────────

h^<4> → [全连接层] → softmax
                      ↓
              [0.05, 0.90, 0.05]
               ↑     ↑     ↑
              负面  正面  中性

预测: 正面 (90%)

完整前向传播代码:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

import torch
import torch.nn as nn

class SentimentClassifier(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim, num_classes):
        super().__init__()

        # 嵌入层 (关键!)
        self.embedding = nn.Embedding(vocab_size, embedding_dim)

        # LSTM层
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)

        # 分类层
        self.fc = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        # x: [batch_size, seq_len] 词索引

        # 步骤1: 词索引 → 词向量
        embedded = self.embedding(x)
        # [batch_size, seq_len, embedding_dim]

        # 步骤2: 词向量 → LSTM
        lstm_out, (h_n, c_n) = self.lstm(embedded)
        # h_n: [1, batch_size, hidden_dim]

        # 步骤3: 最后隐藏状态 → 分类
        logits = self.fc(h_n.squeeze(0))
        # [batch_size, num_classes]

        return logits

# 使用
model = SentimentClassifier(vocab_size=10000, embedding_dim=300,
                           hidden_dim=128, num_classes=3)

# 输入: 词索引序列
x = torch.tensor([[0, 1, 2, 3]])  # "I love deep learning"

# 输出: 分类logits
output = model(x)  # [1, 3]
```

### 阶段3: 固定窗口与上下文矩阵

```
Word2Vec 的核心机制
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

场景: 学习词嵌入 (不是使用预训练的)

输入语料:
"The quick brown fox jumps over the lazy dog"

窗口大小 m = 2:
中心词: "fox"
上下文: ["quick", "brown", "jumps", "over"]

构造训练样本 (Skip-gram):
──────────────────────────

中心词 → 上下文词 (多个预测任务)
"fox" → "quick"
"fox" → "brown"
"fox" → "jumps"
"fox" → "over"

神经网络结构:
─────────────

输入: 中心词的one-hot
o_fox = [0, 0, ..., 1, ..., 0]^T  (|V|维)

嵌入层: 查找词向量
v_fox = E · o_fox  (d维)

输出层: 预测上下文词
u_context = W_out · v_fox
P(context_word | fox) = softmax(u_context)

训练目标: 最大化
log P("quick" | "fox") + log P("brown" | "fox") +
log P("jumps" | "fox") + log P("over" | "fox")

固定窗口形成的向量矩阵:
────────────────────────

对于句子中的每个位置 t:
提取窗口 [t-m, t+m] 的词

示例: m=2, 句子长度T=9
位置 t=3 (中心词="fox"):

上下文窗口矩阵:
[
  e_quick,     ← t-2
  e_brown,     ← t-1
  e_fox,       ← t (中心词)
  e_jumps,     ← t+1
  e_over       ← t+2
]

这个矩阵包含了"fox"的语义上下文!
通过预测任务,调整e_fox使其能够预测上下文
→ 相似上下文的词将有相似的向量

完整Skip-gram训练流程:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

for 每个中心词 w_c in 语料:
    for 每个上下文词 w_o in window(w_c):
        # 前向传播
        v_c = embedding[w_c]           # 中心词向量
        u_o = output_embedding[w_o]     # 上下文词向量
        score = dot(v_c, u_o)

        # 计算损失 (负采样简化版)
        loss = -log(sigmoid(score))

        # 反向传播,更新嵌入矩阵
        gradient = compute_gradient(loss)
        embedding[w_c] -= lr * gradient

关键洞察:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
通过预测任务,相似上下文的词会被"拉近"
→ 自动学习语义相似性
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 🎨 词嵌入特性在神经网络中的体现

### 特性1: 语义相似性 → 参数共享

```
相似词 → 相似向量 → 相似的网络响应

示例:
"cat" → [0.2, -0.5, 0.8]
"dog" → [0.3, -0.4, 0.7]

输入LSTM:
LSTM(v_cat) ≈ LSTM(v_dog)

好处:
✅ 泛化能力: 训练集见过"cat",测试集的"dog"也能处理
✅ 参数共享: 不需要为每个词单独学习
✅ 数据效率: 少量样本就能学习模式
```

---

### 特性2: 词类比 → 向量运算

```
king - man + woman ≈ queen

在神经网络中的应用:
─────────────────────

任务: 词类比补全
输入: ["king", "man", "woman", "?"]
输出: "queen"

神经网络:
v_king - v_man + v_woman
  ↓
[计算最近邻]
  ↓
v_queen

示例代码:
def analogy(word_a, word_b, word_c, embedding_matrix, vocab):
    """
    计算: a is to b as c is to ?
    """
    v_a = embedding_matrix[vocab[word_a]]
    v_b = embedding_matrix[vocab[word_b]]
    v_c = embedding_matrix[vocab[word_c]]

    # 向量运算
    v_target = v_b - v_a + v_c

    # 找最近邻
    similarities = cosine_similarity(v_target, embedding_matrix)
    best_idx = np.argmax(similarities)

    return idx2word[best_idx]

result = analogy("king", "man", "woman", E, vocab)
print(result)  # "queen"

网络学到的不仅是词,还有关系!
```

```

  ↓
```

## 🧠 词嵌入的学习与更新

### 两种学习范式

```
范式1: 预训练 + 冻结
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

步骤1: 在大语料上预训练 (Word2Vec/GloVe)
语料: 维基百科 (数十亿词)
输出: 预训练嵌入矩阵 E_pretrained

步骤2: 加载到下游任务
E = E_pretrained
E.requires_grad = False  # 冻结!

步骤3: 训练任务网络
只更新 LSTM 和分类层的参数
嵌入层保持不变

优点:
✅ 快速训练
✅ 小数据也能工作
✅ 利用大规模语义知识

缺点:
❌ 无法适应特定领域
❌ OOV问题

适用场景:
- 小数据任务 (< 10K样本)
- 通用领域
- 快速原型

范式2: 端到端训练 (微调)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

步骤1: 初始化嵌入矩阵
E = E_pretrained  (如果有) 或 random_init()

步骤2: 联合训练
同时更新嵌入层和任务网络

反向传播流程:
loss → ∂loss/∂output → ∂loss/∂hidden → ∂loss/∂embedding

嵌入更新:
E[word_idx] -= lr * ∂loss/∂E[word_idx]

步骤3: 任务特定嵌入
训练后的E适应了特定任务

优点:
✅ 适应特定领域
✅ 更好的任务性能

缺点:
❌ 需要更多数据
❌ 训练时间长
❌ 可能过拟合

适用场景:
- 大数据任务 (> 100K样本)
- 特定领域 (如医学、法律)
- 追求最佳性能

混合策略: 先冻结后微调
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# 阶段1: 冻结嵌入,训练网络
model.embedding.weight.requires_grad = False
train(model, epochs=5)

# 阶段2: 解冻嵌入,微调
model.embedding.weight.requires_grad = True
train(model, epochs=3, lr=0.0001)  # 小学习率

好处:
✅ 快速收敛
✅ 防止嵌入被破坏
✅ 适应任务
```

## 📊 完整示例：从One-Hot到预测

### 端到端流程

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

# ============================================================
# 阶段1: 准备数据
# ============================================================

# 训练文本
texts = [
    "I love deep learning",
    "I hate bugs",
    "Deep learning is amazing",
    "Debugging is frustrating"
]

labels = [1, 0, 1, 0]  # 1: 正面, 0: 负面

# 构建词汇表
vocabulary = set()
for text in texts:
    vocabulary.update(text.lower().split())

word2idx = {word: idx for idx, word in enumerate(vocabulary)}
word2idx['<PAD>'] = len(word2idx)
vocab_size = len(word2idx)

print("=" * 60)
print("阶段1: 数据准备")
print("=" * 60)
print(f"词汇表: {list(word2idx.keys())}")
print(f"词汇表大小: {vocab_size}")
print()

# 转换为索引序列
def text_to_indices(text, word2idx, max_len=10):
    indices = [word2idx[w.lower()] for w in text.split()]
    # Padding
    if len(indices) < max_len:
        indices += [word2idx['<PAD>']] * (max_len - len(indices))
    else:
        indices = indices[:max_len]
    return indices

X = torch.tensor([text_to_indices(t, word2idx) for t in texts])
y = torch.tensor(labels)

print(f"输入形状: {X.shape}")  # [4, 10]
print(f"标签形状: {y.shape}")  # [4]
print()

# ============================================================
# 阶段2: 构建模型 (嵌入层 + LSTM + 分类器)
# ============================================================

class SentimentModel(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        super().__init__()

        # 嵌入层 (核心!)
        self.embedding = nn.Embedding(vocab_size, embedding_dim)

        # LSTM层
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)

        # 分类层
        self.fc = nn.Linear(hidden_dim, 2)  # 2类: 正/负

    def forward(self, x):
        # x: [batch_size, seq_len] 整数索引

        # 步骤1: 索引 → 词向量 (关键步骤!)
        embedded = self.embedding(x)
        # [batch_size, seq_len, embedding_dim]

        print(f"  嵌入后形状: {embedded.shape}")

        # 步骤2: 词向量序列 → LSTM
        lstm_out, (h_n, c_n) = self.lstm(embedded)
        # h_n: [1, batch_size, hidden_dim]

        # 步骤3: 最后隐藏状态 → 分类
        logits = self.fc(h_n.squeeze(0))
        # [batch_size, 2]

        return logits
```

## 💡 核心要点总结

### 词嵌入工作的五个阶段

```
1. 表示转换: 词 → 索引 → 嵌入向量
   One-Hot (稀疏) → 词嵌入 (稠密)

2. 嵌入查找: E · one-hot = 词向量
   实际实现: E[word_idx] (直接索引)

3. 序列建模: 词向量序列 → RNN/LSTM
   捕捉上下文,形成句子表示

4. 任务预测: 隐藏状态 → 分类/生成
   端到端训练,优化任务目标

5. 嵌入学习: 反向传播 → 更新嵌入
   通过任务信号优化语义表示
```

---

### 关键技术细节

```
查找机制:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
理论: E · one_hot(w)  O(d × |V|)
实践: E[idx(w)]        O(1)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

更新机制:
反向传播: loss → ∂loss/∂E[word_idx]
只更新出现的词的向量 (稀疏更新)

参数共享:
同一词在不同位置使用同一向量
→ 大幅减少参数量

窗口与上下文:
固定窗口 → 局部上下文
用于Word2Vec训练
```
