## 📌 基本定义

**词嵌入去偏 (Debiasing Word Embeddings)** 是消除词向量中隐含的性别、种族、年龄等偏见的技术，确保 AI 系统的公平性。

### 问题背景

```
AI 伦理问题:
═══════════

词嵌入从大规模文本中学习
→ 文本反映社会偏见
→ 词向量继承这些偏见
→ 下游应用放大偏见

示例:
────

语料中的偏见表述:
  "doctor" 常与 "he" 共现
  "nurse" 常与 "she" 共现
  "programmer" 常与 "man" 共现
  "homemaker" 常与 "woman" 共现

学到的词向量:
  doctor ≈ man
  nurse ≈ woman
  programmer ≈ man
  homemaker ≈ woman

后果:
  简历筛选系统可能歧视女性程序员
  职业推荐可能有性别偏见
  语言生成可能强化刻板印象

现实案例:
────────

Google Photos (2015):
  将黑人标记为"大猩猩"
  → 种族偏见

Amazon 招聘 AI (2018):
  系统性歧视女性候选人
  → 性别偏见

这些都源于训练数据中的偏见！
```

## 🎯 检测偏见

### 类比测试

```
词类比任务:
═══════════

原理:
  a - b + c ≈ d

如果词向量有偏见，会出现:
  man - woman + programmer ≈ homemaker 
  father - mother + doctor ≈ nurse

这反映了:
  "programmer" 偏向男性
  "homemaker" 偏向女性
  "doctor" 偏向男性
  "nurse" 偏向女性

检测方法:
────────

定义职业词:
  jobs = ["programmer", "doctor", "nurse", "engineer", ...]

定义性别词对:
  gender_pairs = [("he", "she"), ("man", "woman"), ("boy", "girl"), ...]

测试:
  对每个职业 job:
    计算 similarity(job, "man") vs similarity(job, "woman")

    如果 similarity(job, "man") > similarity(job, "woman"):
      → 职业偏向男性

示例代码:
────────

```python
def detect_gender_bias(embedding, vocab):
    """检测性别偏见"""
    jobs = ["programmer", "doctor", "nurse", "engineer",
            "teacher", "scientist", "artist"]

    male_words = ["man", "he", "his", "boy", "male"]
    female_words = ["woman", "she", "her", "girl", "female"]

    # 计算性别方向
    male_vec = np.mean([embedding[vocab[w]] for w in male_words], axis=0)
    female_vec = np.mean([embedding[vocab[w]] for w in female_words], axis=0)

    gender_direction = male_vec - female_vec
    gender_direction /= np.linalg.norm(gender_direction)

    # 测试每个职业
    for job in jobs:
        if job not in vocab:
            continue

        job_vec = embedding[vocab[job]]

        # 在性别方向上的投影
        projection = np.dot(job_vec, gender_direction)

        if abs(projection) > 0.1:  # 阈值
            bias = "男性" if projection > 0 else "女性"
            print(f"{job:15s}: 偏向 {bias} (强度: {abs(projection):.3f})")
        else:
            print(f"{job:15s}: 中性 (强度: {abs(projection):.3f})")
```

输出示例:
────────

programmer     : 偏向 男性 (强度: 0.342)
doctor         : 偏向 男性 (强度: 0.217)
nurse          : 偏向 女性 (强度: 0.298)
engineer       : 偏向 男性 (强度: 0.401)
teacher        : 偏向 女性 (强度: 0.156)
scientist      : 偏向 男性 (强度: 0.289)
artist         : 中性 (强度: 0.087)

观察:
✅ STEM 职业偏向男性
✅ 护理、教育偏向女性
✅ 艺术相对中性
```

### 词嵌入关联测试 (WEAT)

```
Word Embedding Association Test:
═══════════════════════════════

类似心理学的 IAT (隐式关联测试)

原理:
  测量两组目标词在两组属性词上的关联差异

示例:
────

目标词 X (职业):
  ["programmer", "engineer", "scientist"]

目标词 Y (家庭):
  ["nurse", "teacher", "homemaker"]

属性词 A (男性):
  ["man", "he", "male", "boy"]

属性词 B (女性):
  ["woman", "she", "female", "girl"]

测试:
  s(X, Y, A, B) = Σ_{x∈X} [s(x, A) - s(x, B)]
                - Σ_{y∈Y} [s(y, A) - s(y, B)]

其中:
  s(w, A) = mean_{a∈A} cosine(w, a)

如果 s(X, Y, A, B) > 0:
  → 职业词更关联男性，家庭词更关联女性

代码:
────

```python
def weat_test(embedding, vocab, X, Y, A, B):
    """
    Word Embedding Association Test

    参数:
        X, Y: 两组目标词
        A, B: 两组属性词
    """
    def association(word, attribute_set):
        """计算词和属性集的关联"""
        word_vec = embedding[vocab[word]]
        attr_vecs = [embedding[vocab[a]] for a in attribute_set if a in vocab]

        if not attr_vecs:
            return 0

        similarities = [
            np.dot(word_vec, attr_vec) /
            (np.linalg.norm(word_vec) * np.linalg.norm(attr_vec))
            for attr_vec in attr_vecs
        ]
        return np.mean(similarities)

    # 计算差异
    s_X = sum(association(x, A) - association(x, B) for x in X if x in vocab)
    s_Y = sum(association(y, A) - association(y, B) for y in Y if y in vocab)

    effect_size = s_X - s_Y

    return effect_size

# 使用
X = ["programmer", "engineer", "scientist"]
Y = ["nurse", "teacher", "homemaker"]
A = ["man", "he", "male"]
B = ["woman", "she", "female"]

bias = weat_test(embedding, vocab, X, Y, A, B)
print(f"WEAT 偏见分数: {bias:.3f}")

if bias > 0.5:
    print("检测到显著的性别偏见")
elif bias > 0.2:
    print("检测到中等的性别偏见")
else:
    print("偏见较小或不明显")
```

## 🔧 去偏方法

### 方法 1：中和 (Neutralize)

```
核心思想:
════════

对于性别中性的词（如 "doctor", "programmer"）
移除其在性别方向上的分量

步骤:
────

1. 定义性别方向
   g = (he - she) / ||he - she||
   或: g = mean(male_words) - mean(female_words)

2. 识别性别中性词
   neutral_words = ["doctor", "programmer", "scientist", ...]

3. 中和
   对每个中性词 w:
     w' = w - (w · g) · g
         └────┬────┘
          在 g 上的投影

   效果: 移除性别分量，保留其他语义

可视化:
──────

原向量:
     w (doctor)
      ↗
     / |  ← 性别分量 (偏向男性)
    /  |
   /   ↓
  ────→ 性别方向 g (he - she)

中和后:
     w' (doctor)
      ↑
      |  ← 性别分量被移除
      |
      |
  ────→ 性别方向 g

代码:
────

```python
def neutralize(embedding, vocab, gender_direction, neutral_words):
    """
    中和性别中性词

    参数:
        gender_direction: 性别方向向量
        neutral_words: 需要中和的词列表
    """
    debiased_embedding = embedding.copy()

    for word in neutral_words:
        if word not in vocab:
            continue

        idx = vocab[word]
        w = embedding[idx]

        # 在性别方向上的投影
        projection = np.dot(w, gender_direction) * gender_direction

        # 移除投影
        w_debiased = w - projection

        debiased_embedding[idx] = w_debiased

    return debiased_embedding
```

效果:
────

原始:
  similarity(doctor, man) = 0.52
  similarity(doctor, woman) = 0.21
  → 偏向男性

中和后:
  similarity(doctor, man) = 0.38
  similarity(doctor, woman) = 0.37
  → 接近中性
```

### 方法 2：均衡化 (Equalize)

```
核心思想:
════════

对于性别特定的词对（如 "he/she", "boy/girl"）
确保它们与中性词的距离相等

问题:
────

中和后，可能出现:
  distance(he, doctor) = 0.3
  distance(she, doctor) = 0.5
  → 仍然不平等

解决方案:
────────

对于词对 (w1, w2) (如 "he", "she"):
  找到它们的中点 μ
  μ = (w1 + w2) / 2

  将它们沿性别方向对称化:
  w1' = μ + c · g
  w2' = μ - c · g

  其中 c 使得 ||w1' - μ|| = ||w1 - μ||

效果:
  distance(w1', neutral) = distance(w2', neutral)

代码:
────

```python
def equalize(embedding, vocab, gender_direction, gender_pairs):
    """
    均衡化性别词对

    参数:
        gender_pairs: [(male_word, female_word), ...]
                     如 [("he", "she"), ("man", "woman")]
    """
    debiased_embedding = embedding.copy()

    for male_word, female_word in gender_pairs:
        if male_word not in vocab or female_word not in vocab:
            continue

        male_idx = vocab[male_word]
        female_idx = vocab[female_word]

        w1 = embedding[male_idx]
        w2 = embedding[female_idx]

        # 中点
        mu = (w1 + w2) / 2

        # 原始在性别方向上的距离
        original_dist = np.linalg.norm(w1 - mu)

        # 归一化性别方向
        g_norm = gender_direction / np.linalg.norm(gender_direction)

        # 对称化
        w1_debiased = mu + original_dist * g_norm
        w2_debiased = mu - original_dist * g_norm

        debiased_embedding[male_idx] = w1_debiased
        debiased_embedding[female_idx] = w2_debiased

    return debiased_embedding
```

### 完整去偏流程

```
Hard Debiasing (Bolukbasi et al., 2016):
═══════════════════════════════════════

步骤:
────

1. 识别性别方向
   通过性别词对定义
   g = mean(male_words) - mean(female_words)

2. 识别性别特定词
   definitional_pairs = [
       ("he", "she"),
       ("man", "woman"),
       ("boy", "girl"),
       ...
   ]

3. 识别性别中性词
   equalize_pairs = [
       ("actor", "actress"),
       ("hero", "heroine"),
       ...
   ]

   neutral_words = [
       "doctor", "programmer", "engineer", ...
   ]

4. 中和 (Neutralize)
   对所有中性词移除性别分量

5. 均衡化 (Equalize)
   对性别词对和职业词对均衡化

完整代码:
────────

```python
def debias_hard(embedding, vocab):
    """
    Hard Debiasing for Word Embeddings
    (Bolukbasi et al., 2016)
    """
    # 1. 定义性别方向
    gender_pairs = [
        ("he", "she"),
        ("man", "woman"),
        ("boy", "girl"),
        ("male", "female"),
        ("his", "her")
    ]

    gender_vecs = []
    for w1, w2 in gender_pairs:
        if w1 in vocab and w2 in vocab:
            v1 = embedding[vocab[w1]]
            v2 = embedding[vocab[w2]]
            gender_vecs.append(v1 - v2)

    gender_direction = np.mean(gender_vecs, axis=0)
    gender_direction /= np.linalg.norm(gender_direction)

    print(f"性别方向: {gender_direction[:5]}")

    # 2. 识别词类型
    neutral_words = [
        "doctor", "programmer", "engineer", "scientist",
        "teacher", "nurse", "writer", "artist",
        # ... 更多职业
    ]

    equalize_pairs = [
        ("actor", "actress"),
        ("hero", "heroine"),
        ("waiter", "waitress"),
        # ... 更多词对
    ]

    # 3. 中和
    print("\n中和性别中性词...")
    debiased = neutralize(embedding, vocab, gender_direction, neutral_words)

    # 4. 均衡化
    print("均衡化性别词对...")
    debiased = equalize(debiased, vocab, gender_direction, gender_pairs + equalize_pairs)

    print("去偏完成！")
    return debiased


# 使用
debiased_embedding = debias_hard(embedding, vocab)

# 验证
print("\n去偏前:")
print(f"similarity(doctor, man) = {cosine(embedding[vocab['doctor']], embedding[vocab['man']]):.3f}")
print(f"similarity(doctor, woman) = {cosine(embedding[vocab['doctor']], embedding[vocab['woman']]):.3f}")

print("\n去偏后:")
print(f"similarity(doctor, man) = {cosine(debiased_embedding[vocab['doctor']], debiased_embedding[vocab['man']]):.3f}")
print(f"similarity(doctor, woman) = {cosine(debiased_embedding[vocab['doctor']], debiased_embedding[vocab['woman']]):.3f}")
```

输出:
────

性别方向: [ 0.23 -0.18  0.31 -0.09  0.12]

中和性别中性词...
均衡化性别词对...
去偏完成！

去偏前:
similarity(doctor, man) = 0.521
similarity(doctor, woman) = 0.213

去偏后:
similarity(doctor, man) = 0.367
similarity(doctor, woman) = 0.365
```

## 📊 评估去偏效果

### 指标

```
1. 直接偏见 (Direct Bias)
═════════════════════════

定义:
  对于中性词 w，在性别方向上的投影

  bias(w) = |w · g| / ||w||

去偏目标:
  bias(w) → 0

2. 间接偏见 (Indirect Bias)
═══════════════════════════

定义:
  WEAT 分数等间接关联

3. 语义保留 (Semantic Preservation)
═══════════════════════════════════

确保去偏不破坏词的语义

测试:
  词相似度排名应基本保持
  词类比任务性能不应大幅下降

代码:
────

```python
def evaluate_debiasing(original_emb, debiased_emb, vocab, gender_direction):
    """评估去偏效果"""

    neutral_words = ["doctor", "programmer", "scientist", "teacher"]

    print("=" * 60)
    print("去偏效果评估")
    print("=" * 60)

    # 1. 直接偏见
    print("\n1. 直接偏见 (越小越好):")
    for word in neutral_words:
        if word not in vocab:
            continue

        idx = vocab[word]

        bias_orig = abs(np.dot(original_emb[idx], gender_direction))
        bias_deb = abs(np.dot(debiased_emb[idx], gender_direction))

        print(f"{word:15s}: {bias_orig:.3f} → {bias_deb:.3f} "
              f"(减少 {(bias_orig - bias_deb) / bias_orig * 100:.1f}%)")

    # 2. 性别关联对称性
    print("\n2. 与性别词的相似度:")
    for word in neutral_words:
        if word not in vocab:
            continue

        idx = vocab[word]

        # 原始
        sim_man_orig = cosine(original_emb[idx], original_emb[vocab["man"]])
        sim_woman_orig = cosine(original_emb[idx], original_emb[vocab["woman"]])

        # 去偏后
        sim_man_deb = cosine(debiased_emb[idx], debiased_emb[vocab["man"]])
        sim_woman_deb = cosine(debiased_emb[idx], debiased_emb[vocab["woman"]])

        print(f"\n{word}:")
        print(f"  原始: man={sim_man_orig:.3f}, woman={sim_woman_orig:.3f}, "
              f"差距={abs(sim_man_orig - sim_woman_orig):.3f}")
        print(f"  去偏: man={sim_man_deb:.3f}, woman={sim_woman_deb:.3f}, "
              f"差距={abs(sim_man_deb - sim_woman_deb):.3f}")

    # 3. 语义保留
    print("\n3. 语义保留 (相似词应保持):")
    test_word = "doctor"
    if test_word in vocab:
        # 原始的最相似词
        similar_orig = most_similar(original_emb, vocab, test_word, top_k=5)
        similar_deb = most_similar(debiased_emb, vocab, test_word, top_k=5)

        print(f"\n'{test_word}' 的最相似词:")
        print("原始:", [w for w, _ in similar_orig])
        print("去偏:", [w for w, _ in similar_deb])

        # 重叠度
        overlap = len(set([w for w, _ in similar_orig]) &
                      set([w for w, _ in similar_deb]))
        print(f"重叠: {overlap}/5")

def cosine(v1, v2):
    return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
```

## 💡 局限性与挑战

### 当前方法的问题

```
1. 定义性问题
═════════════

挑战:
  什么是"性别中性"？
  "doctor" 应该是中性的吗？

示例:
  "pregnancy" 与女性强相关
  但这是生理事实，不是偏见

如何区分:
  合理关联 vs 刻板偏见？

2. 多维偏见
═══════════

性别只是一个维度！

其他偏见:
  - 种族
  - 年龄
  - 宗教
  - 性取向
  - 社会经济地位

挑战:
  这些维度可能相互交织
  难以单独处理

3. 后续任务影响
═══════════════

去偏后:
  ✅ 偏见减少
  ⚠️ 性能可能下降

示例:
  情感分类准确率: 88% → 85%

权衡:
  公平性 vs 性能

4. 新的偏见
═══════════

去偏可能引入新偏见！

示例:
  过度中和可能抹杀真实差异
  均衡化可能扭曲语义

5. 语料问题
═══════════

根本问题:
  偏见来自训练语料
  去偏只是"打补丁"

长期方案:
  ✅ 更平衡的训练数据
  ✅ 多样化的数据源
  ✅ 有意识的数据策展
```

### 最佳实践

```
去偏建议:
════════

1. 评估为先 ⚠️
   先检测偏见，再决定是否去偏
   不要盲目去偏

2. 领域相关 🎯
   不同领域的偏见不同
   需要定制化方案

3. 多维考虑 🌐
   不只是性别
   考虑种族、年龄等

4. 保留语义 📚
   去偏不应破坏词的核心语义
   持续监控性能

5. 透明化 📢
   明确告知用户使用了去偏词向量
   说明可能的影响

6. 持续更新 🔄
   随着社会进步，偏见定义会变化
   需要定期重新评估

实践流程:
────────

① 检测偏见 → 量化偏见程度
② 识别偏见类型 → 性别/种族/年龄等
③ 选择去偏方法 → Hard/Soft Debiasing
④ 应用去偏 → 生成去偏词向量
⑤ 评估效果 → 偏见 ↓, 语义保留?
⑥ 下游验证 → 实际任务性能?
⑦ 持续监控 → 是否有新偏见?
```
