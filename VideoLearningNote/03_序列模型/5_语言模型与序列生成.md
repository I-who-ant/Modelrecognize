## 📌 基本定义

**语言模型（Language Model）** 是一个概率模型，用于：

- ✅ 计算**句子的概率** P(sentence)
- ✅ 预测**下一个词的概率** P(w_t | w_1, w_2, ..., w_{t-1})
- ✅ **生成新的文本序列**（采样）
- ✅ 评估文本的**流畅性和合理性**

### 核心思想

```
语言模型的本质:
学习语言的统计规律，预测下一个元素

输入: "我 爱"
语言模型: P("编程" | "我 爱") = 0.3
         P("你" | "我 爱") = 0.25
         P("学习" | "我 爱") = 0.2
         ...

目标:
让合理的句子概率高
让不合理的句子概率低
```

```
应用场景 1: 机器翻译

           → "我爱人工智慧" ✅
           → "AI爱我" ❌ (语法不通)

需求: 判断哪个翻译更流畅

给定开头: "深度学习是"

声音 → "识别" 还是 "石别"?

需求: 在多个候选中选择最合理的
解决: 语言模型判断哪个词更可能

应用场景 4: 拼写纠错
"我喜欢吃苹果" ✅
"我喜欢吃苹果" (拼音输入错误)

需求: 自动纠正
解决: 语言模型判断合理性
```

## 📚 语言模型的数学定义

### 1️⃣ **句子概率**

```
给定句子: w_1, w_2, w_3, ..., w_T

句子的概率（链式法则）:
P(w_1, w_2, ..., w_T) = P(w_1) · P(w_2|w_1) · P(w_3|w_1,w_2) · ... · P(w_T|w_1,...,w_{T-1})

简写:
P(sentence) = ∏_{t=1}^{T} P(w_t | w_1, ..., w_{t-1})

示例:
句子: "我 爱 编程"
P("我 爱 编程") = P("我") · P("爱"|"我") · P("编程"|"我","爱")
                ≈ 0.05 · 0.3 · 0.4
                = 0.006
```

---

### 2️⃣ **条件概率（下一个词）**

```
语言模型的核心任务:
给定历史 h = (w_1, w_2, ..., w_{t-1})
预测下一个词 w_t 的概率分布

P(w_t | w_1, w_2, ..., w_{t-1})

RNN 语言模型:
h^<t-1> ← RNN(w_1, w_2, ..., w_{t-1})  # 编码历史
ŷ^<t> = softmax(W_hy · h^<t-1> + b_y)  # 预测下一个词的概率分布
P(w_t = k | history) = ŷ^<t>[k]        # 第 k 个词的概率
```

## 🔄 RNN 语言模型架构

### 字符级语言模型（Character-Level）

```
结构:
       t=1     t=2     t=3     t=4     t=5
输入:   h       e       l       l       o
        ↓       ↓       ↓       ↓       ↓
       [RNN]→[RNN]→[RNN]→[RNN]→[RNN]
        ↓       ↓       ↓       ↓       ↓
预测:   e       l       l       o      <EOS>

训练目标:
给定 "h"     → 预测 "e"
给定 "h,e"   → 预测 "l"
给定 "h,e,l" → 预测 "l"
...

损失函数:
L = -Σ_{t=1}^{T} log P(y_true^<t> | x^<1>, ..., x^<t>)
  = -Σ_{t=1}^{T} log ŷ^<t>[y_true^<t>]

优点:
✅ 词表小（26个字母 + 标点）
✅ 可以处理任意新词
✅ 模型简单

缺点:
❌ 序列长（每个字符一步）
❌ 长期依赖困难
❌ 计算量大
```

---

### 词级语言模型（Word-Level）

```
结构:
       t=1     t=2      t=3      t=4
输入:   我      爱       人工     智能
        ↓       ↓        ↓        ↓
       [RNN]→[RNN]→ [RNN]→  [RNN]
        ↓       ↓        ↓        ↓
预测:   爱      人工     智能    <EOS>

训练目标:
给定 "我"          → 预测 "爱"
给定 "我,爱"       → 预测 "人工"
给定 "我,爱,人工"  → 预测 "智能"

输入表示:
词 → One-hot 向量 [vocab_size, 1]
或: 词 → 词嵌入向量 [embedding_dim, 1]  ← 更常用

优点:
✅ 序列短（每个词一步）
✅ 语义信息丰富
✅ 训练效率高

缺点:
❌ 词表大（10000-100000）
❌ OOV 问题（Out-of-Vocabulary）
❌ 需要分词
```

## 🧮 完整代码实现

### 字符级语言模型

```python
import numpy as np

class CharRNNLanguageModel:
    """
    字符级 RNN 语言模型
    """
    def __init__(self, vocab_size, hidden_size, learning_rate=0.01):
        """
        参数:
            vocab_size: 字符集大小（如 26 + 标点）
            hidden_size: 隐藏层维度
            learning_rate: 学习率
        """
        self.vocab_size = vocab_size
        self.hidden_size = hidden_size
        self.lr = learning_rate

        # 初始化参数
        self.W_hh = np.random.randn(hidden_size, hidden_size) * 0.01
        self.W_xh = np.random.randn(hidden_size, vocab_size) * 0.01
        self.W_hy = np.random.randn(vocab_size, hidden_size) * 0.01
        self.b_h = np.zeros((hidden_size, 1))
        self.b_y = np.zeros((vocab_size, 1))

    def forward(self, inputs, targets):
        """
        前向传播

        参数:
            inputs: 输入字符序列（索引列表）
            targets: 目标字符序列（索引列表）

        返回:
            loss: 交叉熵损失
            cache: 缓存（用于反向传播）
        """
        h = np.zeros((self.hidden_size, 1))  # 初始隐藏状态
        cache = {'h': [h], 'x': [], 'y': [], 'p': []}
        loss = 0

        for t in range(len(inputs)):
            # 输入字符的 one-hot 编码
            x = np.zeros((self.vocab_size, 1))
            x[inputs[t]] = 1

            # RNN 计算
            h = np.tanh(
                np.dot(self.W_hh, h) +
                np.dot(self.W_xh, x) +
                self.b_h
            )

            # 输出层
            y = np.dot(self.W_hy, h) + self.b_y
            p = self.softmax(y)  # 概率分布

            # 计算损失（交叉熵）
            loss += -np.log(p[targets[t], 0] + 1e-8)

            # 缓存
            cache['h'].append(h.copy())
            cache['x'].append(x)
            cache['y'].append(y)
            cache['p'].append(p)

        return loss, cache

    def sample(self, seed_char, length=100):
        """
        生成文本序列

        参数:
            seed_char: 起始字符索引
            length: 生成长度

        返回:
            generated: 生成的字符索引列表
        """
        h = np.zeros((self.hidden_size, 1))
        x = np.zeros((self.vocab_size, 1))
        x[seed_char] = 1

        generated = [seed_char]

        for _ in range(length):
            # RNN 前向传播
            h = np.tanh(
                np.dot(self.W_hh, h) +
                np.dot(self.W_xh, x) +
                self.b_h
            )

            # 预测下一个字符
            y = np.dot(self.W_hy, h) + self.b_y
            p = self.softmax(y)

            # 采样（从概率分布中抽取）
            char_idx = np.random.choice(range(self.vocab_size), p=p.ravel())

            # 更新输入
            x = np.zeros((self.vocab_size, 1))
            x[char_idx] = 1

            generated.append(char_idx)

        return generated

    @staticmethod
    def softmax(x):
        """Softmax 激活函数"""
        exp_x = np.exp(x - np.max(x))
        return exp_x / np.sum(exp_x)


# 使用示例
if __name__ == "__main__":
    # 构建字符集
    text = "hello world"
    chars = list(set(text))
    char_to_idx = {ch: i for i, ch in enumerate(chars)}
    idx_to_char = {i: ch for i, ch in enumerate(chars)}
    vocab_size = len(chars)

    # 准备训练数据
    inputs = [char_to_idx[ch] for ch in text[:-1]]  # "hello worl"
    targets = [char_to_idx[ch] for ch in text[1:]]  # "ello world"

    # 创建模型
    model = CharRNNLanguageModel(vocab_size, hidden_size=50)

    # 训练
    for epoch in range(100):
        loss, cache = model.forward(inputs, targets)
        if epoch % 10 == 0:
            print(f"Epoch {epoch}, Loss: {loss:.4f}")

    # 生成文本
    seed = char_to_idx['h']
    generated_idx = model.sample(seed, length=20)
    generated_text = ''.join([idx_to_char[i] for i in generated_idx])
    print(f"\n生成的文本: {generated_text}")
```

### 词级语言模型（带词嵌入）

```python
class WordRNNLanguageModel:
    """
    词级 RNN 语言模型（使用词嵌入）
    """
    def __init__(self, vocab_size, embedding_dim, hidden_size, learning_rate=0.01):
        """
        参数:
            vocab_size: 词表大小
            embedding_dim: 词嵌入维度
            hidden_size: 隐藏层维度
        """
        self.vocab_size = vocab_size
        self.embedding_dim = embedding_dim
        self.hidden_size = hidden_size
        self.lr = learning_rate

        # 词嵌入矩阵
        self.W_embed = np.random.randn(embedding_dim, vocab_size) * 0.01

        # RNN 参数
        self.W_hh = np.random.randn(hidden_size, hidden_size) * 0.01
        self.W_xh = np.random.randn(hidden_size, embedding_dim) * 0.01
        self.W_hy = np.random.randn(vocab_size, hidden_size) * 0.01
        self.b_h = np.zeros((hidden_size, 1))
        self.b_y = np.zeros((vocab_size, 1))

    def embed(self, word_idx):
        """
        词嵌入查找

        参数:
            word_idx: 词索引

        返回:
            embedding: 词嵌入向量 [embedding_dim, 1]
        """
        return self.W_embed[:, word_idx:word_idx+1]

    def forward(self, word_indices, targets):
        """
        前向传播

        参数:
            word_indices: 输入词序列（索引列表）
            targets: 目标词序列（索引列表）

        返回:
            loss: 交叉熵损失
        """
        h = np.zeros((self.hidden_size, 1))
        loss = 0

        for t in range(len(word_indices)):
            # 词嵌入
            x = self.embed(word_indices[t])

            # RNN 计算
            h = np.tanh(
                np.dot(self.W_hh, h) +
                np.dot(self.W_xh, x) +
                self.b_h
            )

            # 输出层
            y = np.dot(self.W_hy, h) + self.b_y
            p = self.softmax(y)

            # 损失
            loss += -np.log(p[targets[t], 0] + 1e-8)

        return loss

    def predict_next_word(self, word_sequence):
        """
        预测下一个词的概率分布

        参数:
            word_sequence: 输入词序列（索引列表）

        返回:
            probs: 下一个词的概率分布 [vocab_size]
        """
        h = np.zeros((self.hidden_size, 1))

        # 处理输入序列
        for word_idx in word_sequence:
            x = self.embed(word_idx)
            h = np.tanh(
                np.dot(self.W_hh, h) +
                np.dot(self.W_xh, x) +
                self.b_h
            )

        # 预测下一个词
        y = np.dot(self.W_hy, h) + self.b_y
        probs = self.softmax(y)

        return probs.ravel()

    @staticmethod
    def softmax(x):
        exp_x = np.exp(x - np.max(x))
        return exp_x / np.sum(exp_x)


# 使用示例
if __name__ == "__main__":
    # 词表
    vocab = ["<PAD>", "我", "爱", "编程", "学习", "深度", "机器", "人工智能"]
    word_to_idx = {w: i for i, w in enumerate(vocab)}
    vocab_size = len(vocab)

    # 训练数据: "我 爱 编程" → 预测 "爱 编程 <PAD>"
    inputs = [word_to_idx["我"], word_to_idx["爱"], word_to_idx["编程"]]
    targets = [word_to_idx["爱"], word_to_idx["编程"], word_to_idx["<PAD>"]]

    # 创建模型
    model = WordRNNLanguageModel(
        vocab_size=vocab_size,
        embedding_dim=50,
        hidden_size=100
    )

    # 训练
    for epoch in range(100):
        loss = model.forward(inputs, targets)
        if epoch % 10 == 0:
            print(f"Epoch {epoch}, Loss: {loss:.4f}")

    # 预测下一个词
    sequence = [word_to_idx["我"], word_to_idx["爱"]]
    probs = model.predict_next_word(sequence)
    next_word_idx = np.argmax(probs)
    print(f"\n给定 '我 爱', 预测下一个词: {vocab[next_word_idx]}")
```

## 🎲 序列生成策略

### 1️⃣ **贪婪采样（Greedy Sampling）**

```
策略: 每次选择概率最高的词

伪代码:
def greedy_sample(model, seed, max_length):
    sequence = [seed]
    h = model.init_hidden()

    for _ in range(max_length):
        probs = model.predict(sequence, h)
        next_word = argmax(probs)  # 选最高概率
        sequence.append(next_word)
        h = model.update_hidden(h, next_word)

        if next_word == <EOS>:
            break

    return sequence

示例:
输入: "我 爱"
P("编程"|"我 爱") = 0.4  ← 最高
P("你"|"我 爱") = 0.3
P("学习"|"我 爱") = 0.2

选择: "编程"
结果: "我 爱 编程"

优点:
✅ 简单高效
✅ 确定性输出（可复现）

缺点:
❌ 容易陷入重复
❌ 缺乏多样性
❌ 不一定是最优序列（局部最优）

例子:
"我 爱 编程 编程 编程 编程 ..."  ← 重复!
```

### 2️⃣ **随机采样（Random Sampling）**

```
策略: 从概率分布中随机抽取

伪代码:
def random_sample(model, seed, max_length):
    sequence = [seed]
    h = model.init_hidden()

    for _ in range(max_length):
        probs = model.predict(sequence, h)
        next_word = np.random.choice(vocab, p=probs)  # 随机抽取
        sequence.append(next_word)
        h = model.update_hidden(h, next_word)

        if next_word == <EOS>:
            break

    return sequence

示例:
输入: "我 爱"
P("编程"|"我 爱") = 0.4
P("你"|"我 爱") = 0.3
P("学习"|"我 爱") = 0.2

随机抽取:
第1次: "编程" (40% 概率)
第2次: "你" (30% 概率)
第3次: "学习" (20% 概率)

优点:
✅ 多样性好
✅ 可以探索低概率路径
✅ 不容易重复

缺点:
❌ 可能生成不合理的序列
❌ 质量不稳定
❌ 低概率词也可能被选中

例子:
"我 爱 西瓜 但是 猫 ..."  ← 可能不连贯
```

### 3️⃣ **温度采样（Temperature Sampling）**

```
策略: 通过温度参数 τ 调整概率分布的"尖锐度"

公式:
P_τ(w_i) = exp(y_i / τ) / Σ_j exp(y_j / τ)

其中:
- y_i: 第 i 个词的 logits（未归一化的分数）
- τ: 温度参数

τ = 1.0: 标准 softmax（原始分布）
τ → 0:   分布更尖锐（接近 argmax）
τ → ∞:   分布更平坦（接近均匀分布）

代码实现:
def temperature_sample(model, seed, max_length, temperature=1.0):
    sequence = [seed]
    h = model.init_hidden()

    for _ in range(max_length):
        logits = model.get_logits(sequence, h)  # 未归一化的分数

        # 温度调整
        scaled_logits = logits / temperature
        probs = softmax(scaled_logits)

        next_word = np.random.choice(vocab, p=probs)
        sequence.append(next_word)
        h = model.update_hidden(h, next_word)

        if next_word == <EOS>:
            break

    return sequence

示例:
原始 logits: [2.0, 1.5, 1.0]
原始概率 (τ=1.0): [0.506, 0.307, 0.186]

低温 τ=0.5:
调整后 logits: [4.0, 3.0, 2.0]
概率: [0.705, 0.236, 0.060]  ← 更尖锐（偏向高概率词）

高温 τ=2.0:
调整后 logits: [1.0, 0.75, 0.5]
概率: [0.422, 0.327, 0.251]  ← 更平坦（更随机）

使用建议:
τ = 0.5-0.7: 生成更保守、更连贯的文本
τ = 1.0:     标准采样
τ = 1.5-2.0: 生成更有创意、更多样的文本

优点:
✅ 可控的多样性
✅ 平衡质量和创造性
✅ 广泛应用于文本生成

缺点:
❌ 需要调整超参数 τ
```

### 4️⃣ **束搜索（Beam Search）**

```
策略: 在每步保留 k 个最优候选，最后选择总概率最高的序列

思想:
不是每步只选一个词，而是保留 k 个最佳路径
最后从 k 个完整序列中选择概率最高的

伪代码:
def beam_search(model, seed, max_length, beam_width=3):
    # 初始化: [(sequence, log_prob)]
    beams = [([seed], 0.0)]

    for _ in range(max_length):
        candidates = []

        # 对每个 beam 扩展
        for seq, log_prob in beams:
            if seq[-1] == <EOS>:
                candidates.append((seq, log_prob))
                continue

            # 预测下一个词的概率
            probs = model.predict(seq)

            # 扩展 top-k 个词
            top_k_indices = np.argsort(probs)[-beam_width:]

            for word_idx in top_k_indices:
                new_seq = seq + [word_idx]
                new_log_prob = log_prob + np.log(probs[word_idx])
                candidates.append((new_seq, new_log_prob))

        # 保留概率最高的 k 个候选
        beams = sorted(candidates, key=lambda x: x[1], reverse=True)[:beam_width]

        # 所有 beam 都结束
        if all(seq[-1] == <EOS> for seq, _ in beams):
            break

    # 返回概率最高的序列
    best_seq, best_prob = beams[0]
    return best_seq

示例（beam_width=2）:
步骤 1: "我"
  扩展: "我 爱" (log_prob=-0.5), "我 是" (log_prob=-0.7)
  保留 top-2: ["我 爱", "我 是"]

步骤 2: 从 "我 爱" 扩展
  "我 爱 编程" (log_prob=-0.5-0.3=-0.8)
  "我 爱 学习" (log_prob=-0.5-0.4=-0.9)
        从 "我 是" 扩展
  "我 是 学生" (log_prob=-0.7-0.2=-0.9)
  "我 是 老师" (log_prob=-0.7-0.5=-1.2)

  保留 top-2: ["我 爱 编程" (-0.8), "我 爱 学习" (-0.9)]

最终: "我 爱 编程"

优点:
✅ 考虑全局最优
✅ 质量高于贪婪搜索
✅ 广泛用于机器翻译

缺点:
❌ 计算量大（O(beam_width × vocab_size)）
❌ 仍可能陷入重复
❌ 缺乏多样性
```

### 采样策略对比

| 策略 | 质量 | 多样性 | 计算量 | 适用场景 |
|------|------|--------|--------|----------|
| **贪婪采样** | 中 | 低 | 低 | 快速原型、确定性输出 |
| **随机采样** | 低-中 | 高 | 低 | 创意生成、头脑风暴 |
| **温度采样** | 中-高 | 可调 | 低 | 文本生成、对话系统 |
| **束搜索** | 高 | 低 | 高 | 机器翻译、摘要生成 |

## 📊 语言模型评估：困惑度（Perplexity）

### 定义

```
困惑度（Perplexity, PPL）:
衡量语言模型预测能力的指标

公式:
PPL = exp(L)
    = exp(-1/T * Σ_{t=1}^{T} log P(w_t | w_1, ..., w_{t-1}))
    = [∏_{t=1}^{T} P(w_t | w_1, ..., w_{t-1})]^{-1/T}

其中:
- T: 序列长度
- L: 平均负对数似然（损失）

直观理解:
困惑度 = 模型在每步"困惑"的程度
       = 平均有多少个等可能的选择

示例:
假设每个位置都是均匀分布（词表 10000 个词）
P(每个词) = 1/10000
PPL = 10000  ← 非常困惑！

好的模型:
P(正确词) ≈ 1
PPL ≈ 1  ← 不困惑
```

---

### 计算示例

```python
def calculate_perplexity(model, test_data):
    """
    计算困惑度

    参数:
        model: 训练好的语言模型
        test_data: 测试数据 [(inputs, targets), ...]

    返回:
        perplexity: 困惑度
    """
    total_loss = 0
    total_length = 0

    for inputs, targets in test_data:
        loss, _ = model.forward(inputs, targets)
        total_loss += loss
        total_length += len(targets)

    # 平均负对数似然
    avg_loss = total_loss / total_length

    # 困惑度
    perplexity = np.exp(avg_loss)

    return perplexity

# 使用示例
test_data = [
    ([char_to_idx[c] for c in "hello worl"],
     [char_to_idx[c] for c in "ello world"])
]

ppl = calculate_perplexity(model, test_data)
print(f"困惑度: {ppl:.2f}")
```

---

### 困惑度的解释

```
PPL 范围与解释:

PPL = 1:
完美模型（每次都100%确定）
实际不可能达到

PPL = 10-50:
非常好的模型
字符级语言模型的水平

PPL = 50-100:
好的模型
词级语言模型的水平

PPL = 100-200:
可接受的模型

PPL > 200:
较差的模型
需要改进

比较:
模型 A: PPL = 50
模型 B: PPL = 100
→ 模型 A 更好（困惑度更低）

注意:
✅ PPL 越低越好
✅ 不同数据集的 PPL 不可直接比较
✅ 需要在相同测试集上比较
```

```python
def generate_text(model, seed_text, length=100, temperature=1.0):
    """
    生成连续文本

    参数:
        model: 训练好的语言模型
        seed_text: 起始文本
        length: 生成长度
        temperature: 温度参数

        generated_text: 生成的文本

    # 编码种子文本
    seed_indices = [char_to_idx[c] for c in seed_text]

    # 生成
    generated = model.sample_with_temperature(
        seed_indices,
        length=length,
        temperature=temperature
    )

    # 解码
    generated_text = ''.join([idx_to_char[i] for i in generated])

    return generated_text

# 示例

    model,
    seed_text="Deep learning is",
    length=200,
    temperature=0.8
)

# 输出: "Deep learning is a method of machine learning that..."
```

### 2. **自动补全**

```python
def autocomplete(model, prefix, top_k=5):
    """
    给定前缀，预测最可能的下一个词

    参数:
        model: 词级语言模型
        prefix: 前缀词列表
        top_k: 返回前 k 个候选

    返回:
        candidates: [(word, probability), ...]
    """
    # 预测下一个词的概率分布
    probs = model.predict_next_word(prefix)

    # 获取 top-k
    top_indices = np.argsort(probs)[-top_k:][::-1]
    candidates = [(idx_to_word[i], probs[i]) for i in top_indices]

    return candidates

# 示例
prefix = ["我", "爱"]
suggestions = autocomplete(model, prefix, top_k=5)
print("补全建议:")
for word, prob in suggestions:
    print(f"  {word}: {prob:.3f}")
# 输出:
#   编程: 0.350
#   学习: 0.280
#   你: 0.150
#   ...
```

### 3. **句子评分**

```python
def score_sentence(model, sentence):
    """
    评估句子的流畅性（概率）

    参数:
        model: 语言模型
        sentence: 句子（词列表）

    返回:
        log_prob: 对数概率
        perplexity: 困惑度
    """
    log_prob = 0
    h = model.init_hidden()

    for i in range(len(sentence) - 1):
        word = sentence[i]
        next_word = sentence[i + 1]

        probs = model.predict_next_word([word], h)
        log_prob += np.log(probs[next_word] + 1e-8)
        h = model.update_hidden(h, word)

    perplexity = np.exp(-log_prob / (len(sentence) - 1))

    return log_prob, perplexity

# 示例
sentence1 = ["我", "爱", "编程"]  # 流畅
sentence2 = ["我", "猫", "桌子"]  # 不流畅

log_prob1, ppl1 = score_sentence(model, sentence1)
log_prob2, ppl2 = score_sentence(model, sentence2)

print(f"句子1: log_prob={log_prob1:.2f}, PPL={ppl1:.2f}")
print(f"句子2: log_prob={log_prob2:.2f}, PPL={ppl2:.2f}")
# 输出:
#   句子1: log_prob=-1.50, PPL=12.5  ← 更流畅
#   句子2: log_prob=-4.80, PPL=121.0  ← 不流畅
```

### 语言模型的本质

```
1. 概率建模
   ✅ P(sentence) = ∏ P(w_t | history)
   ✅ 学习语言的统计规律

2. 序列预测
   ✅ 给定历史，预测下一个词
   ✅ 逐步生成完整序列

3. 评估与生成
   ✅ 评估: 困惑度（PPL）
   ✅ 生成: 多种采样策略
```

### RNN 语言模型架构

```
字符级:
- 词表小（26 + 标点）
- 序列长
- 适合小数据集

词级:
- 词表大（10K-100K）
- 序列短
- 需要词嵌入
- 工业界主流
```

```

- 随机采样: 低质量，高多样性
- 温度采样: 可调平衡 ⭐⭐⭐

实时性 vs 准确性:
- 贪婪/随机: 快速
```
