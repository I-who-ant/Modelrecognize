## 基本定义

**现代大模型** 指基于 Transformer Decoder-only 架构，经过特殊优化和扩展的大规模语言模型。

**核心特点**:
- 基于 Transformer 但深度优化
- 数千亿参数规模
- 支持长上下文 (8K-128K+)
- 面向生产环境的高效推理

## 核心架构对比

### 1. GPT 系列 (OpenAI)

#### GPT-3/4 架构

```
GPT 系列架构:
┌─────────────────────────────────────────┐
│ 总参数: ~175B (GPT-3) → ~1T (GPT-4)     │
│ 架构: Transformer Decoder-only          │
│ 层数: 96 层 (GPT-3)                     │
│ 注意力: Multi-Head Attention            │
│ 位置编码: Learned PE (GPT-3) → RoPE (GPT-4) │
│ 激活: GELU                              │
│ 归一化: Layer Norm (Post-LN)            │
│ 训练: 自回归语言建模 + RLHF             │
└─────────────────────────────────────────┘

优势:
✅ 强大的语言生成能力
✅ 优秀的 In-context Learning
✅ 强推理能力 (GPT-4)
✅ 丰富的 emergent abilities

劣势:
❌ 闭源，细节不公开
❌ 推理成本高
❌ KV Cache 占用大
❌ 长上下文效率低
```

## 关键技术创新对比

### 1. 注意力机制

```
注意力优化演进:
┌─────────────────────────────────────────┐
│ MHA (原始):                             │
│ ├─ 并行学习多种模式                     │
│ └─ 内存占用大                           │
│                                        │
│ MQA (2021):                            │
│ ├─ 所有 head 共享 K, V                  │
│ └─ 内存减少 3-5 倍                      │
│                                        │
│ GQA (2023):                            │
│ ├─ 部分 head 共享                       │
│ └─ 内存减少 2-3 倍                      │
│                                        │
│ MLA (2024) ✅                          │
│ ├─ Latent space 压缩                    │
│ └─ 内存减少 10 倍 + 性能保持 ✅          │
└─────────────────────────────────────────┘
```

### 2. 位置编码

```
位置编码选择对比:
┌─────────────────────────────────────────┐
│ Sinusoidal (Transformer 原始):         │
│ ├─ 优点: 可外推                         │
│ └─ 缺点: 相对位置信息弱                 │
│                                        │
│ Learned (BERT):                        │
│ ├─ 优点: 灵活                           │
│ └─ 缺点: 无法外推                       │
│                                        │
│ RoPE (LLaMA, DeepSeek-V3) ✅           │
│ ├─ 优点: ✅ 相对位置效果                │
│ │         ✅ 可外推                     │
│ │         ✅ 计算高效                   │
│ │         ✅ 线性组合                   │
│ └─ 选择: 2024 年主流 ✅                 │
└─────────────────────────────────────────┘
```

### 3. 前馈网络

``` 
FFN 架构演进:
┌─────────────────────────────────────────┐
│ FFN(x) = activation(xW₁ + b₁)W₂ + b₂    │
│                                        │
│ 1. ReLU/GELU (早期):                   │
│    ├─ 简单有效                         │
│    └─ 性能一般                         │
│                                        │
│ 2. SwiGLU (LLaMA, DeepSeek-V3) ✅      │
│    ├─ 门控线性单元                      │
│    ├─ 性能优于 ReLU/GELU               │
│    └─ FFN(x) = (xW₁ ⊙ swish(xW₂))W₃   │
│                                        │
│ 3. MoE (DeepSeek-V3) ✅                │
│    ├─ 混合专家                         │
│    ├─ 稀疏激活                         │
│    └─ 参数效率最大化                   │
└─────────────────────────────────────────┘
```
