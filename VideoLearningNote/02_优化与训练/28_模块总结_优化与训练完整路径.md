### 🛡️ **第二阶段：解决过拟合（对症下药）**

#### 核心问题
> "诊断出高方差（过拟合），有哪些解决方法？"

#### 学习路径

**1. 正则化 (3_正则化.md)**
```
目的: 限制模型复杂度，防止过拟合

原理: 在损失函数中加入惩罚项
  L = 原始损失 + λ·正则项

两种正则化:
  L2 正则化 (权重衰减): λ·Σw²
    └─ 让权重变小，模型更平滑

  L1 正则化 (稀疏性): λ·Σ|w|
    └─ 让部分权重为0，特征选择
```

**2. 正则化缓解过拟合机理 (4_正则化缓解过拟合机理.md)**
```
目的: 深入理解为什么正则化有效

三个视角:
1. 数学视角: 约束优化问题
2. 贝叶斯视角: 权重的先验分布
3. 直观理解:
   └─ 小权重 → 激活函数近似线性 → 模型简化
```

**3. Dropout 正则化 (5_Dropout正则化.md)**
```
目的: 随机丢弃神经元，防止过拟合

工作原理:
训练时: 每个神经元以概率 p 被随机丢弃
测试时: 保留所有神经元，权重乘以 (1-p)

代码:
  train: a = dropout(a, keep_prob=0.8)
  test:  a = a * keep_prob
```

**4. 理解 Dropout (6_理解Dropout.md)**
```
目的: 深入理解 Dropout 的数学原理

为什么有效？
1. 集成学习: 训练多个子网络的平均
2. 打破神经元共适应: 强制学习鲁棒特征
3. 添加噪声: 类似数据增强

数学证明:
  E[Dropout(a)] = a · keep_prob
```

**5. 其他正则化方法 (7_其他正则化方法.md)**
```
目的: 扩展正则化工具箱

其他方法:
├─ 数据增强 (Data Augmentation)
│  └─ 图像: 翻转、旋转、裁剪
├─ Early Stopping
│  └─ 验证误差不再下降时停止
└─ Label Smoothing
   └─ 软化目标标签
```

```
✅ 学会了: 5种正则化方法

✅ 建立了: 防止过拟合的工具箱
```

### ⚡ **第三阶段：优化训练过程（加速与稳定）**

#### 核心问题
> "训练太慢、梯度不稳定，如何优化？"

#### 学习路径

**1. 输入归一化 (8_输入归一化.md)**
```
目的: 让输入特征在相同尺度，加速收敛

原理:
  x_norm = (x - μ) / σ

效果:
  归一化前: 损失函数等高线是椭圆 → 收敛慢
  归一化后: 损失函数等高线是圆形 → 收敛快

类比:
  不归一化 = 走山路 (曲折)
  归一化   = 走平路 (直达)
```

**2. 梯度消失与爆炸 (9_梯度消失与爆炸.md)**
```
目的: 识别深度网络的梯度问题

问题:
  梯度消失: 反向传播时梯度越来越小 (Sigmoid/Tanh)
  梯度爆炸: 反向传播时梯度越来越大

原因:
  深度网络中梯度的连乘效应
  ∂L/∂W1 = ∂L/∂Wn · ∏(∂Wᵢ₊₁/∂Wᵢ)

  如果每层 < 1 → 消失
  如果每层 > 1 → 爆炸
```

**3. 深度网络权重初始化 (10_深度网络权重初始化.md)**
```
目的: 用正确的初始化解决梯度问题

初始化策略:
  Xavier (Glorot):  W ~ N(0, 1/n_in)
    └─ 适合 Sigmoid/Tanh

  He 初始化:        W ~ N(0, 2/n_in)
    └─ 适合 ReLU/Leaky ReLU

原理: 保持方差在前向和反向传播中稳定
```

**4. 梯度数值逼近 (11_梯度数值逼近.md)**
```
目的: 理解如何数值计算梯度

双边差分公式:
  f'(θ) ≈ [f(θ+ε) - f(θ-ε)] / (2ε)

精度: O(ε²) (比单边差分 O(ε) 更准确)

用途: 梯度检验的基础
```

**5. 梯度检验 (12_梯度检验.md + 12.1 + 12.2)**
```
目的: 验证反向传播实现是否正确

步骤:
1. 计算数值梯度 (双边差分)
2. 计算解析梯度 (反向传播)
3. 比较两者差异:
   difference = ||grad_num - grad_bp|| / (||grad_num|| + ||grad_bp||)

判断标准:
  < 10⁻⁷: 完美 ✅
  < 10⁻⁵: 可以 ⚠️
  > 10⁻³: 错误 ❌

注意事项:
  ✓ 只在调试时使用 (太慢)
  ✓ 关闭 Dropout 和正则化
  ✓ 用小数据集测试
```

**6. 梯度检验实现要点 (13_梯度检验实现要点.md)**
```
目的: 正确使用梯度检验

最佳实践:
1. 只在开发阶段使用
2. 检验通过后删除代码
3. 不能与 Dropout 同时使用
4. 检查所有参数（W、b）
5. 使用双边差分（更准确）
```

### 🚀 **第四阶段：改进梯度下降（从SGD到Adam）**

#### 核心问题
> "普通梯度下降太慢，如何更快更好地优化？"

#### 学习路径

**1. 小批量梯度下降 (14_小批量梯度下降.md)**
```
目的: 平衡计算效率和梯度准确性

三种梯度下降:
  批量梯度下降:   使用全部数据 (m个样本)
    └─ 慢但准确

  随机梯度下降:   每次1个样本
    └─ 快但噪声大

  小批量梯度下降: 每次64/128/256个样本 ⭐
    └─ 速度和准确性的平衡

批量大小选择:
  2的幂次: 64, 128, 256, 512
  原因: GPU优化友好
```

**2. 理解小批量梯度下降 (15_理解小批量梯度下降.md)**
```
目的: 深入理解批量大小的影响

批量大小对比:
  小批量 (32):
    ✓ 梯度噪声大 → 正则化效果
    ✓ 更新频繁 → 收敛快
    ✗ 不稳定

  大批量 (512):
    ✓ 梯度准确 → 稳定
    ✓ GPU利用率高
    ✗ 泛化能力可能差

最佳实践: 64-256之间
```

**3. 指数加权平均 (16_指数加权平均.md)**
```
目的: 平滑噪声序列的数学工具

公式:
  v_t = β·v_{t-1} + (1-β)·θ_t

直观理解:
  β=0.9 → 平均最近 10 个值
  β=0.99 → 平均最近 100 个值

特点:
  ✓ 内存高效 (只需存 v_t)
  ✓ 计算简单
  ✓ 适合在线更新
```

**4. 理解指数加权平均 (17_理解指数加权平均.md)**
```
目的: 深入理解 EWA 的数学原理

数学推导:
  v_t = (1-β)·Σ[β^i·θ_{t-i}]

权重衰减:
  当前值:   权重 = (1-β)
  1步前:    权重 = (1-β)·β
  2步前:    权重 = (1-β)·β²
  ...

有效窗口: 约 1/(1-β) 个值
```

**5. 指数加权平均偏差修正 (18_指数加权平均偏差修正.md)**
```
目的: 修正初始阶段的偏差

问题: 初始时 v_0 = 0 导致偏差

修正公式:
  v_t_corrected = v_t / (1 - β^t)

效果:
  t=1: v_1 / (1-β)   → 放大
  t=∞: v_t / 1       → 无修正

用途: Adam 优化器中的关键步骤
```

**6. 动量梯度下降 (19_动量梯度下降.md)**
```
目的: 累积历史梯度，加速收敛

公式:
  v_t = β·v_{t-1} + (1-β)·∇L
  θ = θ - α·v_t

类比: 滚球下山
  ├─ 累积动量 → 加速前进
  ├─ 平滑震荡 → 减少摆动
  └─ 冲过小坡 → 避免局部最优

超参数:
  β = 0.9 (典型值)
```

**7. RMSprop 优化器 (20_RMSprop.md)**
```
目的: 自适应学习率，解决摆动问题

公式:
  s_t = β·s_{t-1} + (1-β)·(∇L)²
  θ = θ - α·∇L / √(s_t + ε)

直观理解:
  震荡方向: 梯度平方大 → 学习率小 → 减少摆动
  前进方向: 梯度平方小 → 学习率大 → 加速前进

优势:
  ✓ 自动调整每个参数的学习率
  ✓ 适合非平稳目标
```

**8. Adam 优化器 (21_Adam优化器.md) ⭐⭐⭐**
```
目的: 结合动量和 RMSprop 的最强优化器

公式:
  # 动量部分
  m_t = β₁·m_{t-1} + (1-β₁)·∇L

  # RMSprop部分
  v_t = β₂·v_{t-1} + (1-β₂)·(∇L)²

  # 偏差修正
  m̂_t = m_t / (1 - β₁^t)
  v̂_t = v_t / (1 - β₂^t)

  # 更新参数
  θ = θ - α·m̂_t / (√v̂_t + ε)

默认超参数:
  α = 0.001
  β₁ = 0.9
  β₂ = 0.999
  ε = 10⁻⁸

优势:
  ✓ 结合动量和自适应学习率
  ✓ 偏差修正
  ✓ 几乎是最优的默认选择
  ✓ DeepSeek-V3 使用!
```

**9. 优化器演进总结 (20_优化器演进总结_从指数加权平均到Adam.md)**
```
优化器演化路径:

  └─ 添加动量,加速收敛

  └─ DeepSeek-V3 使用
```

### 🎛️ **第五阶段：超参数调优（系统化调参）**

#### 核心问题
> "超参数这么多，如何高效地找到最优配置？"

#### 学习路径

**1. 学习率衰减 (22_学习率衰减.md)**
```
目的: 训练后期降低学习率，精细调优

常见策略:
  指数衰减: α_t = α_0 · decay^t
  1/t 衰减: α_t = α_0 / (1 + decay·t)
  阶梯衰减: 每N个epoch降低一次
  余弦退火: α_t = α_min + 0.5·(α_max-α_min)·(1+cos(πt/T))

类比: 找宝藏
  初期: 大步探索 (高学习率)
  后期: 小步精调 (低学习率)
```

**2. 局部最优与鞍点问题 (23_局部最优与鞍点问题.md)**
```
目的: 理解高维优化的难点

传统误解:
  担心陷入局部最优 ✗

现代理解:
  鞍点才是主要问题 ✓

原因:
  高维空间中,所有维度同时是局部最优的概率 → 0
  鞍点(部分维度上升,部分下降) → 常见

动量优化器的作用:
  ✓ 帮助逃离鞍点
  ✓ 加速通过平坦区域
```

**3. 调参流程 (24_调参流程.md)**
```
目的: 系统化的超参数调优方法论

调参优先级:
  1. 学习率 α (最重要!)
  2. 动量参数 β、隐藏单元数
  3. Mini-batch大小、层数
  4. 学习率衰减
  5. Adam的 β₁, β₂, ε (通常用默认值)

搜索策略:
  ❌ 网格搜索 (组合爆炸)
  ✓ 随机搜索 (更高效)
  ✓ 由粗到细 (先大范围,再局部精调)
```

**4. 超参数尺度选择 (25_超参数尺度选择.md)**
```
目的: 正确选择超参数的搜索尺度

尺度选择:
  线性尺度:
    └─ 隐藏单元数、层数
    └─ 范围: [50, 100, 150, 200]

  对数尺度:
    └─ 学习率 α、正则化 λ
    └─ 范围: 10⁻⁴, 10⁻³, 10⁻², 10⁻¹

  特殊处理:
    └─ β (动量): 1-β 用对数尺度
    └─ 范围: 0.9, 0.99, 0.999

原因:
  对数尺度 → 均匀探索多个数量级
  线性尺度 → 局部精细调整
```

**1. 批量归一化 (27_批量归一化.md) ⭐⭐⭐**
```
目的: 稳定隐藏层分布,加速训练

核心思想:
  问题: 深度网络中每层输入分布不断变化 (Internal Covariate Shift)
  解决: 对每个小批量的隐藏层激活值进行归一化

公式:
  # 训练时
  μ_B = 批量均值
  σ²_B = 批量方差
  x̂ = (x - μ_B) / √(σ²_B + ε)
  y = γ·x̂ + β  (可学习参数)

  # 测试时
  使用移动平均的 μ 和 σ²

五大优势:
  ✓ 加速收敛 (2-10倍)
  ✓ 允许更大学习率
  ✓ 减少梯度消失/爆炸
  ✓ 正则化效果 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  ✓ 降低初始化敏感性

DeepSeek-V3 的选择:
  使用 RMSNorm (更快更简单)
  └─ 只用方差,不用均值
  └─ 计算更高效
```

```
✅ 建立了: 现代深度网络的标准组件

批量归一化是深度学习三大技术突破之一! 🎉
```

## 📊 技术对比表

### 优化器对比

| 优化器 | 核心特点 | 优势 | 劣势 | 适用场景 |
|-------|---------|------|------|---------|
| **SGD** | 基础梯度下降 | 简单、理论完善 | 慢、易震荡 | 小型网络 |
| **Momentum** | 累积历史梯度 | 加速、减少震荡 | 仍需手动调学习率 | 传统任务 |
| **RMSprop** | 自适应学习率 | 解决摆动问题 | 需要调 β | RNN任务 |
| **Adam** | 动量+自适应 | 快速、鲁棒、默认选择 | 有时泛化稍差 | 现代深度学习 ⭐ |
| **AdamW** | Adam+解耦衰减 | 更好的泛化 | - | 大模型训练 ⭐⭐⭐ |

### 正则化方法对比

| 方法 | 原理 | 强度 | 适用场景 |
|------|------|------|---------|
| **L2正则化** | 惩罚权重平方和 | 中 | 通用 |
| **L1正则化** | 惩罚权重绝对值 | 中 | 特征选择 |
| **Dropout** | 随机丢弃神经元 | 强 | 全连接层 |
| **数据增强** | 扩充训练数据 | 强 | 计算机视觉 |
| **Early Stopping** | 提前停止训练 | 弱 | 通用辅助 |
| **批量归一化** | 归一化激活值 | 弱(副作用) | 深度网络 |

### 归一化方法对比

| 归一化类型 | 归一化维度 | 批量依赖 | 适用场景 |
|----------|----------|---------|---------|
| **Batch Norm** | 批量+空间 | 是 | CNN分类、检测 |
| **Layer Norm** | 特征 | 否 | Transformer、RNN |
| **RMS Norm** | 特征(只用方差) | 否 | 大模型 (DeepSeek-V3) ⭐ |
| **Group Norm** | 组内特征 | 否 | 小批量训练 |

1. **训练误差大** → 高偏差 → 欠拟合
