## 📌 基本定义

**超参数调优**（Hyperparameter Tuning）是指系统地搜索和选择最优超参数组合，以最大化模型性能的过程。

与模型参数（通过训练学习）不同，超参数需要在训练前设定，无法通过反向传播自动学习。

---

## 🎯 超参数的分类

### 1. 优化相关超参数

```python
# 最重要的超参数
learning_rate = 1e-3        # 学习率 ⭐⭐⭐

# 优化器超参数

T_max = 100000             # 总训练步数 ⭐

```

### 2. 正则化超参数

```python
weight_decay = 0.01         # L2正则化系数 ⭐⭐
```

### 3. 模型架构超参数

## 🔢 超参数重要性排序

### 🔴 最重要 (必须精心调整)

```
1. 学习率 (learning_rate)
   └─ 影响最大，范围: 1e-5 到 1e-1
   └─ 优先级: ⭐⭐⭐⭐⭐

2. 批量大小 (batch_size)
   └─ 影响训练稳定性和速度
   └─ 优先级: ⭐⭐⭐⭐

3. 模型规模 (layers, hidden_size)
   └─ 决定模型容量
   └─ 优先级: ⭐⭐⭐⭐
```

### 🟡 中等重要 (有明显影响)

```
4. 权重衰减 (weight_decay)
   └─ 防止过拟合
   └─ 优先级: ⭐⭐⭐

5. Dropout率 (dropout_rate)
   └─ 正则化效果
   └─ 优先级: ⭐⭐⭐

6. Adam的β参数 (beta1, beta2)
   └─ 优化器行为
   └─ 优先级: ⭐⭐
```

### 🟢 次要 (通常使用默认值)

```
7. ε (epsilon)
   └─ 数值稳定性
   └─ 优先级: ⭐

8. 学习率预热步数 (warmup_steps)
   └─ 训练稳定性
   └─ 优先级: ⭐
```

## 📊 标准调参流程

### 阶段1: 建立基线 (Baseline)

```python
# 第一步: 使用最简单配置
baseline_config = {
    'model': 'small',           # 小模型快速迭代
    'lr': 1e-3,                 # 常用默认值
    'batch_size': 32,           # 小batch快速验证
    'optimizer': 'Adam',
    'epochs': 10,               # 快速训练
    'weight_decay': 0.0,        # 先不加正则化
}

model = train(baseline_config)
baseline_performance = evaluate(model)

print(f"Baseline: {baseline_performance}")
# 例如: Baseline: 65% accuracy
```

**目标**:
- 确认代码能运行
- 建立性能参考点
- 快速发现明显问题

---

### 阶段2: 粗调学习率 (Coarse Learning Rate Search)

```python
# 第二步: 在对数尺度上搜索学习率
lr_candidates = [1e-5, 3e-5, 1e-4, 3e-4, 1e-3, 3e-3, 1e-2]

results = {}
for lr in lr_candidates:
    config = baseline_config.copy()
    config['lr'] = lr

    model = train(config)
    performance = evaluate(model)
    results[lr] = performance

    print(f"LR={lr:.2e}: {performance}")

# 示例输出:
# LR=1e-5: 55%  (太小，收敛慢)
# LR=3e-5: 68%
# LR=1e-4: 72%  ← 最好
# LR=3e-4: 71%
# LR=1e-3: 65%
# LR=3e-3: 30%  (太大，不稳定)
# LR=1e-2: NaN  (爆炸)

best_lr = 1e-4  # 选择最优学习率
```

**搜索策略**:
- 对数尺度: 1e-5, 3e-5, 1e-4, 3e-4, ...
- 快速训练: 10-20个epoch
- 观察训练曲线

---

### 阶段3: 调整批量大小 (Batch Size Tuning)

```python
# 第三步: 测试不同批量大小
batch_sizes = [32, 64, 128, 256, 512]

for bs in batch_sizes:
    config = baseline_config.copy()
    config['lr'] = best_lr
    config['batch_size'] = bs

    # 应用线性缩放规则
    if bs > 64:
        config['lr'] = best_lr * (bs / 64)

    model = train(config)
    performance = evaluate(model)

    print(f"BS={bs}, LR={config['lr']:.2e}: {performance}")

# 示例输出:
# BS=32,  LR=1e-4: 72%
# BS=64,  LR=1e-4: 73%
# BS=128, LR=2e-4: 74%  ← 最好
# BS=256, LR=4e-4: 72%
# BS=512, LR=8e-4: 68%  (泛化变差)
```

**注意事项**:
- 大batch需要调整学习率（线性缩放规则）
- 考虑内存限制
- 平衡训练速度和泛化性能

---

### 阶段4: 模型规模调整 (Model Size)

```python
# 第四步: 增大模型容量
model_configs = [
    {'layers': 6, 'hidden': 256, 'heads': 4},   # Small
    {'layers': 12, 'hidden': 512, 'heads': 8},  # Medium

for model_cfg in model_configs:
```

### 阶段5: 正则化调整 (Regularization)

```python
# 第五步: 加入正则化
reg_configs = [
    {'weight_decay': 0.0, 'dropout': 0.0},
    {'weight_decay': 0.01, 'dropout': 0.1},
    {'weight_decay': 0.05, 'dropout': 0.1},
    {'weight_decay': 0.1, 'dropout': 0.2},
]

for reg_cfg in reg_configs:
    config = best_config.copy()
    config.update(reg_cfg)

    model = train(config)
    train_perf = evaluate(model, train_set)
    val_perf = evaluate(model, val_set)

    print(f"{reg_cfg}")
    print(f"  Train: {train_perf}, Val: {val_perf}")

# 示例输出:
# {'weight_decay': 0.0, 'dropout': 0.0}
#   Train: 95%, Val: 78%  (过拟合)
# {'weight_decay': 0.01, 'dropout': 0.1}
#   Train: 92%, Val: 81%  ← 最好
# {'weight_decay': 0.1, 'dropout': 0.2}
#   Train: 85%, Val: 80%  (正则化过强)
```

---

### 阶段6: 精调 (Fine-tuning)

```python
# 第六步: 在最优配置附近精细搜索
fine_tune_space = {
    'lr': [8e-5, 1e-4, 1.2e-4],
    'weight_decay': [0.008, 0.01, 0.012],
    'dropout': [0.08, 0.1, 0.12],
}

best_performance = 0
best_final_config = None

for lr in fine_tune_space['lr']:
    for wd in fine_tune_space['weight_decay']:
        for dp in fine_tune_space['dropout']:
            config = best_config.copy()
            config.update({
                'lr': lr,
                'weight_decay': wd,
                'dropout': dp,
                'epochs': 100  # 完整训练
            })

            model = train(config)
            perf = evaluate(model, val_set)

            if perf > best_performance:
                best_performance = perf
                best_final_config = config

print(f"Final best: {best_performance}")
print(f"Config: {best_final_config}")
```

## 🔧 自动化调参方法

### 1. 网格搜索 (Grid Search)

```python
from sklearn.model_selection import ParameterGrid

# 定义超参数空间
param_grid = {
    'lr': [1e-4, 3e-4, 1e-3],
    'weight_decay': [0.0, 0.01, 0.1],
    'dropout': [0.0, 0.1, 0.2],
}

# 生成所有组合
grid = ParameterGrid(param_grid)
print(f"Total combinations: {len(grid)}")  # 3 * 3 * 3 = 27

# 遍历所有组合
results = []
for params in grid:
    model = train(params)
    perf = evaluate(model)
    results.append((params, perf))

# 选择最优
best_params, best_perf = max(results, key=lambda x: x[1])
```

**优点**:
- 简单直观
- 保证覆盖所有组合

**缺点**:
- 组合数量爆炸（指数增长）
- 浪费计算资源（很多无意义组合）

---

### 2. 随机搜索 (Random Search) ⭐

```python
import numpy as np

def random_search(n_trials=50):
    """
    随机搜索: 在超参数空间中随机采样
    """
    results = []

    for trial in range(n_trials):
        # 随机采样超参数
        params = {
            'lr': 10 ** np.random.uniform(-5, -2),      # [1e-5, 1e-2]
            'weight_decay': 10 ** np.random.uniform(-3, -1),  # [1e-3, 0.1]
            'dropout': np.random.uniform(0.0, 0.3),
            'batch_size': np.random.choice([32, 64, 128, 256]),
        }

        model = train(params)
        perf = evaluate(model)
        results.append((params, perf))

        print(f"Trial {trial}: {perf:.2f}%")

    # 排序找最优
    results.sort(key=lambda x: x[1], reverse=True)
    return results

# 执行
results = random_search(n_trials=50)
best_params, best_perf = results[0]
print(f"\nBest: {best_perf:.2f}%")
print(f"Params: {best_params}")
```

**优点**:
- 比网格搜索高效得多
- 容易并行化
- 对不重要的超参数不敏感

**缺点**:
- 随机性（需要足够多的trials）
- 可能错过最优组合

**推荐**: 对于大多数任务，随机搜索是最佳选择 ⭐

### 3. 贝叶斯优化 (Bayesian Optimization)

```python
from bayes_opt import BayesianOptimization

def objective_function(lr, weight_decay, dropout):
    """
    目标函数: 返回验证性能
    """
    params = {
        'lr': 10 ** lr,  # 输入是log空间
        'weight_decay': 10 ** weight_decay,
        'dropout': dropout,
    }

    model = train(params)
    perf = evaluate(model)
    return perf

# 定义搜索空间
pbounds = {
    'lr': (-5, -2),              # log10(lr) ∈ [-5, -2]
    'weight_decay': (-3, -1),    # log10(wd) ∈ [-3, -1]
    'dropout': (0.0, 0.3),
}

# 贝叶斯优化
optimizer = BayesianOptimization(
    f=objective_function,
    pbounds=pbounds,
    random_state=42,
)

# 执行优化
optimizer.maximize(
    init_points=5,   # 随机初始化5个点
    n_iter=25,       # 再优化25次
)

# 最优参数
print(f"Best params: {optimizer.max['params']}")
print(f"Best performance: {optimizer.max['target']:.2f}%")
```

**优点**:
- 最高效（利用历史信息）
- 需要更少的trials
- 智能选择下一个试验点

**缺点**:
- 实现复杂
- 对超参数空间的先验假设敏感

### 4. Hyperband / ASHA (异步连续减半)

```python
from ray import tune
from ray.tune.schedulers import ASHAScheduler

def train_function(config):
    """
    训练函数: 支持早停
    """
    model = initialize_model(config)

    for epoch in range(config['max_epochs']):
        train_one_epoch(model)
        val_acc = validate(model)

        # 向Ray Tune报告
        tune.report(accuracy=val_acc)

# 定义搜索空间
config = {
    'lr': tune.loguniform(1e-5, 1e-2),
    'weight_decay': tune.loguniform(1e-3, 0.1),
    'dropout': tune.uniform(0.0, 0.3),
    'batch_size': tune.choice([32, 64, 128, 256]),
    'max_epochs': 100,
}

# ASHA调度器: 提前停止表现差的trial
scheduler = ASHAScheduler(
    metric='accuracy',
    mode='max',
    max_t=100,           # 最大epoch
    grace_period=10,     # 至少训练10个epoch
    reduction_factor=3,  # 每轮保留1/3
)

# 执行调优
analysis = tune.run(
    train_function,
    config=config,
    num_samples=50,      # 50次trial
    scheduler=scheduler,
)

# 最优配置
best_config = analysis.best_config
print(f"Best config: {best_config}")
```

**优点**:
- 极高效（早停差的trial）
- 可以测试大量配置
- 自动资源分配

**缺点**:
- 需要额外的框架（Ray Tune等）
- 设置复杂

## ⚠️ 常见陷阱

### 陷阱1: 过度调参到测试集

```python
# ❌ 错误: 反复在测试集上调参
for config in configs:
    model = train(config)
    test_perf = evaluate(model, test_set)  # 信息泄露!
    if test_perf > best:
        best_config = config

# ✅ 正确: 测试集只用一次
for config in configs:
    model = train(config)
    val_perf = evaluate(model, val_set)  # 用验证集
    if val_perf > best:
        best_config = config

# 最后才在测试集上评估
final_perf = evaluate(best_model, test_set)
```

### 陷阱2: 忽略随机性

```python
# ❌ 单次运行
config = {'lr': 1e-3}
model = train(config, seed=42)
perf = evaluate(model)
# 性能: 75% (可能是运气好)

# ✅ 多次运行取平均
perfs = []
for seed in [42, 43, 44, 45, 46]:
    model = train(config, seed=seed)
    perf = evaluate(model)
    perfs.append(perf)

mean_perf = np.mean(perfs)
std_perf = np.std(perfs)
print(f"Performance: {mean_perf:.2f}% ± {std_perf:.2f}%")
# 性能: 73.5% ± 1.2% (更可靠)
```

### 陷阱3: 线性搜索学习率

```python
# ❌ 线性尺度 (浪费)
lrs = [0.0001, 0.0002, 0.0003, ..., 0.01]  # 100个点
# 大部分在不重要的区域

# ✅ 对数尺度 (高效)
lrs = [1e-5, 3e-5, 1e-4, 3e-4, 1e-3, 3e-3, 1e-2]  # 7个点
# 覆盖更广的范围
```

### 陷阱4: 忽略计算预算

```python
# ❌ 不考虑时间成本
grid = {
    'lr': 10个值,
    'batch_size': 5个值,
    'layers': 5个值,
    'hidden': 5个值,
}
# 总共: 10*5*5*5 = 1250次训练
# 每次10小时 → 12500小时 = 520天! 😱

# ✅ 合理规划
# 阶段1: 粗调LR (10次 * 2小时 = 20小时)
# 阶段2: 调batch size (5次 * 2小时 = 10小时)
# 阶段3: 调模型规模 (5次 * 10小时 = 50小时)
# 总计: 80小时 ✓
```

## 🎓 核心要点总结

### 1. 调参的优先级

```
最重要 (必调):
1. 学习率
2. 批量大小
3. 模型规模

中等重要 (有影响):
4. 正则化 (weight_decay, dropout)
5. 优化器超参数 (betas)

次要 (通常默认):
6. ε, warmup_steps等
```

### 2. 推荐流程

```
建立基线 → 粗调LR → 调batch size
    ↓
调模型规模 → 加正则化 → 精调
    ↓
最终评估(测试集, 只用一次!)
```

### 3. 搜索策略选择

```
快速原型 (<50次): 随机搜索 ⭐
充足预算 (>100次): 贝叶斯优化
极大规模: Hyperband/ASHA
```

### 4. 关键原则

```
✓ 从简单到复杂
✓ 使用对数尺度
✓ 监控训练曲线
✓ 验证集调参，测试集评估
✓ 记录所有实验
✓ 多次运行考虑随机性
```
