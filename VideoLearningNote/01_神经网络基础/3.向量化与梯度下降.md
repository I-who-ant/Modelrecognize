## 基本定义

**向量化 (Vectorization)**: 用矩阵运算替代显式for循环,利用NumPy/GPU并行计算能力,大幅提升计算速度。

**梯度下降 (Gradient Descent)**: 通过迭代更新参数,沿着代价函数梯度的反方向逐步找到最优解的优化算法。

**核心思想**:
- 梯度下降告诉我们"往哪个方向走"
- 向量化告诉我们"如何快速计算这个方向"

## 为什么学这个?

### 重要性 ⭐⭐⭐

1. **性能差异巨大**:
   - for循环处理100万样本: ~几秒到几分钟
   - 向量化处理100万样本: ~几毫秒
   - **速度提升可达100-1000倍!**

2. **深度学习的基础**:
   - 所有现代深度学习框架(PyTorch, TensorFlow)都基于向量化
   - GPU加速的前提就是向量化运算
   - 没有向量化,训练大模型根本不可行

3. **代码简洁性**:
   - 向量化代码往往只有1-2行
   - for循环版本可能需要10+行
   - 更容易理解和维护

### 1. 多样本梯度下降 (课程15) ⭐⭐⭐

#### 单个样本 vs 多个样本

**单个样本的梯度下降**:
```python
# 对于单个样本 (x, y)
z = w^T x + b
ŷ = σ(z)
L = -(y·log(ŷ) + (1-y)·log(1-ŷ))

# 梯度
dw = (ŷ - y) · x
db = ŷ - y

# 更新
w = w - α·dw
b = b - α·db
```

**多个样本的梯度下降(朴素版本,慢!)**:
```python
# 初始化
dw = 0  # 累积梯度
db = 0

# 对每个样本计算梯度并累加
for i in range(m):  # m个样本
    # 前向传播
    z⁽ⁱ⁾ = w^T x⁽ⁱ⁾ + b
    ŷ⁽ⁱ⁾ = σ(z⁽ⁱ⁾)

    # 计算梯度
    dz⁽ⁱ⁾ = ŷ⁽ⁱ⁾ - y⁽ⁱ⁾
    dw += x⁽ⁱ⁾ · dz⁽ⁱ⁾  # 累加每个样本的梯度
    db += dz⁽ⁱ⁾

# 求平均
dw = dw / m
db = db / m

# 更新参数
w = w - α·dw
b = b - α·db
```

**问题**: 有两个for循环!
1. 外层循环: 遍历m个样本
2. 内层循环(隐藏): w^T x 的计算(遍历n个特征)

**结果**: 非常慢! ❌

#### 梯度下降的数学推导

**代价函数**:
```
J(w,b) = 1/m · Σᵢ₌₁ᵐ L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾)
```

**梯度**:
```
∂J/∂w = 1/m · Σᵢ₌₁ᵐ ∂L⁽ⁱ⁾/∂w
      = 1/m · Σᵢ₌₁ᵐ (ŷ⁽ⁱ⁾ - y⁽ⁱ⁾) · x⁽ⁱ⁾

∂J/∂b = 1/m · Σᵢ₌₁ᵐ ∂L⁽ⁱ⁾/∂b
      = 1/m · Σᵢ₌₁ᵐ (ŷ⁽ⁱ⁾ - y⁽ⁱ⁾)
```

**关键观察**: 这个求和可以用向量化!

### 2. 向量化基础 (课程16) ⭐⭐⭐

#### 什么是向量化?

**定义**: 用矩阵/向量运算替代显式循环

**示例1: 向量点积**

```python
# ❌ 非向量化版本(慢)
z = 0
for i in range(n):
    z += w[i] * x[i]

# ✅ 向量化版本(快)
z = np.dot(w, x)  # 或 w.T @ x
```
  # 计算过程(矩阵乘法)
  # w.T @ x = [1, 2, 3] @ [[4],   = [[1*4 + 2*5 + 3*6]]
  #                        [5],
  #                        [6]]
  #           ↑              ↑
  #         (1,3)          (3,1)
  #         行向量         列向量

  # 矩阵乘法的维度规则
  (a, b) @ (b, c) = (a, c)
   ↑       ↑
   必须相等! 


**速度对比**:
```python
import numpy as np
import time

n = 1000000
w = np.random.randn(n)
x = np.random.randn(n)

# 非向量化
start = time.time()
z = 0
for i in range(n):
    z += w[i] * x[i]
print(f"循环版本: {(time.time() - start)*1000:.2f} ms")

# 向量化
start = time.time() # 记录开始时间
z = np.dot(w, x) # 或 w.T @ x : 点积, 等价于 Σᵢ₌₁ⁿ w[i] * x[i] , 即向量w和向量x的内积
print(f"向量化版本: {(time.time() - start)*1000:.2f} ms")

# 输出示例:]
# 循环版本: 474.23 ms
# 向量化版本: 1.45 ms
# 速度提升: ~327倍!
```

#### 为什么向量化这么快?

**原因**:

1. **SIMD指令 (Single Instruction Multiple Data)**:
   ```
   循环版本: 一次只算一个乘法
   w[0]*x[0], 然后 w[1]*x[1], 然后 w[2]*x[2], ...

   向量化: CPU一次性算多个乘法
   [w[0]*x[0], w[1]*x[1], w[2]*x[2], w[3]*x[3]] 同时进行!
   ```

2. **编译器优化**:
   - NumPy底层用C/Fortran实现
   - 高度优化的数学库(BLAS, MKL)
   - 避免Python解释器开销

3. **内存访问优化**:
   - 连续内存访问,缓存友好
   - 减少内存跳转

4. **GPU加速**:
   - 向量化是GPU并行的前提
   - GPU可以同时处理成千上万个元素

### 4. 逻辑回归向量化 (课程18) ⭐⭐⭐

#### 数据维度说明

**约定**:
```c++
X: (n_features, m_samples)  # n个特征, m个样本
    每一列是一个样本
    X = [x⁽¹⁾ x⁽²⁾ x⁽³⁾ ... x⁽ᵐ⁾]

Y: (1, m_samples)  # m个样本的标签
    Y = [y⁽¹⁾ y⁽²⁾ y⁽³⁾ ... y⁽ᵐ⁾]

w: (n_features, 1)  # n维权重向量
b: 标量
```

#### 前向传播向量化

**❌ 非向量化版本**:
```python
m = X.shape[1]  # 样本数
n = X.shape[0]  # 特征数

Z = np.zeros((1, m)) # (1, m)  # 线性组合结果 ,1: 表示只有1行,m: 表示有m列
A = np.zeros((1, m)) # (1, m)  # sigmoid输出 

for i in range(m):
    z = 0
    for j in range(n):
        z += w[j] * X[j, i] # 计算线性组合 # 计算第i个样本的线性组合
    z += b  # 加上偏置项
    Z[0, i] = z  # 存储第i个样本的线性组合结果
    A[0, i] = sigmoid(z) # 计算sigmoid输出
```

**✅ 向量化版本**:
```python
#np.dot(w, x) : 计算向量w和向量x的点积 , 等价于 w.T @ x
Z = w.T @ X + b  # (1, n) @ (n, m) + 标量 = (1, m)  # 线性组合结果

A = sigmoid(Z)   # 逐元素sigmoid
```

**解释**:
```p
w.T @ X 的含义:
= [w₁ w₂ ... wₙ] @ [x⁽¹⁾ x⁽²⁾ ... x⁽ᵐ⁾]

= [w^T x⁽¹⁾  w^T x⁽²⁾  ...  w^T x⁽ᵐ⁾]
  ↑        ↑              ↑
  样本1的z  样本2的z        样本m的z

一行代码完成了 m 个样本的线性组合!
```

**broadcasting机制**:
```p
Z = w.T @ X + b
    (1, m)  + 标量

Z = np.dot(w.T, X) + b  # 与 w.T @ X 等价
Python自动将 b 扩展为 (1, m):
b → [b b b ... b]

相当于每个样本的 z 都加上 b
```

#### Sigmoid向量化

```python
def sigmoid(z):
    """
    可以接受任意形状的数组
    自动逐元素计算sigmoid
    """
    return 1 / (1 + np.exp(-z))

# 示例
Z = np.array([[0.5, -1.2, 2.3]])  # (1, 3)
A = sigmoid(Z)
# A = [[0.622  0.232  0.909]]
# 每个元素都单独计算了sigmoid!
```

### 5. 逻辑回归梯度向量化 (课程19) ⭐⭐⭐

#### 梯度计算的向量化

**数学推导**:
```
∂J/∂w = 1/m · Σᵢ₌₁ᵐ (ŷ⁽ⁱ⁾ - y⁽ⁱ⁾) · x⁽ⁱ⁾
```

**向量化形式**:
```python
dZ = A - Y  # (1, m) - (1, m) = (1, m)
            # dZ = [ŷ⁽¹⁾-y⁽¹⁾  ŷ⁽²⁾-y⁽²⁾  ...  ŷ⁽ᵐ⁾-y⁽ᵐ⁾]
            # A:sigmoid(Z)的输出
dw = 1/m * X @ dZ.T  # (n, m) @ (m, 1) = (n, 1) , 计算每个特征的梯度
            # dw = [∂J/∂w₁  ∂J/∂w₂  ...  ∂J/∂wₙ] 

db = 1/m * np.sum(dZ)  # 标量 , 计算偏置项的梯度
```

**详细解释**:

```p
X @ dZ.T 的含义:

X @ dZ.T = [x⁽¹⁾ x⁽²⁾ ... x⁽ᵐ⁾] @ [dz⁽¹⁾]
                                     [dz⁽²⁾]
                                     [ ... ]
                                     [dz⁽ᵐ⁾]

= x⁽¹⁾·dz⁽¹⁾ + x⁽²⁾·dz⁽²⁾ + ... + x⁽ᵐ⁾·dz⁽ᵐ⁾

= Σᵢ₌₁ᵐ x⁽ⁱ⁾ · (ŷ⁽ⁱ⁾ - y⁽ⁱ⁾)

正是我们需要的求和形式!
```

**完整的梯度下降(向量化版本)**:
```python
# 一次迭代
Z = w.T @ X + b        # (1, m) 前向传播
A = sigmoid(Z)          # (1, m) 激活
dZ = A - Y              # (1, m) 误差
dw = 1/m * X @ dZ.T     # (n, 1) w的梯度
db = 1/m * np.sum(dZ)   # 标量   b的梯度

# 更新
w = w - alpha * dw
b = b - alpha * db
```

**对比循环版本**:
```python
# ❌ 非向量化(两层循环!)
dw = np.zeros((n, 1))
db = 0
for i in range(m):  # 遍历样本
    z = 0
    for j in range(n):  # 遍历特征
        z += w[j] * X[j, i]
    z += b
    a = sigmoid(z)
    dz = a - Y[0, i]

    for j in range(n):  # 又一个特征循环
        dw[j] += X[j, i] * dz
    db += dz

dw /= m
db /= m

w -= alpha * dw
b -= alpha * db
```

**向量化只需5行,循环版本需要15+行!**

## 完整代码对比

### 非向量化版本(慢 ❌)

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def train_logistic_regression_loop(X, Y, num_iterations=1000, learning_rate=0.01):
    """
    非向量化版本 - 慢!

    X: (n, m)
    Y: (1, m)
    """
    n = X.shape[0]  # 特征数
    m = X.shape[1]  # 样本数

    # 初始化
    w = np.zeros((n, 1))
    b = 0

    for iteration in range(num_iterations):
        # 前向传播(循环)
        Z = np.zeros((1, m))
        for i in range(m):
            z = 0
            for j in range(n):
                z += w[j, 0] * X[j, i]
            z += b
            Z[0, i] = z

        A = sigmoid(Z)

        # 计算损失(循环)
        cost = 0
        for i in range(m):
            cost += -(Y[0, i] * np.log(A[0, i]) +
                     (1 - Y[0, i]) * np.log(1 - A[0, i]))
        cost /= m

        # 反向传播(循环)
        dw = np.zeros((n, 1))
        db = 0
        for i in range(m):
            dz = A[0, i] - Y[0, i]
            for j in range(n):
                dw[j, 0] += X[j, i] * dz
            db += dz

        dw /= m
        db /= m

        # 更新
        w -= learning_rate * dw
        b -= learning_rate * db

        if iteration % 100 == 0:
            print(f"迭代 {iteration}, 损失: {cost:.4f}")

    return w, b
```

### 向量化版本(快 ✅)

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def train_logistic_regression_vectorized(X, Y, num_iterations=1000, learning_rate=0.01):
    """
    向量化版本 - 快!

    X: (n, m)
    Y: (1, m)
    """
    n = X.shape[0]
    m = X.shape[1]

    # 初始化
    w = np.zeros((n, 1))
    b = 0

    for iteration in range(num_iterations):
        # 前向传播(向量化)
        Z = w.T @ X + b  # (1, m)
        A = sigmoid(Z)    # (1, m)

        # 计算损失(向量化)
        cost = -1/m * np.sum(Y * np.log(A) + (1 - Y) * np.log(1 - A))

        # 反向传播(向量化)
        dZ = A - Y              # (1, m)
        dw = 1/m * X @ dZ.T     # (n, 1)
        db = 1/m * np.sum(dZ)   # 标量

        # 更新
        w -= learning_rate * dw
        b -= learning_rate * db

        if iteration % 100 == 0:
            print(f"迭代 {iteration}, 损失: {cost:.4f}")

    return w, b
```

## 向量化的通用规则

### 什么时候能向量化?

**✅ 可以向量化的操作**:
1. 数组元素的独立运算
   ```python
   v = v ** 2  # 每个元素独立平方
   ```

2. 矩阵-向量/矩阵-矩阵乘法
   ```python
   y = A @ x
   ```

3. 归约操作(求和、求平均等)
   ```python
   total = np.sum(v)
   ```

4. 逐元素比较
   ```python
   mask = v > 0
   ```

**❌ 难以向量化的操作**:
1. 有依赖关系的递推
   ```python
   # 斐波那契数列
   for i in range(2, n):
       fib[i] = fib[i-1] + fib[i-2]  # 依赖前面的结果
   ```

2. 条件分支复杂的逻辑
   ```python
   for i in range(n):
       if complex_condition(v[i]):
           v[i] = process_A(v[i])
       else:
           v[i] = process_B(v[i])
   ```

### 向量化的最佳实践

1. **尽可能消除显式循环**
   ```python
   # ❌
   for i in range(len(arr)):
       arr[i] = func(arr[i])

   # ✅
   arr = func(arr)  # 如果func支持向量化
   ```

2. **利用broadcasting**
   ```python
   # ❌
   for i in range(m):
       Z[i] = w.T @ X[:, i] + b

   # ✅
   Z = w.T @ X + b  # b自动广播
   ```

3. **用矩阵乘法代替循环求和**
   ```python
   # ❌
   for i in range(m):
       dw += x[:, i] * dz[i]

   # ✅
   dw = X @ dZ.T
   ```

4. **使用NumPy内置函数**
   ```python
   # ❌
   sum = 0
   for x in arr:
       sum += x

   # ✅
   sum = np.sum(arr)
   ```

## 维度分析技巧 ⭐⭐⭐

### 为什么要检查维度?

**防止错误**:
- 矩阵乘法维度不匹配 → 直接报错
- 维度理解错误 → 结果错误但不报错(更危险!)

### 维度检查方法

```python
# 逻辑回归前向传播
X: (n, m)     # n个特征, m个样本
w: (n, 1)     # n维权重
b: 标量

# 计算 Z = w.T @ X + b
w.T:     (1, n)
X:       (n, m)
w.T @ X: (1, n) @ (n, m) = (1, m) ✅ 中间维度n消掉
b:       标量 → 广播为 (1, m)
Z:       (1, m) ✅ 正确!每个样本一个z值

# 计算 dw = 1/m * X @ dZ.T
X:       (n, m)
dZ:      (1, m)
dZ.T:    (m, 1)
X @ dZ.T: (n, m) @ (m, 1) = (n, 1) ✅ 中间维度m消掉
dw:      (n, 1) ✅ 正确!n个特征,每个一个梯度
```

### 维度检查清单

```python
# 在代码中添加assert
def forward_propagation(X, w, b):
    """
    X: (n, m)
    w: (n, 1)
    b: 标量
    """
    n, m = X.shape
    assert w.shape == (n, 1), f"w维度错误: {w.shape}"

    Z = w.T @ X + b
    assert Z.shape == (1, m), f"Z维度错误: {Z.shape}"

    A = sigmoid(Z)
    assert A.shape == (1, m), f"A维度错误: {A.shape}"

    return A
```

## 在DeepSeek-V3中的应用

### 直接应用 🔴

**1. 所有计算都是向量化的**:

```python
# model.py 中的线性层(简化版)
def linear(x, weight, bias=None):
    """
    x:      (batch_size, seq_len, in_features)
    weight: (out_features, in_features)
    bias:   (out_features,) 或 None

    返回:   (batch_size, seq_len, out_features)
    """
    output = x @ weight.T  # 向量化矩阵乘法!
    if bias is not None:
        output = output + bias  # broadcasting!
    return output
```

**2. Attention的向量化**:

```python
# 简化的attention计算
Q: (batch, seq_len, d_model)  # Query
K: (batch, seq_len, d_model)  # Key
V: (batch, seq_len, d_model)  # Value

# Attention scores (完全向量化!)
scores = Q @ K.transpose(-2, -1) / sqrt(d_k)  # (batch, seq, seq)
attn = softmax(scores, dim=-1)                 # (batch, seq, seq)
output = attn @ V                              # (batch, seq, d_model)

# 一次性处理整个batch的所有序列位置!
```

**3. 批量处理**:

```python
# DeepSeek-V3一次处理多个样本
inputs: (batch_size, seq_len)  # 例如 (32, 2048)

# 所有32个样本同时前向传播,完全向量化!
outputs = model(inputs)  # (32, 2048, vocab_size)

# 如果用循环:
for i in range(32):
    output = model(inputs[i])  # 慢32倍!
```

## 常见疑问

### Q1: 为什么NumPy向量化这么快?

**A**: 四个原因

1. **底层C实现**: NumPy底层用C/Fortran写的,比Python快100+倍
2. **SIMD指令**: CPU一次性处理多个数据
3. **缓存优化**: 连续内存访问,CPU缓存命中率高
4. **避免Python开销**: 不需要Python解释器逐条执行

### Q2: 向量化一定比循环快吗?

**A**: **几乎总是快**,但有例外

```python
# 数据量很小时,差异不大
v = np.array([1, 2, 3])  # 只有3个元素
# 向量化 vs 循环,差别微乎其微

# 数据量大时,向量化碾压
v = np.random.randn(1000000)  # 100万元素
# 向量化快100-1000倍!

# 复杂逻辑时,可能需要组合
# 外层用循环,内层向量化
for epoch in range(num_epochs):  # epoch循环保留
    # 但每个epoch内部完全向量化
    Z = w.T @ X + b  # 向量化
    A = sigmoid(Z)   # 向量化
    ...
```

### Q3: X为什么是 (n, m) 而不是 (m, n)?

**A**: **约定问题**,两种都可以,但吴恩达课程用 (n, m)

```python
# 吴恩达约定: X = (n_features, m_samples)
X = (n, m)  # 每一列是一个样本
w = (n, 1)
Z = w.T @ X  # (1, n) @ (n, m) = (1, m) ✅

# Scikit-learn约定: X = (m_samples, n_features)
X = (m, n)  # 每一行是一个样本
w = (n, 1)
Z = X @ w  # (m, n) @ (n, 1) = (m, 1) ✅

# PyTorch通常: (batch, seq_len, features) 或 (batch, features)
```

**重点**: 保持一致即可!理解维度变换最重要!

### Q4: Broadcasting是什么?

**A**: **自动扩展维度**使运算可行

```python
# 例1: 标量 + 向量
a = np.array([1, 2, 3])
b = 10

a + b = [1, 2, 3] + [10, 10, 10] = [11, 12, 13]
           ↑ b自动扩展为 [10, 10, 10]

# 例2: 向量 + 矩阵
A = np.array([[1, 2, 3],
              [4, 5, 6]])  # (2, 3)
b = np.array([10, 20, 30])  # (3,)

A + b = [[1, 2, 3],     [[10, 20, 30],     [[11, 22, 33],
         [4, 5, 6]]  +   [10, 20, 30]]  =   [14, 25, 36]]
                         ↑ b扩展到每一行

# 例3: 逻辑回归中的b
Z = w.T @ X + b
    (1, m)  + 标量

b → [b, b, b, ..., b]  # 扩展到(1, m)
```

**Broadcasting规则**:
1. 从右向左比对维度
2. 维度相同,或其中一个是1,则可以broadcast
3. 维度是1的自动扩展到另一个维度

### Q5: 如何调试向量化代码?

**A**: **检查维度 + 小数据测试**

```python
# 方法1: 打印维度
X = ...
w = ...
print(f"X.shape: {X.shape}")
print(f"w.shape: {w.shape}")

Z = w.T @ X + b
print(f"Z.shape: {Z.shape}")  # 检查是否符合预期

# 方法2: 用小数据对比
# 先用循环版本算出正确答案
X_small = np.random.randn(3, 5)  # 3特征, 5样本
w_small = np.random.randn(3, 1)
b_small = 0.5

# 循环版(慢但直观)
Z_loop = np.zeros((1, 5))
for i in range(5):
    Z_loop[0, i] = np.dot(w_small.T, X_small[:, i]) + b_small

# 向量化版
Z_vec = w_small.T @ X_small + b_small

# 对比
assert np.allclose(Z_loop, Z_vec), "向量化版本错误!"
print("向量化版本正确! ✅")

# 方法3: 使用assert
def forward_prop(X, w, b):
    n, m = X.shape
    assert w.shape == (n, 1), f"w维度应为({n}, 1), 实际为{w.shape}"

    Z = w.T @ X + b
    assert Z.shape == (1, m), f"Z维度应为(1, {m}), 实际为{Z.shape}"

    return Z
```

## 总结

### 核心公式(向量化版本)

```python
# 前向传播
Z = w.T @ X + b           # (1, m)
A = sigmoid(Z)             # (1, m)

# 损失函数
J = -1/m * np.sum(Y * np.log(A) + (1-Y) * np.log(1-A))

# 反向传播
dZ = A - Y                 # (1, m)
dw = 1/m * X @ dZ.T        # (n, 1)
db = 1/m * np.sum(dZ)      # 标量

# 参数更新
w = w - alpha * dw
b = b - alpha * db
```
