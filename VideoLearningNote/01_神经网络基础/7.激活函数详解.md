## 基本定义

**激活函数(Activation Function)**: 应用于神经元线性输出的非线性函数,引入非线性变换能力。

**核心作用**:
- 引入非线性: 使神经网络能够学习复杂的非线性关系
- 梯度传播: 提供梯度用于反向传播
- 输出范围控制: 将输出映射到特定范围

## 为什么学这个?

### 重要性 ⭐⭐⭐

1. **网络表达能力**:
   - 没有激活函数,多层网络退化成单层线性模型
   - 激活函数赋予网络学习复杂模式的能力
   - 是深度学习"深度"的基础

2. **不同任务需要不同激活**:
   - 隐藏层: ReLU, tanh等
   - 二分类输出: Sigmoid
   - 多分类输出: Softmax
   - 回归输出: 线性/ReLU

3. **影响训练效果**:
   - 梯度消失/爆炸问题
   - 训练速度
   - 收敛性

### 与DeepSeek-V3的关系

- 🔴 **SwiGLU激活**: DeepSeek-V3的FFN层使用SwiGLU
- 🔴 **GeLU激活**: Transformer常用激活函数
- 🔴 **Softmax**: 输出层的概率分布
- 🔴 **非线性关键**: 所有Transformer的表达能力基础

### 1. Sigmoid函数

#### 定义和性质

```python
import numpy as np
import matplotlib.pyplot as plt

def sigmoid(z):
    """
    Sigmoid激活函数

    优点:
    - 输出范围 (0, 1),可解释为概率
    - 平滑可导

    缺点:
    - 梯度消失问题(两端梯度接近0)
    - 输出非零中心(均值不为0)
    - 计算exp()相对慢
    """
    return 1 / (1 + np.exp(-z))

# 可视化
z = np.linspace(-10, 10, 1000)
a = sigmoid(z)

plt.figure(figsize=(12, 4))

# Sigmoid函数
plt.subplot(1, 3, 1)
plt.plot(z, a, 'b-', linewidth=2)
plt.grid(True, alpha=0.3)
plt.xlabel('z')
plt.ylabel('a = σ(z)')
plt.title('Sigmoid函数')
plt.axhline(y=0, color='k', linestyle='-', linewidth=0.5)
plt.axhline(y=1, color='k', linestyle='--', linewidth=0.5, alpha=0.5)
plt.axhline(y=0.5, color='r', linestyle='--', linewidth=0.5, alpha=0.5)
plt.axvline(x=0, color='k', linestyle='-', linewidth=0.5)

# 梯度
plt.subplot(1, 3, 2)
grad = a * (1 - a)  # sigmoid导数
plt.plot(z, grad, 'g-', linewidth=2)
plt.grid(True, alpha=0.3)
plt.xlabel('z')
plt.ylabel("σ'(z)")
plt.title('Sigmoid梯度')
plt.axhline(y=0, color='k', linestyle='-', linewidth=0.5)
plt.axvline(x=0, color='k', linestyle='-', linewidth=0.5)

# 输出分布
plt.subplot(1, 3, 3)
plt.hist(a, bins=50, alpha=0.7, color='blue', edgecolor='black')
plt.xlabel('激活值')
plt.ylabel('频率')
plt.title('Sigmoid输出分布')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('sigmoid.png', dpi=100, bbox_inches='tight')
plt.show()

print("Sigmoid特性:")
print(f"  σ(-10) = {sigmoid(-10):.6f}  (接近0)")
print(f"  σ(0)   = {sigmoid(0):.6f}   (0.5)")
print(f"  σ(10)  = {sigmoid(10):.6f}   (接近1)")
print(f"  梯度最大值: {np.max(grad):.6f} (在z=0时)")
print(f"  梯度在z=±5时: {sigmoid(5)*(1-sigmoid(5)):.6f} (梯度消失!)")
```

**关键特性**:
```python
# 输出范围
0 < σ(z) < 1

# 对称性
σ(-z) = 1 - σ(z)

# 梯度
dσ/dz = σ(z) · (1 - σ(z))

# 梯度消失问题
当 |z| > 5 时, 梯度 ≈ 0  ← 很难训练!
```

#### 使用场景

```python
# ✅ 适用场景:
# 1. 二分类问题的输出层
output = sigmoid(z)  # 输出概率 P(y=1|x)

# 2. 需要概率解释的场景
gate = sigmoid(z)  # LSTM的门控机制

# ❌ 不适用场景:
# 1. 深层网络的隐藏层 → 梯度消失
# 2. 需要快速训练 → 计算慢
```

### 2. tanh函数

#### 定义和性质

```python
def tanh(z):
    """
    Tanh (双曲正切) 激活函数

    优点:
    - 输出范围 (-1, 1),零中心
    - 梯度比sigmoid稍强

    缺点:
    - 仍有梯度消失问题
    - 计算exp()相对慢
    """
    return np.tanh(z)
    # 或者: return (np.exp(z) - np.exp(-z)) / (np.exp(z) + np.exp(-z))
    # 或者: return 2 * sigmoid(2*z) - 1

# 可视化
z = np.linspace(-10, 10, 1000)
a = tanh(z)

plt.figure(figsize=(12, 4))

# tanh函数
plt.subplot(1, 3, 1)
plt.plot(z, a, 'b-', linewidth=2, label='tanh(z)')
plt.plot(z, sigmoid(z), 'r--', linewidth=1, alpha=0.5, label='sigmoid(z)')
plt.grid(True, alpha=0.3)
plt.xlabel('z')
plt.ylabel('a')
plt.title('Tanh vs Sigmoid')
plt.axhline(y=0, color='k', linestyle='-', linewidth=0.5)
plt.axhline(y=1, color='k', linestyle='--', linewidth=0.5, alpha=0.5)
plt.axhline(y=-1, color='k', linestyle='--', linewidth=0.5, alpha=0.5)
plt.axvline(x=0, color='k', linestyle='-', linewidth=0.5)
plt.legend()

# 梯度
plt.subplot(1, 3, 2)
grad_tanh = 1 - a**2  # tanh导数
grad_sigmoid = sigmoid(z) * (1 - sigmoid(z))
plt.plot(z, grad_tanh, 'g-', linewidth=2, label="tanh'(z)")
plt.plot(z, grad_sigmoid, 'r--', linewidth=1, alpha=0.5, label="sigmoid'(z)")
plt.grid(True, alpha=0.3)
plt.xlabel('z')
plt.ylabel('梯度')
plt.title('Tanh vs Sigmoid 梯度')
plt.axhline(y=0, color='k', linestyle='-', linewidth=0.5)
plt.axvline(x=0, color='k', linestyle='-', linewidth=0.5)
plt.legend()

# 输出分布
plt.subplot(1, 3, 3)
plt.hist(a, bins=50, alpha=0.7, color='blue', edgecolor='black')
plt.xlabel('激活值')
plt.ylabel('频率')
plt.title('Tanh输出分布')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('tanh.png', dpi=100, bbox_inches='tight')
plt.show()

print("Tanh特性:")
print(f"  tanh(-10) = {tanh(-10):.6f}  (接近-1)")
print(f"  tanh(0)   = {tanh(0):.6f}   (0,零中心!)")
print(f"  tanh(10)  = {tanh(10):.6f}   (接近1)")
print(f"  梯度最大值: {np.max(grad_tanh):.6f} (在z=0时)")
print(f"  梯度在z=±5时: {1-tanh(5)**2:.6f} (梯度消失!)")
```

**关键特性**:
```python
# 输出范围
-1 < tanh(z) < 1

# 零中心 (相比sigmoid更好!)
tanh(0) = 0

# 与sigmoid的关系
tanh(z) = 2·σ(2z) - 1

# 梯度
d(tanh)/dz = 1 - tanh²(z)

# 仍有梯度消失
当 |z| > 5 时, 梯度 ≈ 0
```

#### Tanh vs Sigmoid

```python
# 对比表
"""
特性          Sigmoid       Tanh
输出范围      (0, 1)        (-1, 1)
零中心        ❌            ✅
梯度最大值    0.25          1.0
梯度消失      严重          稍好
计算速度      慢            慢
常用场景      输出层        隐藏层(旧)
"""

# 为什么tanh通常比sigmoid好?
# 1. 零中心 → 梯度更新更平衡
z = np.array([1, 2, 3, 4, 5])
print("Sigmoid输出(非零中心):", sigmoid(z))  # 全是正数
print("Tanh输出(零中心):", tanh(z))  # 有正有负,更balanced

# 2. 梯度更强 → 训练稍快
print(f"Sigmoid最大梯度: {0.25}")
print(f"Tanh最大梯度: {1.0}")  # 4倍!
```

### 3. ReLU函数 ⭐⭐⭐

#### 定义和性质

```python
def relu(z):
    """
    ReLU (Rectified Linear Unit) 激活函数

    优点:
    - 计算极快(max运算)
    - 不饱和(正区间梯度恒为1)
    - 收敛快(相比sigmoid/tanh快6倍)
    - 稀疏激活(约50%神经元被抑制)

    缺点:
    - Dead ReLU问题(负区间梯度为0)
    - 输出非零中心
    """
    return np.maximum(0, z)

# 可视化
z = np.linspace(-5, 5, 1000)
a_relu = relu(z)
a_sigmoid = sigmoid(z)
a_tanh = tanh(z)

plt.figure(figsize=(15, 4))

# 函数对比
plt.subplot(1, 3, 1)
plt.plot(z, a_relu, 'b-', linewidth=2, label='ReLU')
plt.plot(z, a_sigmoid, 'r--', linewidth=1.5, alpha=0.6, label='Sigmoid')
plt.plot(z, a_tanh, 'g--', linewidth=1.5, alpha=0.6, label='Tanh')
plt.grid(True, alpha=0.3)
plt.xlabel('z')
plt.ylabel('a')
plt.title('激活函数对比')
plt.axhline(y=0, color='k', linestyle='-', linewidth=0.5)
plt.axvline(x=0, color='k', linestyle='-', linewidth=0.5)
plt.legend()
plt.ylim([-1.5, 5])

# 梯度对比
plt.subplot(1, 3, 2)
grad_relu = (z > 0).astype(float)  # ReLU导数
grad_sigmoid = sigmoid(z) * (1 - sigmoid(z))
grad_tanh = 1 - tanh(z)**2
plt.plot(z, grad_relu, 'b-', linewidth=2, label="ReLU'")
plt.plot(z, grad_sigmoid, 'r--', linewidth=1.5, alpha=0.6, label="Sigmoid'")

```

**关键特性**:
```python
# 定义
ReLU(z) = max(0, z) = {
    0,  if z < 0
    z,  if z ≥ 0
}

# 梯度
dReLU/dz = {
    0,  if z < 0
    1,  if z > 0
    undefined, if z = 0 (实际取0或1)
}

# 优势:
# 1. 正区间不饱和 → 无梯度消失
# 2. 计算极快 → max(0, z)
# 3. 稀疏激活 → 约50%神经元为0
```

#### Dead ReLU问题

```python
# Dead ReLU: 神经元永久失活

# 例子: 学习率过大导致权重更新过头
W = np.array([[1.0, 2.0]])  # 初始权重
b = np.array([[-0.5]])

# 前向传播
X = np.array([[1.0], [2.0]])  # (2, 1)
z = W @ X + b  # z = 1*1 + 2*2 - 0.5 = 4.5
a = relu(z)    # a = 4.5

print(f"初始: z={z[0,0]:.1f}, a={a[0,0]:.1f}")

# 假设梯度更新导致权重变负
W_new = np.array([[-1.0, -2.0]])  # 权重变负
b_new = np.array([[-0.5]])

z_new = W_new @ X + b_new  # z = -1*1 + -2*2 - 0.5 = -5.5
a_new = relu(z_new)        # a = 0

print(f"更新后: z={z_new[0,0]:.1f}, a={a_new[0,0]:.1f}")

# Dead!
# 因为 a=0, 梯度也为0
# → 权重无法再更新
# → 这个神经元永久死亡
```

**解决方案**:
```python
# 1. 使用较小的学习率
learning_rate = 0.001  # 而不是 0.1

# 2. 使用Leaky ReLU或PReLU
def leaky_relu(z, alpha=0.01): # alpha 是负区间的斜率 , 通常取 0.01 或 0.1,从而避免 Dead ReLU 问题
    """负区间也有小梯度"""
    return np.where(z > 0, z, alpha * z)

# 3. 使用He初始化
W = np.random.randn(n_out, n_in) * np.sqrt(2.0 / n_in)
```

```python
    - 解决Dead ReLU问题
```

### 5. GeLU (Gaussian Error Linear Unit) 🔥

```python
def gelu(z):
    """
    GeLU: Transformer中常用

    优点:
    - 平滑(可导处处连续)
    - 性能通常优于ReLU
    - Transformer的标准选择

    缺点:
    - 计算稍慢(需要erf或近似)
    """
    # 精确版本 (使用误差函数)
    # return 0.5 * z * (1 + erf(z / np.sqrt(2)))

    # 近似版本 (更快)
    return 0.5 * z * (1 + np.tanh(np.sqrt(2/np.pi) * (z + 0.044715 * z**3)))

# 可视化
z = np.linspace(-5, 5, 1000)
a_gelu = gelu(z)
a_relu = relu(z)

plt.figure(figsize=(12, 4))

plt.subplot(1, 2, 1)
plt.plot(z, a_gelu, 'b-', linewidth=2, label='GeLU')
plt.plot(z, a_relu, 'r--', linewidth=1.5, alpha=0.6, label='ReLU')
plt.grid(True, alpha=0.3)
plt.xlabel('z')
plt.ylabel('a')
plt.title('GeLU vs ReLU')
plt.axhline(y=0, color='k', linestyle='-', linewidth=0.5)
plt.axvline(x=0, color='k', linestyle='-', linewidth=0.5)
plt.legend()

plt.subplot(1, 2, 2)
```

### 6. Softmax (多分类输出层)

```python
def softmax(z):
    """
    Softmax: 将向量转换为概率分布

    优点:
    - 输出和为1,可解释为概率
    - 适合多分类任务

    注意:
    - 只用于输出层,不用于隐藏层
    """
    # 数值稳定版本: 减去最大值防止溢出
    exp_z = np.exp(z - np.max(z, axis=0, keepdims=True))
    return exp_z / np.sum(exp_z, axis=0, keepdims=True)

# 示例: 3分类问题
z = np.array([[2.0],   # 类别1的logit
              [1.0],   # 类别2的logit
              [0.1]])  # 类别3的logit

a = softmax(z)

print("Softmax示例:")
print(f"输入 z: {z.flatten()}")
print(f"输出 a: {a.flatten()}")
print(f"总和: {np.sum(a):.6f} (应该=1)")
print(f"最大概率: 类别{np.argmax(a)+1}, 概率={np.max(a):.4f}")

# 温度参数的影响
def softmax_with_temperature(z, temperature=1.0):
    """温度参数控制概率分布的"陡峭"程度"""
    z_scaled = z / temperature
    exp_z = np.exp(z_scaled - np.max(z_scaled, axis=0, keepdims=True))
    return exp_z / np.sum(exp_z, axis=0, keepdims=True)

print("\n温度参数的影响:")
for T in [0.5, 1.0, 2.0]:
    a_T = softmax_with_temperature(z, temperature=T)
    print(f"T={T}: {a_T.flatten()}")
# T越小 → 分布越陡峭(更确定)
# T越大 → 分布越平坦(更均匀)
```

## 第二部分: 为什么需要非线性激活函数 (课程31) ⭐⭐⭐

### 1. 没有激活函数的后果

```python
# 定义一个没有激活函数的2层网络
```

```python
def sigmoid_derivative(z):
    """
    Sigmoid导数: g'(z) = g(z) · (1 - g(z))

    推导:
    g(z) = 1 / (1 + e^(-z))

    g'(z) = d/dz [1 / (1 + e^(-z))]
          = - (1 + e^(-z))^(-2) · (-e^(-z))
          = e^(-z) / (1 + e^(-z))^2
          = [1 / (1 + e^(-z))] · [e^(-z) / (1 + e^(-z))]
          = g(z) · [1 - g(z)]

    实现技巧:
    如果已经计算了 a = σ(z),
    那么 σ'(z) = a · (1 - a)  ← 不需要重新计算!
    """
    a = sigmoid(z)
    return a * (1 - a)
```

### 3. 在反向传播中使用导数

```python
# 完整的前向和反向传播示例 (单样本)

def forward_backward_single_sample(x, y, W1, b1, W2, b2, learning_rate=0.01):
    """
    单样本的完整前向+反向传播

    网络: x → [ReLU] → [Sigmoid] → ŷ
    """
    # ========== 前向传播 ==========

    # 第1层
    z1 = W1 @ x + b1      # (n_h, 1)
    a1 = relu(z1)          # (n_h, 1)

    # 第2层
    z2 = W2 @ a1 + b2     # (1, 1)
    a2 = sigmoid(z2)       # (1, 1)

    # 损失
    loss = -y * np.log(a2) - (1 - y) * np.log(1 - a2)

    # ========== 反向传播 ==========

    # 输出层梯度
    dz2 = a2 - y  # ← 交叉熵+Sigmoid的简化形式
    dW2 = dz2 @ a1.T
    db2 = dz2

    # 隐藏层梯度
    da1 = W2.T @ dz2
    dz1 = da1 * relu_derivative(z1)  # ← ReLU导数!
    dW1 = dz1 @ x.T
    db1 = dz1

    # ========== 参数更新 ==========

    W1 -= learning_rate * dW1
    b1 -= learning_rate * db1
    W2 -= learning_rate * dW2
    b2 -= learning_rate * db2

    return W1, b1, W2, b2, loss[0, 0]

# 示例
np.random.seed(1)
n_x, n_h, n_y = 3, 4, 1

W1 = np.random.randn(n_h, n_x) * 0.01
b1 = np.zeros((n_h, 1))
W2 = np.random.randn(n_y, n_h) * 0.01
b2 = np.zeros((n_y, 1))

x = np.random.randn(n_x, 1)
y = np.array([[1.0]])  # 真实标签

# 训练10步
losses = []
for i in range(10):
    W1, b1, W2, b2, loss = forward_backward_single_sample(
        x, y, W1, b1, W2, b2, learning_rate=0.1
    )
    losses.append(loss)
    if i % 2 == 0:
        print(f"迭代 {i}: 损失 = {loss:.4f}")

plt.figure(figsize=(8, 4))
plt.plot(losses, 'b-o', linewidth=2)
```

```python
# 激活函数及其导数汇总

summary = """
=============================================================
激活函数      |  公式 g(z)              |  导数 g'(z)
=============================================================
Sigmoid       |  1/(1+e^(-z))           |  g(z)·(1-g(z))

2. Tanh:    如果已有 a=tanh(z), 则 tanh'(z) = 1-a²
3. ReLU:    直接用 (z > 0).astype(float)

反向传播中:
dZ[l] = dA[l] * g'(Z[l])  ← 元素wise乘法
      ↑         ↑
    从后传来  激活函数导数
"""
```

## 直观理解

### 类比1: 激活函数 = 信号滤波器

```
线性变换 (W@x+b):
输入信号 → [放大/缩小/组合] → 输出信号
问题: 只能做线性变换

激活函数:
线性输出 → [非线性滤波] → 激活值
- Sigmoid: 压缩到(0,1) - 像音量限制器
- ReLU: 去除负值 - 像半波整流器
- Tanh: 中心化到(-1,1) - 像零点校准器
```

### 类比2: 梯度消失 = 信号衰减

```
深层网络 (10层):
输出层梯度 → [层9] → [层8] → ... → [层1] → 输入层

Sigmoid梯度: 每层最多 ×0.25
10层后: 0.25^10 ≈ 10^(-6)  ← 梯度几乎消失!

ReLU梯度: 每层 ×1 (如果激活)
10层后: 仍然是1  ← 梯度保持!

就像信号传输:
- Sigmoid = 有损电缆,每节衰减75%
- ReLU = 无损光纤,信号无衰减
```

### 类比3: Dead ReLU = 断路

```
神经元 = 电路元件

正常ReLU:
输入>0 → 电路导通 → 信号传递 → 梯度传播 → 参数更新

Dead ReLU:
输入<0 → 电路断开 → 输出恒为0 → 梯度为0 → 无法更新
      ↓
   永久损坏!

Leaky ReLU = 加个小电阻
即使输入<0,也有微弱信号 → 电路还能"抢救"
```

### 1. SwiGLU激活 (FFN层)

```python
# DeepSeek-V3使用SwiGLU激活函数

def swiglu(x, W_gate, W_up):
    """
    SwiGLU = Swish-Gated Linear Unit

    公式:
    SwiGLU(x) = Swish(W_gate @ x) ⊙ (W_up @ x)
              = (W_gate @ x · σ(W_gate @ x)) ⊙ (W_up @ x)

    其中:
    - Swish(z) = z · σ(z)
    - ⊙ 表示元素wise乘法

    优点:
    - 性能优于ReLU和GeLU
    - 门控机制提供更强表达能力
    """
    gate = W_gate @ x
    up = W_up @ x
    swish = gate * sigmoid(gate)  # Swish激活
    return swish * up  # 门控

# 在FFN中的使用
class FFN_DeepSeek:
    def forward(self, x):
        # SwiGLU激活
        gate = self.W_gate @ x
        up = self.W_up @ x
        hidden = gate * sigmoid(gate) * up

        # 输出投影
        output = self.W_down @ hidden
        return output
```

```python
# 语言模型输出概率分布

def lm_output(logits, temperature=1.0):
    """
    DeepSeek-V3的输出层

    logits: (vocab_size,) 每个token的logit
```

## 常见疑问

### Q1: 如何选择激活函数?

**A**: 按场景选择

```python
# 决策树

"""
隐藏层激活函数选择:

1. 默认首选: ReLU
   - 计算快
   - 效果好
   - 适用于大多数任务

2. 如果ReLU效果不好:
   - 尝试 Leaky ReLU (解决Dead ReLU)
   - 尝试 GeLU (Transformer任务)

3. 特殊场景:
   - RNN: tanh 或 GRU/LSTM
   - 需要稀疏激活: ReLU
   - 需要平滑: GeLU/SwiGLU

输出层激活函数选择:

1. 二分类: Sigmoid
2. 多分类: Softmax
3. 回归:
   - 任意值: Linear (无激活)
   - 正值: ReLU
   - 有界: Sigmoid (0-1) 或 Tanh (-1到1)
"""
```

### Q2: 为什么ReLU比Sigmoid好?

**A**: 6个理由

```python
"""
1. 梯度不消失(正区间)
   - ReLU: 梯度恒为1
   - Sigmoid: 梯度最大0.25,两端接近0

2. 计算更快
   - ReLU: max(0,z) - 一个比较
   - Sigmoid: 1/(1+exp(-z)) - exp运算

3. 稀疏激活
   - ReLU: 约50%神经元输出0
   - Sigmoid: 所有神经元都有输出
   → 稀疏性有助于特征学习

4. 收敛更快
   - 实验表明快6倍左右

5. 更符合生物神经元
   - 神经元要么激活要么不激活
   - 不是"部分激活"

6. 无饱和区(正区间)
   - ReLU: z>0时不饱和
   - Sigmoid: z大时饱和
"""
```

### Q3: 能混用不同的激活函数吗?

**A**: 可以,而且常见

```python
# 示例: 混合使用

def forward_mixed_activation(X, params):
    """
    不同层使用不同激活函数
    """
    # 第1层: ReLU
    Z1 = params['W1'] @ X + params['b1']
    A1 = relu(Z1)

    # 第2层: tanh
    Z2 = params['W2'] @ A1 + params['b2']
    A2 = tanh(Z2)

    # 第3层: GeLU
    Z3 = params['W3'] @ A2 + params['b3']
    A3 = gelu(Z3)

    # 输出层: Softmax (多分类)
    Z4 = params['W4'] @ A3 + params['b4']
    A4 = softmax(Z4)

    return A4

# 实际中:
# - 所有隐藏层通常用同一种激活(如全用ReLU)
# - 输出层根据任务选择
# - 特殊情况可以混用(如ResNet用ReLU,LSTM用tanh+sigmoid)
```

### Q4: 激活函数的初始化有关系吗?

**A**: 有!不同激活函数需要不同初始化

```python
# 权重初始化策略

def initialize_weights(n_in, n_out, activation='relu'):
    """
    根据激活函数选择初始化方法
    """
    if activation == 'relu' or activation == 'leaky_relu':
        # He初始化 (适合ReLU)
        W = np.random.randn(n_out, n_in) * np.sqrt(2.0 / n_in)

    elif activation == 'sigmoid' or activation == 'tanh':
        # Xavier初始化 (适合Sigmoid/Tanh)
        W = np.random.randn(n_out, n_in) * np.sqrt(1.0 / n_in)
        # 或者: * np.sqrt(2.0 / (n_in + n_out))

    elif activation == 'linear':
        # Xavier初始化
        W = np.random.randn(n_out, n_in) * np.sqrt(1.0 / n_in)

    else:
        # 默认: He初始化
        W = np.random.randn(n_out, n_in) * np.sqrt(2.0 / n_in)

    b = np.zeros((n_out, 1))

    return W, b

# 为什么ReLU用He初始化?
"""
ReLU会杀死一半神经元(负值→0)
→ 方差减半
→ 需要初始化时方差加倍(×sqrt(2))
→ He初始化: W ~ N(0, 2/n_in)
"""

# 为什么Sigmoid/Tanh用Xavier?
"""
Sigmoid/Tanh在0附近近似线性
→ 希望初始值在线性区
→ Xavier初始化: W ~ N(0, 1/n_in)
"""
```

### Q5: 可以自己设计激活函数吗?

**A**: 可以,但需要满足条件

```python
# 好的激活函数需要满足:

"""
1. ✅ 非线性
   - 否则网络退化成线性

2. ✅ 可导(几乎处处)
   - 反向传播需要梯度
   - ReLU在z=0不可导,但可以接受

3. ✅ 单调性(通常)
   - 有助于优化
   - 但不是必须(如Swish)

4. ✅ 计算高效
   - 深度学习需要大量计算
   - 太复杂的函数不实用

5. ✅ 梯度性质良好
   - 避免梯度消失/爆炸
   - ReLU正区间梯度恒为1

6. 🔶 零中心(可选)
   - tanh是,sigmoid不是
   - 零中心有助于优化

7. 🔶 有界(可选)
   - Sigmoid/Tanh有界
   - ReLU无上界
   - 都可以工作
"""

# 示例: 设计一个新激活函数
def my_activation(z, alpha=0.2):
    """
    自定义激活: Smooth ReLU

    g(z) = z / (1 + α·e^(-z))

    特点:
    - 平滑(处处可导)
    - 单调递增
    - 正区间接近ReLU
    - 负区间有小梯度
    """
    return z / (1 + alpha * np.exp(-z))

# 测试
z = np.linspace(-5, 5, 1000)
a = my_activation(z)

plt.figure(figsize=(10, 4))
plt.plot(z, a, 'b-', linewidth=2, label='自定义激活')
plt.plot(z, relu(z), 'r--', linewidth=1.5, alpha=0.6, label='ReLU')
plt.grid(True, alpha=0.3)
plt.xlabel('z')
plt.ylabel('a')
plt.title('自定义 vs ReLU')
plt.legend()
plt.savefig('custom_activation.png', dpi=100, bbox_inches='tight')
plt.show()

# 但实际上:
# 除非有充分理由,否则用标准激活函数
# (ReLU, GeLU, SwiGLU等已经足够好)
```

## 总结

### 核心公式

```python
# 激活函数定义
Sigmoid:    σ(z) = 1 / (1 + e^(-z))
Tanh:       tanh(z) = (e^z - e^(-z)) / (e^z + e^(-z))
ReLU:       ReLU(z) = max(0, z)
Leaky ReLU: LReLU(z) = max(αz, z)
GeLU:       GeLU(z) ≈ 0.5·z·(1 + tanh(√(2/π)·(z + 0.044715·z³)))

# 导数
σ'(z) = σ(z)·(1 - σ(z))
tanh'(z) = 1 - tanh²(z)
ReLU'(z) = {1 if z>0, 0 if z≤0}
```

### 关键记忆点

1. **激活函数 = 非线性变换**: 赋予网络表达能力
2. **隐藏层首选ReLU**: 快速、有效、无梯度消失
3. **输出层根据任务**: Sigmoid(二分类), Softmax(多分类), Linear(回归)
4. **梯度消失问题**: Sigmoid/Tanh严重, ReLU解决
5. **Dead ReLU**: 负区间梯度为0,可用Leaky ReLU
6. **导数很重要**: 反向传播的核心
