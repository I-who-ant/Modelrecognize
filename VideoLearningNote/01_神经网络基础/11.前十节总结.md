# 前十节总结: 从单个神经元到完整训练流程

**学习日期**: 2025-02-14
**课程来源**: 吴恩达深度学习课程 (第1-10节)
**重要程度**: 🔴必学 (串联前十节核心概念)

## 基本定义与流程概览

本总结把前十节中的关键概念串成完整闭环: **输入特征 → 神经元线性变换 → 激活非线性 → 损失评估 → 链式法则反向传播 → 权重更新 → 下一轮训练**。理解这条链路, 就能掌握神经网络训练的最小工作单元。

## 1. 单个神经元的计算链

- **输入向量 `x ∈ ℝⁿ`**: 每个分量对应一项特征。
- **权重向量 `w ∈ ℝⁿ` 与偏置 `b ∈ ℝ`**: 模型可学习的参数, 决定输入如何被加权。
- **线性组合 `z`**: `z = w·x + b = Σᵢ wᵢ xᵢ + b`, 表示神经元对输入信号的“加权感知”。
- **激活输出 `a`**: `a = σ(z)`, 通过激活函数注入非线性。激活输出会作为下一层的输入或最终预测的组成部分。

> 这一阶段没有求导, 完全是前向计算: 根据当前参数得到预测信号。

## 2. 激活函数与损失的关系

激活函数改变输出的取值范围与梯度形态, 从而影响损失函数的表现与可优化性:

- **Sigmoid (`σ(z) = 1/(1+e^{-z})`)**:
  - 输出落在 (0,1), 适合作为二分类概率。
  - 梯度 `σ(z)(1-σ(z))` 在极大/极小区间趋近 0, 容易导致梯度消失。
  - 与交叉熵搭配时, 损失可写成 `L = -[y log a + (1-y) log (1-a)]`, 对概率输出很自然。
  - 
- **Tanh (`tanh(z)`)**:
  - 输出在 (-1,1), 零中心更有利于梯度传播。
  - 梯度 `1 - tanh²(z)` 仍会在 |z| 大时衰减, 但比 sigmoid 更强。
  - 常用于隐藏层, 搭配均方误差或交叉熵时, 输出分布更平衡。
  - 
- **ReLU (`max(0, z)`)**:
  - 正区间梯度恒为 1, 避免梯度消失; 负区间为 0, 可能出现“神经元死亡”。
  - 与均方误差、交叉熵等损失兼容, 因为其主要作用是提供稀疏性和线性保持。
  - 
- **SwiGLU / GeLU** (前十节的扩展阅读):
  - 在现代 Transformer/DeepSeek 中常见, 通过平滑/门控形式改善梯度流动。

激活函数决定前向输出的分布, 也决定反向传播时 `∂a/∂z` 的大小, 直接影响训练动态。

## 3. 损失函数如何“打分”预测

- **损失函数 `L(y_hat, y)`** 衡量预测 `y_hat` 与真实标签 `y` 的差距。
- 常见示例:
  - 均方误差 (MSE): `L = ½‖y_hat - y‖²`
  - 交叉熵 (二分类): `L = -[y log a + (1-y) log (1-a)]`
- 训练目标: 调整 `w, b` 使所有样本的平均损失最小 (经验风险最小化)。

## 4. 链式法则求梯度的精确过程

对某个隐藏层权重 `w_ij` (连接输入特征 `x_i` 与隐藏单元 `j`) 的梯度展开如下:

```text
∂L/∂w_ij = (∂L/∂a_j) · (∂a_j/∂z_j) · (∂z_j/∂w_ij)
```

三项含义:

1. **`∂L/∂a_j`**: 隐藏单元输出 `a_j` 对最终损失的影响。这是从上一层(更靠近输出的层)反向传回的“误差信号”。
2. **`∂a_j/∂z_j`**: 激活函数的导数, 决定误差信号在该单元的缩放/门控程度。
3. **`∂z_j/∂w_ij` = `x_i`**: 因为 `z_j = Σ_k w_kj x_k + b_j`, 对 `w_ij` 的偏导就是对应输入 `x_i`。

> 通过链式法则, 误差信号可以层层展开: 输出层直接计算, 隐藏层依靠上层传回的梯度依次获得自己的梯度。

## 5. 梯度下降与参数更新

- 得到梯度后, 用学习率 `η` 控制更新步长:

```text
w_ij ← w_ij - η · ∂L/∂w_ij
b_j  ← b_j  - η · ∂L/∂b_j
```

- 学习率过大易震荡或发散, 过小训练缓慢。后续课程会介绍自适应方法 (如 Adam)。
- 每次更新后, 前向传播都会使用最新的参数, 以响应上一轮训练得到的反馈。

## 6. 完整训练循环 (以 mini-batch 为例)

1. **取 mini-batch**: 从训练集取一批样本 `(x_batch, y_batch)`。
2. **前向传播**: 对每个样本计算 `z → a → y_hat`, 汇总损失 `L_batch` (通常取平均)。
3. **反向传播**: 自输出层起, 按链式法则求解每一层的梯度 `∂L/∂w, ∂L/∂b`。
4. **参数更新**: 用学习率更新所有参数。
5. **下一批样本**: 重复步骤 1-4, 直到遍历完整个训练集 (1 个 epoch)。
6. **验证/测试 (可选)**: 使用验证集只做前向传播以评估泛化表现, 不更新参数。

## 7. 关键联系与常见误区

- **线性组合 + 激活 = 表达力**: 没有激活, 多层网络会退化为线性模型。
- **损失函数=训练目标**: 梯度始终围绕损失函数的定义展开, 损失选得不当训练会偏离目标。
- **梯度不是损失本身**: 更新用的是梯度 `∂L/∂w`, 而不是直接用 `L`。
- **误差信号逐层传递**: 每层的梯度来自上一层传回的误差信号; 不需要积分或求原函数。
- **学习率和梯度都重要**: 梯度给方向, 学习率控制步长。二者配合决定收敛速度与稳定性。
