### 2. 序列模型

```
序列建模演进:
┌─────────────────────────────────────────┐
│                                        │
│ RNN (循环神经网络):                    │
│ ├─ 核心思想: 循环结构处理序列          │
│ ├─ 数学: h_t = f(h_{t-1}, x_t)        │
│ ├─ 优点: 理论上可处理任意长度序列       │
│ └─ 缺点: 梯度消失/爆炸                 │
│                                        │
│ LSTM (长短期记忆):                     │
│ ├─ 核心: 门控机制 (遗忘、输入、输出)   │
│ ├─ 公式:                               │
│ │  f_t = σ(W_f[h_{t-1},x_t] + b_f)    │
│ │  i_t = σ(W_i[h_{t-1},x_t] + b_i)    │
│ │  C_t = f_t ⊙ C_{t-1} + i_t ⊙ tanh   │
│ └─ 优势: 缓解梯度消失                   │
│                                        │
│ GRU (门控循环单元):                     │
│ ├─ 更简洁: 2 个门 (更新、重置)          │
│ └─ 性能: 与 LSTM 相当                   │
│                                        │
│ 词嵌入 (Word Embedding):               │
│ ├─ 目标: 将词语映射到向量空间           │
│ ├─ 方法: One-hot → Dense Embedding     │
│ ├─ Word2Vec: CBOW + Skip-gram         │
│ ├─ GloVe: 全局向量表示                 │
│ └─ 性质: 语义关系在向量空间中保持       │
│                                        │
│ 关键洞察:                              │
│ "序列建模的核心是记忆和上下文"         │
│ "词嵌入是 NLP 的基础"                   │
│ "门控机制是 RNN 的关键创新"             │
└─────────────────────────────────────────┘
```

### 3. Attention & Transformer (核心重点)

```
Attention 机制 (从理论到实践):
┌─────────────────────────────────────────┐
│                                        │
│ 基础 Attention (Seq2Seq):              │
│ ├─ 动机: 解决 Seq2Seq 瓶颈              │
│ ├─ 公式:                               │
│ │  attention = softmax(score(Q,K))     │
│ │  output = attention · V              │
│ ├─ 组件:                               │
│ │  Q (Query): "我想找什么"             │
│ │  K (Key): "我能提供什么"             │
│ │  V (Value): "实际内容"               │
│ └─ 意义: 动态选择相关信息               │
│                                        │
│ Self-Attention (Transformer 核心):      │
│ ├─ 本质: Q=K=V=X                        │
│ ├─ 完整公式:                           │
│ │ Attention(Q,K,V) =                   │
│ │  softmax(QK^T / √d_k) V              │
│ ├─ 计算步骤:                           │
│ │  1. QK^T 计算相似度                  │
│ │  2. /√d_k 缩放                       │
│ │  3. softmax 归一化                   │
│ │  4. ×V 加权求和                      │
│ ├─ 矩阵形式:                           │
│ │  X: [seq_len, d_model]              │
│ │  Q,K,V: [seq_len, d_k]              │
│ │  Output: [seq_len, d_k]             │
│ ├─ 优势:                               │
│ │  ✅ 完全并行化                       │
│ │  ✅ 直接连接任意位置                 │
│ │  ✅ 捕获远程依赖                     │
│ │  ✅ 计算复杂度 O(n²d)                │
│ └─ 关键洞察: "每个位置看向所有位置"     │
│                                        │
│ Multi-Head Attention:                   │
│ ├─ 动机: 学习多种模式                   │
│ ├─ 公式:                               │
│ │  head_i = Attention(QW_i^Q, KW_i^K,  │
│ │                 VW_i^V)              │
│ │  MultiHead = Concat(head_1,...,h_h)  │
│ │              W^O                      │
│ ├─ 参数:                               │
│ │  n_heads: 通常 8-16                  │
│ │  d_head = d_model / n_heads          │
│ ├─ 优势:                               │
│ │  ✅ 并行学习多种模式                 │
│ │  ✅ 集成学习效果                     │
│ │  ✅ 计算复杂度不变                   │
│ └─ 可视化: 不同 head 关注不同模式       │
│                                        │
│ Transformer 完整架构:                   │
│ ├─ 整体: Decoder-only (GPT)            │
│ ├─ 层结构:                             │
│ │  ┌─────────────────────────────┐    │
│ │  │ Masked Self-Attention       │    │
│ │  └─────────────────────────────┘    │
│ │  ┌─────────────────────────────┐    │
│ │  │ Layer Norm + Residual       │    │
│ │  └─────────────────────────────┘    │
│ │  ┌─────────────────────────────┐    │
│ │  │ Feed-Forward Network        │    │
│ │  └─────────────────────────────┘    │
│ │  ┌─────────────────────────────┐    │
│ │  │ Layer Norm + Residual       │    │
│ │  └─────────────────────────────┘    │
│ ├─ FFN:                                │
│ │  FFN(x) = max(0, xW₁+b₁)W₂+b₂       │
│ │  维度: d_model → d_ff → d_model      │
│ │  d_ff = 4 × d_model                  │
│ ├─ Layer Norm:                         │
│ │  LN(x) = γ · (x-μ)/σ + β            │
│ │  Pre-LN (现代标准)                   │
│ └─ 关键: 残差连接 + 层归一化            │
│                                        │
│ Position Encoding:                      │
│ ├─ 必要性: Self-Attention 无位置感知   │
│ ├─ 方法演进:                           │
│ │  1. Sinusoidal (Transformer)         │
│ │  2. Learned (BERT)                   │
│ │  3. RoPE (LLaMA, DeepSeek) ✅        │
│ ├─ RoPE 原理:                          │
│ │  复数旋转编码位置                     │
│ │  θ_i = base^(-2i/d_model)           │
│ │  旋转: (x+iy) × e^(i·pos·θ)         │
│ ├─ 性质:                               │
│ │  ✅ 相对位置信息                     │
│ │  ✅ 可外推到更长序列                 │
│ │  ✅ 线性组合性质                     │
│ └─ 关键: 在 latent space 应用 (MLA)     │
│                                        │
│ 关键洞察:                              │
│ "Attention 是现代 AI 的基石"           │
│ "Transformer 统一了 NLP 任务"           │
│ "RoPE 让模型真正理解序列顺序"           │
│ "MLA 是效率与性能的平衡艺术"            │
└─────────────────────────────────────────┘
```

## 🔥 核心技术创新解析

### 1. Multi-Head Latent Attention (MLA)

```
MLA 创新点:
┌─────────────────────────────────────────┐
│ 问题: 传统 MHA KV Cache 占用过大        │
│                                        │
│ 解决方案:                              │
│ 1. 压缩 K, V 到 latent space           │
│    K_latent = K @ W_down               │
│    V_latent = V @ W_down               │
│                                        │
│ 2. 在 latent space 应用 RoPE            │
│    位置信息在低维保持更好               │
│                                        │
│ 3. 解压缩回原始维度                     │
│    K = K_latent @ W_up                 │
│    V = V_latent @ W_up                 │
│                                        │
│ 效果:                                  │
│ ✅ 内存减少: 32×160 → 512 (10 倍)      │
│ ✅ 性能保持: 与 MHA 相当               │
│ ✅ 推理加速: 20-30%                    │
│ ✅ 长上下文: 支持 128K                 │
│                                        │
│ 数学原理:                              │
│ "信息在低维空间的压缩与重构"           │
│ "类似 autoencoder 的思想"               │
│ "不是所有维度都同样重要"               │
│                                        │
│ 工程价值:                              │
│ "让大模型真正可用"                     │
│ "成本降低 95%"                         │
│ "开源推动行业进步"                     │
└─────────────────────────────────────────┘
```

### 3. RoPE 位置编码

```
RoPE 精髓:
┌─────────────────────────────────────────┐
│ 核心思想: 复数旋转编码位置              │
│                                        │
│ 二维旋转:                              │
│ 点 P = (x, y)                          │
│ 旋转角度 θ 后:                          │
│ P' = (x cosθ - y sinθ, x sinθ + y cosθ)│
│                                        │
│ 扩展到高维:                            │
│ 将 d 维向量分成 d/2 个二维平面          │
│ 对每个平面独立应用旋转                  │
│                                        │
│ 位置编码:                              │
│ θ_i = base^(-2i/d_model)              │
│ angle = position × θ_i                  │
│                                        │
│ 关键性质:                              │
│ ✅ 相对位置: 保持相对距离信息          │
│ ✅ 可外推: 数学公式，无学习参数        │
│ ✅ 线性组合: 位置可组合                │
│ ✅ 高效: 计算复杂度 O(d)              │
│                                        │
│ 在 MLA 中的应用:                       │
│ 在 latent space (512 维) 应用 RoPE      │
│ 比在原始空间 (5120 维) 更高效          │
│ 位置信息在低维得到更好保持              │
│                                        │
│ 对比其他位置编码:                      │
│ Sinusoidal: 绝对位置                   │
│ Learned: 学习参数                       │
│ ALiBi: 线性偏置                         │
│ RoPE: ✅ 相对位置 + 可外推             │
│                                        │
│ 关键洞察:                              │
│ "位置编码让 Attention 理解顺序"        │
│ "旋转是保持性质的优雅操作"              │
│ "在正确的地方应用 RoPE 很重要"          │
└─────────────────────────────────────────┘
```
