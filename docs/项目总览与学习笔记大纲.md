## 4. DeepSeek-V3 代码导读指引（面向“看得懂 + 能说清”）
建议阅读顺序（由易到难）：
1) `ModelArgs`（配置）→ 2) `ParallelEmbedding`（嵌入）→ 3) `linear`/`RMSNorm`（基础算子）→ 4) `Attention`（含 MLA 关注点）→ 5) `MLP/SwiGLU` → 6) `DecoderLayer`（整合）→ 7) `generate.py`（推理链路）

对照要点：
- Transformer 基础：Self-Attention、Multi-Head、残差、归一化（RMSNorm）。
- DeepSeek 特色：MLA、多专家（MoE）与载荷均衡策略的思路（先定位模块与调用路径，逐步深入）。
- 配置与权重：`configs/*.json`、权重转换与精度（FP8/BF16）切换的影响面。

## 5. DeepSeek-OCR 实战（可选启用）

- Transformers 路径：参考 README 的 `AutoModel/AutoTokenizer` 示例 或运行 `DeepSeek-OCR-hf/run_dpsk_ocr.py`。

- KISS：文档与示例只保留当下需要的最小集合，避免一次性塞入过多细节。
- YAGNI：不为未来预留空目录与模板；确有需要再补充。
- DRY：概念复用用链接指向原处；相同配置集中在一处维护。
- 上游只读：对官方镜像不做直接修改，必要时通过外层脚本或 `experiments/` 实现。
