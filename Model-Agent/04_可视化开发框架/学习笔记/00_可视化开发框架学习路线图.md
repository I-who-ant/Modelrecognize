#### Day 42: Assistants API开发

**学习内容**:
- [ ] Assistants API核心概念
  - **Assistant**: AI助手实例
  - **Thread**: 对话线程
  - **Message**: 消息对象
  - **Run**: 执行实例
- [ ] Assistants API vs Chat Completions API
  - Assistants: 有状态,自动管理上下文
  - Chat Completions: 无状态,需手动管理历史
- [ ] Thread和Messages
  - Thread: 持久化对话会话
  - Message: 用户和助手的消息
  - 上下文自动管理
- [ ] 原生API使用
  - 创建Assistant
  - 创建Thread
  - 发送Message
  - 执行Run并获取响应

**API调用流程**:
```python
# 1. 创建Assistant
assistant = client.beta.assistants.create(
    name="数学导师",
    instructions="你是一个数学导师...",
    model="gpt-4-turbo"
)

# 2. 创建Thread
thread = client.beta.threads.create()

# 3. 添加Message
message = client.beta.threads.messages.create(
    thread_id=thread.id,
    role="user",
    content="解释一下二次方程"
)

# 4. 运行Assistant
run = client.beta.threads.runs.create(
    thread_id=thread.id,
    assistant_id=assistant.id
)

# 5. 获取响应
messages = client.beta.threads.messages.list(
    thread_id=thread.id
)
```
