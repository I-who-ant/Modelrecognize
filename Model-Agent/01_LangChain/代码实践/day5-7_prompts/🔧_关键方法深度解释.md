## 1️⃣ PromptTemplate.from_template() - 快速创建模板

### 作用
最简洁的方式创建PromptTemplate，通过字符串的变量占位符自动识别。

### 基础用法

```python
from langchain_core.prompts import PromptTemplate

# 方式1: from_template (最简洁，推荐)
template = PromptTemplate.from_template(
    "Translate {text} to {language}"
)

# 自动识别变量
print(template.input_variables)  # ['text', 'language']

# 使用
prompt = template.format(text="Hello", language="Chinese")
# 输出: Translate Hello to Chinese
```

### 与完整定义的对比

```python
from langchain_core.prompts import PromptTemplate

# 方式1: from_template (简洁)
template1 = PromptTemplate.from_template(
    "Write a {style} story about {topic}"
)

# 方式2: 完整定义 (显式)
template2 = PromptTemplate(
    input_variables=["style", "topic"],
    template="Write a {style} story about {topic}",
    template_format="f-string"
)

# 功能完全相同，只是写法不同
prompt1 = template1.format(style="funny", topic="cats")
prompt2 = template2.format(style="funny", topic="cats")

assert prompt1 == prompt2  # ✅ 输出相同
```

### 多行模板的最佳实践

```python
from langchain_core.prompts import PromptTemplate

# ❌ 不推荐：拼接字符串容易出错
template_bad = PromptTemplate.from_template(
    "You are a {role}. Answer: {question}"
)

# ✅ 推荐：使用三引号保持格式清晰
template_good = PromptTemplate.from_template(
    """You are a professional {role}.

Your expertise:
- {skill1}
- {skill2}

Question: {question}

Answer:"""
)

# 使用
prompt = template_good.format(
    role="Python Expert",
    skill1="Web Development",
    skill2="Data Analysis",
    question="What is a decorator?"
)

print(prompt)
# 格式清晰，易于阅读
```

### 内嵌变量验证

```python
from langchain_core.prompts import PromptTemplate

template = PromptTemplate.from_template(
    "Name: {name}, Age: {age}, City: {city}"
)

# ✅ 提供所有变量
prompt = template.format(name="John", age=25, city="NYC")

# ❌ 缺少变量会报错
try:
    template.format(name="John", age=25)  # 缺少city
except KeyError as e:
    print(f"❌ 错误: {e}")

# ⚠️ 多余变量会被忽略
prompt = template.format(
    name="John", age=25, city="NYC", country="USA"
)
# country会被忽略，不会报错
```

## 2️⃣ ChatPromptTemplate.from_messages() - 消息组合

### 作用
为聊天模型创建包含多个角色消息的Prompt模板。

### 基础用法

```python
from langchain_core.prompts import ChatPromptTemplate

# 使用元组定义消息
template = ChatPromptTemplate.from_messages([
    ("system", "你是一个{role}"),
    ("human", "{question}")
])

# 格式化为消息列表
messages = template.format_messages(
    role="Python专家",
    question="什么是装饰器?"
)

# 输出是消息对象列表
print(type(messages[0]))  # <class 'langchain_core.messages.system.SystemMessage'>
print(type(messages[1]))  # <class 'langchain_core.messages.human.HumanMessage'>
```

### 支持的消息角色

```python
from langchain_core.prompts import ChatPromptTemplate

# 支持的角色
template = ChatPromptTemplate.from_messages([
    ("system", "系统消息: {instruction}"),
    ("human", "用户消息: {user_input}"),
    ("ai", "助手消息: {previous_response}"),
    ("function", "函数消息: {function_result}")
])

messages = template.format_messages(
    instruction="你是编程专家",
    user_input="什么是递归?",
    previous_response="递归是一种编程技巧...",
    function_result="代码执行结果..."
)

for msg in messages:
    print(f"{type(msg).__name__}: {msg.content[:30]}...")
```

### 动态构建多轮对话

```python
from langchain_core.prompts import ChatPromptTemplate

template = ChatPromptTemplate.from_messages([
    ("system", """你是一个友好的编程助手。
要求:
1. 给出清晰的解释
2. 提供代码示例
3. 不超过500字"""),
    ("human", "第一个问题: {q1}"),
    ("ai", "{a1}"),
    ("human", "追问: {q2}"),
])

messages = template.format_messages(
    q1="什么是Python?",
    a1="Python是一门简洁易学的编程语言...",
    q2="那Ruby呢?"
)

# 这样可以重现之前的对话上下文
```

### 与invoke()配合

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

template = ChatPromptTemplate.from_messages([
    ("system", "你是{role}"),
    ("human", "{question}")
])

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

# 方式1: 分开处理
messages = template.format_messages(
    role="编程专家",
    question="如何写出高质量代码?"
)
response = llm.invoke(messages)

# 方式2: 使用LCEL管道(更简洁)
chain = template | llm

response = chain.invoke({
    "role": "编程专家",
    "question": "如何写出高质量代码?"
})

print(response.content)
```

## 3️⃣ FewShotPromptTemplate - 少样本学习

### 作用
通过给出几个示例来指导LLM的输出格式和风格。

### 静态示例的基础用法

```python
from langchain_core.prompts import FewShotPromptTemplate, PromptTemplate

# 定义示例
examples = [
    {
        "input": "happy",
        "output": "sad"
    },
    {
        "input": "tall",
        "output": "short"
    }
]

# 定义如何格式化每个示例
example_prompt = PromptTemplate(
    input_variables=["input", "output"],
    template="Input: {input}\nOutput: {output}"
)

# 创建Few-Shot模板
template = FewShotPromptTemplate(
    examples=examples,
    example_prompt=example_prompt,
    prefix="给出单词的反义词:\n",
    suffix="Input: {word}\nOutput:",
    input_variables=["word"]
)

# 使用
prompt = template.format(word="big")
print(prompt)
# 输出包含示例 + 实际问题
```

### 动态示例选择

```python
from langchain_core.prompts import FewShotPromptTemplate, PromptTemplate
from langchain_core.prompts.few_shot import SemanticSimilarityExampleSelector
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import Chroma

# 定义示例库(可以很大)
examples = [
    {"input": "幸福", "output": "快乐是内心的满足感"},
    {"input": "悲伤", "output": "悲伤是对损失的感受"},
    {"input": "勇气", "output": "勇气是在恐惧中坚持的能力"},
    {"input": "智慧", "output": "智慧是正确判断和行动的能力"},
    {"input": "爱", "output": "爱是对他人的无条件关怀"},
    {"input": "恐惧", "output": "恐惧是对未知的警惕反应"},
]

# 使用语义相似度自动选择最相关的示例
example_selector = SemanticSimilarityExampleSelector.from_examples(
    examples,
    OpenAIEmbeddings(),
    Chroma,
    k=2  # 每次选择2个最相关的示例
)

# 创建Few-Shot模板(使用动态选择器)
template = FewShotPromptTemplate(
    example_selector=example_selector,
    example_prompt=PromptTemplate(
        input_variables=["input", "output"],
        template="词语: {input}\n定义: {output}"
    ),
    prefix="根据示例定义词语:\n",
    suffix="词语: {word}\n定义:",
    input_variables=["word"]
)

# 使用：会自动选择最相关的示例！
prompt = template.format(word="希望")
print(prompt)
# 可以看到自动选择了"勇气"、"幸福"等相关词的示例
```

### 示例数量的影响

```python
from langchain_core.prompts import FewShotPromptTemplate, PromptTemplate
from langchain_openai import ChatOpenAI

# 相同的示例库，不同数量
examples = [
    {"input": "happy", "output": "sad"},
    {"input": "tall", "output": "short"},
    {"input": "bright", "output": "dark"},
    {"input": "clean", "output": "dirty"},
    {"input": "strong", "output": "weak"},
]

example_prompt = PromptTemplate(
    input_variables=["input", "output"],
    template="Input: {input}\nOutput: {output}"
)

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

test_word = "big"

for num_examples in [1, 3, 5]:
    template = FewShotPromptTemplate(
        examples=examples[:num_examples],
        example_prompt=example_prompt,
        prefix="给出反义词:\n",
        suffix="Input: {word}\nOutput:",
        input_variables=["word"]
    )

    prompt = template.format(word=test_word)
    tokens = len(prompt.split())

    response = llm.invoke(prompt)

    print(f"\n{num_examples}个示例:")
    print(f"  Prompt Token数: ~{tokens}")
    print(f"  回复: {response.content}")

# 观察：更多示例会增加成本，但可能提高精度
```

## 4️⃣ partial() - 部分变量填充

### 作用
提前填充某些变量，剩下的变量后续再填充。

### 基础用法

```python
from langchain_core.prompts import PromptTemplate

# 定义模板(3个变量)
template = PromptTemplate(
    input_variables=["topic", "language", "length"],
    template="Write a {length} word {language} article about {topic}"
)

# 部分填充：固定language和length
preset_template = template.partial(
    language="English",
    length=200
)

# 使用时只需提供topic
prompt = preset_template.format(topic="AI")
print(prompt)
# 输出: Write a 200 word English article about AI
```

### 动态部分变量(使用函数)

```python
from langchain_core.prompts import PromptTemplate
from datetime import datetime

# 使用函数动态填充
template = PromptTemplate(
    input_variables=["task"],
    template="Today is {date}, please {task}",
    partial_variables={
        "date": lambda: datetime.now().strftime("%Y-%m-%d")
    }
)

# 每次format都会调用函数，获取当前日期
prompt1 = template.format(task="summarize the news")
print(prompt1)

import time
time.sleep(1)

prompt2 = template.format(task="write a report")
print(prompt2)

# 注意：两次的日期可能不同(如跨天的话)
```

### 实际应用：多用户隔离

```python
from langchain_core.prompts import PromptTemplate

# 基础模板
base_template = PromptTemplate(
    input_variables=["user_input"],
    template="""You are assisting user {user_id} with {user_type} account.

User input: {user_input}

Response:""",
    partial_variables={}
)

def create_user_prompt(user_id: str, user_type: str):
    """为每个用户创建预设的模板"""
    return base_template.partial(
        user_id=user_id,
        user_type=user_type
    )

# 为不同用户创建预设
admin_template = create_user_prompt("admin_001", "administrator")
user_template = create_user_prompt("user_123", "regular")

# 使用时各自独立
admin_prompt = admin_template.format(user_input="delete user account")
user_prompt = user_template.format(user_input="reset password")
```

## 5️⃣ save() 和 load_prompt() - 序列化

### 作用
将Prompt保存为文件以便版本控制，从文件加载以便复用。

### 保存为JSON

```python
from langchain_core.prompts import PromptTemplate
from pathlib import Path

# 创建Prompt
template = PromptTemplate.from_template(
    "Translate {text} to {language}"
)

# 保存为JSON
Path("prompts").mkdir(exist_ok=True)
template.save("prompts/translate.json")

# 查看保存的内容
import json
with open("prompts/translate.json") as f:
    print(json.dumps(json.load(f), indent=2))
```

### 保存为YAML(推荐)

```yaml
# prompts/translate.yaml
_type: prompt
input_variables:
  - text
  - language
template: |
  Translate {text} to {language}
template_format: f-string
```

```python
from langchain_core.prompts import load_prompt

# 加载YAML格式的Prompt
template = load_prompt("prompts/translate.yaml")

prompt = template.format(text="Hello", language="Chinese")
```

### 保存Few-Shot模板

```yaml
# prompts/few_shot_demo.yaml
_type: few_shot
input_variables:
  - word
examples:
  - input: happy
    output: sad
  - input: tall
    output: short
example_prompt:
  _type: prompt
  input_variables: [input, output]
  template: "Input: {input}\nOutput: {output}"
prefix: "给出反义词:\n"
suffix: "Input: {word}\nOutput:"
template_format: f-string
```

## 6️⃣ Prompt模板的链接与组合

### 作用
组合多个模板实现复杂的Prompt逻辑。

### 基础组合

```python
from langchain_core.prompts import PromptTemplate

# 子模板1
system_template = PromptTemplate.from_template(
    "You are a professional {role}."
)

# 子模板2
task_template = PromptTemplate.from_template(
    "Your task: {task}"
)

# 子模板3
input_template = PromptTemplate.from_template(
    "Input: {input}"
)

# 手动组合
combined_template = PromptTemplate.from_template(
    """{system}

{task}

{input}

Output:"""
)

# 使用
system = system_template.format(role="translator")
task = task_template.format(task="translate English to Chinese")
input_text = input_template.format(input="Hello World")

final_prompt = combined_template.format(
    system=system,
    task=task,
    input=input_text
)

print(final_prompt)
```

### 使用LCEL管道 : 组合多个组件实现复杂逻辑

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

# 定义Prompt
template = ChatPromptTemplate.from_messages([
    ("system", "你是{role}"),
    ("human", "{question}")
])

# 定义LLM
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

# 使用管道组合(最简洁)
chain = template | llm

# 调用
response = chain.invoke({
    "role": "Python专家",
    "question": "什么是装饰器?"
})

print(response.content)
```

## 📝 速查表

### 何时使用哪个方法？

| 需求 | 推荐方法 | 示例 |
|------|---------|------|
| 简单模板 | `from_template()` | `"Write a {topic} essay"` |
| 聊天消息 | `ChatPromptTemplate.from_messages()` | System + Human消息 |
| 少样本 | `FewShotPromptTemplate` | 给3-5个示例指导格式 |
| 动态示例 | `SemanticSimilarityExampleSelector` | 自动选择相关示例 |
| 部分填充 | `partial()` | 预设某些变量 |
| 持久化 | `save()/load_prompt()` | 版本控制和复用 |

### Prompt设计的黄金法则

| 原则 | 示例 |
|------|------|
| **清晰指令** | ❌"分析这个"vs ✅"用100字总结核心观点" |
| **角色设定** | ❌"帮我翻译"vs ✅"你是专业翻译，翻译这个" |
| **格式说明** | ❌"返回什么"vs ✅"格式: JSON, 包含name和age" |
| **示例** | ❌长说明 vs ✅3个Few-Shot示例 |
| **约束条件** | ❌自由发挥vs ✅"不超过100字"、"只基于事实" |
