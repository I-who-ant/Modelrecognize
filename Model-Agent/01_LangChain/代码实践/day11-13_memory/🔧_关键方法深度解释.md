# 🔧 Day 11-13 关键方法深度解释

## 1️⃣ ConversationBufferMemory - 完整对话历史

### 作用
保存完整的对话历史（Human和AI消息），适合短对话场景。

### 基础用法

```python
from langchain.memory import ConversationBufferMemory

# 创建Memory
memory = ConversationBufferMemory()

# 手动添加对话
memory.save_context(
    {"input": "你好"},
    {"output": "你好！有什么可以帮你？"}
)

memory.save_context(
    {"input": "我叫老王"},
    {"output": "很高兴认识你，老王！"}
)

# 查看历史
history = memory.load_memory_variables({})
print(history['history'])
# Human: 你好
# AI: 你好！有什么可以帮你？
# Human: 我叫老王
# AI: 很高兴认识你，老王！

# 清空Memory
memory.clear()
```

### 与ConversationChain结合

```python
from langchain.chains import ConversationChain
from langchain_openai import ChatOpenAI

memory = ConversationBufferMemory()
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

conversation = ConversationChain(
    llm=llm,
    memory=memory,
    verbose=True  # 显示Prompt，看Memory如何工作
)

# 多轮对话
response1 = conversation.predict(input="我是一名AI工程师")
response2 = conversation.predict(input="我的职业是什么?")
# AI: "你是一名AI工程师" ← 记住了！
```

### 关键参数详解

```python
from langchain.memory import ConversationBufferMemory

memory = ConversationBufferMemory(
    # ===== 关键参数 =====
    memory_key="history",          # Memory在prompt中的变量名
    input_key="input",             # 用户输入的key
    output_key="output",           # AI输出的key
    return_messages=False,         # 返回字符串还是消息列表（重要！）

    # ===== 高级参数 =====
    human_prefix="Human",          # 用户消息前缀
    ai_prefix="AI"                 # AI消息前缀
)

# return_messages详解：
# False（默认）: 返回格式化字符串
# "Human: 你好\nAI: 你好！"

# True: 返回消息列表
# [HumanMessage(content='你好'), AIMessage(content='你好！')]
```

### return_messages的重要性

```python
# ❌ return_messages=False - 用于普通ConversationChain
memory1 = ConversationBufferMemory(return_messages=False)
# 返回: "Human: ...\nAI: ..."

# ✅ return_messages=True - 用于ConversationalRetrievalChain
memory2 = ConversationBufferMemory(return_messages=True)
# 返回: [HumanMessage(...), AIMessage(...)]

# 规则：
# - ConversationChain → return_messages=False
# - ConversationalRetrievalChain → return_messages=True (必须！)
```

## 2️⃣ ConversationBufferWindowMemory - 滑动窗口

### 作用
只保留最近k轮对话，控制Token消耗和成本。

### 基础用法

```python
from langchain.memory import ConversationBufferWindowMemory

# 只保留最近k=3轮对话
memory = ConversationBufferWindowMemory(k=3)

# 添加5轮对话
for i in range(5):
    memory.save_context(
        {"input": f"第{i+1}轮问题"},
        {"output": f"第{i+1}轮回答"}
    )

# 查看Memory - 只包含最近3轮
history = memory.load_memory_variables({})
print(history['history'])
# 只包含：第3轮、第4轮、第5轮
```

### k值的选择策略

```python
# 根据场景选择k值

# k=1: 极度成本敏感，只需要上一轮
memory_k1 = ConversationBufferWindowMemory(k=1)

# k=3: 客服场景（最近3轮通常足够）
memory_k3 = ConversationBufferWindowMemory(k=3)

# k=5: 通用对话（推荐）
memory_k5 = ConversationBufferWindowMemory(k=5)

# k=10: 复杂任务（需要更多上下文）
memory_k10 = ConversationBufferWindowMemory(k=10)

# 权衡：
# - k越小：Token越少，成本越低，但可能丢失重要信息
# - k越大：上下文越完整，但Token消耗更高
```

### Token消耗对比

```python
from langchain.callbacks import get_openai_callback
from langchain.chains import ConversationChain
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

# 场景1：BufferMemory（完整历史）
buffer_memory = ConversationBufferMemory()
conv_buffer = ConversationChain(llm=llm, memory=buffer_memory)

# 场景2：WindowMemory（k=3）
window_memory = ConversationBufferWindowMemory(k=3)
conv_window = ConversationChain(llm=llm, memory=window_memory)

# 10轮对话，对比Token消耗
for i in range(10):
    with get_openai_callback() as cb_buffer:
        conv_buffer.predict(input=f"问题{i+1}")
        buffer_tokens = cb_buffer.total_tokens

    with get_openai_callback() as cb_window:
        conv_window.predict(input=f"问题{i+1}")
        window_tokens = cb_window.total_tokens

    print(f"第{i+1}轮 - Buffer: {buffer_tokens}, Window: {window_tokens}")

# 预期结果：
# 第1轮 - Buffer: 50, Window: 50
# 第5轮 - Buffer: 250, Window: 150
# 第10轮 - Buffer: 500, Window: 150 ← 显著差异！
```

## 3️⃣ ConversationSummaryMemory - 摘要压缩

### 作用
将对话历史压缩成摘要，节省Token消耗，适合超长对话。

### 基础用法

```python
from langchain.memory import ConversationSummaryMemory
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

# 创建摘要Memory（需要LLM）
memory = ConversationSummaryMemory(llm=llm)

# 添加对话
memory.save_context(
    {"input": "我是一名AI工程师"},
    {"output": "很高兴认识你！"}
)

memory.save_context(
    {"input": "我在研究LangChain"},
    {"output": "LangChain是很好的框架！"}
)

memory.save_context(
    {"input": "我最近在学习Memory系统"},
    {"output": "Memory是实现智能对话的核心！"}
)

# 查看摘要
history = memory.load_memory_variables({})
print(history['history'])
# "对话者是一名AI工程师，正在研究LangChain，特别是Memory系统"
# ← 不是完整对话，而是压缩后的摘要
```

### 摘要的生成时机

```python
# 每次save_context时，LLM会生成/更新摘要

memory = ConversationSummaryMemory(llm=llm)

# 第1轮：生成初始摘要
memory.save_context({"input": "我叫老王"}, {"output": "你好老王"})
# 摘要："对话者叫老王"

# 第2轮：更新摘要（将新对话加入）
memory.save_context({"input": "我30岁"}, {"output": "了解"})
# 摘要："对话者叫老王，30岁"

# 第3轮：继续更新
memory.save_context({"input": "我住上海"}, {"output": "好的"})
# 摘要："对话者叫老王，30岁，住在上海"

# 成本分析：
# - 每轮对话调用1次LLM生成摘要（额外成本）
# - 检索时摘要Token << 完整历史Token（节省成本）
```

### 何时使用SummaryMemory

```
对话轮数 < 10轮:
  → 不推荐（生成摘要的成本 > 节省的成本）

对话轮数 10-20轮:
  → 可选（成本基本持平）

对话轮数 > 20轮:
  → 推荐（节省的成本 > 生成摘要的成本）
```

## 4️⃣ ConversationSummaryBufferMemory - 混合策略（推荐）

### 作用
结合摘要和滑动窗口，保留最近完整对话 + 早期摘要。

### 基础用法

```python
from langchain.memory import ConversationSummaryBufferMemory
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

# 混合策略Memory
memory = ConversationSummaryBufferMemory(
    llm=llm,
    max_token_limit=200  # Token限制
)

# 多轮对话
for i in range(10):
    memory.save_context(
        {"input": f"第{i+1}轮问题"},
        {"output": f"第{i+1}轮回答"}
    )

# 查看Memory
history = memory.load_memory_variables({})
print(history['history'])
# 包含：
# 1. 早期对话的摘要（压缩）
# 2. 最近几轮的完整对话（精准）
```

### max_token_limit的工作原理

```python
memory = ConversationSummaryBufferMemory(
    llm=llm,
    max_token_limit=200
)

# 工作流程：
# 1. 添加新对话
# 2. 检查总Token数
# 3. 如果超过max_token_limit:
#    - 将最早的对话压缩成摘要
#    - 保留最近的完整对话
# 4. 如果未超过:
#    - 保留完整对话

# 示例：
# Token < 200: 保留完整对话
# "Human: 问题1\nAI: 回答1\nHuman: 问题2\nAI: 回答2..."

# Token > 200: 部分压缩
# "摘要：之前讨论了问题1和问题2...\nHuman: 问题8\nAI: 回答8..."
```

### 参数选择指南

```python
# 场景1：客服对话（短期记忆为主）
memory = ConversationSummaryBufferMemory(
    llm=llm,
    max_token_limit=150  # 约保留最近3-5轮
)

# 场景2：教育对话（中期记忆）
memory = ConversationSummaryBufferMemory(
    llm=llm,
    max_token_limit=300  # 约保留最近7-10轮
)

# 场景3：长期咨询（长期记忆）
memory = ConversationSummaryBufferMemory(
    llm=llm,
    max_token_limit=500  # 约保留最近15-20轮
)

# 权衡：
# - max_token_limit越小：成本越低，但可能丢失重要上下文
# - max_token_limit越大：上下文越完整，但成本越高
```

## 5️⃣ VectorStoreRetrieverMemory - 语义检索记忆

### 作用
使用向量检索而非时间顺序存储，适合超长对话和精准回忆。

### 基础用法

```python
from langchain.memory import VectorStoreRetrieverMemory
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings

# 1. 创建向量库
vectorstore = Chroma(
    collection_name="conversation_memory",
    embedding_function=OpenAIEmbeddings(model="text-embedding-3-small")
)

# 2. 创建向量检索Memory
memory = VectorStoreRetrieverMemory(
    retriever=vectorstore.as_retriever(search_kwargs={"k": 2})
)

# 3. 添加记忆
memories = [
    ("我最喜欢的颜色是蓝色", "了解，你喜欢蓝色"),
    ("我的生日是5月1日", "记住了，5月1日是你的生日"),
    ("我住在上海", "好的，你住在上海"),
    ("我喜欢吃披萨", "披萨是美味的选择"),
    ("我有一只猫，叫咪咪", "很可爱的名字，咪咪"),
]

for user_input, ai_output in memories:
    memory.save_context(
        {"input": user_input},
        {"output": ai_output}
    )

# 4. 语义检索相关记忆
query = "什么时候是我的生日?"
relevant = memory.load_memory_variables({"prompt": query})
print(relevant['history'])
# 会检索到："我的生日是5月1日" 相关的记忆
```

### search_kwargs参数详解

```python
# k=2: 返回最相关的2条记忆
memory_k2 = VectorStoreRetrieverMemory(
    retriever=vectorstore.as_retriever(search_kwargs={"k": 2})
)

# k=5: 返回最相关的5条记忆
memory_k5 = VectorStoreRetrieverMemory(
    retriever=vectorstore.as_retriever(search_kwargs={"k": 5})
)

# 使用MMR（多样性）
memory_mmr = VectorStoreRetrieverMemory(
    retriever=vectorstore.as_retriever(
        search_type="mmr",
        search_kwargs={"k": 3, "fetch_k": 10}
    )
)

# 使用阈值过滤
memory_threshold = VectorStoreRetrieverMemory(
    retriever=vectorstore.as_retriever(
        search_type="similarity_score_threshold",
        search_kwargs={"score_threshold": 0.7, "k": 3}
    )
)
```

### 何时使用VectorStoreRetrieverMemory

```
场景1: 超长对话（>100轮）
  → 使用时间顺序Memory会超出上下文窗口

场景2: 需要回忆久远信息
  → "我在第5轮提到的那个项目是什么？"

场景3: 用户画像系统
  → 记住用户偏好、习惯、历史行为

场景4: 智能客服
  → 检索相关的历史问题和解决方案
```

## 6️⃣ ConversationalRetrievalChain - 对话式RAG

### 作用
结合Memory和RAG，实现对话式知识问答（支持追问和代词引用）。

### 基础用法

```python
from langchain.chains import ConversationalRetrievalChain
from langchain.memory import ConversationBufferMemory
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain_core.documents import Document

# 1. 准备知识库
docs = [
    Document(page_content="LangChain是一个用于开发LLM应用的框架"),
    Document(page_content="LangChain支持多种Memory类型"),
]

vectorstore = Chroma.from_documents(
    documents=docs,
    embedding=OpenAIEmbeddings(model="text-embedding-3-small")
)

# 2. 创建Memory（⚠️ 必须设置return_messages=True）
memory = ConversationBufferMemory(
    memory_key="chat_history",
    return_messages=True  # ← 关键！
)

# 3. 创建对话式RAG链
qa_chain = ConversationalRetrievalChain.from_llm(
    llm=ChatOpenAI(model="gpt-3.5-turbo", temperature=0),
    retriever=vectorstore.as_retriever(),
    memory=memory
)

# 4. 多轮对话
response1 = qa_chain.invoke({"question": "什么是LangChain?"})
print(f"AI: {response1['answer']}")

# 使用代词"它"追问
response2 = qa_chain.invoke({"question": "它支持哪些Memory类型?"})
print(f"AI: {response2['answer']}")
# AI能理解"它"指LangChain！
```

### 为什么必须设置return_messages=True？

```python
# ❌ 错误：return_messages=False
memory_wrong = ConversationBufferMemory(
    memory_key="chat_history",
    return_messages=False  # 返回字符串格式
)

qa_chain = ConversationalRetrievalChain.from_llm(
    llm=llm,
    retriever=retriever,
    memory=memory_wrong
)
# 会报错！ConversationalRetrievalChain需要消息列表，不是字符串

# ✅ 正确：return_messages=True
memory_correct = ConversationBufferMemory(
    memory_key="chat_history",
    return_messages=True  # 返回消息列表
)

qa_chain = ConversationalRetrievalChain.from_llm(
    llm=llm,
    retriever=retriever,
    memory=memory_correct
)
# 正常工作！
```

### 自定义检索策略

```python
from langchain.chains import ConversationalRetrievalChain

# 策略1：Similarity（默认）
qa_chain_similarity = ConversationalRetrievalChain.from_llm(
    llm=llm,
    retriever=vectorstore.as_retriever(
        search_type="similarity",
        search_kwargs={"k": 3}
    ),
    memory=memory
)

# 策略2：MMR（多样性）
qa_chain_mmr = ConversationalRetrievalChain.from_llm(
    llm=llm,
    retriever=vectorstore.as_retriever(
        search_type="mmr",
        search_kwargs={"k": 3, "fetch_k": 10}
    ),
    memory=memory
)

# 策略3：Threshold（质量优先）
qa_chain_threshold = ConversationalRetrievalChain.from_llm(
    llm=llm,
    retriever=vectorstore.as_retriever(
        search_type="similarity_score_threshold",
        search_kwargs={"score_threshold": 0.7, "k": 3}
    ),
    memory=memory
)
```

## 7️⃣ save_context() vs load_memory_variables()

### save_context() - 保存对话

```python
from langchain.memory import ConversationBufferMemory

memory = ConversationBufferMemory()

# 保存对话
memory.save_context(
    inputs={"input": "用户说的话"},
    outputs={"output": "AI说的话"}
)

# 批量保存
conversations = [
    ({"input": "你好"}, {"output": "你好！"}),
    ({"input": "再见"}, {"output": "再见！"}),
]

for inputs, outputs in conversations:
    memory.save_context(inputs, outputs)
```

### load_memory_variables() - 加载历史

```python
# 加载完整历史
history = memory.load_memory_variables({})
print(history['history'])
# "Human: 你好\nAI: 你好！\nHuman: 再见\nAI: 再见！"

# 传入空字典即可（某些Memory类型可能需要额外参数）
history = memory.load_memory_variables({})

# 查看具体消息
messages = memory.chat_memory.messages
for msg in messages:
    print(f"{msg.type}: {msg.content}")
# human: 你好
# ai: 你好！
```

## 📝 速查表

### 何时使用哪种Memory？

| 场景 | 推荐Memory | 原因 |
|------|-----------|------|
| 短对话(< 10轮) | `ConversationBufferMemory` | 成本可接受，保留完整上下文 |
| 中等对话(10-30轮) | `ConversationBufferWindowMemory` | 控制成本，保留最近上下文 |
| 长对话(30-100轮) | `ConversationSummaryBufferMemory` | 平衡效果和成本 |
| 超长对话(>100轮) | `VectorStoreRetrieverMemory` | 语义检索，只加载相关上下文 |
| 对话式RAG | `ConversationBufferMemory` + `ConversationalRetrievalChain` | 支持追问和代词引用 |

### Memory参数速查表

| Memory类型 | 关键参数 | 默认值 | 用途 |
|-----------|---------|--------|------|
| `ConversationBufferMemory` | `return_messages` | `False` | 返回格式（字符串/消息列表） |
| `ConversationBufferWindowMemory` | `k` | 无 | 保留最近k轮对话 |
| `ConversationSummaryMemory` | `llm` | 必需 | 生成摘要的LLM |
| `ConversationSummaryBufferMemory` | `max_token_limit` | 无 | Token限制 |
| `VectorStoreRetrieverMemory` | `retriever` | 必需 | 向量检索器 |

### Token消耗对比（10轮对话）

| Memory类型 | Token消耗 | 成本 | 适用场景 |
|-----------|----------|------|---------|
| `BufferMemory` | ~500 tokens | ⚠️ 高 | 短对话 |
| `WindowMemory(k=3)` | ~150 tokens | ✅ 低 | 通用对话 |
| `SummaryMemory` | ~200 tokens | ⭐ 中 | 长对话 |
| `SummaryBufferMemory` | ~250 tokens | ⭐ 中 | 推荐 |
| `VectorMemory` | ~100 tokens | ✅ 低 | 超长对话 |
