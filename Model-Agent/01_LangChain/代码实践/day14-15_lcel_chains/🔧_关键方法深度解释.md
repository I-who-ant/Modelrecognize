## 1️⃣ | 操作符 - LCEL的核心语法

### 作用
使用管道操作符 `|` 连接多个组件，形成数据流管道。

### 基础用法

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

# 创建组件
prompt = ChatPromptTemplate.from_template("讲一个关于{topic}的笑话")
llm = ChatOpenAI(model="gpt-3.5-turbo")
parser = StrOutputParser()

# 使用 | 连接
chain = prompt | llm | parser

# 等价于
def manual_chain(input_data):
    step1 = prompt.invoke(input_data)
    step2 = llm.invoke(step1)
    step3 = parser.invoke(step2)
    return step3

# 使用链
result = chain.invoke({"topic": "程序员"})
print(result)
```

### 数据流转过程

```python
chain = prompt | llm | parser

# 数据流：
# 1. 输入: {"topic": "程序员"}
#    ↓
# 2. prompt.invoke() → ChatPromptValue
#    [HumanMessage(content="讲一个关于程序员的笑话")]
#    ↓
# 3. llm.invoke() → AIMessage
#    AIMessage(content="为什么程序员喜欢黑暗？因为光太多会有bug！")
#    ↓
# 4. parser.invoke() → str
#    "为什么程序员喜欢黑暗？因为光太多会有bug！"
#    ↓
# 5. 输出: 字符串
```

### 多步骤链组合

```python
# 步骤1: 生成大纲
outline_chain = (
    ChatPromptTemplate.from_template("为'{topic}'写一个3点大纲")
    | llm | StrOutputParser()
)

# 步骤2: 扩展第一点
expand_chain = (
    ChatPromptTemplate.from_template("扩展以下要点:\n{outline}")
    | llm | StrOutputParser()
)

# 组合：大纲 → 转换 → 扩展
full_chain = (
    outline_chain
    | (lambda x: {"outline": x.split('\n')[0]})  # 取第一点
    | expand_chain
)

# 执行
result = full_chain.invoke({"topic": "人工智能"})
```

## 2️⃣ invoke() vs batch() vs stream()

### invoke() - 同步调用

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

chain = (
    ChatPromptTemplate.from_template("用一句话介绍{topic}")
    | ChatOpenAI(model="gpt-3.5-turbo")
    | StrOutputParser()
)

# 同步调用 - 阻塞等待结果
result = chain.invoke({"topic": "LangChain"})
print(result)
# "LangChain是一个用于开发大语言模型应用的框架"

# 使用场景：
# - 单个请求
# - 同步程序
# - 简单脚本
```

### batch() - 批量处理

```python
# 批量处理多个输入
inputs = [
    {"topic": "Python"},
    {"topic": "JavaScript"},
    {"topic": "Rust"}
]

# 批量调用（显著更快！）
results = chain.batch(inputs)

for i, result in enumerate(results, 1):
    print(f"{i}. {result}")

# 1. Python是一种高级编程语言...
# 2. JavaScript是一种客户端脚本语言...
# 3. Rust是一种系统编程语言...
```

### batch()的性能优势

```python
import time

inputs = [{"topic": f"主题{i}"} for i in range(10)]

# 方法1: 循环调用（慢）
start = time.time()
results1 = []
for inp in inputs:
    result = chain.invoke(inp)
    results1.append(result)
time1 = time.time() - start

# 方法2: 批量调用（快）
start = time.time()
results2 = chain.batch(inputs)
time2 = time.time() - start

print(f"循环调用: {time1:.2f}秒")
print(f"批量调用: {time2:.2f}秒")
print(f"性能提升: {time1/time2:.1f}x")

# 典型结果：
# 循环调用: 25.3秒
# 批量调用: 4.8秒
# 性能提升: 5.3x
```

### stream() - 流式输出

```python
# 流式输出 - 实时显示生成结果
print("结果: ", end="", flush=True)
for chunk in chain.stream({"topic": "人工智能"}):
    print(chunk, end="", flush=True)
print()

# 结果: 人工智能是一种模拟人类智能的技术...
#      （逐字符实时输出）

# 使用场景：
# - 长文本生成
# - 聊天机器人
# - 需要实时反馈的应用
```

## 3️⃣ RunnablePassthrough - 传递输入

### 作用
将输入原样传递到输出，常用于RAG场景（同时需要问题和检索到的上下文）。

### 基础用法

```python
from langchain_core.runnables import RunnablePassthrough

# 场景：需要同时传递多个字段
chain = {
    "context": lambda x: retrieve(x["question"]),  # 检索上下文
    "question": RunnablePassthrough()              # 传递原始问题
} | rag_prompt | llm | StrOutputParser()

# 输入: {"question": "LangChain是什么?"}
# 输出字典:
# {
#   "context": "检索到的相关文档...",
#   "question": "LangChain是什么?"  ← RunnablePassthrough传递
# }
```

### 完整RAG示例

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

# 模拟知识库
knowledge_base = {
    "langchain": "LangChain是一个用于开发LLM应用的框架",
    "memory": "Memory让LLM能够记住对话历史",
}

def retrieve(question: str) -> str:
    """简单检索函数"""
    for key, value in knowledge_base.items():
        if key in question.lower():
            return value
    return "没有找到相关信息"

# RAG Prompt
rag_prompt = ChatPromptTemplate.from_template("""
基于以下上下文回答问题:

上下文: {context}

问题: {question}

回答:
""")

# RAG链
rag_chain = (
    {
        "context": lambda x: retrieve(x["question"]),
        "question": RunnablePassthrough()
    }
    | (lambda x: {"context": x["context"], "question": x["question"]})
    | rag_prompt
    | ChatOpenAI(model="gpt-3.5-turbo", temperature=0)
    | StrOutputParser()
)

# 使用
result = rag_chain.invoke({"question": "什么是LangChain?"})
print(result)
```

### 简化写法对比

```python
# ❌ 复杂写法：使用RunnablePassthrough
chain1 = {
    "context": retriever,
    "question": RunnablePassthrough()
} | rag_prompt | llm

# ✅ 简化写法：直接用lambda
chain2 = {
    "context": retriever,
    "question": lambda x: x["question"]
} | rag_prompt | llm

# 两者等价，但lambda更明确
```

## 4️⃣ RunnableParallel - 并行执行

### 作用
同时执行多个独立任务，显著提升性能。

### 基础用法

```python
from langchain_core.runnables import RunnableParallel
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0.7)

# 创建3个独立的链
joke_chain = (
    ChatPromptTemplate.from_template("讲一个关于{topic}的笑话")
    | llm | StrOutputParser()
)

poem_chain = (
    ChatPromptTemplate.from_template("写一首关于{topic}的诗")
    | llm | StrOutputParser()
)

fact_chain = (
    ChatPromptTemplate.from_template("说一个关于{topic}的事实")
    | llm | StrOutputParser()
)

# 并行执行
parallel_chain = RunnableParallel(
    joke=joke_chain,
    poem=poem_chain,
    fact=fact_chain
)

# 调用 - 3个任务同时执行
results = parallel_chain.invoke({"topic": "人工智能"})

print(f"笑话:\n{results['joke']}\n")
print(f"诗歌:\n{results['poem']}\n")
print(f"事实:\n{results['fact']}\n")
```

### 性能对比

```python
import time

# 串行执行
start = time.time()
joke = joke_chain.invoke({"topic": "AI"})
poem = poem_chain.invoke({"topic": "AI"})
fact = fact_chain.invoke({"topic": "AI"})
serial_time = time.time() - start

# 并行执行
start = time.time()
results = parallel_chain.invoke({"topic": "AI"})
parallel_time = time.time() - start

print(f"串行执行: {serial_time:.2f}秒")
print(f"并行执行: {parallel_time:.2f}秒")
print(f"性能提升: {serial_time/parallel_time:.1f}x")

# 典型结果：
# 串行执行: 15.2秒
# 并行执行: 5.8秒
# 性能提升: 2.6x
```

### 使用场景

```python
# 场景1: 多角度分析
parallel_analysis = RunnableParallel(
    summary=summary_chain,
    sentiment=sentiment_chain,
    keywords=keywords_chain
)

# 场景2: A/B测试
parallel_ab = RunnableParallel(
    version_a=chain_a,
    version_b=chain_b
)

# 场景3: 多模型对比
parallel_models = RunnableParallel(
    gpt4=gpt4_chain,
    gpt35=gpt35_chain,
    claude=claude_chain
)
```

## 5️⃣ RunnableBranch - 条件路由

### 作用
根据输入条件，路由到不同的处理链。

### 基础用法

```python
from langchain_core.runnables import RunnableBranch
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

# 定义不同类型的处理链
translation_chain = (
    ChatPromptTemplate.from_template("将以下文本翻译成中文:\n{text}")
    | llm | StrOutputParser()
)

summary_chain = (
    ChatPromptTemplate.from_template("总结以下文本:\n{text}")
    | llm | StrOutputParser()
)

qa_chain = (
    ChatPromptTemplate.from_template("回答问题:\n{text}")
    | llm | StrOutputParser()
)

# 条件判断函数
def is_translation(x):
    return "翻译" in x.get("text", "")

def is_summary(x):
    return "总结" in x.get("text", "")

# 创建路由链
branch = RunnableBranch(
    (is_translation, translation_chain),  # 条件1
    (is_summary, summary_chain),          # 条件2
    qa_chain  # 默认链
)

# 测试
result1 = branch.invoke({"text": "请翻译: Hello World"})
print(f"翻译: {result1}")

result2 = branch.invoke({"text": "请总结: LangChain是一个很好用的框架"})
print(f"总结: {result2}")

result3 = branch.invoke({"text": "什么是AI?"})
print(f"问答: {result3}")
```

### 工作流程

```
输入 → 检查条件1?
        ├─ True → 链1
        ├─ False → 检查条件2?
                   ├─ True → 链2
                   └─ False → 默认链
```

### 实际应用场景

```python
# 场景1: 智能客服路由
def is_order_query(x):
    return any(word in x["query"] for word in ["订单", "配送", "物流"])

def is_refund_query(x):
    return any(word in x["query"] for word in ["退款", "退货", "退换"])

def is_tech_support(x):
    return any(word in x["query"] for word in ["技术", "bug", "故障"])

customer_service = RunnableBranch(
    (is_order_query, order_chain),
    (is_refund_query, refund_chain),
    (is_tech_support, tech_support_chain),
    general_chain  # 默认：通用咨询
)

# 场景2: 多语言处理
def detect_language(text):
    # 简单语言检测
    if all('\u4e00' <= char <= '\u9fff' for char in text if char.strip()):
        return "zh"
    return "en"

multilang_branch = RunnableBranch(
    (lambda x: detect_language(x["text"]) == "en", english_chain),
    (lambda x: detect_language(x["text"]) == "zh", chinese_chain),
    default_chain
)
```

## 6️⃣ with_fallbacks() - 失败回退

### 作用
主链失败时，自动切换到备选链，提高系统可靠性。

### 基础用法

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

# 主LLM（可能失败）
primary_llm = ChatOpenAI(
    model="gpt-4",
    temperature=0,
    request_timeout=1  # 短超时，容易失败
)

# 备用LLM
backup_llm = ChatOpenAI(
    model="gpt-3.5-turbo",
    temperature=0
)

prompt = ChatPromptTemplate.from_template("用一句话介绍{topic}")

# 创建带回退的链
chain_with_fallback = (
    prompt
    | primary_llm.with_fallbacks([backup_llm])
    | StrOutputParser()
)

# 使用
result = chain_with_fallback.invoke({"topic": "LangChain"})
print(result)
# 如果primary_llm失败，会自动使用backup_llm
```

### 多级回退

```python
# 主链 → 备选1 → 备选2 → 备选3
chain = (
    prompt
    | primary_llm.with_fallbacks([
        backup_llm_1,
        backup_llm_2,
        backup_llm_3
    ])
    | StrOutputParser()
)

# 依次尝试，直到成功或全部失败
```

### 使用场景

```python
# 场景1: 模型降级
# gpt-4失败 → gpt-3.5-turbo
llm_with_fallback = ChatOpenAI(model="gpt-4").with_fallbacks([
    ChatOpenAI(model="gpt-3.5-turbo")
])

# 场景2: 服务降级
# OpenAI失败 → Azure OpenAI → 本地模型
llm_with_fallback = openai_llm.with_fallbacks([
    azure_llm,
    local_llm
])

# 场景3: 超时保护
# 长超时主链 → 短超时备选链
llm_with_fallback = ChatOpenAI(
    request_timeout=10
).with_fallbacks([
    ChatOpenAI(request_timeout=3)
])

# 场景4: 成本控制
# 昂贵模型失败 → 便宜模型
llm_with_fallback = expensive_llm.with_fallbacks([
    cheap_llm
])
```

## 7️⃣ ainvoke() vs astream() - 异步方法

### ainvoke() - 异步调用

```python
import asyncio
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

chain = (
    ChatPromptTemplate.from_template("用一句话介绍{topic}")
    | ChatOpenAI(model="gpt-3.5-turbo")
    | StrOutputParser()
)

# 异步调用
async def async_example():
    result = await chain.ainvoke({"topic": "AI"})
    print(result)

# 运行异步函数
asyncio.run(async_example())
```

### 并发处理多个查询

```python
async def process_multiple_queries():
    # 并发处理多个查询
    tasks = [
        chain.ainvoke({"topic": "Python"}),
        chain.ainvoke({"topic": "JavaScript"}),
        chain.ainvoke({"topic": "Rust"})
    ]

    results = await asyncio.gather(*tasks)
    return results

# 运行
results = asyncio.run(process_multiple_queries())
for i, result in enumerate(results, 1):
    print(f"{i}. {result}")

# 性能：接近单个查询的时间（并发执行）
```

### astream() - 异步流式

```python
async def async_stream_example():
    print("结果: ", end="", flush=True)
    async for chunk in chain.astream({"topic": "AI"}):
        print(chunk, end="", flush=True)
    print()

asyncio.run(async_stream_example())
```

## 📝 速查表

### Runnable方法对比

| 方法 | 用途 | 性能 | 适用场景 |
|------|------|------|---------|
| `invoke()` | 同步调用 | 中 | 单个请求、同步程序 |
| `batch()` | 批量处理 | ⭐⭐⭐⭐⭐ | 多个输入、高效处理 |
| `stream()` | 流式输出 | 中 | 长文本、实时反馈 |
| `ainvoke()` | 异步调用 | ⭐⭐⭐⭐ | 高并发、异步程序 |
| `astream()` | 异步流式 | ⭐⭐⭐⭐ | 异步聊天机器人 |

### 核心组件速查

| 组件 | 用途 | 代码示例 |
|------|------|----------|
| `\|` 操作符 | 连接组件 | `prompt \| llm \| parser` |
| `RunnablePassthrough` | 传递输入 | `{"question": RunnablePassthrough()}` |
| `RunnableParallel` | 并行执行 | `RunnableParallel(task1=chain1, task2=chain2)` |
| `RunnableBranch` | 条件路由 | `RunnableBranch((condition, chain), default)` |
| `with_fallbacks` | 失败回退 | `primary.with_fallbacks([backup])` |

### 性能优化速查

| 优化方法 | 性能提升 | 使用场景 |
|---------|---------|---------|
| `batch()` 替代循环 | 5-10x | 多个输入 |
| `RunnableParallel` | 2-3x | 独立任务 |
| `ainvoke()` 并发 | 2-5x | 异步场景 |
| `stream()` | 用户体验↑ | 长文本生成 |

### 何时使用哪个组件？

| 需求 | 推荐组件 | 原因 |
|------|---------|------|
| 简单串联 | `\|` 操作符 | 简洁优雅 |
| 同时传递多个字段 | `RunnablePassthrough` | RAG场景 |
| 独立任务并行 | `RunnableParallel` | 显著提速 |
| 条件分支 | `RunnableBranch` | 智能路由 |
| 失败保护 | `with_fallbacks` | 提高可靠性 |
| 批量处理 | `batch()` | 5-10x提速 |
| 实时反馈 | `stream()` | 用户体验 |
| 高并发 | `ainvoke()` | 异步优势 |
