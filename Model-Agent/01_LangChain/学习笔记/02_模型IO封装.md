## 📖 Chat Models vs LLMs

### 核心区别

LangChain提供了两种主要的模型抽象：**Chat Models**和**LLMs**

```
┌─────────────────────────────────────────────────┐
│         Chat Models vs LLMs 对比                 │
├─────────────────────────────────────────────────┤
│                                                 │
│  Chat Models (对话模型)                          │
│  ┌─────────────────────────────────────┐       │
│  │ 输入: 消息列表(Message List)         │       │
│  │ 输出: 消息对象(Message)               │       │
│  │ 代表: ChatGPT, Claude, 文心一言      │       │
│  │ 适用: 对话、多轮交互                 │       │
│  └─────────────────────────────────────┘       │
│                                                 │
│  LLMs (文本补全模型)                             │
│  ┌─────────────────────────────────────┐       │
│  │ 输入: 字符串(String)                 │       │
│  │ 输出: 字符串(String)                 │       │
│  │ 代表: GPT-3, Text-Davinci            │       │
│  │ 适用: 文本生成、单次补全              │       │
│  └─────────────────────────────────────┘       │
│                                                 │
└─────────────────────────────────────────────────┘
```

### Chat Models详解

**消息类型**:

LangChain定义了几种标准的消息类型：

| 消息类型 | 类名 | 角色 | 用途 |
|---------|------|------|------|
| **System** | `SystemMessage` | system | 设置AI的行为和角色 |
| **Human** | `HumanMessage` | user | 用户的输入 |
| **AI** | `AIMessage` | assistant | AI的回复 |
| **Function** | `FunctionMessage` | function | 工具/函数的返回结果 |
| **Tool** | `ToolMessage` | tool | 工具调用的结果 |

**示例代码**:

```python
from langchain_core.messages import (
    SystemMessage,
    HumanMessage,
    AIMessage
)
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-3.5-turbo")

# 构建消息列表
messages = [
    SystemMessage(content="你是一个专业的Python编程导师"),
    HumanMessage(content="什么是装饰器?"),
    AIMessage(content="装饰器是Python的语法糖..."),
    HumanMessage(content="请举个例子")
]

# 调用模型
response = llm.invoke(messages)
print(response.content)
```

**关键点**:
1. Chat Models以**对话历史**的形式工作
2. 支持**多轮对话**上下文
3. 可以通过**SystemMessage**设定角色
4. 更接近现代LLM的实际使用方式

### LLMs详解

**特点**:
- 输入：单个字符串
- 输出：单个字符串
- 无对话历史概念
- 适合文本补全任务

**示例代码**:

```python
from langchain_openai import OpenAI

llm = OpenAI(model="gpt-3.5-turbo-instruct")

# 直接输入字符串
response = llm.invoke("完成这句话：Python是一门")
print(response)  # 输出: "面向对象的编程语言..."
```

### 如何选择?

```
使用Chat Models:
✅ 构建对话系统
✅ 需要角色设定(System Prompt)
✅ 多轮交互
✅ 使用现代LLM(GPT-4, Claude等)

使用LLMs:
✅ 简单文本补全
✅ 使用传统模型
✅ 不需要对话历史
```

**老王建议**: 艹，现在都2025年了，99%的场景都应该用**Chat Models**！LLMs基本只是为了兼容老模型。

## 🌊 流式输出 (Streaming)

### 为什么需要流式输出?

传统的`invoke()`方法会等待模型生成完整响应才返回，用户体验差：

```
用户提问 → 等待30秒 → 一次性显示完整答案
            ↑
        用户焦虑等待
```

流式输出可以实时显示生成内容，提升体验：

```
用户提问 → 逐字显示答案...
            ↑
         实时反馈
```

### 实现流式输出

**方法1: 使用stream()方法**

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-3.5-turbo")

# 流式调用
for chunk in llm.stream("写一首关于LangChain的诗"):
    print(chunk.content, end="", flush=True)
```

**输出效果**:
```
Lang开始
LangCha逐字
LangChain，显示...
```

**方法2: 使用astream()异步流式**

```python
import asyncio
from langchain_openai import ChatOpenAI

async def stream_example():
    llm = ChatOpenAI(model="gpt-3.5-turbo")

    async for chunk in llm.astream("解释一下Python的GIL"):
        print(chunk.content, end="", flush=True)

asyncio.run(stream_example())
```

**关键参数**:

```python
llm = ChatOpenAI(
    model="gpt-3.5-turbo",
    streaming=True,  # 启用流式(有些模型需要)
    temperature=0.7
)
```

### 流式输出的应用场景

| 场景 | 优势 |
|------|------|
| **聊天机器人** | 即时反馈，更自然 |
| **长文本生成** | 避免用户等待超时 |
| **Web应用** | 配合SSE实现实时显示 |
| **调试** | 实时观察模型输出 |

## 📊 Token追踪

### 为什么要追踪Token?

1. **成本控制**: API按Token计费，需要监控成本
2. **性能优化**: Token数量影响响应速度
3. **上下文管理**: 避免超过模型的上下文窗口限制

### Token计算方式

**OpenAI模型的Token计算**:

```python
import tiktoken

def count_tokens(text: str, model: str = "gpt-3.5-turbo") -> int:
    """计算文本的Token数量"""
    encoding = tiktoken.encoding_for_model(model)
    return len(encoding.encode(text))

# 示例
text = "LangChain是一个强大的框架"
tokens = count_tokens(text)
print(f"Token数量: {tokens}")  # 输出: Token数量: 15
```

**经验公式**:
- 英文: 1个Token ≈ 4个字符 ≈ 0.75个单词
- 中文: 1个Token ≈ 1.5-2个汉字

### 在LangChain中追踪Token

**方法1: 从响应元数据获取**

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-3.5-turbo")
response = llm.invoke("你好")

# 获取Token使用情况
usage = response.response_metadata["token_usage"]
print(f"Prompt Tokens: {usage['prompt_tokens']}")
print(f"Completion Tokens: {usage['completion_tokens']}")
print(f"Total Tokens: {usage['total_tokens']}")
```

**方法2: 使用回调函数(Callbacks)**

```python
from langchain_openai import ChatOpenAI
from langchain.callbacks import get_openai_callback

llm = ChatOpenAI(model="gpt-3.5-turbo")

# 使用回调追踪
with get_openai_callback() as cb:
    llm.invoke("解释一下LangChain")
    llm.invoke("再详细一点")

    print(f"总Token数: {cb.total_tokens}")
    print(f"总成本: ${cb.total_cost:.4f}")
    print(f"成功请求数: {cb.successful_requests}")
```

**方法3: 自定义回调类**

```python
from langchain.callbacks.base import BaseCallbackHandler
from typing import Any, Dict

class TokenCounterCallback(BaseCallbackHandler):
    """自定义Token计数器"""

    def __init__(self):
        self.total_tokens = 0
        self.prompt_tokens = 0
        self.completion_tokens = 0

    def on_llm_end(self, response: Any, **kwargs: Any) -> None:
        """LLM调用结束时触发"""
        if hasattr(response, 'llm_output'):
            token_usage = response.llm_output.get('token_usage', {})
            self.total_tokens += token_usage.get('total_tokens', 0)
            self.prompt_tokens += token_usage.get('prompt_tokens', 0)
            self.completion_tokens += token_usage.get('completion_tokens', 0)

    def report(self):
        """输出统计报告"""
        print(f"=== Token使用统计 ===")
        print(f"Prompt Tokens: {self.prompt_tokens}")
        print(f"Completion Tokens: {self.completion_tokens}")
        print(f"Total Tokens: {self.total_tokens}")

# 使用
counter = TokenCounterCallback()
llm = ChatOpenAI(model="gpt-3.5-turbo", callbacks=[counter])

llm.invoke("问题1")
llm.invoke("问题2")

counter.report()
```

### 成本估算

**OpenAI定价(2025年1月)**:

| 模型 | Input(每1M tokens) | Output(每1M tokens) |
|------|-------------------|---------------------|
| GPT-4 Turbo | $10.00 | $30.00 |
| GPT-3.5 Turbo | $0.50 | $1.50 |

**计算公式**:

```python
def estimate_cost(prompt_tokens: int, completion_tokens: int,
                 model: str = "gpt-3.5-turbo") -> float:
    """估算API调用成本"""
    prices = {
        "gpt-4-turbo": {"input": 10.00, "output": 30.00},
        "gpt-3.5-turbo": {"input": 0.50, "output": 1.50}
    }

    price = prices.get(model, prices["gpt-3.5-turbo"])
    cost = (prompt_tokens * price["input"] +
            completion_tokens * price["output"]) / 1_000_000
    return cost

# 示例
cost = estimate_cost(1000, 500, "gpt-3.5-turbo")
print(f"成本: ${cost:.6f}")  # 输出: 成本: $0.001250
```

## 📦 结构化输出 (Structured Output)

### 为什么需要结构化输出?

LLM默认输出自然语言文本，但很多场景需要**结构化数据**:

```
自然语言输出:
"张三，25岁，工程师，居住在北京"

结构化输出:
{
    "name": "张三",
    "age": 25,
    "occupation": "工程师",
    "city": "北京"
}
```

### 实现方式

#### 方式1: 使用Pydantic模型

```python
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import PydanticOutputParser
from pydantic import BaseModel, Field

# 1. 定义数据模型
class Person(BaseModel):
    """人物信息"""
    name: str = Field(description="姓名")
    age: int = Field(description="年龄")
    occupation: str = Field(description="职业")
    city: str = Field(description="居住城市")

# 2. 创建解析器
parser = PydanticOutputParser(pydantic_object=Person)

# 3. 获取格式说明
format_instructions = parser.get_format_instructions()

# 4. 构建Prompt
prompt = f"""
从以下文本中提取人物信息：
"张三是一位25岁的软件工程师，目前居住在北京"

{format_instructions}
"""

# 5. 调用LLM
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)
response = llm.invoke(prompt)

# 6. 解析输出
person = parser.parse(response.content)
print(type(person))  # <class 'Person'>
print(person.name)   # "张三"
print(person.age)    # 25
```

#### 方式2: 使用JsonOutputParser

```python
from langchain_core.output_parsers import JsonOutputParser

# 定义JSON Schema
parser = JsonOutputParser()

prompt = f"""
提取以下信息并以JSON格式返回:
- 姓名
- 年龄
- 职业
- 城市

文本: "李四是一位30岁的产品经理，工作在上海"

{parser.get_format_instructions()}
"""

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)
response = llm.invoke(prompt)
data = parser.parse(response.content)

print(data)
# 输出: {'name': '李四', 'age': 30, 'occupation': '产品经理', 'city': '上海'}
```

#### 方式3: 使用StructuredOutputParser

```python
from langchain.output_parsers import StructuredOutputParser, ResponseSchema

# 1. 定义响应结构
response_schemas = [
    ResponseSchema(name="name", description="人物姓名"),
    ResponseSchema(name="age", description="年龄，数字类型"),
    ResponseSchema(name="occupation", description="职业"),
    ResponseSchema(name="sentiment", description="文本的情感倾向: positive/negative/neutral")
]

# 2. 创建解析器
parser = StructuredOutputParser.from_response_schemas(response_schemas)

# 3. 获取格式说明
format_instructions = parser.get_format_instructions()

# 4. 构建Prompt
prompt = f"""
分析以下文本:
"王五是一位优秀的35岁设计师，他热爱自己在深圳的工作"

提取人物信息并分析情感。

{format_instructions}
"""

# 5. 调用并解析
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)
response = llm.invoke(prompt)
result = parser.parse(response.content)

print(result)
# 输出: {'name': '王五', 'age': '35', 'occupation': '设计师', 'sentiment': 'positive'}
```

### 结构化输出对比

| 方式 | 优点 | 缺点 | 适用场景 |
|-----|------|------|---------|
| **PydanticOutputParser** | 类型安全、自动验证 | 需要定义类 | 复杂数据结构 |
| **JsonOutputParser** | 简单灵活 | 无类型检查 | 简单JSON输出 |
| **StructuredOutputParser** | 配置简单 | 功能相对基础 | 固定字段提取 |

### 错误处理

```python
from langchain.output_parsers import OutputFixingParser

# 原始解析器
pydantic_parser = PydanticOutputParser(pydantic_object=Person)

# 包装为自动修复解析器
fixing_parser = OutputFixingParser.from_llm(
    parser=pydantic_parser,
    llm=ChatOpenAI(model="gpt-3.5-turbo")
)

# 即使LLM输出格式有小问题，也能自动修复
response = llm.invoke(prompt)
person = fixing_parser.parse(response.content)
```

## 🎯 综合示例

### 示例1: 流式输出 + Token追踪

```python
from langchain_openai import ChatOpenAI
from langchain.callbacks import get_openai_callback
import sys

def stream_with_tracking(question: str):
    """流式输出并追踪Token"""
    llm = ChatOpenAI(
        model="gpt-3.5-turbo",
        temperature=0.7
    )

    with get_openai_callback() as cb:
        print(f"问题: {question}\n")
        print("回答: ", end="", flush=True)

        # 流式输出
        for chunk in llm.stream(question):
            print(chunk.content, end="", flush=True)
            sys.stdout.flush()

        print("\n")

        # 显示统计
        print(f"\n=== 统计信息 ===")
        print(f"Total Tokens: {cb.total_tokens}")
        print(f"Prompt Tokens: {cb.prompt_tokens}")
        print(f"Completion Tokens: {cb.completion_tokens}")
        print(f"Total Cost: ${cb.total_cost:.6f}")

# 使用
stream_with_tracking("什么是LangChain?")
```

### 示例2: 结构化输出 + 批量处理

```python
from typing import List
from pydantic import BaseModel
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import PydanticOutputParser

class Article(BaseModel):
    """文章信息"""
    title: str
    author: str
    summary: str
    tags: List[str]

def extract_articles(texts: List[str]) -> List[Article]:
    """批量提取文章信息"""
    parser = PydanticOutputParser(pydantic_object=Article)
    llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

    articles = []
    for text in texts:
        prompt = f"""
        从以下文本中提取文章信息:
        {text}

        {parser.get_format_instructions()}
        """

        response = llm.invoke(prompt)
        article = parser.parse(response.content)
        articles.append(article)

    return articles

# 使用
texts = [
    "《LangChain实战》由张三撰写，详细介绍了LangChain框架的使用方法。标签：AI, Python, LLM",
    "《深入理解Agent》作者李四，探讨了AI Agent的设计原理。标签：Agent, AI, 架构设计"
]

articles = extract_articles(texts)
for article in articles:
    print(f"标题: {article.title}")
    print(f"作者: {article.author}")
    print(f"标签: {', '.join(article.tags)}\n")
```
